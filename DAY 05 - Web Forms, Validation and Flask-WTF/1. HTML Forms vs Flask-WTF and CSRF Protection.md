# Day 05: Web Forms, Validation & Flask-WTF

## 1. Flask-WTF & CSRF Protection Mechanics
Flask-WTF integrates **WTForms** with Flask, providing automated Cross-Site Request Forgery (CSRF) protection using cryptographic tokens.

```python
from flask_wtf import FlaskForm
from wtforms import StringField, PasswordField, SubmitField
from wtforms.validators import DataRequired, Email, Length

class RegistrationForm(FlaskForm):
    username = StringField('Username', validators=[DataRequired(), Length(min=3, max=25)])
    email = StringField('Email', validators=[DataRequired(), Email()])
    password = PasswordField('Password', validators=[DataRequired(), Length(min=8)])
    submit = SubmitField('Sign Up')
```
