# Day 05: Custom Validators & Secure File Uploads

## 1. Custom Form Validation
Custom validators can be declared as inline methods inside `FlaskForm`:

```python
def validate_username(self, field):
    if field.data.lower() in ['admin', 'root', 'superuser']:
        raise ValidationError('Reserved username forbidden.')
```

## 2. Secure File Uploads
Use `werkzeug.utils.secure_filename` to prevent path traversal vulnerability attacks (`../../../etc/passwd`).
