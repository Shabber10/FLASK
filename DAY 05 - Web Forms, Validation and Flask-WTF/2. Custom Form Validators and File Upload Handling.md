## 1. Custom Form Validation

WTForms allows defining custom validation logic in two ways:

### 1. In-Line Custom Validators (Method Naming Pattern)
Any method defined inside a `FlaskForm` class named `validate_<field_name>(self, field)` is executed automatically during form validation:

```python
from wtforms.validators import ValidationError

class RegistrationForm(FlaskForm):
    username = StringField('Username')
    
    # Executed automatically when validating `username` field
    def validate_username(self, field):
        reserved_names = ['admin', 'root', 'superuser', 'administrator', 'system']
        if field.data.lower() in reserved_names:
            raise ValidationError(f"The username '{field.data}' is reserved by the system.")
```

### 2. Standalone Reusable Custom Validators
Create reusable validator factory functions that accept custom arguments:

```python
def StrongPassword(min_length=8):
    """Custom Reusable Validator enforcing strong password rules."""
    def _validator(form, field):
        password = field.data or ''
        if len(password) < min_length:
            raise ValidationError(f"Password must be at least {min_length} characters long.")
        if not any(char.isupper() for char in password):
            raise ValidationError("Password must contain at least one uppercase letter.")
        if not any(char.isdigit() for char in password):
            raise ValidationError("Password must contain at least one numeric digit.")
        if not any(char in "!@#$%^&*()_+-=" for char in password):
            raise ValidationError("Password must contain at least one special character (!@#$%^&*).")
    return _validator

class ResetPasswordForm(FlaskForm):
    new_password = PasswordField('New Password', validators=[DataRequired(), StrongPassword(min_length=10)])
```

## 2. Secure File Upload Processing

Handling user file uploads requires multi-layer security protections to mitigate Path Traversal and Remote Code Execution (RCE) attacks.

### Security Checklist for File Uploads
1. **File Extension Whitelisting**: Use `Flask-WTF`'s `FileAllowed` validator.
2. **Filename Sanitization**: Pass uploaded filenames through `secure_filename()`.
3. **Payload Size Enforcement**: Set `app.config['MAX_CONTENT_LENGTH']`.
4. **Storage Isolation**: Store uploads outside the web root directory.

### Implementation Example

```python
import os
from flask import Flask, render_template, request, flash
from flask_wtf import FlaskForm
from flask_wtf.file import FileField, FileRequired, FileAllowed
from werkzeug.utils import secure_filename

app = Flask(__name__)
# Enforce Maximum 16 Megabyte File Upload Size
app.config['MAX_CONTENT_LENGTH'] = 16 * 1024 * 1024
app.config['UPLOAD_FOLDER'] = os.path.join(app.root_path, 'uploads')

class AvatarUploadForm(FlaskForm):
    avatar = FileField('Upload Avatar', validators=[
        FileRequired(message="Please select a file to upload."),
        FileAllowed(['jpg', 'png', 'jpeg', 'gif'], message="Images only (jpg, png, gif)!")
    ])

@app.route('/upload', methods=['GET', 'POST'])
def upload():
    form = AvatarUploadForm()
    if form.validate_on_submit():
        file_storage = form.avatar.data
        # 1. Sanitize Filename to strip directory traversal (../etc/passwd)
        filename = secure_filename(file_storage.filename)
        
        # 2. Save file safely
        save_path = os.path.join(app.config['UPLOAD_FOLDER'], filename)
        file_storage.save(save_path)
        
        flash("Avatar uploaded successfully!", "success")
        return redirect(url_for('upload'))
        
    return render_template('upload.html', form=form)
```

## 3. Categorized Flash Messaging

Flash messages provide one-time status notifications to users following redirects:

```python
from flask import flash, get_flashed_messages

# Sending Categorized Flash Messages
flash("Account created successfully!", "success")
flash("Invalid username or password.", "danger")
flash("Your session will expire in 5 minutes.", "warning")
```

In Jinja2 Templates (`get_flashed_messages(with_categories=True)`):

```html
{% with messages = get_flashed_messages(with_categories=true) %}
  {% if messages %}
    {% for category, message in messages %}
      <div class="alert alert-{{ category }}">{{ message }}</div>
    {% endfor %}
  {% endif %}
{% endwith %}
```
