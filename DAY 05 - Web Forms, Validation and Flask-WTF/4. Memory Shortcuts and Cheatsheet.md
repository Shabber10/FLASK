## 🧠 Memory Mnemonics

### 1. The Anti-CSRF Protection Lifecycle
Remember **C-S-R-F** for Flask-WTF security:
- **C**: **Cryptographic Token** (Generated using `SECRET_KEY` & session ID)
- **S**: **Secret Key Setting** (`app.config['SECRET_KEY'] = 'secret'`)
- **R**: **Render Hidden Input** (`{{ form.csrf_token }}` in Jinja2 template)
- **F**: **Form Verification** (`form.validate_on_submit()` checks POST method & token signature)

---

### 2. File Upload Security Checklist
Remember **S-E-C-U-R-E** for handling uploads:
- **S**: **`secure_filename()`** (Strip directory traversal chars `../`)
- **E**: **Extension Whitelist** (`FileAllowed(['jpg', 'png'])`)
- **C**: **Content-Length Max** (`app.config['MAX_CONTENT_LENGTH'] = 16MB`)
- **U**: **Upload Directory** (Store outside application root web directory)
- **R**: **Require File** (`FileRequired()`)
- **E**: **Explicit Encoding** (`enctype="multipart/form-data"`)

## ⚡ Quick-Reference Code Snippets

### 1. WTForms Form Definition
```python
from flask_wtf import FlaskForm
from wtforms import StringField, PasswordField, SubmitField
from wtforms.validators import DataRequired, Email, Length, ValidationError

class UserForm(FlaskForm):
    username = StringField('Username', validators=[DataRequired(), Length(min=3)])
    email = StringField('Email', validators=[DataRequired(), Email()])
    submit = SubmitField('Submit')

    # In-line Custom Validator
    def validate_username(self, field):
        if field.data == 'admin':
            raise ValidationError('Username "admin" is reserved.')
```

### 2. Secure File Upload Handler
```python
from werkzeug.utils import secure_filename

if form.validate_on_submit():
    f = form.avatar.data
    filename = secure_filename(f.filename)
    f.save(os.path.join(app.config['UPLOAD_FOLDER'], filename))
```
