### Q1: What is Cross-Site Request Forgery (CSRF) and how does Flask-WTF defend against it?
**Answer**:
CSRF is an attack where a malicious website causes a victim's web browser to execute unwanted actions on a trusted site where the user is logged in. Browsers automatically attach cookies (including session cookies) to cross-site requests.

Flask-WTF defends against CSRF by injecting a unique, cryptographically signed token into HTML forms via `{{ form.csrf_token }}`. When submitted, Flask-WTF verifies that the submitted form token matches the token stored in the user's active session. Since third-party sites cannot read or predict this secret token under the Same-Origin Policy, forged requests are rejected.

### Q2: What does `form.validate_on_submit()` check under the hood?
**Answer**:
`form.validate_on_submit()` performs two checks:
1. Verifies that `request.method` is an HTTP verb that submits data (`POST`, `PUT`, `PATCH`, or `DELETE`).
2. Calls `form.validate()`, which triggers all field validators and validates the CSRF token.

It returns `True` only if both conditions are met.

### Q3: How do you implement an inline custom validator method inside a `FlaskForm` class?
**Answer**:
Define a method following the naming convention `validate_<field_name>(self, field)`. WTForms automatically detects and invokes this method when validating the corresponding field:

```python
class ProfileForm(FlaskForm):
    username = StringField('Username')

    def validate_username(self, field):
        if User.query.filter_by(username=field.data).first():
            raise ValidationError("That username is already taken. Please choose another.")
```

### Q4: Why is `secure_filename()` necessary when saving user-uploaded files?
**Answer**:
User-provided filenames can contain path traversal characters (such as `../../../etc/passwd` or `C:\Windows\System32\malicious.exe`). Saving files with unsanitized filenames allows attackers to overwrite critical system files or upload executable scripts into web directories. `secure_filename()` strips all path separators, leading slashes, and non-ASCII characters, leaving only a safe relative filename.

### Q5: How do you restrict the maximum file upload size in a Flask application?
**Answer**:
Set the `MAX_CONTENT_LENGTH` configuration key on the Flask application instance:

```python
# Limit uploads to 16 Megabytes (16 * 1024 * 1024 bytes)
app.config['MAX_CONTENT_LENGTH'] = 16 * 1024 * 1024
```

If a client attempts to upload a file exceeding this limit, Werkzeug aborts the request automatically and returns a `413 Payload Too Large` HTTP response.

### Q6: What HTML attribute is required on `<form>` elements to support file uploads?
**Answer**:
The `enctype` attribute must be set to `multipart/form-data`:

```html
<form method="POST" enctype="multipart/form-data">
    {{ form.csrf_token }}
    {{ form.file() }}
</form>
```

Without `enctype="multipart/form-data"`, the browser sends only the filename string as plain text rather than transmitting binary file stream bytes.

### Q7: How do you pass custom parameters into a standalone WTForms validator function?
**Answer**:
Use a validator factory function that returns a closure accepting `(form, field)` arguments:

```python
def MaxWords(max_count):
    def _validator(form, field):
        words = (field.data or '').split()
        if len(words) > max_count:
            raise ValidationError(f"Field cannot contain more than {max_count} words.")
    return _validator

class ArticleForm(FlaskForm):
    body = TextAreaField('Article Body', validators=[MaxWords(500)])
```

### Q8: How do categorized flash messages work in Flask, and how are they rendered in templates?
**Answer**:
`flash(message, category)` stores temporary feedback strings in the user's session cookie under a specific category name (e.g. `'success'`, `'danger'`, `'warning'`). 

In Jinja2 templates, calling `get_flashed_messages(with_categories=True)` retrieves and clears all pending messages:

```jinja2
{% with messages = get_flashed_messages(with_categories=true) %}
  {% for category, msg in messages %}
    <div class="alert alert-{{ category }}">{{ msg }}</div>
  {% endfor %}
{% endwith %}
```

### Q9: How can you enable CSRF protection for non-HTML form requests, such as AJAX or Fetch API calls?
**Answer**:
Initialize `CSRFProtect(app)` globally:

```python
from flask_wtf.csrf import CSRFProtect

csrf = CSRFProtect(app)
```

In client JavaScript, send the CSRF token in an HTTP header (e.g. `X-CSRFToken`):

```javascript
fetch('/api/data', {
    method: 'POST',
    headers: {
        'X-CSRFToken': csrf_token_value,
        'Content-Type': 'application/json'
    },
    body: JSON.stringify(payload)
});
```

### Q10: How do `FileRequired()` and `FileAllowed()` validators work in Flask-WTF?
**Answer**:
- `FileRequired()`: Validates that the uploaded field contains a non-empty `FileStorage` object.
- `FileAllowed(allowed_extensions, message)`: Inspects the filename extension of the uploaded `FileStorage` object and raises a `ValidationError` if the extension is not in the whitelist (e.g. `['jpg', 'png']`).
