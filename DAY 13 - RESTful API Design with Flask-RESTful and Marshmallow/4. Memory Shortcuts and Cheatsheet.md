## 🧠 Memory Mnemonics

### 1. HTTP Verbs & Idempotency Rules
Remember **G-P-P-P-D** for REST operations:
- **G**: **`GET`** (Safe, Idempotent: Fetch resource)
- **P**: **`POST`** (Unsafe, Non-Idempotent: Create resource -> `201 Created`)
- **P**: **`PUT`** (Unsafe, Idempotent: Complete replacement)
- **P**: **`PATCH`** (Unsafe, Non-Idempotent: Partial modification)
- **D**: **`DELETE`** (Unsafe, Idempotent: Remove resource -> `204 No Content`)

---

### 2. Marshmallow Data Direction
- **`schema.dump(obj)`**: Python Object -> JSON Dict (Serialization)
- **`schema.load(json_dict)`**: JSON Dict -> Validated Python Dict (Deserialization)

```python
class UserResource(Resource):
    def get(self, user_id):
```

### 2. Marshmallow Schema Declaration
```python
from marshmallow import Schema, fields, validate

class UserSchema(Schema):
    id = fields.Int(dump_only=True)
    username = fields.Str(required=True, validate=validate.Length(min=3))
    email = fields.Email(required=True)
    created_at = fields.DateTime(dump_only=True)
```

### 3. Payload Validation with `schema.load()`
```python
try:
    data = user_schema.load(request.json)
except ValidationError as err:
    return {"errors": err.messages}, 422
```
