# Day 13: Flask-RESTful & Marshmallow Serialization

In this section, we examine building class-based REST resources with `Flask-RESTful` and data serialization/validation with `Marshmallow`.

---

## 1. Flask-RESTful Resource Routing

**Flask-RESTful** replaces function-based routes with class-based `Resource` objects mapping HTTP verbs to class methods:

```python
from flask import Flask, request
from flask_restful import Api, Resource

app = Flask(__name__)
api = Api(app)

class ArticleResource(Resource):
    def get(self, article_id):
        # Triggered on GET /api/articles/<article_id>
        return {"id": article_id, "title": "Flask REST Architecture"}, 200

    def put(self, article_id):
        # Triggered on PUT /api/articles/<article_id>
        return {"message": f"Article {article_id} updated"}, 200

    def delete(self, article_id):
        # Triggered on DELETE /api/articles/<article_id>
        return '', 204

# Register Resource Endpoints
api.add_resource(ArticleResource, '/api/articles/<int:article_id>')
```

## 2. Marshmallow Serialization & Deserialization

**Marshmallow** is an ecosystem-standard library for converting complex data types (such as ORM model instances) to and from native Python data types (lists, dicts, primitives) suitable for JSON encoding.

```
+--------------------------+                      +--------------------------+
|  SQLAlchemy Model        | --- Schema.dump() -> |   JSON Response Payload  |
|  `article = Article()`   |                      |  `{"title": "Flask..."}` |
+--------------------------+                      +--------------------------+
                                                               |
+--------------------------+                      | Schema.load()
|  Validated Python Dict   | <--------------------+
|  `data = {...}`          | (Deserializes & Validates Input)
+--------------------------+
```

### Defining Marshmallow Schemas

```python
from marshmallow import Schema, fields, validate, ValidationError

class AuthorSchema(Schema):
    id = fields.Int(dump_only=True)
    name = fields.Str(required=True, validate=validate.Length(min=2, max=100))
    email = fields.Email(required=True)

class ArticleSchema(Schema):
    id = fields.Int(dump_only=True)
    title = fields.Str(required=True, validate=validate.Length(min=5, max=200))
    content = fields.Str(required=True)
    status = fields.Str(validate=validate.OneOf(['draft', 'published', 'archived']))
    created_at = fields.DateTime(dump_only=True)
    
    # Nested Serialization
    author = fields.Nested(AuthorSchema, dump_only=True)
    author_id = fields.Int(load_only=True, required=True)
```

## 3. `schema.dump()` vs. `schema.load()`

### 1. Serialization (`schema.dump()`)
Converts Python objects / ORM instances into JSON-serializable dictionaries:

```python
article = Article.query.get(1)
schema = ArticleSchema()

# Dump single object
result = schema.dump(article)

# Dump collection of objects (many=True)
articles = Article.query.all()
results = schema.dump(articles, many=True)
```

### 2. Deserialization & Validation (`schema.load()`)
Validates incoming client JSON payloads against schema rules, raising a `ValidationError` if rules are violated:

```python
schema = ArticleSchema()

try:
    # Validates input JSON dict and converts to clean Python dict
    data = schema.load(request.json)
    new_article = Article(**data)
except ValidationError as err:
    # Returns 422 Unprocessable Entity with error dict
    return {"errors": err.messages}, 422
```
