## 1. Designing a Custom Exception Hierarchy

Creating custom domain exceptions provides clean error handling across business logic layers:

```python
class BaseAPIException(Exception):
    """Base exception class for all custom application errors."""
    def __init__(self, message, status_code=400, payload=None):
        super().__init__()
        self.message = message
        self.status_code = status_code
        self.payload = payload or {}

class ResourceNotFoundException(BaseAPIException):
    def __init__(self, resource_name, resource_id):
        super().__init__(
            message=f"{resource_name} with ID #{resource_id} was not found.",
            status_code=404
        )

class ValidationException(BaseAPIException):
    def __init__(self, validation_errors):
        super().__init__(
            message="Request validation failed.",
            status_code=422,
            payload={"validation_details": validation_errors}
        )
```

## 2. Centralized Error Handlers (`@app.errorhandler`)

Register global exception interceptors on your Flask app object:

```python
from flask import jsonify, app

# 1. Catch Custom Domain Exceptions
@app.errorhandler(BaseAPIException)
def handle_custom_api_exception(error):
    app.logger.warning(f"Domain Exception [{error.status_code}]: {error.message}")
    response_body = {
        "error": {
            "code": error.status_code,
            "message": error.message,
            "details": error.payload
        }
    }
    return jsonify(response_body), error.status_code

# 2. Catch Standard HTTP 404 Not Found
@app.errorhandler(404)
def handle_404_error(error):
    return jsonify({
        "error": {"code": 404, "type": "NOT_FOUND", "message": "The requested API endpoint or URL path does not exist."}
    }), 404

# 3. Catch Unhandled 500 Server Crashes (Safety Net!)
@app.errorhandler(Exception)
def handle_unhandled_exception(error):
    # Log full traceback to file for developer investigation
    app.logger.error(f"Unhandled Exception: {str(error)}", exc_info=True)
    
    # Return clean generic JSON to client (DO NOT expose raw traceback!)
    return jsonify({
        "error": {
            "code": 500,
            "type": "INTERNAL_SERVER_ERROR",
            "message": "An unexpected internal server error occurred. Our engineering team has been notified."
        }
    }), 500
```

## 3. Production Stack Trace Security Rule 🛡️

> ⚠️ **SECURITY RULE**: Never set `debug=True` in production!
>
> Exposing raw Python stack traces (file paths, database passwords, library versions) in production API responses provides hackers with a roadmap to compromise your server.
>
> **Best Practice**: Log the full traceback to file/Sentry using `app.logger.error(..., exc_info=True)` and return a generic 500 JSON error payload to the user!

## 4. APM Error Tracking Integration (Sentry)

Integrate real-time error tracking using **Sentry**:

```bash
pip install sentry-sdk[flask]
```

Initialize Sentry in your app factory:

```python
import sentry_sdk
from sentry_sdk.integrations.flask import FlaskIntegration

sentry_sdk.init(
    dsn="https://examplePublicKey@o0.ingest.sentry.io/0",
    integrations=[FlaskIntegration()],
    traces_sample_rate=1.0,
    environment="production"
)
```
