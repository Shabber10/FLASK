# Day 27: Structured JSON Logging

## 1. Python Logging Configuration
Configure structured JSON logs for ingest into Datadog, ELK, or CloudWatch:

```python
import logging
from logging.config import dictConfig

dictConfig({
    'version': 1,
    'formatters': {
        'json': {'format': '%(asctime)s %(levelname)s %(name)s %(message)s'}
    },
    'handlers': {
        'console': {'class': 'logging.StreamHandler', 'formatter': 'json'}
    },
    'root': {'level': 'INFO', 'handlers': ['console']}
})
```
