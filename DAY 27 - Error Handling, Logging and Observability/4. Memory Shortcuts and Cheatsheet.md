## 🔤 Error Handling & Observability Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Error Handling** | Intercepting application crashes to return clean JSON error payloads. | `@app.errorhandler(500)` |
| **Logging** | Flight data recorder saving timestamped event records to stdout or files. | `app.logger.info("Order created")` |
| **Observability** | Ability to query system state and trace requests across microservices. | Datadog / CloudWatch dashboard |
| **Correlation ID** | Unique UUID tracking a single HTTP request across all log entries. | `X-Request-ID: req-uuid-1234` |
| **Structured JSON** | Machine-readable log format encoding log fields as JSON objects. | `{"time": "...", "level": "INFO"}` |
| **`dictConfig`** | Standard Python logging dictionary configuration helper. | `logging.config.dictConfig({...})` |
| **`exc_info=True`** | Parameter capturing full exception stack tracebacks into log files. | `app.logger.error("Crash", exc_info=True)` |
| **Sentry** | Real-time APM error tracking service capturing production crashes. | `sentry_sdk.init(...)` |

## 🧠 Memory Mnemonics

### 1. Structured Logging Setup (`L-O-G-S`)
Remember **L-O-G-S** for production logging:
- **L** -> **Level Selection** (`DEBUG`, `INFO`, `WARN`, `ERROR`, `CRITICAL`)
- **O** -> **Organize in JSON Format** (Structured key-value output)
- **G** -> **Generate Request Correlation ID** (`X-Request-ID`)
- **S** -> **Stream to Console & Rotating Files** (`RotatingFileHandler`)

---

### 2. Error Handling Lifecycle (`T-R-A-C-E`)
Remember **T-R-A-C-E** for handling exceptions:
- **T** -> **Type Custom Exceptions** (`BaseAPIException`)
- **R** -> **Raise Domain Errors** (`raise ResourceNotFoundException()`)
- **A** -> **App Error Interceptor** (`@app.errorhandler()`)
- **C** -> **Clean JSON Payload** (Return status code + error message)
- **E** -> **Enforce No Stack Trace Leak** (Hide tracebacks from users in production)

## ⚡ Quick-Reference Code Snippets

### 1. Correlation ID Middleware (`X-Request-ID`)
```python
import uuid
from flask import request, g

@app.before_request
def add_correlation_id():
    g.correlation_id = request.headers.get('X-Request-ID') or str(uuid.uuid4())

@app.after_request
def send_correlation_id(response):
    response.headers['X-Request-ID'] = getattr(g, 'correlation_id', '')
    return response
```

### 2. Custom Exception & Centralized Error Handler
```python
class ResourceNotFound(Exception):
    def __init__(self, message):
        self.message = message
        self.status_code = 404

@app.errorhandler(ResourceNotFound)
def handle_404(err):
    return jsonify({"error": err.message}), err.status_code

@app.errorhandler(Exception)
def handle_500(err):
    app.logger.error("Unhandled Crash", exc_info=True)
    return jsonify({"error": "Internal Server Error"}), 500
```
