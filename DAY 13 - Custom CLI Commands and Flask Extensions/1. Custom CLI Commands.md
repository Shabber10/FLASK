# Day 13: Custom CLI Commands & Flask Extensions

## 1. Creating Custom Flask CLI Commands
Flask integrates **Click** for creating custom command line interfaces:

```python
import click
from flask.cli import with_appcontext

@app.cli.command("seed-db")
@click.option("--count", default=10, help="Number of records to seed")
@with_appcontext
def seed_db(count):
    click.echo(f"Seeding {count} records into database...")
```
