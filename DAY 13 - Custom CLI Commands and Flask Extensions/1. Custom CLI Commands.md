## 1. Registering Custom CLI Commands (`@app.cli.command`)

To register a terminal command on your Flask application, decorate a function with **`@app.cli.command()`**:

```python
import click
from flask import Flask

app = Flask(__name__)

# Register command: accessible via $ flask hello
@app.cli.command("hello")
def hello_command():
    """Prints a friendly greeting in the terminal."""
    click.echo("👋 Hello from your custom Flask CLI command!")
```

#### ⚖️ Public HTTP Endpoints vs Terminal CLI Commands

| Operational Feature | Public Web Endpoint (`@app.route('/reset')`) | Terminal CLI Command (`@app.cli.command('reset')`) |
| :--- | :--- | :--- |
| **Security Risk** | ❌ Vulnerable to web attacks or accidental triggers | ✅ Accessible **ONLY** by server administrators via SSH |
| **Execution Medium** | HTTP GET/POST request via web browser | Direct terminal shell execution (`$ flask reset`) |
| **User Interaction** | Form inputs & button clicks | Command options (`--count 10`) & prompts (`click.confirm`) |
| **Best Use Case** | End-user features (Login, Search, Checkout) | Admin ops (Seeding DB, migrations, cron maintenance) |

## 2. Arguments vs. Options in Click

Commands can accept user input via **Arguments** (positional values) or **Options** (flag switches):

```python
import click
from flask import Flask

app = Flask(__name__)

@app.cli.command("seed-users")
# 1. Positional Argument (Required)
@click.argument("role")
# 2. Flag Option with Default Value (Optional)
@click.option("--count", default=5, help="Number of users to create")
def seed_users(role, count):
    """Seed sample users into database. Example: $ flask seed-users admin --count 10"""
    click.echo(f"🌱 Creating {count} sample users with role '{role}'...")
```

## 3. Requiring Application Context (`@with_appcontext`)

If your CLI command needs to query database models (`db.session`) or access application settings (`current_app.config`), decorate your command with **`@with_appcontext`**:

```python
import click
from flask.cli import with_appcontext
from extensions import db
from models import User

@app.cli.command("reset-db")
@with_appcontext  # Ensures active app context & database connection!
def reset_db():
    """Drops and recreates all database tables."""
    if click.confirm("⚠️ Are you sure you want to drop all database tables?", abort=True):
        db.drop_all()
        db.create_all()
        click.echo(click.style("✅ Database reset successfully!", fg="green", bold=True))
```

## 4. Terminal Prompts & Styling (`click.style`)

Enhance CLI user experience using built-in Click utilities:

*   **`click.echo()`**: Cross-platform terminal print.
*   **`click.style(msg, fg='green', bold=True)`**: Applies ANSI colors (`green`, `red`, `yellow`, `blue`).
*   **`click.prompt(msg)`**: Pauses execution and prompts user for text input.
*   **`click.confirm(msg, default=False)`**: Prompts user for a Yes/No (`y/n`) confirmation.

## 5. Grouping CLI Commands (`AppGroup`)

Group related CLI commands together into logical namespaces (e.g. `flask user create`, `flask user list`):

```python
from flask.cli import AppGroup

# Define CLI Command Group
user_cli = AppGroup('user', help='User management operations.')

@user_cli.command('create')
@click.argument('username')
def create_user(username):
    click.echo(f"User '{username}' created!")

# Register group on app ($ flask user create alice)
app.cli.add_command(user_cli)
```
