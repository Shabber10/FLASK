## 🔤 Custom CLI Commands & Extensions Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **CLI** | Command Line Interface controlled by typing terminal text. | `flask run`, `flask db upgrade` |
| **Click** | Python library integrated into Flask for creating terminal commands. | `@click.option()`, `click.echo()` |
| **`@app.cli.command`** | Decorator registering a function as a terminal CLI command. | `@app.cli.command("seed")` |
| **`@with_appcontext`** | Decorator pushing active Flask application context for CLI tasks. | Required for `db.session` inside CLI |
| **`@click.option`** | Flag option with optional defaults. | `@click.option("--count", default=10)` |
| **`@click.argument`** | Required positional command line argument. | `@click.argument("name")` |
| **Extension** | Reusable Python class enhancing Flask features. | `Flask-SQLAlchemy`, `Flask-Migrate` |
| **`init_app()`** | Standard extension method binding instance to Flask app. | `ext.init_app(app)` |
| **`app.extensions`** | Dictionary storing active extension instance references on app. | `app.extensions['my_ext'] = self` |

## 🧠 Memory Mnemonics

### 1. CLI Command Creation (`C-O-M-M-A-N-D`)
Remember **C-O-M-M-A-N-D** for building custom terminal tools:
- **C** -> **Command Decorator** (`@app.cli.command("cmd-name")`)
- **O** -> **Option/Argument Flags** (`@click.option()`, `@click.argument()`)
- **M** -> **Mode `@with_appcontext`** (Pushes active app context for DB access)
- **M** -> **Message Styling** (`click.style("msg", fg="green")`)
- **A** -> **Action Execution** (Run database queries or admin scripts)
- **N** -> **Notify Terminal** (`click.echo("Complete!")`)
- **D** -> **Done** (Return clean exit status)

---

### 2. Custom Extension Authoring (`E-X-T-E-N-D`)
Remember **E-X-T-E-N-D** for writing reusable Flask extensions:
- **E** -> **Extension Class** (`class MyExtension:`)
- **X** -> **eXecute `__init__(self, app=None)`** (Constructor supporting optional app)
- **T** -> **Target `init_app(self, app)`** (Core initialization method)
- **E** -> **Establish Config Defaults** (`app.config.setdefault('KEY', default_val)`)
- **N** -> **Name in `app.extensions`** (`app.extensions['my_ext'] = self`)
- **D** -> **Decorate Hooks & Commands** (`app.before_request()`, `@app.cli.command()`)

## ⚡ Quick-Reference Code Snippets

### 1. Custom CLI Command with Arguments, Options & Prompts
```python
import click
from flask.cli import with_appcontext

@app.cli.command("seed-users")
@click.argument("role")
@click.option("--count", default=5, help="Number of records")
@with_appcontext
def seed_users(role, count):
    """Seed sample users into database."""
    if click.confirm(f"Create {count} users with role '{role}'?"):
        # Run DB operation here
        click.echo(click.style("✅ Seeding complete!", fg="green", bold=True))
```

### 2. Custom Flask Extension Skeleton Class
```python
class CustomExtension:
    def __init__(self, app=None):
        if app is not None:
            self.init_app(app)

    def init_app(self, app):
        app.config.setdefault('CUSTOM_SETTING', True)
        if not hasattr(app, 'extensions'):
            app.extensions = {}
        app.extensions['custom_extension'] = self
        
        # Attach request hook
        app.before_request(self._before_hook)

    def _before_hook(self):
        pass
```
