# Day 13: Writing Custom Flask Extensions

## 1. Extension Pattern Architecture
A custom Flask extension is a Python class adhering to the `init_app` pattern:

```python
class MyExtension:
    def __init__(self, app=None):
        if app is not None:
            self.init_app(app)

    def init_app(self, app):
        app.config.setdefault('MY_EXT_SETTING', True)
        app.extensions['my_extension'] = self
```
