# Day 13 - Module 2: Authoring Reusable Custom Flask Extensions

Welcome to **Module 2** of Day 13! Now that we know how to write custom CLI commands, let's explore **how to write reusable Custom Flask Extensions** from scratch!

---

## 1. Extension Architecture Standards & Conventions

Official Flask extensions adhere to strict architectural conventions:

1.  **Class-Based Design**: Enclosed in a single main Python class named `Flask<Feature>` or `<Feature>Ext`.
2.  **Dual Initialization**: Supports passing `app` directly during `__init__(app=None)` OR deferring attachment via `init_app(app)` for Application Factories.
3.  **Config Defaults**: Sets default settings using `app.config.setdefault('MY_SETTING', default_val)`.
4.  **State Storage**: Saves extension instance reference inside **`app.extensions['extension_name']`**.

---

## 2. Authoring a Custom Extension Class Skeleton

Here is a complete production blueprint for writing a custom Flask extension (e.g. `RequestAnalyticsExt`):

```python
from flask import Flask, current_app, request
import time

class RequestAnalyticsExt:
    """Custom Flask Extension tracking application request counts and latency."""

    def __init__(self, app=None):
        """Dual Initialization Pattern constructor."""
        if app is not None:
            self.init_app(app)

    def init_app(self, app):
        """Binds extension instance to Flask application."""
        # 1. Set default configuration settings
        app.config.setdefault('ANALYTICS_ENABLED', True)
        app.config.setdefault('ANALYTICS_HEADER_NAME', 'X-Response-Time-MS')

        # 2. Store extension instance reference on app.extensions
        if not hasattr(app, 'extensions'):
            app.extensions = {}
        app.extensions['request_analytics'] = self

        # 3. Register request lifecycle hooks
        app.before_request(self._before_request_hook)
        app.after_request(self._after_request_hook)

    def _before_request_hook(self):
        """Internal hook executing before each HTTP request."""
        g_start_time = time.time()
        request._start_time = g_start_time

    def _after_request_hook(self, response):
        """Internal hook executing after each HTTP request."""
        if current_app.config.get('ANALYTICS_ENABLED'):
            duration = round((time.time() - getattr(request, '_start_time', time.time())) * 1000, 2)
            header_name = current_app.config.get('ANALYTICS_HEADER_NAME')
            response.headers[header_name] = f"{duration}ms"
        return response
```

## 3. Bundling CLI Commands Inside Custom Extensions

Custom extensions can automatically register dedicated CLI commands onto the host Flask app inside `init_app()`:

```python
class DatabaseSeederExt:
    def __init__(self, app=None):
        if app is not None:
            self.init_app(app)

    def init_app(self, app):
        app.extensions['db_seeder'] = self
        
        # Bundling custom CLI command inside extension!
        @app.cli.command("ext-seed")
        def ext_seed_cmd():
            """CLI command bundled inside custom extension."""
            print("🌱 Custom Extension: Database seeded!")
```

## 4. Retrieving Extension Instances (`app.extensions`)

To access an extension instance inside view functions or custom helpers, query `current_app.extensions`:

```python
from flask import current_app

def get_analytics_ext():
    """Helper retrieving active extension instance."""
    return current_app.extensions.get('request_analytics')
```
