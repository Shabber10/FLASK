## 1. Understanding CI vs. CD

Modern DevOps engineering automates software quality assurance and release lifecycles using **CI/CD Pipelines**:

```
[ Developer Git Push ]
        |
        v
+-------------------------------------------------------------------+
| Continuous Integration (CI)                                       |
|  1. Code Linting & Formatting (Ruff, Flake8, Black)               |
|  2. Static Security Scanning (Bandit, Pip-Audit)                  |
|  3. Automated Unit & Integration Tests (Pytest)                    |
|  4. Code Coverage Verification (Pytest-Cov)                       |
+-------------------------------------------------------------------+
        |
        v (All Tests & Scans PASSED!)
+-------------------------------------------------------------------+
| Continuous Deployment (CD)                                        |
|  1. Build Multi-Stage Docker Image                                |
|  2. Push Docker Image to Container Registry (GHCR / Docker Hub)    |
|  3. Zero-Downtime Deployment to Staging / Production Servers      |
+-------------------------------------------------------------------+
```

## 2. GitHub Actions Architecture & Workflow Syntax

GitHub Actions executes automated workflows defined as YAML files inside the `.github/workflows/` directory:

- **Workflow**: Automated process defined in YAML (e.g. `ci.yml`).
- **Events (`on:`)**: Triggers that initiate the workflow (e.g., `push`, `pull_request`).
- **Jobs**: Sets of steps executed on a specified runner runner environment (`ubuntu-latest`).
- **Steps**: Individual execution commands or actions (`actions/checkout@v4`).

## 3. Build Matrix Strategy

A **Build Matrix** allows running parallel test jobs across multiple Python versions or operating systems automatically:

```yaml
jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ['3.10', '3.11', '3.12']
    steps:
      - uses: actions/checkout@v4
      - name: Set up Python ${{ matrix.python-version }}
        uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}
      - name: Run Pytest
        run: |
          pip install -r requirements.txt
          pytest
```
