## 2. Static Security Analysis Tools

### 1. Bandit (Python Code SAST Scanner)
`Bandit` parses the Python Abstract Syntax Tree (AST) to identify security risks (hardcoded passwords, `eval()` usage, insecure random generators, unsafe subprocessing):

```bash
# Scan all Python files in app/ directory recursively
bandit -r app/ -ll -ii
```

### 2. Pip-Audit (Dependency Vulnerability Scanner)
`pip-audit` checks installed third-party PyPI packages against Known Vulnerability Databases (CVEs):

```bash
# Scan requirements.txt for known security vulnerabilities
pip-audit -r requirements.txt
```

## 3. Zero-Downtime Deployment Strategies

When deploying updated code to production, users should experience zero request failures or downtime.

### 1. Blue-Green Deployment
Maintains two identical production environments (**Blue** = Active Live, **Green** = Idle Staging). The new release is deployed to Green, tested, and Nginx instantly switches live traffic from Blue to Green.

### 2. Canary Deployment
Rolls out the new application version to a small percentage (e.g. 5%) of production traffic first. If error rates remain low, traffic is incrementally shifted to 100%.
