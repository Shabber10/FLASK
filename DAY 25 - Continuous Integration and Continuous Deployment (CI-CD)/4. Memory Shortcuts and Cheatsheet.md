## 🧠 Memory Mnemonics

### 1. The Four Quality Gates of CI
Remember **L-S-T-D** for automated CI pipelines:
- **L**: **Linting** (`flake8` / `ruff` for PEP 8 compliance)
- **S**: **Security Scanning** (`bandit` SAST & `pip-audit` CVE checks)
- **T**: **Testing** (`pytest` unit & integration execution)
- **D**: **Docker Build & Deploy** (`docker build` & registry push)

---

### 2. GitHub Actions Structure
- **Workflow** -> `.github/workflows/*.yml`
- **Trigger** -> `on: [push, pull_request]`
- **Runner** -> `runs-on: ubuntu-latest`
- **Matrix** -> `strategy: matrix: python-version: ['3.10', '3.11', '3.12']`

## ⚡ Quick-Reference Code Snippets

### 1. Minimal GitHub Actions CI Workflow (`.github/workflows/ci.yml`)
```yaml
name: Flask CI

on: [push, pull_request]

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Install Dependencies
        run: |
          pip install -r requirements.txt
          pip install flake8 bandit pytest pytest-cov
      - name: Run Quality Checks
        run: |
          flake8 .
          bandit -r . -ll
          pytest --cov=app
```

### 2. Security Scan Commands
```bash
# Bandit Static Security Scan
bandit -r app/ -ll -ii

# Dependency Vulnerability Audit
pip-audit -r requirements.txt
```
