## 1. What are Periodic Tasks & Scheduled Jobs?

In real-world web applications, many tasks must run automatically without waiting for a user to click a button on a web page:

*   **Database Maintenance**: Deleting expired user session tokens every 10 minutes.
*   **Billing & Subscriptions**: Processing monthly credit card renewals at midnight on the 1st of every month.
*   **Daily Analytics**: Aggregating yesterday's web traffic statistics at 2:00 AM.

A **Periodic Task (or Scheduled Job)** is an automated background function configured to run repeatedly based on a time schedule.

---

## 2. What is Celery Beat?

Think of **Celery Beat** as a digital alarm clock for your web application:

```
┌────────────────────────┐         ┌────────────────────────┐         ┌────────────────────────┐
│   Celery Beat Clock    │         │    Message Broker      │         │     Celery Worker      │
│  (Scheduler Process)   │ ──────> │    (Redis Queue)       │ ──────> │  (Background Process)  │
│  Fires alarm at 00:00  │         │  Holds task message    │         │  Executes DB Cleanup   │
└────────────────────────┘         └────────────────────────┘         └────────────────────────┘
```

1.  **Celery Beat Scheduler**: Runs in the background terminal, keeping track of time. When the clock hits a scheduled time (e.g. Midnight), Beat sends a task message to the Redis queue.
2.  **Celery Worker**: Picks up the task message from Redis and executes the code!

> ⚠️ **Critical Rule**: Celery Beat does NOT execute tasks itself! Beat only sends the "wake up" message to Redis; Celery Workers execute the actual code!

## 3. What is Cron Syntax & `crontab()`?

**Cron** is the universal Linux format for specifying scheduled times:

```
┌───────────── minute (0 - 59)
│ ┌─────────── hour (0 - 23)
│ │ ┌───────── day of month (1 - 31)
│ │ │ ┌─────── month (1 - 12)
│ │ │ │ ┌───── day of week (0 - 6) (Sunday=0)
│ │ │ │ │
* * * * *
```

In Celery, we write clean Python code using the **`crontab()`** helper function:

```python
from celery.schedules import crontab

# Every midnight (00:00)
schedule = crontab(hour=0, minute=0)

# Every Monday morning at 9:30 AM
schedule = crontab(day_of_week='mon', hour=9, minute=30)
```

## 4. In-Process Alternative: `APScheduler`

For smaller Flask applications that don't deploy Redis or Celery, Python provides **`APScheduler` (Advanced Python Scheduler)**, which runs periodic schedules inside your Flask app process without requiring external workers!
