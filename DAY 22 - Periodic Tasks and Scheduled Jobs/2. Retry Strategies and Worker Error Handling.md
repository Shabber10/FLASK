# Day 22: Celery Task Retries & Dead Letter Queues

## 1. Automatic Task Retries
Use `autoretry_for` to handle transient network errors:

```python
@celery.task(bind=True, max_retries=3, default_retry_delay=60)
def fetch_external_api(self):
    try:
        # API call
        pass
    except Exception as exc:
        raise self.retry(exc=exc)
```
