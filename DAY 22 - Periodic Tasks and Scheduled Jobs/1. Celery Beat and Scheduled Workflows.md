# Day 22: Periodic Tasks & Scheduled Jobs

## 1. Celery Beat Scheduler
**Celery Beat** is a periodic task scheduler that triggers tasks at specified time intervals or cron-like schedules.

```python
from celery.schedules import crontab

celery.conf.beat_schedule = {
    'nightly-db-cleanup': {
        'task': 'tasks.clean_expired_sessions',
        'schedule': crontab(hour=0, minute=0), # Midnight
    },
}
```
