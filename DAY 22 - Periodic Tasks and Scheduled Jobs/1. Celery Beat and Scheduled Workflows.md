## 1. Defining `beat_schedule` Configurations

Configure periodic task schedules on your `Celery` instance using the `beat_schedule` dictionary:

```python
from datetime import timedelta
from celery.schedules import crontab
from app_factory import celery_app

# 1. Define Background Tasks
@celery_app.task
def cleanup_expired_sessions_task():
    """Deletes expired session records from DB."""
    # DB cleanup logic...
    return "Expired sessions purged."

@celery_app.task
def generate_weekly_report_task():
    """Generates weekly analytics report."""
    return "Weekly analytics report generated."

# 2. Configure Beat Schedule Dictionary
celery_app.conf.beat_schedule = {
    # Job 1: Interval Schedule (Runs every 10 minutes)
    'cleanup-sessions-every-10min': {
        'task': 'app_factory.cleanup_expired_sessions_task',
        'schedule': timedelta(minutes=10),
    },
    # Job 2: Crontab Schedule (Runs every Monday at 9:00 AM)
    'weekly-report-monday-9am': {
        'task': 'app_factory.generate_weekly_report_task',
        'schedule': crontab(day_of_week='monday', hour=9, minute=0),
    },
}
```

## 2. Master Class `crontab()` Schedule Patterns

The `celery.schedules.crontab()` helper supports precise date/time matching:

```python
from celery.schedules import crontab

# 1. Every Night at Midnight (00:00)
crontab(hour=0, minute=0)

# 2. Every 15 Minutes
crontab(minute='*/15')

# 3. Twice Daily at 8:00 AM and 8:00 PM
crontab(hour='8,20', minute=0)

# 4. First Day of Every Month at Midnight
crontab(day_of_month=1, hour=0, minute=0)

# 5. Every Weekday (Mon-Fri) at 5:00 PM
crontab(day_of_week='mon-fri', hour=17, minute=0)
```

## 3. Running Celery Beat in Production

In production environments, Celery Beat must run as a **separate dedicated process**:

### Terminal 1: Launch Celery Worker (Executes Tasks)
```bash
celery -A app_factory.celery_app worker --loglevel=info
```

### Terminal 2: Launch Celery Beat (Fires Schedules)
```bash
celery -A app_factory.celery_app beat --loglevel=info
```

### Combined Development Command (Worker + Embedded Beat)
```bash
# Convenient for local development (DO NOT USE IN PRODUCTION MULTI-SERVER CLUSTERS!)
celery -A app_factory.celery_app worker --beat --loglevel=info
```
