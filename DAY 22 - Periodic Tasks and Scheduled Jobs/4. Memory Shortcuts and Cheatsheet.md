## 🔤 Periodic Tasks & Celery Beat Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Periodic Task** | Automated background job executed on a time or calendar schedule. | Running DB cleanup every midnight |
| **Celery Beat** | Clock scheduler process sending task triggers to Redis at scheduled times. | `celery -A app.celery_app beat` |
| **`beat_schedule`** | Celery configuration dictionary mapping job names to tasks and schedules. | `celery_app.conf.beat_schedule` |
| **`crontab()`** | Celery helper function formatting calendar-based time schedules. | `crontab(hour=0, minute=0)` |
| **Interval Schedule** | Time schedule triggering tasks at fixed second/minute frequencies. | `schedule=10.0` (Every 10 secs) |
| **Backoff & Jitter** | Retry strategy adding exponential delay variance to prevent server overload. | `retry_backoff=True, retry_jitter=True` |
| **Single Beat Rule** | Production rule requiring only 1 Beat instance to avoid duplicate tasks. | Single container for Celery Beat |
| **`APScheduler`** | In-process Python scheduler library for Flask without Celery/Redis. | `Flask-APScheduler` |

## 🧠 Memory Mnemonics

### 1. Celery Beat Workflow (`B-E-A-T`)
Remember **B-E-A-T** for configuring periodic schedules:
- **B** -> **Bind Task Decorators** (`@celery_app.task`)
- **E** -> **Enter `beat_schedule` Config** (`celery_app.conf.beat_schedule = {...}`)
- **A** -> **Apply `crontab()` or Interval** (`schedule=crontab(hour=0, minute=0)`)
- **T** -> **Trigger via Redis Broker** (Beat sends message to Redis at scheduled time)

---

### 2. Cron Expression Fields (`C-R-O-N`)
Remember **C-R-O-N** for calendar schedules:
- **C** -> **Clock Minutes** (`minute='0'`)
- **R** -> **Recurring Hours** (`hour='*/2'`)
- **O** -> **Observe Month Days** (`day_of_month=1`)
- **N** -> **Name Weekdays** (`day_of_week='mon-fri'`)

## ⚡ Quick-Reference Code Snippets

### 1. Celery Beat Schedule Configuration
```python
from datetime import timedelta
from celery.schedules import crontab

celery_app.conf.beat_schedule = {
    'nightly-db-cleanup': {
        'task': 'tasks.clean_sessions',
        'schedule': crontab(hour=0, minute=0), # Midnight
    },
    'hourly-analytics': {
        'task': 'tasks.sync_analytics',
        'schedule': timedelta(hours=1),
    },
}
```

### 2. Master Class `crontab()` Expressions
```python
# Every 15 minutes
crontab(minute='*/15')

# Every Monday at 9:00 AM
crontab(day_of_week='mon', hour=9, minute=0)

# 1st of every month at midnight
crontab(day_of_month=1, hour=0, minute=0)
```

### 3. Celery Beat CLI Command
```bash
celery -A app.celery_app beat --loglevel=info
```
