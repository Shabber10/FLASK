## 🧠 Memory Mnemonics

### 1. The Three Parts of a JWT
Remember **H-P-S** for JWT structure:
- **H**: **Header** (Base64URL encoded JSON: `alg`, `typ`)
- **P**: **Payload** (Base64URL encoded Claims: `sub`, `exp`, `jti`, `role`)
- **S**: **Signature** (Cryptographic HMAC-SHA256 hash using `SECRET_KEY`)

---

### 2. Dual-Token Strategy Rules
Remember **A-C-C-E-S-S** vs **R-E-F-R-E-S-H**:
- **Access Token**: Short-lived (15 mins), sent in `Authorization: Bearer <token>` for general API calls.
- **Refresh Token**: Long-lived (7-30 days), sent ONLY to `/api/refresh` to obtain new access tokens.

## ⚡ Quick-Reference Code Snippets

### 1. Flask-JWT-Extended Setup
```python
from flask_jwt_extended import JWTManager, create_access_token, create_refresh_token, jwt_required

app.config['JWT_SECRET_KEY'] = 'crypto-secret-key'
jwt = JWTManager(app)
```

### 2. Issuing Tokens in Login Route
```python
access_token = create_access_token(identity=str(user.id), additional_claims={"role": user.role})
refresh_token = create_refresh_token(identity=str(user.id))
```

### 3. Protecting Routes & Reading Claims
```python
@app.route('/api/protected')
@jwt_required()
def protected():
    current_user_id = get_jwt_identity() # Retrieves 'sub' claim
    claims = get_jwt()                    # Retrieves full claims dict
    return jsonify(user_id=current_user_id, role=claims['role'])
```

### 4. Revoking Tokens via Blocklist Loader
```python
@jwt.token_in_blocklist_loader
def check_if_token_revoked(jwt_header, jwt_payload):
    jti = jwt_payload['jti']
    return jti in revoked_token_jti_set
```
