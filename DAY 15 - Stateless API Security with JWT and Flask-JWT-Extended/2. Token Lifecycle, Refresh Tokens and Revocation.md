# Day 15: Token Lifecycle, Refresh Tokens & Revocation

In this section, we examine the Access Token vs Refresh Token dual-token strategy, `Flask-JWT-Extended` integration, token revocation blocklisting, and custom JWT error handlers.

---

## 1. Dual-Token Architecture (Access vs. Refresh Tokens)

To balance security and user experience, enterprise APIs implement a **Dual-Token System**:

```
+-------------------------------------------------------------------+
|                        Client Application                         |
+-------------------------------------------------------------------+
  |                                 |                             |
  | 1. POST /api/login              | 2. GET /api/protected       | 3. POST /api/refresh
  |    (Username/Password)          |    (Authorization: Bearer   |    (Authorization: Bearer
  |                                 |     Access Token)           |     Refresh Token)
  v                                 v                             v
+-------------------------------------------------------------------+
|                         Flask REST API                            |
|  - Issues Short-Lived           - Validates Access Token        - Issues NEW Access Token
|    Access Token (15 mins)         Signature & Expiration          without password login
|  - Issues Long-Lived
|    Refresh Token (30 days)
+-------------------------------------------------------------------+
```

- **Access Token**: Short lifespan (e.g. 15 minutes). Sent in `Authorization: Bearer <access_token>` header for API calls. If stolen, the attacker's access window is minimal.
- **Refresh Token**: Long lifespan (e.g. 30 days). Used solely at the `/api/refresh` endpoint to obtain a new Access Token.

## 2. Flask-JWT-Extended Integration

### 1. Initializing `JWTManager`
```python
from datetime import timedelta
from flask import Flask
from flask_jwt_extended import JWTManager

app = Flask(__name__)
app.config['JWT_SECRET_KEY'] = 'jwt-super-secret-key-30-days'
app.config['JWT_ACCESS_TOKEN_EXPIRES'] = timedelta(minutes=15)
app.config['JWT_REFRESH_TOKEN_EXPIRES'] = timedelta(days=30)

jwt = JWTManager(app)
```

### 2. Issuing Tokens (`create_access_token`, `create_refresh_token`)
```python
from flask_jwt_extended import create_access_token, create_refresh_token

@app.route('/api/login', methods=['POST'])
def login():
    username = request.json.get('username')
    password = request.json.get('password')
    
    user = User.authenticate(username, password)
    if not user:
        return jsonify({"error": "Invalid credentials"}), 401
        
    access_token = create_access_token(identity=str(user.id), additional_claims={"role": user.role})
    refresh_token = create_refresh_token(identity=str(user.id))
    
    return jsonify({
        "access_token": access_token,
        "refresh_token": refresh_token
    }), 200
```

### 3. Protecting Endpoints (`@jwt_required()`)
```python
from flask_jwt_extended import jwt_required, get_jwt_identity, get_jwt

@app.route('/api/profile')
@jwt_required() # Protects route; requires valid Access Token in Bearer header
def profile():
    user_id = get_jwt_identity() # Retrieves 'sub' claim (user ID)
    claims = get_jwt()           # Retrieves full JWT claims dictionary
    return jsonify({"user_id": user_id, "role": claims.get('role')})

@app.route('/api/refresh', methods=['POST'])
@jwt_required(refresh=True) # Requires valid REFRESH Token
def refresh():
    identity = get_jwt_identity()
    new_access_token = create_access_token(identity=identity)
    return jsonify({"access_token": new_access_token}), 200
```

## 3. Token Revocation & Denylist Blocklisting

Because JWTs are stateless, the server cannot "delete" an issued token before it expires unless it maintains a **Token Denylist (Blocklist)** of revoked unique token IDs (`jti`):

```python
# In-Memory or Redis Revoked Token Blocklist Set
revoked_jwt_jti_set = set()

@jwt.token_in_blocklist_loader
def check_if_token_revoked(jwt_header, jwt_payload):
    """Callback function checking if JWT jti exists in blocklist."""
    jti = jwt_payload['jti']
    return jti in revoked_jwt_jti_set

@app.route('/api/logout', methods=['POST'])
@jwt_required()
def logout():
    """Revokes current active Access Token on logout."""
    jti = get_jwt()['jti']
    revoked_jwt_jti_set.add(jti)
    return jsonify({"message": "Successfully logged out. Token revoked."}), 200
```
