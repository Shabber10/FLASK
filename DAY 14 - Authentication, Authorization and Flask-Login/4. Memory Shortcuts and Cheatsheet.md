## 🧠 Memory Mnemonics

### 1. Flask-Login Setup Sequence
Remember **L-O-G-I-N** for authentication setup:
- **L**: **`LoginManager()`** (Instantiate extension object)
- **O**: **`user_loader`** (Define `@login_manager.user_loader` callback)
- **G**: **Guard Routes** (Protect views with `@login_required`)
- **I**: **`init_app(app)`** (Bind extension to Flask app instance)
- **N**: **Navigation Proxy** (Use `current_user` in views/templates)

---

### 2. `UserMixin` Methods
- **`is_authenticated`**: `True` if user has active session.
- **`is_active`**: `True` if user account is enabled (not banned).
- **`is_anonymous`**: `True` if guest user.
- **`get_id()`**: Returns string user ID.

### 3. Role-Based Access Control (RBAC) Decorator
```python
from functools import wraps
from flask_login import current_user
from flask import abort

def roles_required(*roles):
    def decorator(f):
        @wraps(f)
        def decorated(*args, **kwargs):
            if not current_user.is_authenticated or current_user.role not in roles:
                abort(403)
            return f(*args, **kwargs)
        return decorated
    return decorator
```
