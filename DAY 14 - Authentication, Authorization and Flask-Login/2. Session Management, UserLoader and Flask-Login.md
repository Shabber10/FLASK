## 1. Flask-Login Architecture

**Flask-Login** manages user session states, logged-in user tracking (`current_user`), session cookies, and authentication guards.

```
+------------------+                   +------------------+
| User submits     | Validates Password| Flask-Login      |
| Login Credentials| ----------------> | `login_user(u)`  |
+------------------+                   +--------+---------+
                                                | Serializes user.id into
                                                | signed session cookie
                                                v
+------------------+                   +------------------+
| Subsequent       | Session Cookie    | `@user_loader`   |
| HTTP Request     | ----------------> | Callback fetches |
+------------------+                   | User from DB     |
                                       +--------+---------+
                                                |
                                                v
                                       Sets `current_user`
```

---

## 2. The `UserMixin` Class

Flask-Login requires user model classes to implement four essential properties/methods. Inheriting from `UserMixin` provides default implementations:

| `UserMixin` Method | Description | Default Return Value |
| :--- | :--- | :--- |
| `is_authenticated` | `True` if user has valid credentials logged in | `True` |
| `is_active` | `True` if user account is enabled (not banned) | `True` |
| `is_anonymous` | `True` if unauthenticated guest user | `False` |
| `get_id()` | Returns unique string identifier for user | `str(self.id)` |

## 3. Implementing the `@user_loader` Callback

Flask-Login uses the user loader callback to reload user objects from database primary key IDs stored in session cookies:

```python
from flask_login import LoginManager, UserMixin

login_manager = LoginManager()
login_manager.login_view = 'auth.login' # Redirect route for unauthenticated access attempts
login_manager.login_message_category = 'warning'

@login_manager.user_loader
def load_user(user_id):
    """Reloads User instance from DB using primary key stored in session."""
    return db.session.get(User, int(user_id))
```

## 4. Login & Logout Workflows

```python
from flask import request, redirect, url_for, flash
from flask_login import login_user, logout_user, login_required, current_user

@app.route('/login', methods=['POST'])
def login():
    username = request.form['username']
    password = request.form['password']
    
    user = User.query.filter_by(username=username).first()
    if user and user.check_password(password):
        # Establish session cookie
        login_user(user, remember=True)
        flash("Logged in successfully!", "success")
        
        # Redirect to originally requested page (next parameter) or dashboard
        next_page = request.args.get('next')
        return redirect(next_page or url_for('dashboard'))
        
    flash("Invalid credentials.", "danger")
    return redirect(url_for('login'))

@app.route('/logout')
@login_required
def logout():
    logout_user() # Clears session cookie
    flash("You have been logged out.", "info")
    return redirect(url_for('login'))
```

## 5. Custom Role-Based Access Control (RBAC) Decorators

Extend `@login_required` to enforce role permissions (e.g. `@admin_required`):

```python
from functools import wraps
from flask import abort
from flask_login import current_user

def roles_required(*roles):
    """Decorator restricting route access to specified user roles."""
    def decorator(f):
        @wraps(f)
        def decorated_function(*args, **kwargs):
            if not current_user.is_authenticated:
                return redirect(url_for('login'))
            if current_user.role not in roles:
                abort(403) # Return HTTP 403 Forbidden
            return f(*args, **kwargs)
        return decorated_function
    return decorator

# Route usage:
@app.route('/admin/system')
@roles_required('admin', 'superuser')
def admin_system():
    return "Admin System Panel"
```
