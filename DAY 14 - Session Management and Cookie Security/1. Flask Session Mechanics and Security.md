# Day 14: Session Management & Cookie Security

## 1. How Default Flask Sessions Work
Flask's default `session` object uses **signed client-side cookies** serialized via `itsdangerous`:
- The session payload is readable by the client (base64 encoded) but **tamper-proof** because it is cryptographically signed using `SECRET_KEY`.

## 2. Cookie Security Flags
- `SESSION_COOKIE_HTTPONLY = True`: Prevents client JavaScript access (mitigates XSS).
- `SESSION_COOKIE_SECURE = True`: Forces transmission over HTTPS only.
- `SESSION_COOKIE_SAMESITE = 'Lax'`: Protects against Cross-Site Request Forgery (CSRF).
