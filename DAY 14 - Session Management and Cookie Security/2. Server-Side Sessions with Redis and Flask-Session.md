# Day 14: Server-Side Sessions with Flask-Session

## 1. Server-Side Session Storage
Client-side cookies have a 4KB size limit and store sensitive data on the user browser. **Flask-Session** moves session payloads server-side to Redis or database backends.

```python
from flask_session import Session

app.config['SESSION_TYPE'] = 'redis'
app.config['SESSION_REDIS'] = redis_client
Session(app)
```
