## 🔤 Session & Cookie Security Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **HTTP Statelessness** | Server forgetting user identity between separate HTTP requests. | Requiring cookies to recognize active users |
| **Cookie** | Small text file stored in browser and sent automatically on requests (~4KB). | `res.set_cookie("username", "Jani")` |
| **Session** | Mechanism persisting user state across page visits. | `session['username'] = 'admin'` |
| **Client-Side Session** | Default Flask session signed via HMAC and stored in browser cookie. | `itsdangerous` signing |
| **Server-Side Session** | Session payload stored on server disk/Redis; cookie holds UUID only. | `Flask-Session` extension |
| **`HttpOnly`** | Flag hiding cookie from browser JavaScript to block XSS theft. | `SESSION_COOKIE_HTTPONLY = True` |
| **`Secure`** | Flag forcing cookie transmission over encrypted HTTPS only. | `SESSION_COOKIE_SECURE = True` |
| **`SameSite`** | Flag restricting cross-site cookie sending to block CSRF. | `SESSION_COOKIE_SAMESITE = 'Lax'` |
| **`SESSION_TYPE`** | Backend target for server-side sessions (`filesystem`, `redis`). | `app.config['SESSION_TYPE'] = 'redis'` |

## 🧠 Memory Mnemonics & Comparison Matrix

### 1. Cookie Security Flags (`S-E-C-U-R-E`)
- **S** -> **`SameSite = 'Lax'`** (Block cross-site request forgery CSRF)
- **E** -> **Expiration Window** (`PERMANENT_SESSION_LIFETIME = timedelta(days=7)`)
- **C** -> **Clear Session on Logout** (`session.clear()`)
- **U** -> **Use `HttpOnly = True`** (Block JavaScript XSS cookie theft)
- **R** -> **Require HTTPS `Secure = True`** (Force encrypted transmission)
- **E** -> **Enforce Signed `SECRET_KEY`** (Cryptographic HMAC tamper detection)

### 2. Cookies vs. Sessions Comparison Matrix
| Feature | Cookie (Client-Side) | Session (Server-Side / Signed) |
| :--- | :--- | :--- |
| **Where Stored?** | Browser (Client) | Server (Memory / File / DB / Redis) |
| **Security Level** | ❌ Less Secure (visible/modifiable) | ✅ Highly Secure |
| **Data Size Limit** | Strict ~4 KB limit | Large (server capacity) |
| **Best For** | UI Theme, Language preferences | User Login, Shopping Cart, Roles |
| **Client Modifiable?**| Yes (via browser console) | No (server enforces signature/ID) |

### 3. The 3 Session Invalidation Triggers
| Trigger | Action | Cookie State | Dashboard Access |
| :--- | :--- | :--- | :--- |
| **1. Session Timeout** | `permanent_session_lifetime` expires | Timestamp rejected | ❌ Blocked |
| **2. User Logout** | `session.pop()` or `session.clear()` | Data wiped / reset | ❌ Blocked |
| **3. Manual Clear** | User clears browser cookies | Cookie physically deleted | ❌ Blocked |

## ⚡ Quick-Reference Code Snippets

### 1. Setting and Reading Cookies in Flask
```python
from flask import make_response, request

# Set cookie (1 day lifetime)
res = make_response("Cookie set!")
res.set_cookie("theme", "dark", max_age=60 * 60 * 24)

# Read cookie
theme = request.cookies.get("theme", "light")
```

### 2. Standard Session Operations
```python
from datetime import timedelta

app.secret_key = "production_key"
app.permanent_session_lifetime = timedelta(minutes=30)

# Set session
session["username"] = "admin"
session.permanent = True

# Read session
user = session.get("username")

# Single key removal vs Full Wipe
session.pop("username", None)
session.clear()
```

### 3. Hardened Cookie Security Configuration
```python
app.config['SECRET_KEY'] = 'strong-production-crypto-key'
app.config['SESSION_COOKIE_HTTPONLY'] = True
app.config['SESSION_COOKIE_SECURE'] = True
app.config['SESSION_COOKIE_SAMESITE'] = 'Lax'
app.config['PERMANENT_SESSION_LIFETIME'] = timedelta(days=7)
```

### 4. Server-Side Filesystem Sessions (`Flask-Session`)
```python
from flask_session import Session

app.config["SESSION_TYPE"] = "filesystem"
app.config["SESSION_PERMANENT"] = False
Session(app)
```

### 5. Server-Side Redis Sessions (`Flask-Session`)
```python
import redis
from flask_session import Session

app.config['SESSION_TYPE'] = 'redis'
app.config['SESSION_REDIS'] = redis.Redis(host='127.0.0.1', port=6379)
app.config['SESSION_USE_SIGNER'] = True
Session(app)
```

### 6. Secure Password Hashing with Werkzeug
```python
from werkzeug.security import generate_password_hash, check_password_hash

# Hash password
hash_val = generate_password_hash("userpassword", method="scrypt")

is_valid = check_password_hash(hash_val, entered_password)
```
