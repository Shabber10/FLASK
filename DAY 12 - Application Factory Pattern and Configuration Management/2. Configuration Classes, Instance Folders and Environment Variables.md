# Day 12: Configuration Classes & Environment Variables

In this section, we examine class-based configuration inheritance (`BaseConfig`, `DevConfig`, `TestConfig`, `ProdConfig`), environment variable loading with `python-dotenv`, and secret `instance/` folders.

---

## 1. Class-Based Configuration Inheritance

Organize application settings into an object-oriented class hierarchy (`config.py`):

```python
import os

class BaseConfig:
    """Base Configuration holding common application settings."""
    SECRET_KEY = os.environ.get('SECRET_KEY', 'default-fallback-dev-key-change-in-prod')
    SQLALCHEMY_TRACK_MODIFICATIONS = False
    MAX_CONTENT_LENGTH = 16 * 1024 * 1024 # 16MB Max Upload

class DevelopmentConfig(BaseConfig):
    """Development Environment Settings."""
    DEBUG = True
    SQLALCHEMY_DATABASE_URI = os.environ.get('DEV_DATABASE_URL', 'sqlite:///dev.db')
    SQLALCHEMY_ECHO = True

class TestingConfig(BaseConfig):
    """Automated Testing Environment Settings."""
    TESTING = True
    WTF_CSRF_ENABLED = False  # Disable CSRF during automated test suite execution
    SQLALCHEMY_DATABASE_URI = 'sqlite:///:memory:' # In-Memory Database for fast tests

class ProductionConfig(BaseConfig):
    """Production Deployment Settings."""
    DEBUG = False
    TESTING = False
    SQLALCHEMY_DATABASE_URI = os.environ.get('DATABASE_URL')
    SQLALCHEMY_ENGINE_OPTIONS = {
        'pool_size': 15,
        'pool_recycle': 1800,
        'pool_pre_ping': True
    }

# Environment Configuration Dictionary Mapping
config_by_name = {
    'development': DevelopmentConfig,
    'testing': TestingConfig,
    'production': ProductionConfig,
    'default': DevelopmentConfig
}
```

## 2. Environment Variables & `.env` Files

Secrets (API keys, database passwords, secret keys) should **never** be hardcoded into version control git repositories.

Flask automatically loads environment variables from `.env` and `.flaskenv` files if `python-dotenv` is installed.

### Sample `.env` File (Ignored by Git)
```env
FLASK_APP=app.py
FLASK_ENV=development
SECRET_KEY=super-secret-crypto-key-998811
DATABASE_URL=postgresql://dbuser:strongpass@localhost:5432/proddb
```

## 3. Instance Folders for Unversioned Local Configs

Flask provides an **Instance Folder** (`instance/`) located outside the main application package directory. It is designed for non-version-controlled configuration overrides or SQLite files:

```python
# Load unversioned secret instance config if present
app.config.from_pyfile('config.py', silent=True)
```

Adding `instance/` to `.gitignore` guarantees local secrets are never committed accidentally to remote repositories.
