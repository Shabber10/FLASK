# Day 20: View Caching, Memoization & Redis

In this section, we examine `Flask-Caching` initialization, route view caching (`@cache.cached`), function memoization (`@cache.memoize`), and direct Redis key-value operations.

---

## 1. Initializing Flask-Caching

Initialize `Cache` at module level and bind to Flask app instance:

```python
from flask import Flask
from flask_caching import Cache

cache = Cache()

def create_app():
    app = Flask(__name__)
    app.config['CACHE_TYPE'] = 'RedisCache'
    app.config['CACHE_REDIS_URL'] = 'redis://localhost:6379/0'
    app.config['CACHE_DEFAULT_TIMEOUT'] = 300 # 5 minutes default
    
    cache.init_app(app)
    return app
```

---

## 2. Full View Response Caching (`@cache.cached`)

The `@cache.cached()` decorator caches the entire HTTP response (status code, headers, body) returned by a view function:

```python
@app.route('/api/catalog')
@cache.cached(timeout=120, query_string=True)
def get_catalog():
    """Caches response for 120 seconds.
    `query_string=True` ensures /api/catalog?page=1 and /api/catalog?page=2 are cached separately!
    """
    # Expensive DB Query
    products = Product.query.all()
    return jsonify([p.to_dict() for p in products])
```

## 3. Function Memoization (`@cache.memoize`)

While `@cache.cached()` operates on HTTP requests, **`@cache.memoize()`** caches the return values of arbitrary Python functions based on the specific argument values passed to the function:

```python
@cache.memoize(timeout=600)
def calculate_user_loyalty_score(user_id, include_bonus=True):
    """Caches calculation output per user_id and include_bonus parameter combination."""
    time.sleep(2) # Simulate heavy DB aggregation computation
    return {"user_id": user_id, "score": 850}
```

### Invalidating Memoized Function Caches

When user data changes in the database, clear the memoized cache for that specific user ID:

```python
@app.route('/users/<int:user_id>/update', methods=['POST'])
def update_user(user_id):
    # Update user in DB...
    db.session.commit()
    
    # Invalidate ONLY the memoized cache for this user_id!
    cache.delete_memoized(calculate_user_loyalty_score, user_id)
    return jsonify({"status": "updated"})
```

## 4. Direct Key-Value Cache Manipulation

Manipulate cache keys programmatically using `.get()`, `.set()`, `.delete()`, and `.clear()`:

```python
# 1. Store value in cache with 60-second TTL
cache.set('global_announcement', 'System maintenance tonight at 11 PM', timeout=60)

# 2. Retrieve value from cache
announcement = cache.get('global_announcement') # Returns None if expired or missing

# 3. Explicitly delete key
cache.delete('global_announcement')

# 4. Flush entire cache storage
cache.clear()
```
