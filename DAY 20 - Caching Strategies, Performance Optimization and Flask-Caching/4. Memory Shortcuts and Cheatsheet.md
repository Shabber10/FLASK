## 🧠 Memory Mnemonics

### 1. Flask-Caching Decorator Selection
Remember **V-I-E-W** vs **F-U-N-C**:
- **`@cache.cached(timeout=60)`**: Caches entire **HTTP View Responses** (headers, status, body). Use `query_string=True` for GET parameter support.
- **`@cache.memoize(timeout=300)`**: Caches return values of individual **Python Functions** based on input argument values.

---

### 2. Cache Invalidation Rules
- **`cache.delete('key')`**: Deletes explicit key.
- **`cache.delete_memoized(func_name, arg1, arg2)`**: Invalidates memoized function output for specific parameter values.
- **`cache.clear()`**: Flushes entire cache storage.

---

## ⚡ Quick-Reference Code Snippets

### 1. Flask-Caching Initialization
```python
from flask import Flask
from flask_caching import Cache

app = Flask(__name__)
app.config['CACHE_TYPE'] = 'RedisCache'
app.config['CACHE_REDIS_URL'] = 'redis://localhost:6379/0'

cache = Cache(app)
```

### 2. View Caching with Query Parameters
```python
@app.route('/api/products')
@cache.cached(timeout=300, query_string=True)
def get_products():
    return jsonify(Product.query.all())
```

### 3. Function Memoization & Invalidation
```python
@cache.memoize(timeout=600)
def get_user_orders(user_id):
    return Order.query.filter_by(user_id=user_id).all()

# Invalidate when new order is created
@app.route('/orders/create', methods=['POST'])
def create_order():
    # Save order...
    cache.delete_memoized(get_user_orders, user_id)
```
