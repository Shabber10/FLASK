## 1. What is `render_template()` in Flask?

### 🔍 Definition & Purpose
`render_template()` is a built-in Flask function used to render (display) HTML pages from your Flask application. It connects your Python backend code with HTML template files stored in a mandatory directory called **`templates`**.

```python
from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def home():
    # Looks inside 'templates/' folder for 'home.html'
    return render_template("home.html")
```

### 🔍 How it Works:
`return render_template("home.html")` tells Flask:  
*"Look inside the `templates` folder for a file named `home.html` and render it in the browser!"*

## 2. What is Jinja2 in Simple Words?

**Jinja2** is a fast, expressive templating engine built into Flask that allows you to:
1.  **Embed Python-like code** (such as loops and conditionals) directly inside HTML files.
2.  **Dynamically render content** (variables, lists, dictionaries) passed from your Flask backend into the HTML webpage.

### Why is Jinja2 Used?
When you pass data from Python to HTML, Jinja2 allows you to insert and display that dynamic data seamlessly inside the webpage presentation layer.

```python
# app.py (Flask Python Backend)
@app.route('/')
def home():
    user_name = "Jani Basha"
    return render_template("index.html", name=user_name)
```

```html
<!-- templates/index.html -->
<!DOCTYPE html>
<html>
<head><title>Home Page</title></head>
<body>
    <h1>Welcome, {{ name }}!</h1>
</body>
</html>
```

**Output in Browser**: `Welcome, Jani Basha!`

## 3. Jinja2 Syntax Guide

Jinja2 uses distinct delimiters to separate Python logic from standard HTML:

| Jinja2 Delimiter | Purpose | Example |
| :--- | :--- | :--- |
| **`{{ variable }}`** | Print / Output variable value | `{{ name }}` or `{{ price * 1.1 }}` |
| **`{% control %}`** | Control statements (`if`, `for`, `block`) | `{% if logged_in %}` |
| **`{# comment #}`** | Internal template comments (hidden in output) | `{# This is a Jinja comment #}` |

## 4. Control Flow in Jinja2 (`if`, `else`, `for`)

### 🌟 1. Using `if` and `else` in Jinja2

**`app.py`**:
```python
@app.route("/")
def home():
    user_logged_in = True
    return render_template("home.html", logged_in=user_logged_in)
```

**`templates/home.html`**:
```html
<!DOCTYPE html>
<html>
<body>
    {% if logged_in %}
        <h2>Welcome back, user!</h2>
    {% else %}
        <h2>Please log in to continue.</h2>
    {% endif %}
</body>
</html>
```

### 🔁 2. Using `for` Loop in Jinja2

**`app.py`**:
```python
@app.route("/courses")
def course_list():
    courses = ["HTML", "CSS", "JavaScript", "Python"]
    return render_template("courses.html", course_list=courses, content=["apple", "banana", "cherry"])
```

**`templates/courses.html`**:
```html
<!DOCTYPE html>
<html>
<body>
    <h3>Fruits List:</h3>
    {% for i in content %}
        <p>{{ i }}</p>
    {% endfor %}

    <h3>Available Courses:</h3>
    <ul>
        {% for course in course_list %}
            <li>{{ course }}</li>
        {% endfor %}
    </ul>
</body>
</html>
```

## 5. Flask Project Folder Structure & Static Files

To build organized applications, follow this project folder layout:

```
my_flask_project/
│
├── app.py                  # Main Python application file
├── requirements.txt        # Package dependencies
│
├── templates/              # Folder for HTML templates
│   ├── base.html
│   ├── index.html
│   └── about.html
│
└── static/                 # Folder for CSS, JS, Images
    ├── style.css
    └── images/
        └── hyderabad.jpg
```

### 📄 Loading Static Files with `url_for('static', filename='...')`

1.  **Loading CSS Stylesheet**:
    ```html
    <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
    ```
2.  **Loading Images**:
    ```html
    <img src="{{ url_for('static', filename='images/hyderabad.jpg') }}" alt="Hyderabad Image" width="300">
    ```
3.  **Hyperlink to another route**:
    ```html
    <a href="/about">Go to About Page</a>
    ```

## 6. Template Inheritance (`{% extends %}` & `{% block %}`)

Template inheritance allows you to create a master layout (`base.html`) with headers, navbars, and footers, while child templates override only specific content blocks. This follows the **DRY (Don't Repeat Yourself)** principle.

### 📄 `templates/base.html` (Master Layout)
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}My Website{% endblock %}</title>
    <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
</head>
<body>
    <header>
        <h1>My Awesome Website</h1>
        <nav>
            <a href="/">Home</a> | <a href="/about">About</a>
        </nav>
    </header>

    <main>
        {% block content %}
        <!-- Child templates will fill this content block -->
        {% endblock %}
    </main>

    <footer>
        <p>&copy; 2026 My Website</p>
    </footer>
</body>
</html>
```

### 📄 `templates/home.html` (Child Page)
```html
{% extends "base.html" %}

{% block title %}Home - My Website{% endblock %}

{% block content %}
    <h2>Welcome to the Home Page!</h2>
    <p>This is where your journey begins.</p>
{% endblock %}
```

### 📄 `templates/about.html` (Child Page)
```html
{% extends "base.html" %}

{% block title %}About Us - My Website{% endblock %}

{% block content %}
    <h2>About Us</h2>
    <p>We build enterprise web applications using Flask and Jinja2.</p>
{% endblock %}
```

## 7. Reusable Components with `{% include %}`

While `{% extends %}` provides parent-child layout inheritance, **`{% include %}`** literally inserts the raw contents of another template file into any template.

```html
<!-- base.html -->
<body>
    {% include '_header.html' %}
    
    <main>
        {% block content %}{% endblock %}
    </main>
    
    {% include '_footer.html' %}
</body>
```

### ⚖️ Inheritance (`extends`) vs Inclusion (`include`)

| Concept | Action | Typical Use Case |
| :--- | :--- | :--- |
| **`{% extends %}`** | Child template inherits structure from master `base.html` | Page views (`home.html`, `about.html`) |
| **`{% block %}`** | Placeholder slot in `base.html` overridden by child | Title, main content body |
| **`{% include %}`** | Directly inserts external template contents at that exact spot | Reusable widgets, `_header.html`, `_footer.html` |
