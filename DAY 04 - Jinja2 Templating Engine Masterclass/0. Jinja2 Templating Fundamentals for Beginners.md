## 1. What is Jinja2 Templating Engine? (Class Notes Definition)

**Jinja2** is the fast, secure templating engine used in Flask to create dynamic web pages.

### 🌟 Why We Use Jinja2:
When building real websites, we do not want to write static HTML where data is hardcoded. We want HTML that changes dynamically based on Python data:
- Displaying the logged-in student's name dynamically.
- Generating HTML table rows automatically from a MySQL database list.
- Showing or hiding buttons based on user permissions using `if/else`.

```
Python Server (Flask) ──(Passes Data: students=[...])──> Jinja2 Engine ──(Compiles HTML)──> Browser
```

## 2. Jinja2 Syntax Delimiters (The 3 Core Tags)

| Delimiter Syntax | Name | Purpose | Example |
| :--- | :--- | :--- | :--- |
| **`{{ ... }}`** | **Expression Tag** | Prints variables, calculations, or function returns. | `{{ username }}`, `{{ 10 * 5 }}` |
| **`{% ... %}`** | **Statement Tag** | Control flow logic (conditionals, loops, inheritance).| `{% if score >= 40 %}`, `{% for s in students %}` |
| **`{# ... #}`** | **Comment Tag** | Template comments (hidden from rendered HTML output).| `{# This is a comment #}` |

## 3. Conditionals & Loops in Jinja2

### 1️⃣ Conditionals (`if / elif / else / endif`)
```html
{% if student.marks >= 80 %}
    <p style="color: green;">Grade: Distinction 🌟</p>
{% elif student.marks >= 40 %}
    <p style="color: blue;">Grade: Pass ✅</p>
{% else %}
    <p style="color: red;">Grade: Fail ❌</p>
{% endif %}
```

### 2️⃣ Loops & The `loop` Helper Variable (`for / endfor`)
```html
<table border="1">
    <tr>
        <th>S.No</th>
        <th>Student Name</th>
        <th>Marks</th>
        <th>Status</th>
    </tr>
    {% for s in students %}
    <tr class="{{ 'even-row' if loop.index is even else 'odd-row' }}">
        <td>{{ loop.index }}</td>  <!-- 1-indexed counter (1, 2, 3...) -->
        <td>{{ s.sname }}</td>
        <td>{{ s.smarks }}</td>
        <td>
            {% if loop.first %}<b>First Student</b>{% endif %}
            {% if loop.last %}<b>Last Student</b>{% endif %}
        </td>
    </tr>
    {% else %}
    <tr><td colspan="4">No student records found!</td></tr>
    {% endfor %}
</table>
```

## 4. What is Template Inheritance? (Class Notes Project Structure)

**Template Inheritance** allows you to create a master layout (`base.html`) that contains the common elements of your website (Header, Navigation Bar, Footer, CSS/JS links) and lets child pages override specific content blocks!

```
                   ┌────────────────────────────────────────┐
                   │        templates/base.html             │
                   │  - Header & Navbar (<nav> links)       │
                   │  - {% block content %}{% endblock %}   │
                   │  - Footer (@Copyright 2026)            │
                   └───────────────────┬────────────────────┘
                                       │
            ┌──────────────────────────┼──────────────────────────┐
            ▼                          ▼                          ▼
┌───────────────────────┐  ┌───────────────────────┐  ┌───────────────────────┐
│  templates/home.html  │  │ templates/about.html  │  │templates/contact.html │
│ {% extends 'base.html'%} │ {% extends 'base.html'%} │ {% extends 'base.html'%}│
│ {% block content %}   │  │ {% block content %}   │  │ {% block content %}   │
│   <h1>Home Page</h1>  │  │   <h1>About Page</h1> │  │   <h1>Contact Page</h1>│
│ {% endblock %}        │  │ {% endblock %}        │  │ {% endblock %}        │
└───────────────────────┘  └───────────────────────┘  └───────────────────────┘
```

### 📄 Master Layout: `templates/base.html`
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}My College Website{% endblock %}</title>
    <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
</head>
<body>
    <header>
        <h1>Welcome to my College Website</h1>
        <nav>
            <a href="/home">Home</a> | 
            <a href="/about">About</a> | 
            <a href="/contact">Contact</a>
        </nav>
    </header>
    <hr>

    <main>
        {% block content %}
        <!-- Filled dynamically by child templates -->
        {% endblock %}
    </main>

    <hr>
    <footer>
        <p>2026 @copyright all rights are reserved</p>
    </footer>
</body>
</html>
```

### 📄 Child Template: `templates/home.html`
```html
{% extends 'base.html' %}

{% block title %}Home Page - College Portal{% endblock %}

{% block content %}
<h1>Welcome to Home Page</h1>
<p>This is the dynamic home page rendered with Jinja2 inheritance!</p>
{% endblock %}
```

## 5. Linking Static Assets with `url_for()`
Never hardcode static asset URLs like `<link href="/static/style.css">`. Always use Flask's dynamic URL generator:
```html
<link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
<img src="{{ url_for('static', filename='images/logo.png') }}" alt="Logo">
```
