# Day 04: Template Inheritance, Macros & Dynamic Layouts

## 1. Template Inheritance Architecture
Inheritance allows base layout components to be shared across pages:

```html
<!-- base.html -->
<!DOCTYPE html>
<html>
<head><title>{% block title %}Default App{% endblock %}</title></head>
<body>
    {% block content %}{% endblock %}
</body>
</html>
```

```html
<!-- index.html -->
{% extends "base.html" %}
{% block title %}Home Page{% endblock %}
{% block content %}
    <h1>Welcome Home!</h1>
{% endblock %}
```
