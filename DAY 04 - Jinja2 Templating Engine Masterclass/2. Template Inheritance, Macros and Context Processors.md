# Day 04: Template Inheritance, Macros & Dynamic Layouts

In this section, we explore template inheritance architecture, parent block referencing with `super()`, Jinja2 macros, reusable component includes, and dynamic static asset binding with `url_for('static')`.

---

## 1. Template Inheritance Architecture

Template inheritance allows you to construct a base skeleton layout containing common UI headers, navigation bars, sidebars, and footers, leaving `{% block %}` regions for child templates to override.

```
+-------------------------------------------------------------+
| base.html (Master Skeleton)                                 |
| +---------------------------------------------------------+ |
| | Navbar & Global Header                                  | |
| +---------------------------------------------------------+ |
| | {% block content %}                                     | |
| |   (Child template content injected here)                | |
| | {% endblock %}                                          | |
| +---------------------------------------------------------+ |
| | Footer & Global Scripts                                 | |
| +---------------------------------------------------------+ |
+-------------------------------------------------------------+
```

### Base Layout (`templates/base.html`)

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}Enterprise Platform{% endblock %}</title>
    <link rel="stylesheet" href="{{ url_for('static', filename='css/main.css') }}">
    {% block styles %}{% endblock %}
</head>
<body>
    <header>
        <nav>
            <a href="{{ url_for('home') }}">Home</a>
        </nav>
    </header>

    <main class="container">
        {% block content %}{% endblock %}
    </main>

    <footer>
        <p>&copy; 2026 Enterprise Platform</p>
    </footer>

    {% block scripts %}{% endblock %}
</body>
</html>
```

### Child Template (`templates/dashboard.html`)

```html
{% extends "base.html" %}

{% block title %}Dashboard - Enterprise Platform{% endblock %}

{% block content %}
    <h1>User Analytics Dashboard</h1>
    <p>Welcome back, {{ user.username }}!</p>
{% endblock %}

{% block scripts %}
    {{ super() }} <!-- Keeps any parent script tags -->
    <script src="{{ url_for('static', filename='js/dashboard.js') }}"></script>
{% endblock %}
```

## 2. Reusable UI Components with Jinja2 Macros

**Macros** are analogous to Python functions inside templates. They encapsulate reusable HTML snippets (e.g. form fields, user cards, modal dialogs, status badges).

### Defining Macros (`templates/macros.html`)

```jinja2
{% macro render_badge(status) %}
    {% if status == 'active' %}
        <span class="badge badge-success">Active</span>
    {% elif status == 'pending' %}
        <span class="badge badge-warning">Pending Approval</span>
    {% else %}
        <span class="badge badge-danger">Disabled</span>
    {% endif %}
{% endmacro %}

{% macro render_input(name, label, value='', type='text') %}
    <div class="form-group">
        <label for="{{ name }}">{{ label }}</label>
        <input type="{{ type }}" id="{{ name }}" name="{{ name }}" value="{{ value }}" class="form-control">
    </div>
{% endmacro %}
```

### Importing & Using Macros in Templates

```html
{% from "macros.html" import render_badge, render_input %}

<form method="POST">
    {{ render_input('email', 'Email Address', type='email') }}
    {{ render_input('password', 'Account Password', type='password') }}
    <button type="submit">Login</button>
</form>

<p>User Status: {{ render_badge(user.status) }}</p>
```

## 3. Template Includes (`{% include %}`)

Includes render another template file directly in-place:

```html
<!-- Include Navigation Bar Component -->
{% include "partials/navbar.html" %}

<!-- Include with explicit context isolation -->
{% include "partials/sidebar.html" without context %}

<!-- Include with ignore missing fallback -->
{% include "partials/custom_banner.html" ignore missing %}
```

### Difference Between Macros & Includes
- **Includes**: Static insertion of partial template files. Shares active template context.
- **Macros**: Functional parametric components. Accept parameters and output customized HTML.
