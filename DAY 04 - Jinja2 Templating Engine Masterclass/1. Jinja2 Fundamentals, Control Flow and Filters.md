## 1. How Jinja2 Compiles Templates

Jinja2 is a fast, expressive, and secure templating engine for Python. When `render_template()` is called, Jinja2 does not parse strings dynamically on every render; it compiles templates into optimized Python bytecode:

```
+--------------------+      +--------------------+      +--------------------+      +--------------------+
|  HTML Template     | ---> |   Jinja Lexer      | ---> |  Abstract Syntax   | ---> | Python Bytecode    |
|  (with Jinja tags) |      |   & Parser         |      |  Tree (AST)        |      | (Executed by PyVM) |
+--------------------+      +--------------------+      +--------------------+      +--------------------+
```

## 2. Jinja2 Delimiters & Expressions

Jinja2 utilizes four primary syntax delimiters:

| Delimiter | Purpose | Example |
| :--- | :--- | :--- |
| `{{ ... }}` | **Output Expression**: Prints evaluation result | `{{ user.username|title }}` |
| `{% ... %}` | **Control Statement**: Conditionals, loops, blocks | `{% for item in items %}` |
| `{# ... #}` | **Comment**: Stripped before HTML generation | `{# Internal Developer Note #}` |
| `{%- ... -%}` | **Whitespace Control**: Strips whitespace | `{%- if user -%}` |

## 3. Control Flow & The `loop` Context Variable

### 1. Conditionals (`if / elif / else`)
```jinja2
{% if user.is_admin %}
    <span class="badge badge-admin">Administrator</span>
{% elif user.is_moderator %}
    <span class="badge badge-mod">Moderator</span>
{% else %}
    <span class="badge badge-user">Standard User</span>
{% endif %}
```

### 2. For Loops & The `loop` Helper Variable
Inside a Jinja2 `for` loop, a special `loop` object supplies iteration metadata:

| `loop` Property | Description |
| :--- | :--- |
| `loop.index` | 1-indexed current iteration count (`1, 2, 3...`) |
| `loop.index0` | 0-indexed current iteration count (`0, 1, 2...`) |
| `loop.first` | `True` if evaluating the first item in the loop |
| `loop.last` | `True` if evaluating the last item in the loop |
| `loop.length` | Total item count in the collection |
| `loop.cycle('even', 'odd')` | Cycles through values on each iteration (useful for zebra striping tables) |

```jinja2
<ul>
{% for u in users %}
    <li class="{{ loop.cycle('row-even', 'row-odd') }}">
        #{{ loop.index }} of {{ loop.length }}: {{ u.name }}
        {% if loop.first %}(First Item){% endif %}
    </li>
{% else %}
    <li>No users found in database.</li>
{% endfor %}
</ul>
```

## 4. Built-in Filters & Custom Filter Registration

Filters transform variable outputs using the pipe `|` operator.

### Essential Built-in Filters
- `{{ text|title }}`: Capitalizes words.
- `{{ bio|striptags|truncate(50) }}`: Strips HTML tags and truncates to 50 characters.
- `{{ value|default("N/A", true) }}`: Fallback value if `value` is None or empty.
- `{{ payload|tojson }}`: Safely serializes Python dictionaries/lists to JSON strings.

### Registering Custom Jinja Filters & Tests

```python
from flask import Flask
import datetime

app = Flask(__name__)

# 1. Custom Filter using Decorator
@app.template_filter('currency')
def format_currency(value, symbol='$'):
    return f"{symbol}{value:,.2f}"

# 2. Custom Filter using Direct Assignment
def time_ago(dt):
    delta = datetime.datetime.now() - dt
    return f"{delta.days} days ago"

app.jinja_env.filters['timeago'] = time_ago

# 3. Custom Jinja Test (Used with `if var is test_name`)
@app.template_test('prime')
def is_prime(n):
    if n < 2: return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0: return False
    return True
```

In Jinja2:
```jinja2
<p>Price: {{ product.price|currency('€') }}</p>
{% if number is prime %}
    <p>{{ number }} is a prime number!</p>
{% endif %}
```

## 5. Autoescaping & XSS Security

By default, Flask configures Jinja2 to **autoescape all HTML tags** rendered inside `{{ ... }}` to mitigate Cross-Site Scripting (XSS) vulnerabilities:

- Input: `<script>alert('hack');</script>`
- Rendered HTML Output: `&lt;script&gt;alert(&#39;hack&#39;);&lt;/script&gt;`

### Overriding Autoescaping Safely
Only mark content as safe if it has been thoroughly sanitized server-side:

```python
from markupsafe import Markup

# 1. Using Markup() class in Python code
safe_html = Markup("<strong>Trusted HTML</strong>")

# 2. Using |safe filter in Jinja2 template
# {{ unsanitized_user_input|safe }}  <-- WARNING: Extreme XSS Risk!
```
