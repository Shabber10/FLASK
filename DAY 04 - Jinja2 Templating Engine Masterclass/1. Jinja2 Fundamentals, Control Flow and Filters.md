## 1. How Jinja2 Compiles Templates Under the Hood

Jinja2 is a fast and expressive templating engine. When you call `render_template('index.html')`, Jinja2 does not parse strings dynamically on every render; it compiles templates into optimized **Python bytecode**:

```
+--------------------+      +--------------------+      +--------------------+      +--------------------+
|  HTML Template     | ---> |   Jinja Lexer      | ---> |  Abstract Syntax   | ---> | Python Bytecode    |
|  (with Jinja tags) |      |   & Parser         |      |  Tree (AST)        |      | (Executed by PyVM) |
+--------------------+      +--------------------+      +--------------------+      +--------------------+
```

Because compiled bytecode is cached in memory, subsequent page renders execute at near C-speed directly in the Python Virtual Machine!

## 2. Delimiters & Whitespace Control

Jinja2 uses 4 syntax delimiters:

| Delimiter | Purpose | Example |
| :--- | :--- | :--- |
| `{{ ... }}` | **Output Expression**: Evaluates and prints value | `{{ user.username }}` |
| `{% ... %}` | **Control Statement**: Conditionals, loops, blocks | `{% for item in items %}` |
| `{# ... #}` | **Comment**: Stripped before rendering HTML | `{# Internal Note #}` |
| `{%- ... -%}` | **Whitespace Strip**: Removes surrounding spaces | `{%- if user -%}` |

## 3. Control Flow & The `loop` Helper Variable

### 1. Conditionals (`if / elif / else`)
```jinja2
{% if user.is_admin %}
    <span class="badge badge-admin">Administrator</span>
{% elif user.is_moderator %}
    <span class="badge badge-mod">Moderator</span>
{% else %}
    <span class="badge badge-user">Standard User</span>
{% endif %}
```

### 2. Loops & The `loop` Metadata Object
Inside a Jinja2 `for` loop, Jinja provides a special `loop` object containing iteration metadata:

| `loop` Property | Description | Example Output |
| :--- | :--- | :--- |
| `loop.index` | 1-indexed loop counter | `1, 2, 3...` |
| `loop.index0` | 0-indexed loop counter | `0, 1, 2...` |
| `loop.first` | `True` if evaluating the first item | `True / False` |
| `loop.last` | `True` if evaluating the last item | `True / False` |
| `loop.length` | Total item count in collection | `10` |
| `loop.cycle('even', 'odd')` | Alternates between strings per iteration | Zebra striping table rows |

```jinja2
<ul>
{% for u in users %}
    <li class="{{ loop.cycle('row-even', 'row-odd') }}">
        #{{ loop.index }} of {{ loop.length }}: {{ u.name }}
        {% if loop.first %}(First User){% endif %}
    </li>
{% else %}
    <li>No users found in database.</li>
{% endfor %}
</ul>
```

## 4. Filters & Custom Filter/Test Registration

Filters modify variable output using the pipe `|` operator.

### Essential Built-in Filters
*   `{{ text|title }}`: Capitalizes words (`"john doe"` -> `"John Doe"`).
*   `{{ bio|striptags|truncate(50) }}`: Strips HTML tags and truncates to 50 characters.
*   `{{ value|default("N/A", true) }}`: Fallback value if `value` is None or empty.
*   `{{ payload|tojson }}`: Safely converts Python dicts/lists into valid JSON strings.

### Registering Custom Jinja Filters & Tests

```python
from flask import Flask
import datetime

app = Flask(__name__)

# 1. Custom Filter using Decorator (Used as {{ price|currency('$') }})
@app.template_filter('currency')
def format_currency(value, symbol='$'):
    return f"{symbol}{value:,.2f}"

# 2. Custom Test using Decorator (Used as {% if number is prime %})
@app.template_test('prime')
def is_prime(n):
    if n < 2: return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0: return False
    return True
```

## 5. Autoescaping & XSS Security

By default, Flask configures Jinja2 to **autoescape all HTML characters** inside `{{ ... }}` to protect against Cross-Site Scripting (XSS) attacks:

*   Input string: `<script>alert('hack');</script>`
*   Rendered HTML Output: `&lt;script&gt;alert(&#39;hack&#39;);&lt;/script&gt;`

### Overriding Autoescaping Safely
Only bypass autoescaping if the content has been thoroughly sanitized server-side:

```python
from markupsafe import Markup

# Safe: Mark trusted HTML in Python code
safe_html = Markup("<strong>Trusted System Notice</strong>")
```

> ⚠️ **SECURITY WARNING**: Avoid using `{{ user_input|safe }}` in templates. If `user_input` comes from an untrusted web user, attackers can inject malicious JavaScript execution scripts!
