# Day 04: Jinja2 Templating Engine Masterclass

## 1. Jinja2 Expressions & Directives
Jinja2 compiles HTML templates into optimized Python bytecode:
- `{{ variable }}`: Evaluates and prints expression output.
- `{% statement %}`: Control flow (loops, conditionals, block definitions).
- `{# comment #}`: Internal template comments.

### Common Jinja Filters
- `{{ title|title }}`: Capitalizes words.
- `{{ items|length }}`: Returns collection length.
- `{{ user_input|striptags }}`: Sanitizes HTML tags.
- `{{ data|tojson }}`: Safely serializes data structure to JSON string.
