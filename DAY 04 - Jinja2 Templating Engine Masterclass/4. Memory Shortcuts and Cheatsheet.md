## 🔤 Jinja2 Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Template Engine** | Tool that compiles HTML blueprints with Python data. | Jinja2 |
| **Expression** | Tag evaluating and outputting a value to HTML. | `{{ user.name }}` |
| **Statement** | Tag executing control logic (if/for/block). | `{% for item in list %}` |
| **Filter** | Pipe transformation formatting output values. | `{{ name|title }}` |
| **Test** | Boolean condition checker used in `if` statements. | `{% if num is prime %}` |
| **Macro** | Reusable HTML component function accepting arguments. | `{{ render_input('email') }}` |
| **Inheritance** | Layout structure where child pages extend a master skeleton. | `{% extends "base.html" %}` |
| **Autoescaping** | Automatic conversion of HTML chars (`<`) to entity codes (`&lt;`). | Mitigates XSS attacks |

## 🧠 Memory Mnemonics

### 1. Jinja2 Syntax Delimiters (`E-S-C-W`)
Remember **E-S-C-W** for Jinja delimiters:
- **E** -> **`{{ ... }}`** (**Expression Output**: Evaluates & prints variables)
- **S** -> **`{% ... %}`** (**Statement**: Control flow, loops, blocks, imports)
- **C** -> **`{# ... #}`** (**Comment**: Stripped before HTML rendering)
- **W** -> **`{%- ... -%}`** (**Whitespace Strip**: Trims surrounding spaces)

---

### 2. Useful `loop` Helper Properties
- **`loop.index`**: 1-based index counter (`1, 2, 3...`)
- **`loop.index0`**: 0-based index counter (`0, 1, 2...`)
- **`loop.first`** / **`loop.last`**: Boolean flags for boundary checks
- **`loop.cycle('even', 'odd')`**: Alternates returning values per iteration (zebra striping)

## ⚡ Quick-Reference Code Snippets

### 1. Template Inheritance Skeleton
```jinja2
<!-- Parent (base.html) -->
<html>
<head><title>{% block title %}App{% endblock %}</title></head>
<body>
    {% block content %}{% endblock %}
</body>
</html>

<!-- Child (index.html) -->
{% extends "base.html" %}
{% block content %}
    <h1>Child Page Content</h1>
{% endblock %}
```

### 2. Custom Filter & Test Registration
```python
# Custom Filter (Used as {{ val|currency }})
@app.template_filter('currency')
def format_currency(val):
    return f"${val:,.2f}"

# Custom Test (Used as {% if val is even_num %})
@app.template_test('even_num')
def is_even(n):
    return n % 2 == 0
```

### 3. Reusable Macro Definition & Usage
```jinja2
<!-- Definition -->
{% macro btn(label, type='primary') %}
    <button class="btn btn-{{ type }}">{{ label }}</button>
{% endmacro %}

<!-- Invocation -->
{{ btn('Submit Order', 'success') }}
```
