## 🧠 Memory Mnemonics

### 1. Production Launch Checklist (`D-E-P-L-O-Y`)
Remember **D-E-P-L-O-Y** for production readiness:
- **D** -> **Disable Debug Mode** (`DEBUG = False`)
- **E** -> **Enforce HTTPS SSL Encryption** (Nginx + Let's Encrypt)
- **P** -> **Process Workers in Gunicorn** (`(2 * CPU) + 1`)
- **L** -> **Log JSON Streams to Stdout**
- **O** -> **Organize Secrets in Environment Variables** (`.env`)
- **Y** -> **Yield Health Probes** (`/healthz` & `/readyz`)

---

### 2. Dockerfile Best Practices (`D-O-C-K-E-R`)
Remember **D-O-C-K-E-R** for container security:
- **D** -> **Declare Slim Base Image** (`FROM python:3.11-slim`)
- **O** -> **Optimize Layer Caching** (Copy `requirements.txt` before code)
- **C** -> **Create Non-Root System User** (`USER appuser`)
- **K** -> **Keep Secrets Out of Images**
- **E** -> **Expose Application Port** (`EXPOSE 8000`)
- **R** -> **Run Gunicorn Command** (`CMD ["gunicorn", ...]`)

## ⚡ Quick-Reference Code Snippets

### 1. Gunicorn Startup Command
```bash
# Gunicorn with 5 workers on 2 CPU Cores
gunicorn --workers=5 --bind=0.0.0.0:8000 "app:create_app('production')"
```

### 2. Nginx Reverse Proxy Pass
```nginx
server {
    listen 80;
    server_name api.example.com;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### 3. Production Dockerfile Snippet
```dockerfile
FROM python:3.11-slim
RUN useradd -m appuser
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
USER appuser
EXPOSE 8000
CMD ["gunicorn", "--workers=4", "--bind=0.0.0.0:8000", "app:app"]
```

### 4. Kubernetes Health & Readiness Probes
```python
@app.route('/healthz')
def healthz():
    return jsonify({"status": "UP"}), 200

@app.route('/readyz')
def readyz():
    db.session.execute(text('SELECT 1'))
    return jsonify({"status": "READY"}), 200
```
