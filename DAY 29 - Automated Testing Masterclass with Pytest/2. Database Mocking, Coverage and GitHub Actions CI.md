## 1. Mocking External Services (`pytest-mock` / `unittest.mock`)

> ⚠️ **THE MOCKING RULE**: Automated tests must **NEVER** call real external third-party APIs (like Stripe, Twilio, or AWS S3) during test runs! Doing so makes tests slow, flaky, and expensive.

Use **`mocker.patch()`** to intercept external HTTP calls and substitute fake response objects:

```python
# service.py
import requests

def send_payment_charge(amount_cents, card_token):
    # Real external API call to Stripe
    response = requests.post("https://api.stripe.com/v1/charges", data={"amount": amount_cents})
    return response.json()


# test_payment_service.py
def test_payment_charge_success(mocker):
    # 1. Create a fake response object
    fake_response = mocker.Mock()
    fake_response.json.return_value = {"id": "ch_12345", "status": "succeeded"}

    # 2. Patch requests.post to return fake response instantly
    mocker.patch('requests.post', return_value=fake_response)

    # 3. Call service function (executes in 0.001s without hitting Stripe network!)
    result = send_payment_charge(5000, "tok_visa")

    assert result["status"] == "succeeded"
    assert result["id"] == "ch_12345"
```

## 2. Measuring Code Coverage (`pytest-cov`)

Install `pytest-cov`:

```bash
pip install pytest-cov
```

Run tests and generate coverage reports:

```bash
# Terminal summary output
pytest --cov=app

# HTML interactive visual coverage report
pytest --cov=app --cov-report=html
```

Open `htmlcov/index.html` in your browser to view a line-by-line highlight showing which code paths were executed and which branches were missed by tests!

## 3. GitHub Actions Continuous Integration (CI) Pipeline

Automate test execution on GitHub every time a developer pushes code or submits a Pull Request.

Create `.github/workflows/ci.yml`:

```yaml
name: Flask Automated Test Suite

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest

    services:
      redis:
        image: redis:alpine
        ports:
          - 6379:6379

    steps:
      - name: Checkout Code Repository
        uses: actions/checkout@v3

      - name: Set up Python 3.11
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'

      - name: Install Dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt
          pip install pytest pytest-cov

      - name: Execute Pytest Suite with Coverage Check
        run: |
          pytest --cov=. --cov-fail-under=80
```
