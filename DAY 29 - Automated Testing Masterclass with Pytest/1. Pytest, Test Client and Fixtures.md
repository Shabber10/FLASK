## 1. Testing Flask Apps with Pytest & Test Client
Flask provides `app.test_client()` to simulate HTTP requests without launching a live server:

```python
import pytest
from app import create_app, db

@pytest.fixture
def app():
    app = create_app('TestingConfig')
    with app.app_context():
        db.create_all()
        yield app
        db.drop_all()

@pytest.fixture
def client(app):
    return app.test_client()

def test_homepage(client):
    response = client.get('/')
    assert response.status_code == 200
```
