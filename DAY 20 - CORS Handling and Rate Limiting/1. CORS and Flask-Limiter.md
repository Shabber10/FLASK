# Day 20: CORS Handling & Rate Limiting

## 1. Cross-Origin Resource Sharing (CORS)
Browsers block cross-origin HTTP requests by default under the **Same-Origin Policy**. **Flask-CORS** configures `Access-Control-Allow-Origin` headers:

```python
from flask_cors import CORS

app = Flask(__name__)
CORS(app, resources={r"/api/*": {"origins": "https://myapp.com"}})
```

## 2. API Rate Limiting with Flask-Limiter
Prevent denial-of-service (DoS) and brute force attacks using **Flask-Limiter**:

```python
from flask_limiter import Limiter
from flask_limiter.util import get_remote_address

limiter = Limiter(get_remote_address, app=app, default_limits=["200 per day", "50 per hour"])
```
