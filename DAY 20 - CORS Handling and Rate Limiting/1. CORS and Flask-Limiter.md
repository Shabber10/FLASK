## 1. Configuring `Flask-CORS`

Install `Flask-CORS`:

```bash
pip install Flask-CORS
```

Bind CORS rules to your Flask application:

```python
from flask import Flask, jsonify
from flask_cors import CORS

app = Flask(__name__)

# Enterprise CORS Configuration: Allow specific frontend origins
CORS(app, resources={
    r"/api/*": {
        "origins": ["http://localhost:3000", "https://myapp.company.com"],
        "methods": ["GET", "POST", "PUT", "PATCH", "DELETE", "OPTIONS"],
        "allow_headers": ["Content-Type", "Authorization", "X-API-KEY"],
        "supports_credentials": True,  # Allows cookies/auth headers across domains
        "max_age": 600                 # Caches preflight OPTIONS check for 10 minutes (600s)
    }
})
```

## 2. Preflight `OPTIONS` Header Processing

When a browser makes a cross-origin request with custom headers (like `Authorization: Bearer`), `Flask-CORS` automatically intercepts the preflight `OPTIONS` HTTP request and returns:

```http
HTTP/1.1 200 OK
Access-Control-Allow-Origin: http://localhost:3000
Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS
Access-Control-Allow-Headers: Content-Type, Authorization
Access-Control-Max-Age: 600
```

## 3. Rate Limiting with `Flask-Limiter`

Install `Flask-Limiter`:

```bash
pip install Flask-Limiter
```

Initialize `Limiter` using `get_remote_address` (which tracks client IP addresses):

```python
from flask import Flask, jsonify
from flask_limiter import Limiter
from flask_limiter.util import get_remote_address

app = Flask(__name__)

# Initialize Limiter with global default limits
limiter = Limiter(
    key_func=get_remote_address,
    app=app,
    default_limits=["1000 per day", "100 per hour"]
)

# 1. Endpoint with default rate limits
@app.route('/api/v1/products')
def get_products():
    return jsonify({"data": "Product list"})

# 2. Endpoint with strict custom rate limits
@app.route('/api/v1/auth/login', methods=['POST'])
@limiter.limit("5 per minute")  # Prevents brute-force password guessing!
def login():
    return jsonify({"message": "Login attempt"})

# 3. Exempt specific endpoints from rate limits
@app.route('/api/v1/health')
@limiter.exempt
def health_check():
    return jsonify({"status": "healthy"})
```

## 4. Handling `HTTP 429 Too Many Requests`

Customize the JSON error response returned when a client exceeds their rate limit:

```python
@app.errorhandler(429)
def ratelimit_handler(e):
    return jsonify({
        "error": {
            "code": 429,
            "type": "TOO_MANY_REQUESTS",
            "message": f"Rate limit exceeded: {e.description}",
            "retry_after": e.retry_after
        }
    }), 429
```
