## 🔤 CORS & Rate Limiting Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **SOP** | Same-Origin Policy (Browser security rule blocking cross-domain JS requests). | Browser blocking `localhost:3000` from calling `localhost:5000` |
| **CORS** | Cross-Origin Resource Sharing (Server headers allowing cross-domain requests). | `Access-Control-Allow-Origin: http://localhost:3000` |
| **Preflight Request** | Automatic `OPTIONS` request sent by browser before complex API calls. | Browser asking server permission |
| **Rate Limiting** | Restricting the maximum number of requests a client can make per time window. | Max 10 requests per minute |
| **`HTTP 429`** | Status code returned when a client exceeds their rate limit limit. | `429 Too Many Requests` |
| **`get_remote_address`** | Default Limiter key function tracking client IP addresses. | `key_func=get_remote_address` |
| **Redis Storage** | Shared memory cache storing rate limit counters across WSGI workers. | `storage_uri="redis://localhost:6379"` |

## 🧠 Memory Mnemonics

### 1. CORS Configuration Steps (`C-O-R-S`)
Remember **C-O-R-S** for cross-origin setups:
- **C** -> **Check Origin Domain** (`origins=["http://localhost:3000"]`)
- **O** -> **OPTIONS Preflight Handling** (`methods=["GET", "POST", "OPTIONS"]`)
- **R** -> **Request Headers Permitted** (`allow_headers=["Authorization", "Content-Type"]`)
- **S** -> **Supports Credentials** (`supports_credentials=True`)

---

### 2. Rate Limiting Lifecycle (`L-I-M-I-T`)
Remember **L-I-M-I-T** for rate limit enforcement:
- **L** -> **Listen to Key Function** (`get_remote_address` or `X-API-KEY`)
- **I** -> **Identify Client IP / Key**
- **M** -> **Measure Trailing Window Counter** (Calculate request count in 60s)
- **I** -> **Intercept Over-limit Traffic**
- **T** -> **Throw 429 Exception** (`@app.errorhandler(429)`)

## ⚡ Quick-Reference Code Snippets

### 1. Flask-CORS Configuration
```python
from flask_cors import CORS

CORS(app, resources={
    r"/api/*": {
        "origins": ["http://localhost:3000"],
        "methods": ["GET", "POST", "PUT", "DELETE", "OPTIONS"],
        "allow_headers": ["Authorization", "Content-Type"],
        "supports_credentials": True,
        "max_age": 600
    }
})
```

### 2. Flask-Limiter & Route Protection
```python
from flask_limiter import Limiter
from flask_limiter.util import get_remote_address

limiter = Limiter(
    key_func=get_remote_address,
    app=app,
    default_limits=["1000 per day", "100 per hour"]
)

# Route specific limit
@app.route('/login', methods=['POST'])
@limiter.limit("3 per minute")
def login():
    return jsonify({"message": "Attempt logged"})

# Route exemption
@app.route('/health')
@limiter.exempt
def health():
    return jsonify({"status": "healthy"})
```

### 3. Custom HTTP 429 Error Handler
```python
@app.errorhandler(429)
def ratelimit_handler(e):
    return jsonify({
        "error": {
            "code": 429,
            "type": "TOO_MANY_REQUESTS",
            "message": "Rate limit exceeded. Please try again later."
        }
    }), 429
```
