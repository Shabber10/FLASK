## 1. Profiling CPU Execution with Werkzeug `ProfilerMiddleware`

Werkzeug provides built-in WSGI middleware that profiles every incoming request using Python's standard `cProfile` module:

```python
from flask import Flask
from werkzeug.middleware.profiler import ProfilerMiddleware

app = Flask(__name__)

# Attach Profiler Middleware in Development/Staging
app.wsgi_app = ProfilerMiddleware(
    app.wsgi_app,
    restrictions=[30],               # Show top 30 slowest functions
    profile_dir='./profiler_logs'     # Save raw .prof files for visualization
)

@app.route('/heavy-calculation')
def heavy_calc():
    total = sum(i * i for i in range(5000000))
    return jsonify({"result": total})
```

When a request arrives, the terminal prints a `cProfile` breakdown table:

```
ncalls  tottime  percall  cumtime  percall filename:lineno(function)
     1    0.350    0.350    0.350    0.350 app.py:12(heavy_calc)
     1    0.120    0.120    0.120    0.120 {built-in method sum}
```

## 2. SQLAlchemy Slow Query Event Listener

Inject custom event listeners onto the SQLAlchemy database engine to intercept and log queries exceeding a target latency threshold (e.g. > 200 ms):

```python
import time
from sqlalchemy import event
from sqlalchemy.engine import Engine
from flask import app

# 1. Capture query start timestamp
@event.listens_for(Engine, "before_cursor_execute")
def before_cursor_execute(conn, cursor, statement, parameters, context, execmany):
    conn.info.setdefault('query_start_time', []).append(time.time())

# 2. Calculate query duration upon completion
@event.listens_for(Engine, "after_cursor_execute")
def after_cursor_execute(conn, cursor, statement, parameters, context, execmany):
    total_time = time.time() - conn.info['query_start_time'].pop()
    
    # Trigger Warning Log for Slow Queries (> 0.20 seconds)
    if total_time > 0.20:
        print(f"⚠️ [SLOW QUERY WARNING] Execution Time: {total_time:.3f}s\nSQL: {statement}\nParams: {parameters}\n")
```

## 3. Auditing Memory Leaks with `tracemalloc`

Detect Python memory leaks and track memory allocation spikes using Python's built-in `tracemalloc` module:

```python
import tracemalloc
from flask import Flask, jsonify

app = Flask(__name__)

# Start tracking memory allocations
tracemalloc.start()

@app.route('/api/v1/memory-stats')
def memory_stats():
    snapshot = tracemalloc.take_snapshot()
    top_stats = snapshot.statistics('lineno')
    
    top_allocations = []
    for stat in top_stats[:5]:  # Top 5 memory hogging lines
        top_allocations.append({
            "size_kb": round(stat.size / 1024, 2),
            "count": stat.count,
            "trace": str(stat.traceback)
        })
        
    return jsonify({
        "status": "success",
        "top_memory_allocations": top_allocations
    })
```
