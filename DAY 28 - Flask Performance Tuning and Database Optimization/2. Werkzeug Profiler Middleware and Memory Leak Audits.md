# Day 28: Database Query Profiling

## 1. SQLAlchemy Query Execution Time Auditing
Inspect slow queries using SQLAlchemy event listeners:

```python
from sqlalchemy import event
from sqlalchemy.engine import Engine
import time

@event.listens_for(Engine, "before_cursor_execute")
def before_cursor_execute(conn, cursor, statement, parameters, context, execmany):
    conn.info.setdefault('query_start_time', []).append(time.time())

@event.listens_for(Engine, "after_cursor_execute")
def after_cursor_execute(conn, cursor, statement, parameters, context, execmany):
    total = time.time() - conn.info['query_start_time'].pop()
    if total > 0.5:
        print(f"SLOW QUERY ({total:.2f}s): {statement}")
```
