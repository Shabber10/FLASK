# Day 28: Flask Performance Tuning & Optimization

## 1. Response Compression with Flask-Compress
Compress HTTP responses using Gzip to minimize network payload sizes:

```python
from flask_compress import Compress

Compress(app)
```

## 2. Profiling Flask Apps with Werkzeug Profiler
Use `ProfilerMiddleware` to identify cpu-bound view bottlenecks:

```python
from werkzeug.middleware.profiler import ProfilerMiddleware

app.wsgi_app = ProfilerMiddleware(app.wsgi_app, restrictions=[30])
```
