## 1. Resolving N+1 Queries with `joinedload` & `selectinload`

When querying parent models that reference child relationships, instruct SQLAlchemy to eager load them:

```python
from flask import Flask, jsonify
from sqlalchemy.orm import joinedload, selectinload
from models import db, Author, Book

# ❌ UNOPTIMIZED: Causes 101 Database Queries! (N+1 Trap)
@app.route('/api/v1/unoptimized-authors')
def get_authors_slow():
    authors = Author.query.all()
    result = []
    for author in authors:
        # Accessing author.books triggers a NEW SELECT query per author!
        books_list = [b.title for b in author.books]
        result.append({"author": author.name, "books": books_list})
    return jsonify(result)

# ✅ OPTIMIZED: Executed in 1 SINGLE SQL JOIN Query!
@app.route('/api/v1/optimized-authors')
def get_authors_fast():
    # joinedload performs SQL LEFT OUTER JOIN instantly
    authors = Author.query.options(joinedload(Author.books)).all()
    result = []
    for author in authors:
        books_list = [b.title for b in author.books]
        result.append({"author": author.name, "books": books_list})
    return jsonify(result)
```

### When to use `joinedload` vs `selectinload`:
*   **`joinedload()`**: Best for One-to-One and Many-to-One relationships (uses SQL `JOIN`).
*   **`selectinload()`**: Best for One-to-Many and Many-to-Many relationships with large datasets (uses an efficient SQL `IN (...)` query).

## 2. Database Connection Pool Tuning

Database connections are expensive to open and close. Flask-SQLAlchemy uses connection pooling to reuse database sockets:

```python
app.config['SQLALCHEMY_ENGINE_OPTIONS'] = {
    'pool_size': 10,         # Maintain 10 persistent open connections
    'max_overflow': 20,      # Allow up to 20 temporary extra connections under load
    'pool_recycle': 1800,    # Recycle connections every 30 minutes to prevent stale timeouts
    'pool_pre_ping': True    # Tests connection health before handing to worker
}
```

## 3. HTTP Response Compression (`Flask-Compress`)

Install `Flask-Compress`:

```bash
pip install Flask-Compress
```

Initialize `Compress(app)` to transparently compress all JSON and text responses:

```python
from flask_compress import Compress

app = Flask(__name__)

# Configurable minimum size threshold (e.g. compress responses > 500 bytes)
app.config['COMPRESS_MIN_SIZE'] = 500
Compress(app)
```

Browser responses will automatically include `Content-Encoding: gzip`, reducing payload sizes by up to 80%!

## 4. Query Pagination (`paginate`)

Never run `.all()` on tables containing thousands of records. Always paginate database queries:

```python
@app.route('/api/v1/products')
def get_products():
    page = request.args.get('page', 1, type=int)
    per_page = request.args.get('per_page', 20, type=int)
    
    pagination = Product.query.order_by(Product.id.asc()).paginate(
        page=page, per_page=per_page, error_out=False
    )
    
    return jsonify({
        "products": [p.to_dict() for p in pagination.items],
        "total_items": pagination.total,
        "total_pages": pagination.pages,
        "current_page": page
    })
```
