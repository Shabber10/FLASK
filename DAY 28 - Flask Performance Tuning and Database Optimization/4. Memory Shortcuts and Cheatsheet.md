## 🔤 Performance Tuning Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **N+1 Query Problem** | Performance bug where 1 query for N items triggers N additional SQL queries in a loop. | 100 posts causing 101 SQL queries |
| **Lazy Loading** | Default ORM behavior loading child relationships only when accessed. | `post.author` (triggers SQL on access) |
| **Eager Loading** | Instructing ORM to fetch parent and child records in 1 single JOIN query. | `query.options(joinedload(Post.author))` |
| **`joinedload()`** | SQLAlchemy eager loading strategy using SQL `JOIN`. | Best for 1-to-1 / Many-to-1 |
| **`selectinload()`** | SQLAlchemy eager loading strategy using SQL `IN (...)`. | Best for 1-to-Many / Many-to-Many |
| **`Flask-Compress`** | Extension zipping HTTP response payloads with Gzip on the fly. | `Compress(app)` |
| **`ProfilerMiddleware`** | Werkzeug WSGI middleware profiling CPU function execution times. | `app.wsgi_app = ProfilerMiddleware(...)` |
| **`tracemalloc`** | Python standard library module tracking memory allocations to find leaks. | `tracemalloc.take_snapshot()` |
| **Query Listener** | SQLAlchemy engine event hook timing SQL cursor execution durations. | `@event.listens_for(Engine, "after_cursor_execute")` |

## 🧠 Memory Mnemonics

### 1. Application Performance Optimization (`S-P-E-E-D`)
Remember **S-P-E-E-D** for high-throughput Flask APIs:
- **S** -> **Single JOIN Query** (Eliminate N+1 queries)
- **P** -> **Paginate Large Datasets** (`paginate(page=1, per_page=20)`)
- **E** -> **Enable Gzip Compression** (`Flask-Compress`)
- **E** -> **Eager Load Relationships** (`joinedload()`)
- **D** -> **Disable Debug Mode in Production** (`debug=False`)

---

### 2. Database Query Optimization (`E-A-G-E-R`)
Remember **E-A-G-E-R** for database tuning:
- **E** -> **Eliminate N+1 Query Traps**
- **A** -> **Attach `joinedload()` Options**
- **G** -> **Group Queries Efficiently**
- **E** -> **Evaluate Execution Timings** (Event listeners)
- **R** -> **Recycle Stale Connections** (`pool_recycle=1800`)

## ⚡ Quick-Reference Code Snippets

### 1. SQLAlchemy Eager Loading
```python
from sqlalchemy.orm import joinedload, selectinload

# Left Outer Join (1-to-1 or Many-to-1)
users = User.query.options(joinedload(User.profile)).all()

# SQL IN (...) Clause (1-to-Many)
authors = Author.query.options(selectinload(Author.books)).all()
```

### 2. Response Payload Compression
```python
from flask_compress import Compress

app = Flask(__name__)
app.config['COMPRESS_MIN_SIZE'] = 500
Compress(app)
```

### 3. CPU Execution Profiler
```python
from werkzeug.middleware.profiler import ProfilerMiddleware

app.wsgi_app = ProfilerMiddleware(
    app.wsgi_app,
    restrictions=[30],
    profile_dir='./profiler_logs'
)
```

### 4. Database Slow Query Logger Listener
```python
from sqlalchemy import event
from sqlalchemy.engine import Engine
import time

@event.listens_for(Engine, "before_cursor_execute")
def start_timer(conn, cursor, statement, parameters, context, execmany):
    conn.info.setdefault('start', []).append(time.time())

@event.listens_for(Engine, "after_cursor_execute")
def stop_timer(conn, cursor, statement, parameters, context, execmany):
    duration = time.time() - conn.info['start'].pop()
    if duration > 0.2:
        print(f"SLOW QUERY ({duration:.2f}s): {statement}")
```
