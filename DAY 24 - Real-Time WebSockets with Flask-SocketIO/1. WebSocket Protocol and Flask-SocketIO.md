## 1. The WebSocket Protocol Handshake (`HTTP 101`)

A WebSocket connection begins as a standard HTTP request containing an **Upgrade** header:

```http
GET /socket.io/?EIO=4&transport=websocket HTTP/1.1
Host: localhost:5000
Upgrade: websocket
Connection: Upgrade
Sec-WebSocket-Key: dGhlIHNhbXBsZSBub25jZQ==
```

If the server supports WebSockets, it responds with **`HTTP 101 Switching Protocols`**:

```http
HTTP/1.1 101 Switching Protocols
Upgrade: websocket
Connection: Upgrade
Sec-WebSocket-Accept: s3pPLMBiTxaQ9kYGzzhZRbK+xOo=
```

From this moment on, the HTTP protocol is dropped, and the raw TCP socket remains open for bi-directional binary/text frames!

## 2. Initializing `Flask-SocketIO`

Install the extension:

```bash
pip install Flask-SocketIO
```

Initialize `SocketIO` on your Flask application:

```python
from flask import Flask
from flask_socketio import SocketIO

app = Flask(__name__)
app.config['SECRET_KEY'] = 'socketio-masterclass-secret'

# Initialize SocketIO with CORS permissions
socketio = SocketIO(app, cors_allowed_origins="*")
```

## 3. Registering Event Handlers (`@socketio.on`)

Define handlers for built-in events (`connect`, `disconnect`) and custom events:

```python
from flask import request
from flask_socketio import emit

# Built-in Event: Connection established
@socketio.on('connect')
def handle_connect():
    client_sid = request.sid  # Unique Socket ID assigned to client
    print(f"🔌 [CONNECTED] Client connected with SID: {client_sid}")
    emit('server_response', {'data': f'Welcome! Connected as SID {client_sid}'})

# Built-in Event: Client disconnected
@socketio.on('disconnect')
def handle_disconnect():
    print(f"❌ [DISCONNECTED] Client SID {request.sid} disconnected.")

# Custom Event: Handle incoming chat message
@socketio.on('send_chat_message')
def handle_chat_message(data):
    user_name = data.get('username', 'Anonymous')
    text = data.get('message', '')
    
    # Broadcast message to ALL connected clients!
    emit('receive_chat_message', {
        'username': user_name,
        'message': text,
        'timestamp': data.get('timestamp')
    }, broadcast=True)
```

## 4. Launching the App with `socketio.run`

Standard `app.run()` does not support persistent WebSocket event loops. **Always launch your app using `socketio.run(app)`**:

```python
if __name__ == '__main__':
    print("🚀 Starting Flask-SocketIO Real-Time Server...")
    socketio.run(app, host='127.0.0.1', port=5000, debug=True)
```
