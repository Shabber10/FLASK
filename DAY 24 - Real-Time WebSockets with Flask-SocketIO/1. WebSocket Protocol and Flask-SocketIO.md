# Day 24: Real-Time WebSockets with Flask-SocketIO

## 1. WebSockets vs HTTP Polling
Unlike HTTP's request-response pattern, **WebSockets** provide persistent, bi-directional, full-duplex communication over a single TCP socket connection.

```python
from flask_socketio import SocketIO, emit

socketio = SocketIO(app, cors_allowed_origins="*")

@socketio.on('message')
def handle_message(data):
    emit('response', {'data': data}, broadcast=True)
```
