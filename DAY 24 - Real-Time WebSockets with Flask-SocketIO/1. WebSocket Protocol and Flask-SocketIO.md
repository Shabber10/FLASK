## 1. The WebSocket Protocol Handshake (`HTTP 101`)

A WebSocket connection begins as a standard HTTP request containing an **Upgrade** header:

```http
GET /socket.io/?EIO=4&transport=websocket HTTP/1.1
Host: localhost:5000
Upgrade: websocket
Connection: Upgrade
Sec-WebSocket-Key: dGhlIHNhbXBsZSBub25jZQ==
```

If the server supports WebSockets, it responds with **`HTTP 101 Switching Protocols`**:

```http
HTTP/1.1 101 Switching Protocols
Upgrade: websocket
Connection: Upgrade
Sec-WebSocket-Accept: s3pPLMBiTxaQ9kYGzzhZRbK+xOo=
```

From this moment on, the HTTP protocol is dropped, and the raw TCP socket remains open for bi-directional binary/text frames!

#### ⚖️ Standard HTTP Protocol vs WebSocket Persistent Protocol

| Protocol Characteristic | Standard HTTP/1.1 Protocol | Persistent WebSocket Protocol |
| :--- | :--- | :--- |
| **Communication Flow** | ✉️ Half-Duplex (Client requests, Server responds) | 📡 Full-Duplex (Client & Server push simultaneously) |
| **Connection Lifespan** | Ephemeral (Opens per request, closes on response) | Persistent (Single TCP socket connection stays open) |
| **Header Overhead** | High (Sends 500+ bytes of HTTP headers per request) | Tiny (Sends 2 to 10 bytes frame overhead after handshake) |
| **Server Initiative** | 🛑 Server CANNOT send data unless Client asks | ✅ Server pushes instant real-time events anytime |
| **Ideal Use Cases** | Page rendering, REST APIs, form submissions | Live Chat, Trading Tickers, Multiplayer Gaming |

## 2. Initializing `Flask-SocketIO`

Install the extension:

```bash
pip install Flask-SocketIO
```

Initialize `SocketIO` on your Flask application:

```python
from flask import Flask
from flask_socketio import SocketIO

app = Flask(__name__)
app.config['SECRET_KEY'] = 'socketio-masterclass-secret'

# Initialize SocketIO with CORS permissions
socketio = SocketIO(app, cors_allowed_origins="*")
```

## 3. Securing WebSockets with JWT Authentication on Connect

### ❓ Security Challenge:
Anyone with a network connection can attempt to open a WebSocket connection. You must authenticate the client during the `connect` handshake and reject unauthorized connections!

### 💻 Code Example: Intercepting JWT Tokens on Connect

```python
import jwt
from flask import request
from flask_socketio import ConnectionRefusedError, emit

JWT_SECRET = "jwt-secret-key-32bytes"

@socketio.on('connect')
def handle_authenticated_connect(auth):
    """
    Client passes auth payload during handshake:
    const socket = io({ auth: { token: "Bearer eyJhbGciOi..." } });
    """
    token = None
    if auth and isinstance(auth, dict):
        raw_token = auth.get('token', '')
        if raw_token.startswith('Bearer '):
            token = raw_token.split(' ')[1]
        else:
            token = raw_token

    if not token:
        # Reject connection immediately with ConnectionRefusedError
        raise ConnectionRefusedError("Authentication token is missing.")

    try:
        # Decode and verify JWT signature and expiration
        payload = jwt.decode(token, JWT_SECRET, algorithms=["HS256"])
        user_id = payload.get('sub')
        
        # Save user identity to the socket session
        print(f"✅ Authenticated User #{user_id} on Socket ID {request.sid}")
        emit('authenticated', {"message": f"Connected as User {user_id}"})
        
    except jwt.ExpiredSignatureError:
        raise ConnectionRefusedError("Token has expired.")
    except jwt.InvalidTokenError:
        raise ConnectionRefusedError("Invalid authentication token.")
```

## 4. Registering Event Handlers & Broadcasting

```python
# Built-in Event: Client disconnected
@socketio.on('disconnect')
def handle_disconnect():
    print(f"❌ [DISCONNECTED] Client SID {request.sid} disconnected.")

# Custom Event: Handle incoming chat message
@socketio.on('send_chat_message')
def handle_chat_message(data):
    user_name = data.get('username', 'Anonymous')
    text = data.get('message', '')
    
    # Broadcast message to ALL connected clients!
    emit('receive_chat_message', {
        'username': user_name,
        'message': text,
        'timestamp': data.get('timestamp')
    }, broadcast=True)
```

## 5. Launching the App with `socketio.run`

Standard `app.run()` does not support persistent WebSocket event loops. **Always launch your app using `socketio.run(app)`**:

```python
if __name__ == '__main__':
    print("🚀 Starting Flask-SocketIO Real-Time Server...")
    socketio.run(app, host='127.0.0.1', port=5000, debug=True)
```
