# Day 24: Rooms & Multi-Node Scaling with Redis

## 1. Rooms & Namespaces
Group clients into channels using `join_room(room_name)` and `leave_room(room_name)`:

```python
@socketio.on('join')
def on_join(data):
    room = data['room']
    join_room(room)
    emit('status', {'msg': f"User joined room {room}"}, to=room)
```
