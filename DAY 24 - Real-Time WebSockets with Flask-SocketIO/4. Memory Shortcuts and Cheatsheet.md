## 🔤 Real-Time WebSockets Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **WebSocket** | Persistent, bi-directional, full-duplex TCP protocol. | Two-way walkie-talkie connection |
| **`HTTP 101`** | Handshake status code upgrading HTTP to WebSocket. | `101 Switching Protocols` |
| **Event** | Custom named message exchanged between server and client. | `@socketio.on('chat_msg')` |
| **`emit()`** | Function sending an event and data payload to clients. | `emit('response', data, to=room)` |
| **Room** | Virtual channel grouping connected socket SIDs. | `join_room('Tech-Support')` |
| **Namespace** | Multiplexing separate socket channels on distinct URL paths. | `Namespace('/admin')` |
| **`broadcast=True`** | Emits an event to all connected clients across server. | Global system notifications |
| **`message_queue`** | Redis Pub/Sub backend scaling sockets across WSGI workers. | `message_queue='redis://...'` |

## 🧠 Memory Mnemonics

### 1. WebSocket Features (`W-A-L-K-I-E`)
Remember **W-A-L-K-I-E** for two-way socket communication:
- **W** -> **Walkie-Talkie Bi-Directional** (Push messages anytime)
- **A** -> **Always-Open Persistent TCP Connection**
- **L** -> **Listen with `@socketio.on()`**
- **K** -> **Key Event Handlers** (`connect`, `disconnect`, custom events)
- **I** -> **Instant Sub-Millisecond Latency**
- **E** -> **Emit Payload** (`emit('custom_event', payload)`)

---

### 2. Multi-Room Channels (`R-O-O-M-S`)
Remember **R-O-O-M-S** for channel management:
- **R** -> **Receive Join Event** (`@socketio.on('join')`)
- **O** -> **Organize SID into Channel** (`join_room(room_name)`)
- **O** -> **Outbound Targeted Emission** (`emit('msg', payload, to=room_name)`)
- **M** -> **Manage Room Exit** (`leave_room(room_name)`)
- **S** -> **Separate Room Traffic**

### 1. Flask-SocketIO Server Initialization
```python
from flask import Flask
from flask_socketio import SocketIO, emit, join_room, leave_room

app = Flask(__name__)
socketio = SocketIO(app, cors_allowed_origins="*")

# Handshake connection
@socketio.on('connect')

# Room joining & emitting
@socketio.on('join')
def on_join(data):
    room = data['room']
    join_room(room)
    emit('status', {'msg': f"Joined room {room}"}, to=room)

# Start server
if __name__ == '__main__':
    socketio.run(app, debug=True)
```

### 2. Client-Side Browser JavaScript (Socket.IO)
```html
<script src="https://cdn.socket.io/4.7.2/socket.io.min.js"></script>
<script>
    const socket = io();
    
    // Connect listener
    socket.on('connect', () => {
        socket.emit('join', { room: 'Lobby', username: 'Alice' });
    });
    
    // Listen for custom event
    socket.on('status', (data) => {
        console.log(data.msg);
    });
</script>
```
