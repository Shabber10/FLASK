# Day 11: Blueprint Subdomains & Layout Isolation

## 1. Registering Blueprints with Main App
```python
from flask import Flask
from auth import auth_bp

app = Flask(__name__)
app.register_blueprint(auth_bp)
```

## 2. Blueprint Subdomains & Static Folders
Blueprints can be bound to specific subdomains (`subdomain='admin'`) or isolate dedicated `static` and `template` folders.
