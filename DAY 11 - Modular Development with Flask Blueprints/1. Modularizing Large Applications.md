# Day 11: Modular Development with Flask Blueprints

## 1. What is a Flask Blueprint?
A **Blueprint** is a template for creating application components, routes, templates, and static assets in a modular, decoupled architecture.

```python
from flask import Blueprint

auth_bp = Blueprint('auth', __name__, url_prefix='/auth', template_folder='templates')

@auth_bp.route('/login')
def login():
    return "Login Page"
```
