## 🔤 Blueprints & Modular Architecture Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Blueprint** | Sub-module container holding routes, templates, and static assets. | `auth_bp = Blueprint('auth', __name__)` |
| **`url_prefix`** | Common base URL prepended to all routes in a blueprint. | `url_prefix='/auth'` |
| **Namespacing** | Prefixing route names with blueprint name to prevent route collisions. | `url_for('auth.login')` |
| **Subdomain** | Binding a blueprint to a specific domain prefix. | `Blueprint('admin', __name__, subdomain='admin')` |
| **Asset Isolation** | Setting dedicated template and static folders per blueprint. | `template_folder='templates'` |
| **Nested Blueprint** | Registering a child blueprint inside a parent blueprint. | `api_bp.register_blueprint(v1_bp)` |
| **`@bp.before_request`** | Hook executing ONLY for routes inside that specific blueprint. | `@auth_bp.before_request` |

---

## 🧠 Memory Mnemonics

### Blueprint Lifecycle Steps (`R-E-G-I-S-T-E-R`)
Remember **R-E-G-I-S-T-E-R** for building modular blueprints:
- **R** -> **Request Blueprint Object** (`auth_bp = Blueprint('auth', __name__)`)
- **E** -> **Establish URL Prefix** (`url_prefix='/auth'`)
- **G** -> **Group Related Routes** (`@auth_bp.route('/login')`)
- **I** -> **Isolate Template/Static Folders** (Set `template_folder='templates/auth'`)
- **S** -> **Set Dedicated Request Hooks** (`@auth_bp.before_request`)
- **T** -> **Target with `url_for`** (`url_for('auth.login')`)
- **E** -> **Execute Registration on App** (`app.register_blueprint(auth_bp)`)
- **R** -> **Run Main Application** (`app.run()`)

## ⚡ Quick-Reference Code Snippets

### 1. Defining & Registering a Blueprint
```python
from flask import Flask, Blueprint

# 1. Instantiate Blueprint
auth_bp = Blueprint('auth', __name__, url_prefix='/auth')

@auth_bp.route('/login')
def login():
    return "Login Form"

# 2. Register on Main App
app = Flask(__name__)
app.register_blueprint(auth_bp)
```

### 2. Cross-Blueprint `url_for()` References
```python
# Route to view function in SAME blueprint (relative dot prefix)
url_for('.login')

# Route to view function in DIFFERENT blueprint (absolute blueprint.endpoint)
url_for('auth.login')

# Reference static assets inside a blueprint
url_for('auth.static', filename='css/style.css')
```

### 3. Blueprint Subdomain & Nested Registration
```python
# Subdomain Blueprint
admin_bp = Blueprint('admin', __name__, subdomain='admin')

# Nested Blueprints (Flask 2.0+)
api_bp = Blueprint('api', __name__, url_prefix='/api')
v1_bp = Blueprint('v1', __name__, url_prefix='/v1')

api_bp.register_blueprint(v1_bp)  # Final URL: /api/v1/...
app.register_blueprint(api_bp)
```
