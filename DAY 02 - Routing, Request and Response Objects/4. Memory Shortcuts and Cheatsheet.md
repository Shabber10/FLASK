## 🧠 Memory Mnemonics

### 1. Built-in URL Converters
Remember **S-I-F-P-U-A** for Flask path converters:
- **S**: **`string`** (Default text without `/`)
- **I**: **`int`** (Positive integers)
- **F**: **`float`** (Floating-point numbers)
- **P**: **`path`** (Strings containing slashes `/`)
- **U**: **`uuid`** (Standard 36-char UUID format)
- **A**: **`any`** (Matches explicitly listed values `any(a, b)`)

---

### 2. Request Data Sources
Remember **A-F-J-H-F** for `request` attributes:
- **A**: `request.args` (Query parameters `?key=val`)
- **F**: `request.form` (POST form payloads)
- **J**: `request.json` / `request.get_json()` (JSON body)
- **H**: `request.headers` (HTTP headers dict)
- **F**: `request.files` (Uploaded files `FileStorage`)

## ⚡ Quick-Reference Code Snippets

### 1. Registering Custom Regex Converter
```python
from werkzeug.routing import BaseConverter

class RegexConverter(BaseConverter):
    def __init__(self, url_map, *items):
        super().__init__(url_map)
        self.regex = items[0]

app.url_map.converters['regex'] = RegexConverter

@app.route('/item/<regex(r"[A-Z]{3}-\d+"):code>')
def get_item(code):
    return f"Code: {code}"
```

### 2. URL Building with `url_for()`
```python
# Query parameters automatically appended for unmapped kwargs
url = url_for('search', query='flask', page=2, _external=True)
# Output: "http://localhost:5000/search?query=flask&page=2"
```

### 3. Creating Custom Responses with Cookies
```python
from flask import make_response, jsonify

resp = make_response(jsonify(status="success"), 201)
resp.headers['X-Custom-Header'] = 'Value'
resp.set_cookie('token', 'secret123', httponly=True, secure=True, samesite='Lax')
return resp
```
