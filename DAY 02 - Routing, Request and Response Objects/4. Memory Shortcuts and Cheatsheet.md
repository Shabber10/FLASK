## 🔤 Routing & Request Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **URL Route** | The pattern rule mapped to a Python function. | `@app.route('/user/<id>')` |
| **View Function** | The Python function executed when a route matches. | `def user_profile(id):` |
| **Path Parameter** | Variable embedded directly inside the URL path. | `/user/42` |
| **Query Parameter** | Key-value pairs appended after a `?` in the URL. | `/search?q=flask&page=2` |
| **HTTP Verb** | The action requested by the client. | `GET`, `POST`, `PUT`, `DELETE` |
| **HTTP Header** | Metadata key-value pair sent alongside requests/responses. | `Content-Type: application/json` |
| **HTTP Cookie** | Small key-value text saved by browser to track sessions. | `session_token=xyz123` |

## 🧠 Memory Mnemonics

### 1. Built-in URL Converters (`S-I-F-P-U-A`)
Remember **S-I-F-P-U-A** for Flask path converters:
- **S** -> **`string`** (Default text without slashes `/`)
- **I** -> **`int`** (Positive integers)
- **F** -> **`float`** (Floating-point numbers)
- **P** -> **`path`** (Strings containing slashes `/`)
- **U** -> **`uuid`** (Standard 36-character UUID format)
- **A** -> **`any`** (Matches explicitly listed values `any(about, contact)`)

---

### 2. Request Data Attributes (`A-F-J-H-F`)
Remember **A-F-J-H-F** for `request` attributes:
- **A** -> `request.args` (Query parameters `?key=val`)
- **F** -> `request.form` (POST form payloads)
- **J** -> `request.json` / `request.get_json()` (JSON body)
- **H** -> `request.headers` (HTTP headers dictionary)
- **F** -> `request.files` (Uploaded files `FileStorage`)

## ⚡ Quick-Reference Code Snippets

### 1. Registering Custom Regex Converter
```python
from werkzeug.routing import BaseConverter

class RegexConverter(BaseConverter):
    def __init__(self, url_map, *items):
        super().__init__(url_map)
        self.regex = items[0]

app.url_map.converters['regex'] = RegexConverter

@app.route('/item/<regex(r"[A-Z]{3}-\d+"):code>')
def get_item(code):
    return f"Item Code: {code}"
```

### 2. Dynamic URL Building with `url_for()`
```python
from flask import url_for

# Unmapped keyword arguments automatically become query string parameters
url = url_for('search', q='flask', page=2, _external=True)
# Output: "http://127.0.0.1:5000/search?q=flask&page=2"
```

### 3. Custom Response with Headers & Secure Cookies
```python
from flask import make_response, jsonify

resp = make_response(jsonify(status="success"), 201)
resp.headers['X-Custom-Header'] = 'Active'
resp.set_cookie('token', 'secret123', httponly=True, secure=True, samesite='Lax')
return resp
```

### 4. Redirection: Hardcoded vs Dynamic `url_for()`
```python
from flask import redirect, url_for, abort

# ❌ Hardcoded Redirect (Fragile! Breaks if URL path changes):
return redirect('/admin')

# ✅ Dynamic Redirect (Best Practice! Binds to Python view function name 'admin'):
return redirect(url_for('admin'))

# Dynamic Redirect with Parameters:
return redirect(url_for('user', name='shabber'))  # Redirects to /user/shabber

# Aborting with HTTP error status code:
abort(403, description="Forbidden")
```
