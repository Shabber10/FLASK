## 1. What is URL Routing?

In Flask, **Routing** maps a specific URL path typed into the browser (e.g., `/getstudents` or `/register`) to a specific Python Python function (called a **View Function** or **Route Handler**).

```python
@app.route('/home')
def Home():
    return "Welcome to Home Page"
```

---

## 2. What are URL Converters? (Class Notes Core Concept)

**Definition**: URL converters are used inside a route decorator to specify what type of dynamic variable Flask should expect from the URL. They automatically extract and type-cast the URL fragment into a Python variable!

### 📌 Basic Syntax
```python
@app.route('/route/<converter:variable_name>')
def function_name(variable_name):
    # variable_name is automatically converted to the specified type!
    return ...
```

## 3. Complete Flask Built-in URL Converters Table

| Converter | Accepted Data Type | Example Route | Matching URL Example | Non-Matching URL (Yields 404) |
| :--- | :--- | :--- | :--- | :--- |
| **`string`** *(Default)* | Any text without slashes `/` | `@app.route('/user/<string:name>')` | `/user/john` | `/user/john/doe` (has slash) |
| **`int`** | Positive integers only | `@app.route('/student/<int:sid>')` | `/student/101` | `/student/abc` or `/student/10.5` |
| **`float`** | Floating-point numbers | `@app.route('/price/<float:cost>')` | `/price/49.99` | `/price/free` |
| **`path`** | Text including slashes `/` | `@app.route('/files/<path:filepath>')`| `/files/docs/python/notes.pdf`| None (accepts full subpath) |
| **`uuid`** | Universal Unique Identifiers | `@app.route('/order/<uuid:order_id>')`| `/order/123e4567-e89b-12d3...` | `/order/999` |

### 💻 Code Examples from Class Notes:
```python
from flask import Flask
app = Flask(__name__)

# 1. String Converter (Default)
@app.route('/user/<string:name>')
def show_user(name):
    return f"User Profile: {name}"

# 2. Integer Converter (e.g. Student ID or Calculations)
@app.route('/square/<int:num>')
def calculate_square(num):
    return f"Square of {num} is {num * num}"

# 3. Float Converter
@app.route('/price/<float:cost>')
def show_price(cost):
    return f"Total Price with Tax: {cost * 1.18:.2f}"

# 4. Path Converter (Accepts sub-directories)
@app.route('/download/<path:subpath>')
def download_file(subpath):
    return f"Accessing file from path: {subpath}"
```

## 4. The 4 Ways of Accessing Client Data in Flask

Whenever a client sends data to your Flask application, Flask's global `request` object provides 4 primary mechanisms:

```
                          ┌───────────────────────────┐
                          │   Flask `request` Object  │
                          └─────────────┬─────────────┘
                                        │
      ┌──────────────────┬──────────────┴───────────────┬──────────────────┐
      ▼                  ▼                              ▼                  ▼
1. `request.args`   2. `request.form`            3. `request.json`   4. `request.files`
   (URL Query Params) (HTML Form POST Data)        (API JSON Data)     (Uploaded Files)
   e.g. ?page=2&q=py  e.g. username, password      e.g. {"id": 1}      e.g. avatar.png
```

### 1️⃣ Query Parameters: `request.args` (HTTP GET)
Used for search filters, sorting, and pagination appended after `?` in the URL:
```python
from flask import request

@app.route('/search')
def search():
    query = request.args.get('q', default='')           # returns string or default
    page = request.args.get('page', default=1, type=int)# automatically converts to int!
    tags = request.args.getlist('tag')                  # handles multiple: ?tag=py&tag=flask
    return f"Query: {query}, Page: {page}, Tags: {tags}"
```

### 2️⃣ Form Data: `request.form` (HTTP POST)
Used when HTML forms submit data securely in the request body:
```python
@app.route('/register', methods=['POST'])
def handle_registration():
    name = request.form['myname']       # raises KeyError if missing
    email = request.form.get('myemail') # returns None if missing (safer!)
    skills = request.form.getlist('skills') # gets all checked checkboxes
    return f"Registered {name} ({email}) with skills: {skills}"
```

### 3️⃣ JSON Body: `request.get_json()` (APIs & JavaScript `fetch`)
```python
@app.route('/api/student', methods=['POST'])
def add_student_api():
    data = request.get_json()
    student_name = data.get('name')
    return {"status": "created", "student": student_name}, 201
```

### 4️⃣ File Uploads: `request.files`
```python
@app.route('/upload', methods=['POST'])
def upload_file():
    uploaded_file = request.files['profile_pic']
    uploaded_file.save(f"./uploads/{uploaded_file.filename}")
    return "File uploaded successfully!"
```

## 5. Important `request` Object Properties Reference Table

| Property | Description | Example Value |
| :--- | :--- | :--- |
| **`request.method`** | The HTTP method used | `'GET'`, `'POST'`, `'PUT'`, `'DELETE'` |
| **`request.url`** | Full URL with query string | `'http://127.0.0.1:5000/search?q=flask'` |
| **`request.base_url`**| URL without query string | `'http://127.0.0.1:5000/search'` |
| **`request.path`** | Requested path relative to host | `'/search'` |
| **`request.headers`** | HTTP Request headers dictionary | `request.headers.get('User-Agent')` |
| **`request.cookies`** | Cookies sent by client browser | `request.cookies.get('session_id')` |
| **`request.remote_addr`**| IP address of client | `'127.0.0.1'` |
