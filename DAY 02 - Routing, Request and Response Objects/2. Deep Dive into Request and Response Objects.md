# Day 02: Deep Dive into Request & Response Objects

In this section, we examine the internal structure of Flask's `request` and `response` objects, payload extraction methods, header manipulation, cookie handling, and status codes.

---

## 1. The `request` Object Data Structure

The `request` proxy object exposes incoming HTTP request data via Werkzeug's `ImmutableMultiDict` data structures.

```
                          +-------------------------------+
                          |   Incoming HTTP Request       |
                          +---------------+---------------+
                                          |
        +------------------+--------------+--------------+-------------------+
        |                  |                             |                   |
        v                  v                             v                   v
+---------------+  +---------------+             +---------------+   +---------------+
| request.args  |  | request.form  |             | request.json  |   | request.files |
| (Query String)|  | (POST Form)   |             | (Parsed JSON) |   | (FileStorage) |
+---------------+  +---------------+             +---------------+   +---------------+
```

### 1. Extracting URL Query Parameters (`request.args`)
`request.args` parses the query string (`?search=python&page=2&tag=flask&tag=web`):

```python
from flask import request

# Get single value with default fallback and type coercion
search_query = request.args.get('search', '', type=str)
page = request.args.get('page', 1, type=int)

# Get multi-value lists (keys repeated in query string)
tags = request.args.getlist('tag') # Returns ['flask', 'web']
```

### 2. Extracting Form Data (`request.form`)
Parses `application/x-www-form-urlencoded` and `multipart/form-data` payloads:

```python
username = request.form.get('username')
passcode = request.form.get('password')
```

### 3. Parsing JSON Payloads (`request.json` / `get_json()`)
Parses incoming `application/json` HTTP bodies:

```python
# Returns parsed dictionary or raises 400 Bad Request if invalid JSON
data = request.get_json(silent=True) # Set silent=True to return None on parse error
```

### 4. Header & Client Metadata Inspection
- `request.headers`: Case-insensitive dictionary of HTTP request headers.
- `request.headers.get('Authorization')`: Access authentication tokens.
- `request.remote_addr`: Client IP address.
- `request.user_agent`: `request.user_agent.string` browser/device metadata.
- `request.is_secure`: `True` if request arrived over HTTPS.

## 2. The `response` Object Architecture

Flask view functions can return several valid response formats:

### Valid Flask View Function Return Types

1. **String / HTML**: `return "<h1>Success</h1>"`
2. **Dictionary / List** (Auto-JSONified): `return {"status": "ok"}, 200`
3. **Response Tuple**: `(response_body, status_code, headers_dict)`
4. **Werkzeug Response Instance**: Explicit `Response` or `make_response()` instance.

---

## 3. Using `make_response()` for Explicit Control

Use `make_response()` to attach custom HTTP headers or manage cookies:

```python
from flask import Flask, make_response, jsonify

app = Flask(__name__)

@app.route('/api/custom-response')
def custom_response():
    data = {"message": "Resource generated successfully"}
    
    # 1. Create response instance
    response = make_response(jsonify(data), 201)
    
    # 2. Attach Custom Response Headers
    response.headers['X-Server-ID'] = 'Node-EU-01'
    response.headers['Cache-Control'] = 'no-cache, no-store, must-revalidate'
    
    # 3. Set Secure HTTP Cookie
    response.set_cookie(
        key='session_token',
        value='xyz987token',
        max_age=3600,       # Expires in 1 hour (seconds)
        httponly=True,      # Protects against XSS
        secure=True,        # Requires HTTPS
        samesite='Lax'      # Protects against CSRF
    )
    
    return response
```

## 4. Redirects & Aborting Requests

### 1. HTTP Redirections (`redirect()`)
```python
from flask import redirect, url_for

@app.route('/old-page')
def old_page():
    # Sends 302 Found redirect (or 301 Moved Permanently)
    return redirect(url_for('new_page'), code=301)
```

### 2. Aborting Requests (`abort()`)
Immediately raises an `HTTPException` to interrupt view execution:

```python
from flask import abort

@app.route('/admin')
def admin():
    if not is_authorized():
        # Stops execution immediately and sends 403 Forbidden response
        abort(403, description="Access Restricted to System Administrators.")
```
