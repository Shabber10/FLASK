## 1. Query Parameters — `request.args` (GET)

### 🔹 What is `request.args`?
`request.args` is an `ImmutableMultiDict` object in Flask that stores query parameters (key-value pairs appended to the URL after a `?`).

When a client visits:
`http://127.0.0.1:5000/search?name=Jani&course=Python&course=Flask`
Everything after `?` (`name=Jani&course=Python&course=Flask`) becomes query parameters.

### 🔹 What is an `ImmutableMultiDict`?
Flask uses `ImmutableMultiDict` to store query parameters. It is similar to a Python dictionary, but:
1.  **Supports Duplicate Keys**: Can hold multiple values for the exact same key (`course=Python&course=Flask`).
2.  **Read-Only (Immutable)**: Cannot be modified directly. (To modify, convert first using `.to_dict()`).

### 🛒 Shopping List Analogy
Think of `ImmutableMultiDict` like a shopping list where you can write down multiple items under the same heading:
*   `course` → Python
*   `course` → Flask

If you convert it using `.to_dict()`, it keeps only the **last value**: `{'course': 'Flask'}`.  
If you convert it using `.to_dict(flat=False)`, it preserves **all values as lists**: `{'course': ['Python', 'Flask']}`.

---

### 🔹 Access Methods Summary Table for `request.args`

| Purpose / Method | Description | Example Code | Output for `?name=Jani&course=Python&course=Flask` |
| :--- | :--- | :--- | :--- |
| **`request.args.get('key')`** | Gets single value (first found) | `request.args.get('name')` | `'Jani'` |
| **`request.args.get('key', default, type)`** | Direct type conversion with fallback | `request.args.get('age', type=int, default=18)` | `18` (int) |
| **`request.args.getlist('key')`** | Gets ALL values for duplicate key as list | `request.args.getlist('course')` | `['Python', 'Flask']` |
| **`request.args.to_dict()`** | Normal dict (keeps last value of duplicates) | `request.args.to_dict()` | `{'name': 'Jani', 'course': 'Flask'}` |
| **`request.args.to_dict(flat=False)`** | Normal dict (keeps lists for all keys) | `request.args.to_dict(flat=False)` | `{'name': ['Jani'], 'course': ['Python', 'Flask']}` |
| **`str(request.args)` / `print(request.args)`** | Shows raw ImmutableMultiDict structure | `print(request.args)` | `ImmutableMultiDict([('name', 'Jani'), ...])` |

### 🧪 Practical `request.args` Code Example with `jsonify()`

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/')
def home():
    name = request.args.get('name', '')
    age = request.args.get('age')
    a = request.args.get('a', type=float, default=1)
    b = request.args.get('b', type=int, default=1)
    fruits = request.args.getlist('f')
    
    return jsonify({
        'name': name,
        'age': f'age is {age} ',
        'add': a + b,
        'fruitslist': fruits
    })

if __name__ == '__main__':
    app.run(debug=True)
```

**Testing in Browser / curl**:  
`http://127.0.0.1:5000/?name=hari&age=3&a=10&b=20&f=grapes&f=jam`

**JSON Output returned**:
```json
{
  "add": 30.0,
  "age": "age is 3 ",
  "fruitslist": [
    "grapes",
    "jam"
  ],
  "name": "hari"
}
```

## 2. Form Data — `request.form` (POST)

### 🔹 What is Form Data?
Form data refers to data submitted from an HTML `<form method="POST">` element. Flask accesses it via `request.form` (`application/x-www-form-urlencoded`).

### 🔹 Access Methods for `request.form`
*   `request.form.get('username')`: Safely retrieves value (returns `None` if key missing).
*   `request.form['username']`: Direct dictionary lookup (raises `KeyError` if key missing).
*   `request.form.to_dict()`: Converts form fields to Python dictionary.

---

### 📄 Full Registration Form Example (`app.py` + `templates/`)

**Folder Structure**:
```
flask_form_app/
├── app.py
└── templates/
    ├── register.html
    └── success.html
```

#### **`app.py`**:
```python
from flask import Flask, request, render_template

app = Flask(__name__)

@app.route('/register', methods=['GET', 'POST'])
def register():
    if request.method == 'POST':
        # Form submitted (POST request) -> read inputs from request.form
        username = request.form.get('username')
        email = request.form.get('email')
        course = request.form.get('course')
        
        # render success page with submitted user details
        return render_template('success.html', username=username, email=email, course=course)
    
    # Page first loaded (GET request) -> show registration form
    return render_template('register.html')

if __name__ == '__main__':
    app.run(debug=True)
```

## 3. JSON Data — `request.get_json()` vs `request.json`

### 🔹 Definition
JSON data is sent in the body of an HTTP request (`Content-Type: application/json`) by modern JavaScript frameworks (React, Angular, Vue), mobile apps, or Postman.

### ⚙️ Difference Between `request.get_json()` and `request.json`

| Feature | `request.get_json()` | `request.json` | `request.json.get('key')` |
| :--- | :--- | :--- | :--- |
| **Type** | Method (callable function) | Property (attribute access) | Method call on parsed dict |
| **Behavior** | Explicitly parses JSON body | Shortcut calling `get_json(silent=True)` | Directly extracts key value |
| **Error Handling** | Raises 400 Bad Request if invalid JSON | Returns `None` if invalid JSON | Returns `None` or default fallback |
| **Parameters** | Accepts `force=True`, `silent=True` | No parameters accepted | Accepts default fallback value |
| **Recommendation** | **Recommended for production APIs** | Quick/simple API routes | Quick shortcut |

---

### 🧪 Complete API CRUD Example (POST, PUT, DELETE)

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

# In-memory storage list (stored in RAM)
users = [
    {'id': 1, "name": "ramu", "age": 23},
    {'id': 2, "name": "harish", "age": 19}
]

# 1. POST - Add new user
@app.route('/add_student', methods=['POST'])
def add_student():
    data = request.get_json()
    new_user = {
        'id': len(users) + 1,
        'name': data.get('name'),
        'age': data.get('age')
    }
    users.append(new_user)
    return jsonify({"message": "Student added successfully!", "user": new_user}), 201

# 2. PUT - Update user age
@app.route('/updateuser/<int:uid>', methods=['PUT'])
def update_user(uid):
    data = request.get_json()
    new_age = data.get('age')
    
    for user in users:
        if user['id'] == uid:
            user['age'] = new_age
            return jsonify({"message": f"User with id {uid} updated successfully", "updated_data": users})
            
    return jsonify({"message": f"User id {uid} not found..."}), 404

# 3. DELETE - Remove user by ID
@app.route('/deleteuser/<int:uid>', methods=['DELETE'])
def delete_user(uid):
    for index, user in enumerate(users):
        if user['id'] == uid:
            users.pop(index)
            return jsonify({
                "message": f"User data with id {uid} deleted successfully",
                "updated_data": users
            }), 200
            
    return jsonify({"message": f"User id {uid} not found..."}), 404

# 4. RESET - Reset in-memory RAM data
@app.route('/reset', methods=['GET'])
def reset_data():
    global users
    users = [
        {'id': 1, "name": "ramu", "age": 23},
        {'id': 2, "name": "harish", "age": 19}
    ]
    return jsonify({"message": "Data reset successful", "users": users})

if __name__ == '__main__':
    app.run(debug=True)
```

## 4. What is `jsonify()` in Flask?

`jsonify()` is a Flask helper function that:
1.  Converts Python data structures (dictionaries, lists) into JSON strings.
2.  Returns a `Response` object with HTTP Header `Content-Type: application/json`.

```python
# Converts Python dictionary -> JSON response
return jsonify({"status": "success", "data": users})
```
