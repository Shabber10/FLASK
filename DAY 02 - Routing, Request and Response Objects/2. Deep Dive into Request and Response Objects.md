# Day 02: Deep Dive into Request & Response Objects

## 1. The `request` Object
The `request` object encapsulates incoming HTTP payload data:
- `request.args`: Query string parameters (`?page=1&limit=10`)
- `request.form`: HTML POST form data
- `request.json`: Parsed JSON body
- `request.headers`: HTTP headers dictionary
- `request.files`: MultiDict of uploaded files

## 2. Building Custom `Response` Objects
Use `make_response()` or import `Response` from `flask`:

```python
from flask import make_response

@app.route('/custom')
def custom_response():
    resp = make_response("Custom Body Content", 201)
    resp.headers['X-Custom-Header'] = 'FlaskMasterclass'
    return resp
```
