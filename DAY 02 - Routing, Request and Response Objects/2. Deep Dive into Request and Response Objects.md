## 1. Query Parameters — `request.args` (GET)

### 🔹 What is `request.args`?
`request.args` is an `ImmutableMultiDict` object in Flask that stores query parameters (key-value pairs appended to the URL after a `?`).

When a client visits:
`http://127.0.0.1:5000/search?name=Jani&course=Python&course=Flask`
Everything after `?` (`name=Jani&course=Python&course=Flask`) becomes query parameters.

### 🔹 What is an `ImmutableMultiDict`?
Flask uses `ImmutableMultiDict` to store query parameters. It is similar to a Python dictionary, but:
1.  **Supports Duplicate Keys**: Can hold multiple values for the exact same key (`course=Python&course=Flask`).
2.  **Read-Only (Immutable)**: Cannot be modified directly. (To modify, convert first using `.to_dict()`).

---

### 🔹 Access Methods Summary Table for `request.args`

| Purpose / Method | Description | Example Code | Output for `?name=Jani&course=Python&course=Flask` |
| :--- | :--- | :--- | :--- |
| **`request.args.get('key')`** | Gets single value (first found) | `request.args.get('name')` | `'Jani'` |
| **`request.args.get('key', default, type)`** | Direct type conversion with fallback | `request.args.get('age', type=int, default=18)` | `18` (int) |
| **`request.args.getlist('key')`** | Gets ALL values for duplicate key as list | `request.args.getlist('course')` | `['Python', 'Flask']` |
| **`request.args.to_dict()`** | Normal dict (keeps last value of duplicates) | `request.args.to_dict()` | `{'name': 'Jani', 'course': 'Flask'}` |
| **`request.args.to_dict(flat=False)`** | Normal dict (keeps lists for all keys) | `request.args.to_dict(flat=False)` | `{'name': ['Jani'], 'course': ['Python', 'Flask']}` |

## 2. Form Data — `request.form` (POST / PUT)

When a web browser submits an HTML form (`<form method="POST">`), the data arrives encoded as `application/x-www-form-urlencoded` or `multipart/form-data`:

```python
@app.route('/submit-form', methods=['POST'])
def handle_form():
    username = request.form.get('username')
    email = request.form.get('email')
    hobbies = request.form.getlist('hobbies') # For checkboxes
    return f"Received form for {username} ({email})"
```

## 3. JSON Payloads — `request.get_json()` (APIs)

When mobile apps or React single-page apps send JSON payloads with `Content-Type: application/json`:

```python
@app.route('/api/v1/users', methods=['POST'])
def create_user():
    # request.get_json(silent=True) returns None instead of raising 400 error on bad JSON
    data = request.get_json(silent=True) or {}
    
    name = data.get('name')
    age = data.get('age')
    
    return jsonify({"status": "created", "user": {"name": name, "age": age}}), 201
```

## 4. Standard Response Helpers (`render_template`, `jsonify`, `redirect`)

```python
from flask import render_template, jsonify, redirect, url_for, make_response

# 1. HTML Rendering
@app.route('/')
def home():
    return render_template('index.html', title="Home Page")

# 2. JSON Response
@app.route('/api/status')
def status():
    return jsonify({"status": "healthy", "code": 200})

# 3. HTTP Redirect (302 Found)
@app.route('/legacy-url')
def legacy():
    return redirect(url_for('home'))

# 4. Custom Response with Headers & Cookies
@app.route('/custom-headers')
def custom_headers():
    resp = make_response(jsonify({"message": "Custom header payload"}), 200)
    resp.headers['X-Custom-Header'] = 'EnterpriseFlask-v1'
    resp.set_cookie('tracking_id', 'trk_987654', httponly=True, samesite='Lax')
    return resp
```

## 5. Streaming Responses & Server-Sent Events (SSE)

### 📖 What is a Streaming Response?
A **Streaming Response** allows Flask to send data in chunks as it becomes available over an open HTTP connection, rather than waiting for the entire payload to be generated in memory.

### ❓ Use Cases:
- Large CSV / Data exports with millions of rows without memory exhaustion.
- Server-Sent Events (SSE) streaming real-time LLM chat tokens or server metrics.

### 💻 Code Example: Streaming Real-Time Data

```python
import time
from flask import Response, stream_with_context

@app.route('/api/v1/stream-events')
def stream_events():
    def event_stream_generator():
        for i in range(1, 6):
            time.sleep(1) # Simulate real-time data arrival
            # Server-Sent Events format: "data: <message>\n\n"
            yield f"data: Progress step {i}/5 completed at {time.strftime('%X')}\n\n"
            
    # stream_with_context ensures request/app contexts remain active inside generator
    return Response(
        stream_with_context(event_stream_generator()), 
        mimetype="text/event-stream"
    )
```

## 6. File Downloads & Serving (`send_file`, `send_from_directory`)

### 📖 What is `send_file()`?
`send_file()` sends the contents of a file from the server's filesystem to the client with automatic MIME type detection and streaming optimization.

### 💻 Code Example: Downloading Generated CSV Files

```python
import io
import os
from flask import send_file, send_from_directory, current_app

# 1. Download file as an attachment
@app.route('/download/report')
def download_report():
    # Stream in-memory byte buffer without saving to disk
    buffer = io.BytesIO(b"id,name,role\n1,Alice,Admin\n2,Bob,Developer\n")
    buffer.seek(0)
    
    return send_file(
        buffer,
        as_attachment=True,          # Forces browser 'Save As' download dialog
        download_name="report.csv",  # Downloaded filename
        mimetype="text/csv"
    )

# 2. Secure static file serving from specific directory (prevents path traversal)
@app.route('/static/downloads/<filename>')
def serve_download(filename):
    return send_from_directory(
        directory=os.path.join(current_app.root_path, 'uploads'),
        path=filename,
        as_attachment=False
    )
```

## 7. Custom Error Handlers & Pages (`@app.errorhandler`)

When a client requests a missing resource (404) or an unexpected server exception occurs (500), Flask displays a generic default error page. You can customize this globally:

```python
from flask import render_template, jsonify, request

# Custom 404 Not Found Handler
@app.errorhandler(404)
def not_found_error(error):
    # Return JSON for API consumers, HTML for browser requests
    if request.path.startswith('/api/'):
        return jsonify({
            "error": {
                "code": 404,
                "type": "NOT_FOUND",
                "message": "The requested API endpoint does not exist."
            }
        }), 404
        
    return render_template('404.html'), 404


# Custom 500 Internal Server Error Handler
@app.errorhandler(500)
def internal_server_error(error):
    if request.path.startswith('/api/'):
        return jsonify({
            "error": {
                "code": 500,
                "type": "INTERNAL_SERVER_ERROR",
                "message": "An unexpected server error occurred."
            }
        }), 500
        
    return render_template('500.html'), 500
```
