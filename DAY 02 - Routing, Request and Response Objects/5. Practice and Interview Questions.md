# Day 02: Practice & Technical Interview Questions

This question bank is divided into **3 progression levels**, starting from absolute routing concepts up to Werkzeug internals and cookie security.

---

## 🟢 Level 1: Absolute Beginner Questions

### Q1: What is URL Routing in Flask?
**Answer**:
URL Routing is the process of mapping specific URL paths requested by web browsers (like `/about` or `/user/10`) to specific Python functions in your Flask app. Flask uses `@app.route('/path')` decorators to register these mappings.

---

### Q2: What is the difference between a Path Parameter (`/user/42`) and a Query Parameter (`/search?q=flask`)?
**Answer**:
*   **Path Parameter**: Directly part of the URL structure used to uniquely identify a resource (e.g., user ID `42`). Defined in Flask as `@app.route('/user/<int:id>')`.
*   **Query Parameter**: Key-value pairs attached after a `?` in the URL used for filtering, sorting, or searching (e.g., search term `q=flask`). Extracted in Flask via `request.args.get('q')`.

---

### Q3: What HTTP verb is used to read data vs submit form data?
**Answer**:
*   `GET`: Used to fetch/read data from the server without modifying anything.
*   `POST`: Used to submit new data to the server (like form entries, logins, or file uploads).

---

### Q4: What is an HTTP Cookie and why do websites use them?
**Answer**:
HTTP is stateless—it treats every request as a new stranger. An **HTTP Cookie** is a tiny piece of text data saved by your browser on your computer. When you log in, the server gives your browser a cookie (`session=xyz`). On every subsequent click, your browser sends that cookie back so the server remembers who you are.

---

### Q5: How do you extract query parameters from a URL in Flask?
**Answer**:
Use `request.args`:
```python
search_term = request.args.get('q', default='', type=str)
```

## 🟡 Level 2: Intermediate Questions

### Q6: What is the difference between `path` and `string` URL converters in Flask?
**Answer**:
*   `string` (default): Matches text excluding forward slashes (`/`). Route `/files/<filename>` fails to match `/files/docs/report.pdf`.
*   `path`: Matches text **including** forward slashes (`/`). Route `/files/<path:filepath>` matches `/files/docs/report.pdf` and passes `"docs/report.pdf"` as the parameter.

---

### Q7: What type of data structure is `request.args` and how do you extract multiple values for the same key?
**Answer**:
`request.args` is an instance of Werkzeug's `ImmutableMultiDict`. Standard dictionary indexing `request.args['key']` returns only the first value. To retrieve all values for repeated query keys (e.g., `?tag=python&tag=flask`), use `request.args.getlist('tag')`, which returns `['python', 'flask']`.

---

### Q8: Why is `url_for()` preferred over hardcoding URLs in templates and redirects?
**Answer**:
1.  **Refactoring Safety**: Changing a route URL in `@app.route('/new-path')` updates all generated links automatically across your entire application without editing HTML templates.
2.  **Character Encoding**: Automatically URL-encodes special characters.
3.  **Domain & Scheme Handling**: Easily forces HTTPS (`_scheme='https'`) or external domains (`_external=True`).

---

### Q9: What happens if a client sends invalid JSON to a route calling `request.get_json()`?
**Answer**:
By default, `request.get_json()` raises a `400 Bad Request` HTTP exception if the payload contains invalid JSON syntax or if the `Content-Type` header is not `application/json`.
To prevent an exception, pass `silent=True`: `request.get_json(silent=True)` returns `None` instead of throwing an error.

---

### Q10: What is the difference between `redirect()` and `abort()` in Flask?
**Answer**:
*   `redirect(location, code=302)`: Sends an HTTP redirection response back to the browser, instructing it to visit a different URL.
*   `abort(status_code, description)`: Immediately halts view function execution by raising an `HTTPException`, returning an error page or custom error handler.

## 🔴 Level 3: Advanced & Enterprise Questions

### Q11: Explain how Werkzeug matches incoming URL paths to Flask view functions.
**Answer**:
When Flask starts, `@app.route()` decorators generate `werkzeug.routing.Rule` objects that are stored inside `app.url_map` (`Map` object). When an HTTP request arrives, `app.url_map.bind_to_environ(environ)` creates a `MapAdapter`. The adapter compiles route rules into regular expressions and tests `PATH_INFO`. Upon finding a match, it returns the target endpoint name and a dictionary of parsed URL arguments.

---

### Q12: How do you create a custom URL converter in Flask that converts path values to custom Python objects?
**Answer**:
Subclass `BaseConverter` from `werkzeug.routing` and implement `to_python()` and `to_url()` methods:

```python
from werkzeug.routing import BaseConverter

class PointConverter(BaseConverter):
    regex = r'\d+,\d+'
    
    def to_python(self, value):
        x, y = value.split(',')
        return (int(x), int(y))  # Converts URL string "10,20" to tuple (10, 20)
        
    def to_url(self, value):
        return f"{value[0]},{value[1]}"

app.url_map.converters['point'] = PointConverter
```

### Q13: How do you set HTTP-only, Secure, and SameSite flags when returning cookies in Flask?
**Answer**:
Use `make_response()` and call `set_cookie()`:

```python
resp = make_response(jsonify(status="ok"))
resp.set_cookie(
    'session_id',
    'val123',
    max_age=3600,
    httponly=True,   # Mitigates XSS attacks (JS cannot access cookie)
    secure=True,     # Requires HTTPS connection
    samesite='Lax'   # Mitigates CSRF attacks
)
return resp
```

### Q14: How does Flask handle HTTP `HEAD` and `OPTIONS` requests automatically?
**Answer**:
If a route specifies `methods=['GET']`, Flask enables `HEAD` and `OPTIONS` automatically:
*   For `HEAD` requests, Flask executes the `GET` view function, but Werkzeug strips the response body before sending, returning only headers and status code.
*   For `OPTIONS` requests, Werkzeug automatically responds with an `Allow` header listing permitted HTTP verbs (e.g. `Allow: GET, POST, OPTIONS`).

---

### Q15: Explain the valid return types of a Flask view function.
**Answer**:
A Flask view function can return:
1.  A string or HTML fragment (defaults to `200 OK`, `text/html`).
2.  A `dict` or `list` (automatically converted to JSON with `200 OK`, `application/json`).
3.  A response tuple `(body, status_code)` or `(body, status_code, headers_dict)`.
4.  An explicit `Response` or `make_response()` instance.
