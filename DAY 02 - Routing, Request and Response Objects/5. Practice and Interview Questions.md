# Day 02: Technical Interview Questions

### Q1: How do you create a custom URL converter in Flask?
**Answer**: Subclass `BaseConverter` from `werkzeug.routing`, set `self.regex`, and register it in `app.url_map.converters['name'] = CustomConverter`.

### Q2: What is the difference between `request.args` and `request.form`?
**Answer**: `request.args` accesses URL query parameters (HTTP GET), whereas `request.form` accesses form-encoded body payloads (HTTP POST/PUT).
