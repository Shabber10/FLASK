# Day 02: Practice & Technical Interview Questions

### Q1: Explain how Werkzeug matches incoming URL paths to Flask view functions.
**Answer**:
When a Flask app starts, `@app.route()` decorators generate `werkzeug.routing.Rule` objects that are added to `app.url_map` (`Map` object). 

When an HTTP request arrives, `app.url_map.bind_to_environ(environ)` creates a `MapAdapter`. The adapter compiles route rules into regular expressions and tests `PATH_INFO`. Upon finding a match, it returns the target endpoint name and a dictionary of parsed URL arguments.

### Q2: What is the difference between `path` and `string` URL converters in Flask?
**Answer**:
- `string`: Matches any sequence of characters excluding forward slashes (`/`). Route `/user/<name>` fails to match if `/user/john/doe` is requested.
- `path`: Matches any sequence of characters **including** forward slashes (`/`). Route `/files/<path:filepath>` matches `/files/documents/2026/report.pdf` and passes `"documents/2026/report.pdf"` as `filepath`.

### Q3: How do you create a custom URL converter in Flask that converts path values to custom Python objects?
**Answer**:
Subclass `BaseConverter` from `werkzeug.routing` and implement `to_python()` and `to_url()` methods:

```python
from werkzeug.routing import BaseConverter

class PointConverter(BaseConverter):
    regex = r'\d+,\d+'
    
    def to_python(self, value):
        x, y = value.split(',')
        return (int(x), int(y)) # Returns tuple (x, y) to view function
        
    def to_url(self, value):
        return f"{value[0]},{value[1]}"

app.url_map.converters['point'] = PointConverter
```

### Q4: What type of data structure is `request.args` and how do you extract multiple values for the same key?
**Answer**:
`request.args` is an instance of Werkzeug's `ImmutableMultiDict`. Standard dictionary indexing `request.args['key']` returns only the first value. To retrieve all values for repeated query keys (e.g. `?tag=python&tag=flask`), use `request.args.getlist('tag')`, which returns `['python', 'flask']`.

### Q5: Why is `url_for()` preferred over hardcoding URL strings in templates and redirects?
**Answer**:
1. **Refactoring Safety**: Changing a route URL pattern in `@app.route('/new-path')` updates all generated URLs automatically across the application without editing template files.
2. **Special Character Encoding**: `url_for()` automatically URL-encodes special characters and query parameter values.
3. **Subdomain & Scheme Handling**: Easily forces HTTPS (`_scheme='https'`) or absolute domains (`_external=True`).

### Q6: What happens if a client sends invalid JSON to a route calling `request.get_json()`?
**Answer**:
By default, `request.get_json()` raises a `400 Bad Request` HTTP exception if the `Content-Type` header is not `application/json` or if the payload contains invalid JSON syntax. 

To prevent raising an exception, pass `silent=True`: `request.get_json(silent=True)` returns `None` instead of raising an error.

### Q7: Explain the signature and return options for Flask view functions.
**Answer**:
A view function can return:
1. A single string or HTML fragment (defaults to 200 OK, `text/html`).
2. A dict or list (Flask automatically converts to JSON with `200 OK`, `application/json`).
3. A tuple of `(body, status_code)` or `(body, status_code, headers_dict)`.
4. A `Response` or `make_response()` instance.

### Q8: How do you set HTTP-only and SameSite flags when returning cookies in Flask?
**Answer**:
Use `make_response()` and call `set_cookie()`:

```python
resp = make_response(jsonify(status="ok"))
resp.set_cookie(
    'session_id',
    'val123',
    max_age=3600,
    httponly=True,   # Mitigates XSS attacks
    secure=True,     # Requires HTTPS
    samesite='Lax'   # Mitigates CSRF attacks
)
return resp
```

### Q9: How does Flask handle HTTP `HEAD` and `OPTIONS` requests automatically?
**Answer**:
If a route specifies `methods=['GET']`, Flask automatically enables `HEAD` and `OPTIONS`:
- For `HEAD` requests, Flask executes the `GET` view function, but Werkzeug strips the response body before sending, returning only headers and status code.
- For `OPTIONS` requests, Werkzeug automatically responds with an `Allow` header listing allowed verbs (e.g. `Allow: GET, POST, OPTIONS`).

### Q10: What is the difference between `redirect()` and `abort()` in Flask?
**Answer**:
- `redirect(location, code=302)`: Returns an HTTP redirection response informing the browser to request a different URL target.
- `abort(status_code, description)`: Immediately halts view execution by raising an `HTTPException`, transferring execution directly to an error handler or returning an error page.
