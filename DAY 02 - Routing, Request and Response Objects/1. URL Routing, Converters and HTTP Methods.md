# Day 02: URL Routing, Converters & HTTP Methods

## 1. Flask Routing Mechanism
Routes map incoming URL endpoints to Python view functions using `@app.route(rule, **options)`.

### Built-in URL Converters
- `<string:name>`: Matches any string without a slash (default).
- `<int:id>`: Matches positive integers.
- `<float:val>`: Matches floating point numbers.
- `<path:subpath>`: Matches strings including forward slashes.
- `<uuid:user_uuid>`: Matches UUID strings.

```python
@app.route('/user/<int:user_id>')
def show_user(user_id):
    return f"User ID: {user_id}"
```

## 2. Custom URL Converters
