# Day 22: Memory Shortcuts & Cheatsheet

---

## 🧠 Memory Mnemonics

### 1. Dockerfile Layer Optimization Rule
Remember **L-E-A-S-T** to **M-O-S-T**:
- Place **Least** frequently changed instructions (`FROM`, `WORKDIR`, `COPY requirements.txt`, `RUN pip install`) at the TOP of `Dockerfile`.
- Place **Most** frequently changed instructions (`COPY . .`, `CMD`) at the BOTTOM to maximize layer cache hits!

---

### 2. Docker Compose DNS Resolution
> ⚠️ **CRITICAL**: Use service names (`db:5432`, `redis:6379`) defined in `docker-compose.yml` as network hostnames, NOT `127.0.0.1` or `localhost`!

## ⚡ Quick-Reference Code Snippets

### 1. Multi-Stage Production `Dockerfile`
```dockerfile
# Stage 1: Build dependencies
FROM python:3.11-slim AS builder
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir --user -r requirements.txt

# Stage 2: Minimal Runtime
FROM python:3.11-slim AS runner
WORKDIR /app
RUN useradd -m -u 1000 appuser
COPY --from=builder /root/.local /home/appuser/.local
COPY . .
USER appuser
ENV PATH="/home/appuser/.local/bin:${PATH}"
CMD ["gunicorn", "--bind", "0.0.0.0:5000", "wsgi:app"]
```

### 2. Docker CLI Commands
```bash
# Build image
docker build -t my-flask-app:latest .

# Run container in background mapping port 5000
docker run -d -p 5000:5000 --name flask_api my-flask-app:latest

# Docker Compose Management
docker-compose up -d --build
docker-compose logs -f web
docker-compose down -v
```
