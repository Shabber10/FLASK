# Day 09: Database Migrations with Flask-Migrate

## 1. Schema Evolution Principles
In production environments, `db.create_all()` is unsafe because it cannot modify existing table definitions. **Flask-Migrate** wraps **Alembic** to track database version control.

### CLI Workflow Commands
1. `flask db init`: Initializes migration repository inside `migrations/`.
2. `flask db migrate -m "message"`: Generates migration script based on model changes.
3. `flask db upgrade`: Applies pending migrations to the database.
4. `flask db downgrade`: Rolls back the last applied migration step.
