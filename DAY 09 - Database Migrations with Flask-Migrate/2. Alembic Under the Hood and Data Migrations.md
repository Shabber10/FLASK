# Day 09: Alembic Under the Hood & Data Migrations

## 1. Inside `alembic_version` Table
Alembic creates a single table `alembic_version` containing the current revision hash (e.g. `a1b2c3d4e5`).

## 2. Writing Manual Data Migrations
Migration scripts expose `upgrade()` and `downgrade()` functions where raw SQL or Alembic operations execute.
