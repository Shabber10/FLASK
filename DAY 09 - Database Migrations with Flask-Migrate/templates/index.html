💻 Essential Migration Terminal CLI Commands

# 1. Initialize migration repository (Run once per app):
flask db init

# 2. Autogenerate new migration revision script after modifying models:
flask db migrate -m "Add UserAccount schema"

# 3. Apply pending migration scripts to active database:
flask db upgrade

# 4. Rollback last applied migration step:
flask db downgrade
