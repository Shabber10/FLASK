# Day 09: Memory Shortcuts & Cheatsheet

## 🔤 Database Migrations Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Migration** | Version-controlled structural change to a database schema. | Adding a new column live without wiping data |
| **Revision** | Single migration script checkpoint file with unique hash ID. | `versions/a1b2c3d4e5f6_add_phone.py` |
| **Alembic** | Python's underlying database migration engine for SQLAlchemy. | Autogenerates schema diffs |
| **Flask-Migrate** | Flask extension exposing Alembic commands under `flask db`. | `migrate = Migrate(app, db)` |
| **`alembic_version`** | Single-column SQL table tracking active DB version hash. | `SELECT * FROM alembic_version;` |
| **Batch Mode** | Alembic mode enabling SQLite `ALTER TABLE` operations. | `Migrate(app, db, render_as_batch=True)` |
| **Upgrade** | Applying pending migration scripts to active database. | `flask db upgrade` |
| **Downgrade** | Reverting the most recent migration step on active database. | `flask db downgrade` |

---

## 🧠 Memory Mnemonics

### Migration Lifecycle Workflow (`I-M-U-D`)
Remember **I-M-U-D** for the 4 core migration steps:
- **I** -> **`flask db init`** (Initialize `migrations/` folder once per project)
- **M** -> **`flask db migrate -m "msg"`** (Autogenerate revision script in `migrations/versions/`)
- **U** -> **`flask db upgrade`** (Apply pending migration scripts to active DB)
- **D** -> **`flask db downgrade`** (Rollback most recent migration step if needed)

## ⚡ Quick-Reference Code Snippets

### 1. Flask-Migrate Python Setup (with SQLite Batch Mode)
```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy
from flask_migrate import Migrate

app = Flask(__name__)
db = SQLAlchemy(app)

# Always use render_as_batch=True for SQLite support!
migrate = Migrate(app, db, render_as_batch=True)
```

### 2. Manual Data Migration inside Revision Script (`upgrade()`)
```python
def upgrade():
    # 1. Add column as nullable initially
    op.add_column('users', sa.Column('is_active', sa.Boolean(), nullable=True))
    
    # 2. Populate existing rows with default data!
    op.execute("UPDATE users SET is_active = TRUE WHERE is_active IS NULL")
    
    # 3. Enforce NOT NULL constraint
    op.alter_column('users', 'is_active', nullable=False)
```

### 3. Inspection & Version Checking CLI Commands
```bash
# Show active database revision hash
flask db current

# Show latest available script revision hash
flask db heads

# Show full migration history
flask db history

# Force DB version pointer to specific revision without running SQL
flask db stamp <revision_hash>
```
