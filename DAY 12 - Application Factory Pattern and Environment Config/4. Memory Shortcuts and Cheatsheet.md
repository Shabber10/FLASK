## 🔤 Application Factory & Config Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Design Pattern** | Battle-tested architectural recipe for software design. | Factory Pattern, Singleton, Decorator |
| **Application Factory** | Function creating & configuring fresh Flask app instances. | `def create_app(config): return app` |
| **Deferred Binding** | Instantiating extensions globally and attaching via `.init_app()`. | `db = SQLAlchemy()`; `db.init_app(app)` |
| **Circular Import** | Bug where 2 Python files attempt to import each other simultaneously. | `app.py` importing `routes.py` importing `app.py` |
| **Environment Config** | Setting app parameters based on Dev/Test/Prod stage. | `DevelopmentConfig`, `ProductionConfig` |
| **`.env` File** | Local file holding secret keys outside Git source code. | `SECRET_KEY=9a8b7c6d5e4f` |
| **In-Memory DB** | Isolated SQLite database existing only in RAM for fast unit testing. | `sqlite:///:memory:` |

## 🧠 Memory Mnemonics

### Application Factory Steps (`F-A-C-T-O-R-Y`)
Remember **F-A-C-T-O-R-Y** for `create_app()` execution sequence:
- **F** -> **Function Definition** (`def create_app(config_name):`)
- **A** -> **App Initialization** (`app = Flask(__name__)`)
- **C** -> **Config Loading** (`app.config.from_object(config_class)`)
- **T** -> **To Bind Extensions** (`db.init_app(app)`, `migrate.init_app(app, db)`)
- **O** -> **Optionally Register Blueprints** (`app.register_blueprint(auth_bp)`)
- **R** -> **Register Error Handlers** (`@app.errorhandler(404)`)
- **Y** -> **Yield App Instance** (`return app`)

## ⚡ Quick-Reference Code Snippets

### 1. Class-Based Configuration Hierarchy
```python
import os

class BaseConfig:
    SECRET_KEY = os.environ.get('SECRET_KEY', 'default-fallback-secret')
    SQLALCHEMY_TRACK_MODIFICATIONS = False

class DevConfig(BaseConfig):
    DEBUG = True
    SQLALCHEMY_DATABASE_URI = 'sqlite:///dev.db'

class TestConfig(BaseConfig):
    TESTING = True
    SQLALCHEMY_DATABASE_URI = 'sqlite:///:memory:'

class ProdConfig(BaseConfig):
    DEBUG = False
    SQLALCHEMY_DATABASE_URI = os.environ.get('DATABASE_URL')
```

### 2. Application Factory Skeleton with Deferred Binding
```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

# Unattached global extension instance
db = SQLAlchemy()

def create_app(config_class=DevConfig):
    app = Flask(__name__)
    app.config.from_object(config_class)
    
    # Deferred Extension Binding
    db.init_app(app)
    
    # Blueprint Registration
    from auth.routes import auth_bp
    app.register_blueprint(auth_bp)
    
    return app
```
