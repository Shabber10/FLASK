## 1. Class-Based Configuration Inheritance

Organize application settings into a Python class hierarchy. Derive specific environment classes (`DevelopmentConfig`, `TestingConfig`, `ProductionConfig`) from a shared `BaseConfig` class:

```python
import os

class BaseConfig:
    """Shared baseline configuration settings."""
    SECRET_KEY = os.environ.get('SECRET_KEY', 'default-fallback-secret-key')
    SQLALCHEMY_TRACK_MODIFICATIONS = False
    MAX_CONTENT_LENGTH = 16 * 1024 * 1024  # 16MB max upload

class DevelopmentConfig(BaseConfig):
    """Local Development Configuration."""
    DEBUG = True
    TESTING = False
    SQLALCHEMY_DATABASE_URI = os.environ.get('DEV_DATABASE_URL', 'sqlite:///dev.db')

class TestingConfig(BaseConfig):
    """Automated Unit Testing Configuration."""
    DEBUG = False
    TESTING = True
    SQLALCHEMY_DATABASE_URI = 'sqlite:///:memory:'  # Isolated in-memory DB!
    WTF_CSRF_ENABLED = False  # Disable CSRF for faster automated API tests

```python
class ProductionConfig(BaseConfig):
    """Secure Live Production Configuration."""
    DEBUG = False
    TESTING = False
    SQLALCHEMY_DATABASE_URI = os.environ.get('DATABASE_URL')
    SESSION_COOKIE_SECURE = True
    REMEMBER_COOKIE_SECURE = True
```

#### ⚖️ Environment Configuration Matrix

| Setting / Feature | `DevelopmentConfig` | `TestingConfig` | `ProductionConfig` |
| :--- | :--- | :--- | :--- |
| **`DEBUG` Flag** | `True` (Verbose interactive debugger) | `False` | `False` (Hides error stack traces) |
| **`TESTING` Flag** | `False` | `True` | `False` |
| **Database URI** | Local file (`dev.db`) | In-Memory (`sqlite:///:memory:`) | Production PostgreSQL URL from `.env` |
| **CSRF Protection** | `True` | `False` (Faster automated tests) | `True` |
| **Cookie Security** | `False` (Local HTTP) | `False` | `True` (`SESSION_COOKIE_SECURE = True`) |

## 2. Loading Settings (`app.config.from_object`)

Inside your application factory, load configuration classes dynamically using **`app.config.from_object()`**:

```python
def create_app(config_name="development"):
    app = Flask(__name__)
    
    # Map configuration string keys to Config classes
    config_map = {
        'development': 'config.DevelopmentConfig',
        'testing': 'config.TestingConfig',
        'production': 'config.ProductionConfig'
    }
    
    selected_config = config_map.get(config_name, 'config.DevelopmentConfig')
    
    # Load settings from object path
    app.config.from_object(selected_config)
    return app
```

## 3. Managing Secrets with `python-dotenv`

Install `python-dotenv` to automatically load environment variables from `.env` and `.flaskenv` files:

```bash
pip install python-dotenv
```

Flask automatically checks for two special files in your project root directory:

```
my_project/
├── .env                # Secret keys, database passwords, API tokens (MUST be in .gitignore!)
├── .flaskenv           # Public Flask CLI environment flags (FLASK_APP, FLASK_DEBUG)
└── .gitignore          # Must include `.env` to prevent secret leaks!
```

### Example `.env` File:
```env
FLASK_APP="3. Practice App - Production Ready Factory Pattern with Config Classes.py"
FLASK_DEBUG=1
SECRET_KEY=9a8b7c6d5e4f3a2b1c0d
DATABASE_URL=postgresql://dbuser:supersecretpass@localhost:5432/prod_db
```
