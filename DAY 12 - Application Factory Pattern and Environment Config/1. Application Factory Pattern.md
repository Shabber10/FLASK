# Day 12: Application Factory Pattern

## 1. Why Use Application Factories?
The **Application Factory Pattern** (`create_app()`) creates Flask application instances dynamically at runtime rather than at global import time.

### Key Benefits
1. Avoids circular import issues.
2. Allows isolated testing environments (`TestingConfig`).
3. Enables launching multiple instances of the app concurrently.

```python
def create_app(config_class=DevelopmentConfig):
    app = Flask(__name__)
    app.config.from_object(config_class)
    
    db.init_app(app)
    app.register_blueprint(auth_bp)
    
    return app
```
