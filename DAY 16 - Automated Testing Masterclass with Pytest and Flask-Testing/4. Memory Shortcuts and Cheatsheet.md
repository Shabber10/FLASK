## 🧠 Memory Mnemonics

### 1. Pytest Fixture Lifecycle
Remember **F-I-X-T-U-R-E** for writing Pytest test fixtures:
- **F**: **Function Scope** (`scope='function'` default for complete isolation)
- **I**: **In-Memory DB** (`sqlite:///:memory:` for lightning fast tests)
- **X**: **Explicit Context** (`with app.app_context():`)
- **T**: **Test Client** (`app.test_client()` simulates requests without live server)
- **U**: **Up-and-Down Yield** (`db.create_all()` -> `yield` -> `db.drop_all()`)
- **R**: **Response Assertions** (`assert response.status_code == 200`)
- **E**: **Error Code Validation** (`assert response.json['error'] == 'Unauthorized'`)

## ⚡ Quick-Reference Code Snippets

### 1. Pytest App & Client Fixture Pattern
```python
import pytest
from app import create_app, db

@pytest.fixture
def app():
    app_inst = create_app('testing')
    with app_inst.app_context():
        db.create_all()
        yield app_inst
        db.session.remove()
        db.drop_all()

@pytest.fixture
def client(app):
    return app.test_client()
```

### 2. Testing API Endpoints with `client`
```python
def test_create_item(client):
    # Simulate POST JSON request
    res = client.post('/api/items', json={"name": "Widget", "price": 19.99})
    assert res.status_code == 201
    assert res.json['name'] == "Widget"
```

### 3. Measuring Code Coverage
```bash
# Run tests with code coverage report
python -m pytest --cov=app --cov-report=term-missing
```
