## 1. Modern Flask Factory Integration (`celery_init_app`)

In modern Flask (2.3+ / 3.0+), the official pattern for integrating Celery creates a custom `Task` class subclass that pushes Flask's Application Context automatically during background task execution:

```python
from celery import Celery, Task
from flask import Flask

def celery_init_app(app: Flask) -> Celery:
    """Official Flask-Celery Application Factory Helper."""
    
    class FlaskTask(Task):
        def __call__(self, *args, **kwargs):
            # Pushes Flask Application Context automatically inside background worker!
            with app.app_context():
                return self.run(*args, **kwargs)

    celery_app = Celery(app.name, task_cls=FlaskTask)
    celery_app.config_from_object(app.config["CELERY"])
    celery_app.set_default()
    app.extensions["celery"] = celery_app
    return celery_app
```

## 2. Configuring Redis Broker & Result Backend

Configure Celery settings inside your Flask application configuration dictionary under the `CELERY` namespace key:

```python
app = Flask(__name__)

# Configure Redis Broker and Result Backend URLs
app.config.from_mapping(
    CELERY=dict(
        broker_url="redis://localhost:6379/0",
        result_backend="redis://localhost:6379/0",
        task_ignore_result=False,
        result_expires=3600,  # Expire task results in Redis after 1 hour (3600s)
    ),
)

celery_app = celery_init_app(app)
```

## 3. Defining Celery Tasks (`@celery.task`)

Decorate functions with **`@celery_app.task`** to turn them into asynchronous background tasks:

```python
import time
from celery import shared_task

@celery_app.task(bind=True)
def send_welcome_email_task(self, recipient_email, user_name):
    """Background task simulating email dispatch."""
    print(f"📧 [BACKGROUND WORKER] Sending email to {recipient_email}...")
    time.sleep(3)  # Simulate 3-second network latency
    return f"Welcome email successfully delivered to {user_name} ({recipient_email})!"
```
