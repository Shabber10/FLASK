# Day 21: Background Processing with Celery & Redis

## 1. Why Asynchronous Task Queues?
Long-running operations (sending emails, processing video files, external API integration) block web request threads. **Celery** offloads tasks to background worker processes.

```python
from celery import Celery

def make_celery(app):
    celery = Celery(
        app.import_name,
        backend=app.config['CELERY_RESULT_BACKEND'],
        broker=app.config['CELERY_BROKER_URL']
    )
    celery.conf.update(app.config)
    return celery
```
