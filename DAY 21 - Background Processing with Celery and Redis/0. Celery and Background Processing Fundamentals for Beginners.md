## 1. Class Notes Foundation: Email Sending in Python (`smtplib`)

Email automation allows Python applications to send custom emails automatically (e.g., meeting reminders, password reset links, welcome emails) without manually opening Gmail.

### 🛠️ Key Tools & Concepts

| Tool / Module | Full Form | Purpose |
| :--- | :--- | :--- |
| **`smtplib`** | **S**imple **M**ail **T**ransfer **P**rotocol **Lib**rary | Built-in Python module to send emails using standard internet email protocols. |
| **`smtplib.SMTP_SSL()`** | **SMTP** over **S**ecure **S**ockets **L**ayer | Establishes a secure, encrypted connection to email servers (like Gmail on port `465`) protecting credentials and data. |
| **`email.message.EmailMessage`** | Email Message Object | Python standard library class to construct structured emails (`Subject`, `From`, `To`, body text/HTML). |
| **Gmail App Password** | Application-Specific Password | A 16-character security code generated under Google Account 2-Step Verification for automated scripts. |

## 2. Step-by-Step Gmail & Python Setup

### Step 1: Enable 2-Step Verification & App Password
1. Navigate to your Google Account Security: `https://myaccount.google.com/security`
2. Turn on **2-Step Verification**.
3. Go to **App Passwords**: `https://myaccount.google.com/apppasswords`
4. Select **Mail** and **Windows Computer**, then click **Generate**.
5. Copy the generated **16-character password** (e.g., `ktsi quvu syfy jylh`).

### Step 2: Python Script Implementation (`send_email.py`)

```python
import smtplib
from email.message import EmailMessage

# 1. Email configuration details
sender_email = 'yourgmail@gmail.com'
receiver_email = 'yourfriend@example.com'
app_password = 'your_16_char_app_password'

# 2. Create email message object
msg = EmailMessage()
msg['Subject'] = 'Meeting Reminder'
msg['From'] = sender_email
msg['To'] = receiver_email
msg.set_content('''Hi Guys,

Just reminding you about our meeting tomorrow at 10 AM.

Regards,
Jani''')

# 3. Secure connection & dispatch
try:
    with smtplib.SMTP_SSL('smtp.gmail.com', 465) as smtp:
        smtp.login(sender_email, app_password)
        smtp.send_message(msg)
        print("Email sent successfully!!")
except Exception as e:
    print("Error sending email:", e)
```

### 🔍 Line-by-Line Code Breakdown

| Code Statement | What It Does |
| :--- | :--- |
| `import smtplib` | Imports Python's built-in Simple Mail Transfer Protocol library. |
| `from email.message import EmailMessage` | Imports the class to format modern RFC-compliant email payloads. |
| `msg['Subject']`, `['From']`, `['To']` | Sets standard email header fields. |
| `msg.set_content(body)` | Injects the plain-text or HTML message content. |
| `with smtplib.SMTP_SSL('smtp.gmail.com', 465)` | Establishes a secure SSL encrypted tunnel to Gmail's mail server. |
| `smtp.login(sender, app_password)` | Authenticates your script with Google using the secure App Password. |
| `smtp.send_message(msg)` | Transmits the email to the recipient. |

## 3. Scheduled Automated Email Sending (`schedule` Library)

To send reminder emails automatically at a specific time every day (e.g., every morning at 10:00 AM), we combine `smtplib` with Python's `schedule` library:

```python
import smtplib
from email.message import EmailMessage
import schedule
import time

def send_daily_reminder():
    msg = EmailMessage()
    msg['Subject'] = 'Daily Reminder!'
    msg['From'] = 'yourgmail@gmail.com'
    msg['To'] = 'yourfriend@example.com'
    msg.set_content('Hi friend, Just sending you a daily reminder as planned. Have a great day! – Jani')
    
    with smtplib.SMTP_SSL('smtp.gmail.com', 465) as smtp:
        smtp.login('yourgmail@gmail.com', 'your_app_password')
        smtp.send_message(msg)
        print("Email sent successfully at 10 AM!")

# Schedule the task every day at 10:00 AM
schedule.every().day.at("10:00").do(send_daily_reminder)

print("Scheduler started... Will send email every day at 10 AM.")
while True:
    schedule.run_pending()
    time.sleep(60)  # Check every 60 seconds
```

## 4. The Problem: Synchronous Blocking in Web Applications

When you trigger `smtplib.send_message()` directly inside a Flask route handler, the entire web server thread pauses:

```
1. SYNCHRONOUS ROUTE (Blocking - Slow!)
   User Clicks "Register" ──> Flask pauses for 3-5 seconds waiting for Gmail SMTP ──> User waits 5s! 😫

2. ASYNCHRONOUS BACKGROUND WORKER (Non-Blocking - Fast!)
   User Clicks "Register" ──> Flask saves user & queues task in 1ms ──> Returns Instant Response! ⚡
                                      │
                                      ▼
                        Celery Worker executes smtplib.send_message()
                        in the background (User experiences zero delay!)
```

*   **Synchronous**: The web server pauses and waits for network roundtrips to finish before responding to the user.
*   **Asynchronous**: The web server hands off the email task to a message broker queue (Redis), responds immediately with HTTP `202 Accepted` or a redirect, and lets a background worker (Celery) finish sending the email!

---

## 5. What is Celery and Redis?

1. **Celery**: Python's distributed asynchronous task queue. It manages background execution, retries, and scheduled workflows.
2. **Redis**: An in-memory data store used as the **Message Broker** (the mailbox holding pending email jobs) and **Result Backend** (storing delivery status).
3. **Celery Worker**: An independent background process running in a separate terminal that pulls tasks from Redis and executes `send_email()`.
