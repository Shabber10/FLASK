# Day 21: Task State Tracking & Async Execution

## 1. Invoking Celery Tasks
- `.delay(*args, **kwargs)`: Asynchronously queues task for execution.
- `.apply_async((args,), countdown=60)`: Schedules task execution with delayed countdown or ETA.

```python
@celery.task
def send_async_email(email_address):
    # Long running task code...
    return f"Email sent to {email_address}"

# Trigger task in view:
task = send_async_email.delay("user@example.com")
```
