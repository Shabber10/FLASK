## 🔤 Celery & Background Processing Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Synchronous** | Execution mode where server freezes waiting for task completion. | Standard Flask HTTP request |
| **Asynchronous** | Execution mode offloading tasks to background queues. | Task queued in 1ms |
| **Celery** | Distributed background task queue framework for Python. | `@celery_app.task` |
| **Message Broker** | RAM queue storing pending task messages. | Redis (`redis://localhost:6379/0`) |
| **Result Backend** | Database storing task completion states & return values. | Redis / PostgreSQL |
| **Celery Worker** | Independent CLI process executing tasks in the background. | `celery -A app.celery_app worker` |
| **`.delay()`** | Shorthand method triggering asynchronous task execution. | `task.delay(arg1, arg2)` |
| **`AsyncResult`** | Class querying task status from Result Backend by UUID. | `AsyncResult(task_id)` |
| **`HTTP 202`** | Status code indicating request accepted for background processing. | `202 Accepted` |

## 🧠 Memory Mnemonics

### 1. Celery Architecture Pipeline (`C-E-L-E-R-Y`)
Remember **C-E-L-E-R-Y** for background task setups:
- **C** -> **Create Tasks** (`@celery_app.task`)
- **E** -> **Enable Redis Broker** (`broker_url="redis://..."`)
- **L** -> **Launch Worker Process** (`celery -A app worker`)
- **E** -> **Execute Asynchronously** (`task.delay()`)
- **R** -> **Read AsyncResult State** (`PENDING` -> `SUCCESS`)
- **Y** -> **Yield HTTP 202 Accepted**

---

### 2. Asynchronous Flow (`A-S-Y-N-C`)
Remember **A-S-Y-N-C** for background job execution:
- **A** -> **Accept Request** (Receive POST payload)
- **S** -> **Send Message to Broker** (`.delay()`)
- **Y** -> **Yield Immediate 202 Response** (Return `task_id`)
- **N** -> **Navigate Background Worker** (Worker picks task from Redis)
- **C** -> **Complete & Write Result** (Store result in backend)

## ⚡ Quick-Reference Code Snippets

### 1. Celery Factory Integration
```python
from celery import Celery, Task

def celery_init_app(app):
    class FlaskTask(Task):
        def __call__(self, *args, **kwargs):
            with app.app_context():
                return self.run(*args, **kwargs)

    celery_app = Celery(app.name, task_cls=FlaskTask)
    celery_app.config_from_object(app.config.get("CELERY", {}))
    return celery_app
```

### 2. Task Definition & Trigger
```python
@celery_app.task(bind=True)
def send_email_task(self, recipient):
    # Long running work...
    return f"Email sent to {recipient}"

# Trigger task asynchronously in route:
@app.route('/send-email', methods=['POST'])
def send_email():
    task = send_email_task.delay("user@test.com")
    return jsonify({"task_id": task.id, "status": "accepted"}), 202
```

### 3. Celery Worker Terminal Command
```bash
celery -A app.celery_app worker --loglevel=info
```
