## 🔤 JWT Authentication Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **JWT** | JSON Web Token (Stateless digitally signed passport). | `Header.Payload.Signature` |
| **Bearer Token** | HTTP Authorization header scheme carrying access tokens. | `Authorization: Bearer <token>` |
| **Access Token** | Short-lived token (15 mins) used for API resource calls. | `create_access_token(identity=101)` |
| **Refresh Token** | Long-lived token (7 days) used to request new access tokens. | `create_refresh_token(identity=101)` |
| **JTI** | JWT ID (Unique UUID string assigned to every token). | Used for token revocation tracking |
| **Blocklist** | Cache (Redis) storing revoked JTI strings to reject logged-out tokens. | `@jwt.token_in_blocklist_loader` |
| **Claims** | Dictionary key-value pairs stored inside JWT payload. | `sub`, `exp`, `jti`, `role` |

## 🧠 Memory Mnemonics

### 1. Anatomy of a JWT (`H-P-S`)
Remember **H-P-S** for the 3 Base64 segments of a JWT string:
- **H** -> **Header** (Specifies algorithm `HS256` and token type)
- **P** -> **Payload** (Stores claims like `sub`, `exp`, `role`)
- **S** -> **Signature** (HMAC SHA-256 hash using `JWT_SECRET_KEY` preventing tampering)

---

### 2. JWT Token Lifecycle (`J-W-T`)
Remember **J-W-T** for token handling steps:
- **J** -> **JSON Web Token Generation** (`create_access_token`, `create_refresh_token`)
- **W** -> **With Bearer Header** (Client sends `Authorization: Bearer <token>`)
- **T** -> **Terminate via JTI Blocklist** (Add `jti` to blocklist on `/logout`)

## ⚡ Quick-Reference Code Snippets

### 1. Flask-JWT-Extended Setup
```python
from datetime import timedelta
from flask_jwt_extended import JWTManager, create_access_token, create_refresh_token

app.config['JWT_SECRET_KEY'] = 'strong-production-jwt-secret-key'
app.config['JWT_ACCESS_TOKEN_EXPIRES'] = timedelta(minutes=15)
app.config['JWT_REFRESH_TOKEN_EXPIRES'] = timedelta(days=7)

jwt = JWTManager(app)
```

### 2. Protecting Routes & Reading User Identity
```python
from flask_jwt_extended import jwt_required, get_jwt_identity, get_jwt

@app.route('/profile')
@jwt_required()
def profile():
    user_id = get_jwt_identity()
    jti = get_jwt()['jti']
    return jsonify({"user_id": user_id, "jti": jti}), 200

@app.route('/refresh', methods=['POST'])
@jwt_required(refresh=True)
def refresh():
    user_id = get_jwt_identity()
    new_access_token = create_access_token(identity=user_id)
    return jsonify(access_token=new_access_token), 200
```

### 3. JTI Revocation Blocklist Callback
```python
blocklist = set()

@jwt.token_in_blocklist_loader
def check_if_revoked(header, payload):
    return payload['jti'] in blocklist

@app.route('/logout', methods=['POST'])
@jwt_required()
def logout():
    blocklist.add(get_jwt()['jti'])
    return jsonify({"message": "Token revoked"}), 200
```
