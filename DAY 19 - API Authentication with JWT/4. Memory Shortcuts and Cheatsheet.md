## 🔤 Complete JWT Terminology & Definition Glossary

| Term | Plain-English Definition | Real-World Code / Header Example |
| :--- | :--- | :--- |
| **JWT** | JSON Web Token; a compact, URL-safe, signed digital credential. | `Header.Payload.Signature` |
| **Bearer Token** | HTTP Authorization header carrying an access token. | `Authorization: Bearer eyJhbGci...` |
| **Access Token** | Short-lived token (15 mins) used for calling protected API routes. | `create_access_token(identity="101")` |
| **Refresh Token** | Long-lived token (7 days) used exclusively to rotate new token pairs. | `create_refresh_token(identity="101")` |
| **`jti` (JWT ID)** | Unique UUID identifier assigned to every token for revocation tracking. | `jti: "d7b9c2a1-8f3e-4b2a..."` |
| **Claims** | Key-value pairs stored in the JWT payload (`sub`, `exp`, `role`). | `{"sub": "101", "role": "Admin"}` |
| **`sub` (Subject)** | Standard RFC 7519 claim holding the user identity string. | `{"sub": "101"}` |
| **`exp` (Expiration)** | Standard RFC 7519 claim holding the Unix expiration timestamp. | `{"exp": 1740000900}` |
| **Redis Blocklist** | Distributed cache storing revoked `jti` strings with key TTL. | `redis.setex("jwt:revoked:<jti>", ttl, "true")` |
| **Rotation** | Single-use refresh token pattern: revoking old refresh token upon each refresh. | Prevents replay attacks from stolen refresh tokens |
| **HS256** | Symmetric HMAC SHA-256 signing with a single shared secret key. | Monolithic API services |
| **RS256** | Asymmetric RSA signing (Private key signs, Public key verifies). | Distributed microservice architectures |
| **Clock Drift / Leeway** | Small grace window (10s) allowed for minor cluster time mismatch. | `JWT_DECODE_LEEWAY = timedelta(seconds=10)` |

## 🧠 Memory Mnemonics

### 1. Anatomy of a JWT (`H-P-S`)
Remember **H-P-S** for the 3 Base64 segments of a JWT string:
- **H** -> **Header** (`alg`, `typ`)
- **P** -> **Payload** (`sub`, `exp`, `jti`, `role`)
- **S** -> **Signature** (HMAC-SHA256 tamper-proof cryptographic hash)

---

### 2. The 3 Loaders in Flask-JWT-Extended (`I-L-B`)
Remember **I-L-B** for the 3 core extension callback decorators:
- **I** -> **`@jwt.user_identity_loader`**: Serializes user model to string `sub`.
- **L** -> **`@jwt.user_lookup_loader`**: Deserializes string `sub` into `current_user` object.
- **B** -> **`@jwt.token_in_blocklist_loader`**: Checks if `jti` is revoked in Redis.

---

### 3. JWT Token Lifecycle (`J-W-T`)
- **J** -> **JSON Web Token Generation** (`create_access_token`, `create_refresh_token`)
- **W** -> **With Bearer Header** (Client sends `Authorization: Bearer <token>`)
- **T** -> **Terminate via Redis JTI Blocklist** (Add `jti` to Redis on `/logout` and rotate on `/refresh`)

## ⚡ Quick-Reference Code Snippets

### 1. Flask-JWT-Extended Setup with Environment Config
```python
import os
from datetime import timedelta
from flask_jwt_extended import JWTManager

app.config['JWT_SECRET_KEY'] = os.environ.get('JWT_SECRET_KEY', 'secure-jwt-secret-key-32bytes')
app.config['JWT_ACCESS_TOKEN_EXPIRES'] = timedelta(minutes=15)
app.config['JWT_REFRESH_TOKEN_EXPIRES'] = timedelta(days=7)
app.config['JWT_DECODE_LEEWAY'] = timedelta(seconds=10)

jwt = JWTManager(app)
```

### 2. Protecting Routes & Resolving Current User
```python
from flask_jwt_extended import jwt_required, get_jwt_identity, get_jwt, current_user

@app.route('/api/v1/profile')
@jwt_required()
def profile():
    user_id = get_jwt_identity()
    claims = get_jwt()
    return jsonify({
        "user_id": user_id, 
        "username": current_user['username'], 
        "role": claims.get('role'),
        "jti": claims.get('jti')
    }), 200
```

### 3. Redis-Backed JTI Revocation & Refresh Token Rotation
```python
import os
import redis
from datetime import datetime, timezone
from flask_jwt_extended import jwt_required, get_jwt, get_jwt_identity, create_access_token, create_refresh_token

redis_client = redis.Redis.from_url(os.environ.get("REDIS_URL", "redis://localhost:6379/0"), decode_responses=True)

@jwt.token_in_blocklist_loader
def check_if_revoked(jwt_header, jwt_payload):
    return redis_client.get(f"jwt:revoked:{jwt_payload['jti']}") is not None

@app.route('/api/v1/auth/logout', methods=['POST'])
@jwt_required(verify_type=False)
def logout():
    jwt_data = get_jwt()
    jti, exp = jwt_data['jti'], jwt_data['exp']
    ttl = max(int(exp - datetime.now(timezone.utc).timestamp()), 1)
    redis_client.setex(f"jwt:revoked:{jti}", ttl, "true")
    return jsonify({"message": "Token successfully revoked."}), 200

@app.route('/api/v1/auth/refresh', methods=['POST'])
@jwt_required(refresh=True)
def refresh():
    jwt_data = get_jwt()
    old_jti, exp = jwt_data['jti'], jwt_data['exp']
    ttl = max(int(exp - datetime.now(timezone.utc).timestamp()), 1)
    redis_client.setex(f"jwt:revoked:{old_jti}", ttl, "true")  # Revoke old refresh token

    user_id = get_jwt_identity()
    return jsonify({
        "access_token": create_access_token(identity=user_id),
        "refresh_token": create_refresh_token(identity=user_id)
    }), 200
```
