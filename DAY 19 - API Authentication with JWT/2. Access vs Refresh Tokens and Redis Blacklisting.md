# Day 19: Refresh Tokens & Token Revocation

## 1. Access vs Refresh Token Pair
- **Access Token**: Short-lived (15 minutes), sent in `Authorization: Bearer <token>` header.
- **Refresh Token**: Long-lived (7 days), used exclusively to request a new access token without re-entering passwords.

## 2. Token Revocation / Blacklisting
Store revoked token JTI (JWT ID) strings in Redis with an expiration matching the token's lifetime.
