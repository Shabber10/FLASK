# Day 19: API Authentication with JWT

## 1. JSON Web Token (JWT) Mechanics
JWT provides stateless authentication comprising three base64-encoded segments: `Header.Payload.Signature`.

## 2. Flask-JWT-Extended Integration
```python
from flask_jwt_extended import JWTManager, create_access_token, jwt_required, get_jwt_identity

jwt = JWTManager(app)

@app.route('/login', methods=['POST'])
def login():
    token = create_access_token(identity='user_101')
    return jsonify(access_token=token)
```
