## 1. Configuring `Flask-JWT-Extended`

Install the extension:

```bash
pip install Flask-JWT-Extended
```

Configure JWT settings on your Flask application object:

```python
from datetime import timedelta
from flask import Flask
from flask_jwt_extended import JWTManager

app = Flask(__name__)

# Cryptographic signing key for JWT tokens (MUST be secret in production!)
app.config['JWT_SECRET_KEY'] = 'jwt-masterclass-secret-key-32bytes'

# Configure Access Token Expiration Window (e.g. 15 minutes)
app.config['JWT_ACCESS_TOKEN_EXPIRES'] = timedelta(minutes=15)

# Initialize JWT Manager Extension
jwt = JWTManager(app)
```

## 2. Generating Access Tokens (`create_access_token`)

When a user logs in with valid credentials, issue a signed JWT Access Token using **`create_access_token()`**:

```python
from flask import request, jsonify
from flask_jwt_extended import create_access_token
from werkzeug.security import check_password_hash

@app.route('/api/v1/auth/login', methods=['POST'])
def login():
    username = request.json.get('username')
    password = request.json.get('password')

    user = User.query.filter_by(username=username).first()
    
    if user and check_password_hash(user.password_hash, password):
        # Create signed access token embedding user.id as identity subject ('sub')
        access_token = create_access_token(identity=user.id)
        return jsonify({
            "status": "success",
            "access_token": access_token,
            "token_type": "Bearer"
        }), 200

    return jsonify({"error": "Invalid username or password"}), 401
```

## 3. Protecting Endpoints (`@jwt_required`)

Decorate routes with **`@jwt_required()`** to restrict access exclusively to requests presenting a valid Bearer token in the `Authorization` header:

```python
from flask_jwt_extended import jwt_required, get_jwt_identity, get_jwt

@app.route('/api/v1/profile', methods=['GET'])
@jwt_required()  # Validates Authorization: Bearer <token> automatically!
def get_user_profile():
    # Retrieve user_id embedded in active JWT token
    current_user_id = get_jwt_identity()
    
    # Retrieve full raw JWT payload claims dictionary
    raw_claims = get_jwt()
    
    user = User.query.get(current_user_id)
    return jsonify({
        "status": "success",
        "data": {
            "user_id": user.id,
            "username": user.username,
            "email": user.email,
            "token_jti": raw_claims['jti']
        }
    }), 200
```

## 4. Injecting Custom Claims (`@jwt.additional_claims_loader`)

Attach extra attributes (such as user role or tenant ID) into the JWT payload during token creation:

```python
@jwt.additional_claims_loader
def add_claims_to_access_token(identity):
    user = User.query.get(identity)
    return {
        "role": user.role,
        "is_admin": user.role == 'Admin'
    }
```
