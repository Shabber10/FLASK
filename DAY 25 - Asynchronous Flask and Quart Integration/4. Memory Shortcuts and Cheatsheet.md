## 🔤 Async Flask & Quart Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **`async` / `await`** | Python syntax defining non-blocking coroutines and awaiting I/O. | `async def route(): await fetch()` |
| **WSGI** | Synchronous 1-thread-per-request web server gateway interface. | Standard Flask / Gunicorn |
| **ASGI** | Asynchronous event-loop driven server gateway interface. | Quart / Uvicorn / Hypercorn |
| **`asgiref`** | Underlying ASGI-WSGI bridge adapter powering Flask 2.0+ async routes. | `pip install asgiref` |
| **`asyncio.gather()`** | Runs multiple async coroutines concurrently in parallel. | `await asyncio.gather(t1, t2)` |
| **`asyncio.to_thread()`** | Offloads blocking synchronous calls to a background thread pool. | `await asyncio.to_thread(db_query)` |
| **Quart** | Full ASGI-native reimplementation of Flask using `asyncio`. | `from quart import Quart` |
| **Event Loop** | Central engine scheduling and executing async coroutines. | Python `asyncio` loop |

## 🧠 Memory Mnemonics

### 1. Asynchronous Execution (`A-S-Y-N-C`)
Remember **A-S-Y-N-C** for async coroutine routes:
- **A** -> **Await Non-Blocking I/O** (`await asyncio.sleep(1)`)
- **S** -> **Single-Threaded Event Loop**
- **Y** -> **Yield Control to Loop** (Frees CPU to serve other requests)
- **N** -> **Non-Blocking Coroutine** (`async def route():`)
- **C** -> **Concurrent Parallel Execution** (`asyncio.gather()`)

---

### 2. ASGI Architecture (`A-S-G-I`)
Remember **A-S-G-I** for modern async server standards:
- **A** -> **Asynchronous Server Gateway Interface**
- **S** -> **Supports WebSockets & HTTP Streaming**
- **G** -> **Gather Concurrent Tasks**
- **I** -> **Integrates with Uvicorn / Hypercorn**

## ⚡ Quick-Reference Code Snippets

### 1. Native Async Route in Flask 2.0+
```python
import asyncio
from flask import Flask, jsonify

app = Flask(__name__)

@app.route('/async-data')
async def get_data():
    await asyncio.sleep(1) # Non-blocking async sleep
    return jsonify({"status": "Finished"})
```

### 2. Parallel Concurrency with `asyncio.gather()`
```python
@app.route('/aggregate')
async def aggregate():
    # Runs all 3 tasks concurrently in ~1 sec total!
    res1, res2, res3 = await asyncio.gather(
        fetch_api(1),
        fetch_api(2),
        fetch_api(3)
    )
    return jsonify({"results": [res1, res2, res3]})
```

### 3. Quart Application Setup
```python
from quart import Quart, jsonify, request

app = Quart(__name__)

@app.route('/data', methods=['POST'])
async def handle():
    payload = await request.get_json() # Note await on request in Quart!
    return jsonify(payload)
```
