## 1. What is `async` / `await` in Plain English?

Imagine a restaurant with 1 Waiter serving customers:

```
1. SYNCHRONOUS WAITER (1 Waiter = 1 Table at a time - Slow!)
   Waiter takes order from Table 1 ──> Stands in kitchen 15 mins waiting for food ──> Serves Table 1
   (Table 2 waits 15 minutes just to give their order! 😫)

2. ASYNCHRONOUS WAITER (1 Waiter = 10 Tables concurrently - Fast!)
   Waiter takes order from Table 1 ──> Gives order to kitchen ──> IMMEDIATELY takes order from Table 2! ⚡
   (While Table 1's food cooks in the background, the Waiter keeps serving other tables!)
```

*   **Synchronous (`def`)**: The thread freezes while waiting for network I/O (like calling an external payment API).
*   **Asynchronous (`async def` / `await`)**: The thread pauses the route execution, frees the CPU to serve other incoming requests, and resumes when the network I/O completes!

---

## 2. WSGI vs. ASGI Explained Simply

*   **WSGI (Web Server Gateway Interface)**: The classic Python web standard (used by Flask 1.x and Django 1.x). It processes requests **synchronously**, dedicating 1 operating system thread per request.
*   **ASGI (Asynchronous Server Gateway Interface)**: The modern Python web standard (used by Quart, FastAPI, and Starlette). Powered by Python's `asyncio` event loop, a single thread can handle thousands of concurrent I/O requests!

---

## 3. Native Async Support in Flask 2.0+

Starting in **Flask 2.0+**, you can write native asynchronous route functions using `async def`!

```python
# Flask 2.0+ Native Async Route!
@app.route('/api/v1/fast-data')
async def get_fast_data():
    # Non-blocking async sleep or async HTTP call
    await asyncio.sleep(1)
    return jsonify({"status": "Finished without blocking other requests!"})
```

Under the hood, Flask uses **`asgiref`** to run your `async def` function on Python's `asyncio` event loop.

---

## 4. What is Quart?

**Quart** is an ASGI web framework designed as a **100% API-compatible async clone of Flask**!

If you know Flask syntax (`from flask import Flask, jsonify, request`), you already know Quart syntax (`from quart import Quart, jsonify, request`)! Quart runs natively on ASGI without needing `asgiref` wrappers, unlocking massive concurrency performance!
