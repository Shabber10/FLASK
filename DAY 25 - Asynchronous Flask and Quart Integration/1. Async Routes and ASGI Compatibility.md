# Day 25: Asynchronous Flask (Flask 2.0+) & Quart

## 1. Native `async` / `await` in Flask 2.0+
Flask 2.0+ supports `async` view functions when `asgiref` is installed:

```python
import asyncio
from flask import Flask

app = Flask(__name__)

@app.route('/async-endpoint')
async def async_route():
    await asyncio.sleep(1) # Non-blocking I/O
    return {"status": "Async execution finished"}
```
