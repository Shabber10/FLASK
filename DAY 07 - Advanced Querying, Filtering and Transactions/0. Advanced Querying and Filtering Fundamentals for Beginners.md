## 1. Raw SQL vs. Flask-SQLAlchemy Query Translation Table

| Query Goal | Raw MySQL Query (`collegedb`) | Flask-SQLAlchemy ORM Equivalent |
| :--- | :--- | :--- |
| **Fetch All Students** | `SELECT * FROM student` | `Student.query.all()` |
| **Fetch by Primary Key** | `SELECT * FROM student WHERE id = 1` | `Student.query.get(1)` / `db.session.get(Student, 1)` |
| **Filter by Condition** | `SELECT * FROM student WHERE smarks >= 80`| `Student.query.filter(Student.smarks >= 80).all()` |
| **Filter by Exact Match**| `SELECT * FROM student WHERE scity = 'Hyderabad'`| `Student.query.filter_by(scity='Hyderabad').all()` |
| **Order by Highest Marks**| `SELECT * FROM student ORDER BY smarks DESC`| `Student.query.order_by(Student.smarks.desc()).all()` |
| **Search by Substring** | `SELECT * FROM student WHERE sname LIKE '%raj%'`| `Student.query.filter(Student.sname.ilike('%raj%')).all()` |
| **Count Total Students** | `SELECT COUNT(*) FROM student` | `db.session.query(func.count(Student.id)).scalar()` |
| **Average Marks** | `SELECT AVG(smarks) FROM student` | `db.session.query(func.avg(Student.smarks)).scalar()` |

## 2. Advanced Query Logic in Flask

```python
from flask import Flask, render_template, request
from models import db, Student
from sqlalchemy import func

@app.route('/search-students')
def search_students():
    city = request.args.get('city')
    min_marks = request.args.get('min_marks', type=int, default=0)
    
    query = Student.query.filter(Student.smarks >= min_marks)
    if city:
        query = query.filter_by(scity=city)
        
    students = query.order_by(Student.smarks.desc()).all()
    avg_marks = db.session.query(func.avg(Student.smarks)).scalar() or 0
    
    return render_template('filtered_students.html', students=students, avg_marks=avg_marks)
```
