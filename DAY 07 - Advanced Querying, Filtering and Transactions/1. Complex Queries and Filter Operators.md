# Day 07: Complex Queries & Filter Operators

## 1. Filter Expressions in SQLAlchemy 2.0+
Use `filter()` for complex logical expressions (`or_`, `and_`, `in_`, `like`, `ilike`):

```python
from sqlalchemy import or_, and_, func

# Filter products with price between 10 and 100 or stock > 50
query = db.select(Product).filter(
    or_(
        and_(Product.price >= 10, Product.price <= 100),
        Product.stock > 50
    )
)
```
