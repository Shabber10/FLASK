# Day 07: Complex Queries & Filter Operators

Welcome to **Day 07** of the 30-Day Enterprise Flask Masterclass! Today, we explore advanced querying techniques in SQLAlchemy 2.0+, logical operator composition (`and_`, `or_`, `not_`), pattern matching (`like`, `ilike`), range filtering, ordering, and limiting.

---

## 1. Filter Expressions in SQLAlchemy 2.0+

SQLAlchemy 2.0 constructs queries using `db.select(Model)` objects combined with filter clauses:

```python
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

# Basic Filter Statement
stmt = db.select(Product).where(Product.price > 50.00)
products = db.session.execute(stmt).scalars().all()
```

### `where()` vs. `filter()`
In SQLAlchemy 2.0+, `where()` and `filter()` behave identically when passed column expressions. `where()` aligns with standard ANSI SQL syntax conventions.

## 2. Comparison & Logical Operators

SQLAlchemy overloads Python operators to generate SQL expressions:

| Operator / Expression | Description | Generated SQL Equivalent |
| :--- | :--- | :--- |
| `Model.field == val` | Exact equality | `field = 'val'` |
| `Model.field != val` | Inequality | `field != 'val'` |
| `Model.field > val` | Greater than | `field > val` |
| `Model.field.in_(['a', 'b'])` | In set | `field IN ('a', 'b')` |
| `Model.field.notin_([1, 2])` | Not in set | `field NOT IN (1, 2)` |
| `Model.field.is_(None)` | Null check | `field IS NULL` |
| `Model.field.is_not(None)` | Not null check | `field IS NOT NULL` |
| `Model.field.like('%term%')` | Case-sensitive pattern match | `field LIKE '%term%'` |
| `Model.field.ilike('%term%')` | Case-insensitive pattern match | `LOWER(field) LIKE '%term%'` |

## 3. Combining Operators (`and_`, `or_`, `not_`)

Import logical operators from `sqlalchemy`:

```python
from sqlalchemy import and_, or_, not_

# Complex Filter Example:
# Find products in ('Electronics', 'Computers') WHERE (Price between 100 and 500 OR Rating >= 4.5)
stmt = db.select(Product).where(
    and_(
        Product.category.in_(['Electronics', 'Computers']),
        or_(
            and_(Product.price >= 100, Product.price <= 500),
            Product.rating >= 4.5
        ),
        not_(Product.is_discontinued == True)
    )
)
results = db.session.execute(stmt).scalars().all()
```

## 4. Sorting & Ordering (`order_by`)

Sort query results using `order_by()`:

```python
# 1. Single Column Ascending / Descending
stmt = db.select(Product).order_by(Product.price.desc())

# 2. Multi-Column Sorting (Sort by Category ASC, then Price DESC)
stmt = db.select(Product).order_by(
    Product.category.asc(),
    Product.price.desc()
)
```

---

## 5. Slicing Results (`limit` and `offset`)

Restrict query bounds using `limit()` and `offset()`:

```python
# Fetch 10 records starting from row offset 20 (Page 3)
stmt = db.select(Product).order_by(Product.id).offset(20).limit(10)
items = db.session.execute(stmt).scalars().all()
```
