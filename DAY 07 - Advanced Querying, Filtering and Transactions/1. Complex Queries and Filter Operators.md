## 1. Filter Expressions in SQLAlchemy 2.0+

In modern SQLAlchemy 2.0+, queries start with a `db.select(Model)` statement and append filter clauses via `.where()`:

```python
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

# Basic Filter Statement
stmt = db.select(Product).where(Product.price > 50.00)
products = db.session.execute(stmt).scalars().all()
```

## 2. Comparison & Pattern Match Operators

SQLAlchemy overloads standard Python operators and methods to generate ANSI SQL expressions:

| Operator / Method | Description | Generated SQL Equivalent |
| :--- | :--- | :--- |
| `Model.field == val` | Exact equality match | `field = 'val'` |
| `Model.field != val` | Inequality match | `field != 'val'` |
| `Model.field > val` | Greater than | `field > val` |
| `Model.field.in_(['a', 'b'])` | In set list | `field IN ('a', 'b')` |
| `Model.field.notin_([1, 2])` | Not in set list | `field NOT IN (1, 2)` |
| `Model.field.is_(None)` | Null check | `field IS NULL` |
| `Model.field.is_not(None)` | Not null check | `field IS NOT NULL` |
| `Model.field.like('%term%')` | Case-sensitive pattern match | `field LIKE '%term%'` |
| `Model.field.ilike('%term%')` | Case-insensitive pattern match | `LOWER(field) LIKE '%term%'` |

## 3. Combining Logical Operators (`and_`, `or_`, `not_`)

To build complex search filters combining multiple conditions, import logical functions from `sqlalchemy`:

```python
from sqlalchemy import and_, or_, not_

# Complex Query Example:
# Find active products in ('Electronics', 'Computers') 
# WHERE (Price is between $100 and $500 OR Rating >= 4.5)
stmt = db.select(Product).where(
    and_(
        Product.category.in_(['Electronics', 'Computers']),
        or_(
            and_(Product.price >= 100.0, Product.price <= 500.0),
            Product.rating >= 4.5
        ),
        not_(Product.is_discontinued == True)
    )
)
results = db.session.execute(stmt).scalars().all()
```

> **Note**: Passing multiple comma-separated expressions directly into `.where(cond1, cond2)` automatically joins them with `AND`.

## 4. Sorting Results (`order_by`)

Sort query results using `.order_by()`:

```python
# 1. Single Column Ascending (Low to High) / Descending (High to Low)
stmt = db.select(Product).order_by(Product.price.desc())

# 2. Multi-Column Sorting (Sort by Category A-Z, then Price High to Low)
stmt = db.select(Product).order_by(
    Product.category.asc(),
    Product.price.desc()
)
```

---

## 5. Result Slicing Bounds (`limit` and `offset`)

Restrict query boundaries directly using `limit()` and `offset()`:

```python
# Fetch 10 records starting from row 20 (Simulates Page 3 offset)
stmt = db.select(Product).order_by(Product.id).offset(20).limit(10)
items = db.session.execute(stmt).scalars().all()
```
