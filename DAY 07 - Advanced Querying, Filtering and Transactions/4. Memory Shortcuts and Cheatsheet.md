## 🔤 Advanced Querying & Filtering Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Query** | Asking a database to retrieve specific matching rows. | `db.select(Product)` |
| **Filter** | Adding conditions to restrict returned rows. | `.where(Product.price < 50)` |
| **Pattern Match** | Searching for partial text matches. | `Product.name.ilike('%phone%')` |
| **Pagination** | Splitting large result sets into page chunks. | `db.paginate(stmt, page=1, per_page=10)` |
| **Aggregation** | Calculating summary statistics across rows. | `func.avg()`, `func.count()` |
| **Savepoint** | A temporary checkpoint allowing partial transaction rollback. | `db.session.begin_nested()` |

---

## 🧠 Memory Mnemonics

### 1. SQL Query Statement Pipeline Order (`S-W-G-H-O-L`)
Remember **S-W-G-H-O-L** for query statement construction:
- **S** -> **`select()`** (Specify target model or column expressions)
- **W** -> **`where()`** (Apply filtering constraints)
- **G** -> **`group_by()`** (Group by categorical attributes)
- **H** -> **`having()`** (Filter aggregated groups)
- **O** -> **`order_by()`** (Sort by columns ASC/DESC)
- **L** -> **`limit()` / `offset()`** (Set result pagination bounds)

---

### 2. Common `func` Aggregation Functions
- **`func.count(Model.id)`**: Counts total records.
- **`func.avg(Model.price)`**: Computes average of column values.
- **`func.sum(Model.amount)`**: Computes sum of column values.
- **`func.min(Model.score)`** / **`func.max(Model.score)`**: Minimum and Maximum column values.

## ⚡ Quick-Reference Code Snippets

### 1. Multi-Condition Filtering Query
```python
from sqlalchemy import and_, or_

stmt = db.select(Product).where(
    and_(
        Product.category == 'Electronics',
        or_(Product.price < 50.0, Product.rating >= 4.8)
    )
).order_by(Product.price.asc())

results = db.session.execute(stmt).scalars().all()
```

### 2. Flask-SQLAlchemy `db.paginate()` Usage
```python
stmt = db.select(Product).order_by(Product.name)
pagination = db.paginate(stmt, page=current_page, per_page=10, error_out=False)

items = pagination.items        # List of model instances for active page
total_pages = pagination.pages  # Total computed page count
```

### 3. Nested Transaction Savepoint (`begin_nested()`)
```python
try:
    db.session.add(parent_obj)
    savepoint = db.session.begin_nested()
    try:
        db.session.add(child_obj)
    except Exception:
        savepoint.rollback()  # Rollback child only; parent stays staged
    db.session.commit()
except Exception:
    db.session.rollback()     # Full parent rollback
```
