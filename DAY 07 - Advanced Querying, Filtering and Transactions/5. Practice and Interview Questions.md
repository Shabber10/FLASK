# Day 07: Practice & Technical Interview Questions

This question bank is divided into **3 progression levels**, starting from absolute querying fundamentals up to `WHERE` vs `HAVING` and nested savepoints.

---

## 🟢 Level 1: Absolute Beginner Questions

### Q1: What is Database Filtering in simple terms?
**Answer**:
Database Filtering is the process of adding rules (`WHERE` conditions) to a database query so that it returns only the specific rows that match a user's request (e.g. *"Only show products under $50"*), rather than returning every row in the table.

---

### Q2: What is the difference between `like()` and `ilike()` in SQLAlchemy?
**Answer**:
*   `like()`: Performs a **case-sensitive** search. Pattern `'python'` matches `'python'`, but fails to match `'Python'`.
*   `ilike()`: Performs a **case-insensitive** search. Pattern `'%python%'` matches `'Python'`, `'PYTHON'`, and `'PyThOn'`.

---

### Q3: What is Pagination and why is it used on websites?
**Answer**:
Pagination is the practice of splitting large search results into small page chunks (e.g. 10 items per page). It is used on websites to prevent browsers from freezing and to stop database servers from crashing when querying thousands of items at once.

---

### Q4: What is an Aggregation in SQL?
**Answer**:
An Aggregation is a summary calculation performed across multiple rows of data to produce a single value. Examples include `func.count()` (total rows), `func.avg()` (average price), `func.max()` (highest price), and `func.min()` (lowest price).

---

### Q5: How do you search for records containing a specific keyword anywhere in their name?
**Answer**:
Use `.ilike()` with `%` wildcard characters:
```python
stmt = db.select(Product).where(Product.name.ilike('%phone%'))
```

---

## 🟡 Level 2: Intermediate Questions

### Q6: How does `db.paginate()` calculate the total page count under the hood?
**Answer**:
`db.paginate(stmt, page, per_page)` executes two SQL queries:
1.  Adds `LIMIT per_page OFFSET (page - 1) * per_page` to `stmt` to fetch items for the current active page.
2.  Constructs a secondary `SELECT COUNT(*)` query based on `stmt` to count total matching rows.

Total pages is computed as $\lceil \text{Total Rows} / \text{Per Page} \rceil$.

---

### Q7: How do you perform multi-column ordering in SQLAlchemy 2.0?
**Answer**:
Pass multiple column expressions into `.order_by()`:
```python
stmt = db.select(Product).order_by(
    Product.category.asc(),
    Product.price.desc()
)
```
This orders results by Category alphabetically, and within each category, orders products from highest price to lowest.

---

### Q8: How do `and_()` and comma-separated arguments inside `where()` differ?
**Answer**:
In SQLAlchemy, passing multiple comma-separated expressions directly into `.where(cond1, cond2, cond3)` is functionally identical to `.where(and_(cond1, cond2, cond3))`. Both emit SQL `AND` operators joining the conditions.

---

### Q9: How do you search for `NULL` or non-`NULL` values using SQLAlchemy?
**Answer**:
Use `.is_(None)` and `.is_not(None)` methods:
```python
# Find products without a category
stmt = db.select(Product).where(Product.category.is_(None))

# Find products with a valid category
stmt = db.select(Product).where(Product.category.is_not(None))
```

---

### Q10: How do you retrieve a distinct list of values for a specific column?
**Answer**:
Call `.distinct()` on the select statement:
```python
stmt = db.select(Product.category).distinct()
categories = db.session.execute(stmt).scalars().all()
```

## 🔴 Level 3: Advanced & Enterprise Questions

### Q11: What is the difference between `WHERE` and `HAVING` clauses in SQL queries?
**Answer**:
*   `WHERE`: Filters individual table rows **before** any grouping or aggregation takes place.
*   `HAVING`: Filters aggregated groups **after** `GROUP BY` has collapsed rows.

```python
# Select categories with average price > 100 where stock > 0
stmt = db.select(
    Product.category,
    func.avg(Product.price)
).where(Product.stock > 0).group_by(Product.category).having(func.avg(Product.price) > 100)
```

---

### Q12: What is a Savepoint in database transaction management and how is it used in SQLAlchemy?
**Answer**:
A Savepoint allows creating a nested transaction boundary inside an existing database transaction. If an error occurs within the savepoint, you can issue `savepoint.rollback()` to undo operations back to the savepoint without invalidating or rolling back the parent transaction.

In SQLAlchemy, create savepoints using `savepoint = db.session.begin_nested()`.

---

### Q13: What is the difference between `func.count(1)` and `func.count(Model.column_name)`?
**Answer**:
*   `func.count(1)` (or `func.count(*)`): Counts total rows matching the query criteria, including rows where some columns are NULL.
*   `func.count(Model.column_name)`: Counts only rows where `column_name` contains a non-NULL value.

---

### Q14: How do you perform case-insensitive exact matching in SQLAlchemy?
**Answer**:
Use `func.lower()`:
```python
stmt = db.select(User).where(func.lower(User.email) == email_input.lower())
```

---

### Q15: How do `limit()` and `offset()` work together for manual API pagination?
**Answer**:
*   `limit(N)`: Specifies maximum rows to return per page ($N$).
*   `offset((page - 1) * N)`: Specifies how many initial rows to skip before returning $N$ items.
