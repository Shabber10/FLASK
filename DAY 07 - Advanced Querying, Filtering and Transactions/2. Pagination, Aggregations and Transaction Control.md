# Day 07: Pagination, Aggregations & Transactions

## 1. Flask-SQLAlchemy Pagination
`db.paginate()` divides large query datasets into chunks:

```python
page = request.args.get('page', 1, type=int)
pagination = db.paginate(db.select(Product), page=page, per_page=10, error_out=False)
items = pagination.items
total = pagination.total
```
