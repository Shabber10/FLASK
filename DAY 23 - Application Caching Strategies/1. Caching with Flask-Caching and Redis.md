## 1. Configuring `Flask-Caching`

Install `Flask-Caching`:

```bash
pip install Flask-Caching
```

Initialize `Cache` with your Flask application:

```python
from flask import Flask
from flask_caching import Cache

app = Flask(__name__)

# 1. Development In-Memory Cache (SimpleCache)
app.config['CACHE_TYPE'] = 'SimpleCache'
app.config['CACHE_DEFAULT_TIMEOUT'] = 300  # Default 5-minute timeout (300s)

cache = Cache(app)
```

## 2. Supported Cache Backends Compared

| Backend | Configuration | Ideal Use Case | Pros / Cons |
| :--- | :--- | :--- | :--- |
| **`SimpleCache`** | `'CACHE_TYPE': 'SimpleCache'` | Local Development & Unit Tests | In-memory Python dict; lost when server restarts; isolated per WSGI worker. |
| **`RedisCache`** | `'CACHE_TYPE': 'RedisCache'`, `'CACHE_REDIS_URL': 'redis://localhost:6379/0'` | **Production Multi-Worker Deployments** | High-performance shared RAM store across Gunicorn workers; persistent. |
| **`MemcachedCache`** | `'CACHE_TYPE': 'MemcachedCache'`, `'CACHE_MEMCACHED_SERVERS': ['127.0.0.1:11211']` | Distributed High-Throughput Caching | Fast key-value store; lacks persistent disk dumps. |
| **`FileSystemCache`** | `'CACHE_TYPE': 'FileSystemCache'`, `'CACHE_DIR': '/tmp/flask_cache'` | Disk-based Caching | Persists across restarts without Redis; slower than RAM. |

## 3. Production Enterprise Redis Setup

In production multi-server deployments, configure `RedisCache`:

```python
app.config.from_mapping(
    CACHE_TYPE='RedisCache',
    CACHE_REDIS_URL='redis://localhost:6379/0',
    CACHE_DEFAULT_TIMEOUT=600,
    CACHE_KEY_PREFIX='masterclass_' # Prevents key collisions across microservices!
)
cache = Cache(app)
```

## 4. Custom Cache Key Generators (`make_cache_key`)

By default, Flask-Caching generates cache keys using request path URLs. You can define custom key functions that include query parameters, user roles, or headers:

```python
from flask import request

def make_user_specific_cache_key():
    """Generates unique cache keys incorporating URL path + X-API-KEY header."""
    api_key = request.headers.get('X-API-KEY', 'anonymous')
    return f"cache:{request.path}?key={api_key}"

@app.route('/api/v1/user-dashboard')
@cache.cached(timeout=120, key_prefix=make_user_specific_cache_key)
def user_dashboard():
    return jsonify({"data": "Personalized dashboard payload"})
```
