# Day 23: Application Caching Strategies

## 1. Flask-Caching Architecture
Caching stores expensive calculation outputs or DB queries in fast key-value stores (Redis/Memcached).

```python
from flask_caching import Cache

cache = Cache(config={
    'CACHE_TYPE': 'RedisCache',
    'CACHE_REDIS_URL': 'redis://localhost:6379/0'
})
cache.init_app(app)
```
