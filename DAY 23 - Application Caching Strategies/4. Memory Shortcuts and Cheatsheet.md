## 🔤 Application Caching Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Caching** | Saving computed responses in fast RAM to avoid querying slow databases. | Response time drops from 200ms to 0.5ms |
| **Cache Hit** | Requested data is found in RAM memory instantly. | Fast 0.5ms response |
| **Cache Miss** | Requested data is not in RAM memory, requiring a database query. | Slow 200ms response |
| **Cache Invalidation** | Deleting or purging old cached data from RAM when database records change. | `cache.delete_memoized(func, id)` |
| **View Caching** | Caching the complete HTML rendered string or JSON API response. | `@cache.cached(timeout=60)` |
| **Memoization** | Caching the return value of an internal Python function based on arguments. | `@cache.memoize(timeout=300)` |
| **`SimpleCache`** | In-memory Python dict cache backend for local development. | `'CACHE_TYPE': 'SimpleCache'` |
| **`RedisCache`** | Shared Redis RAM backend for multi-worker production servers. | `'CACHE_TYPE': 'RedisCache'` |
| **Cache Stampede** | Traffic spike swarming DB when a high-frequency cache key expires. | Thundering Herd |

## 🧠 Memory Mnemonics

### 1. Caching Lifecycle (`C-A-C-H-E`)
Remember **C-A-C-H-E** for application caching:
- **C** -> **Check RAM First** (`cache.get(key)`)
- **A** -> **Access Fast Copy** (Return instant Cache Hit)
- **C** -> **Compute on Miss** (Query DB on Cache Miss)
- **H** -> **Hold in Memory** (Save copy with timeout expiration)
- **E** -> **Expire / Invalidate** (Purge when record updates)

---

### 2. Cache Hit Performance (`H-I-T-S`)
Remember **H-I-T-S** for performance goals:
- **H** -> **Hit in Memory** (Target > 90% cache hit ratio)
- **I** -> **Instant Sub-Millisecond Response** (< 1ms latency)
- **T** -> **Timeout Expiration Control** (`CACHE_DEFAULT_TIMEOUT=300`)
- **S** -> **Store Fresh DB Results**

## ⚡ Quick-Reference Code Snippets

### 1. Flask-Caching Configuration
```python
from flask_caching import Cache

# Production Redis Setup
app.config.from_mapping(
    CACHE_TYPE='RedisCache',
    CACHE_REDIS_URL='redis://localhost:6379/0',
    CACHE_DEFAULT_TIMEOUT=300
)
cache = Cache(app)
```

### 2. View Caching & Function Memoization
```python
# 1. View Caching (Caches full route response)
@app.route('/catalog')
@cache.cached(timeout=60)
def get_catalog():
    return jsonify(products)

# 2. Function Memoization (Caches function return value per argument)
@cache.memoize(timeout=300)
def calculate_discount(product_id, tier):
    return compute_heavy_discount(product_id, tier)
```

### 3. Cache Invalidation
```python
@app.route('/product/<int:id>', methods=['PUT'])
def update_product(id):
    # Update DB...
    cache.delete('/catalog')                     # Invalidate view cache
    cache.delete_memoized(calculate_discount, id) # Invalidate memoized function
    return jsonify({"message": "Updated!"})
```
