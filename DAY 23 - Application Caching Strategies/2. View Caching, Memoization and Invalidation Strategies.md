## 1. View Caching (`@cache.cached`)

View Caching stores the complete HTTP response (HTML rendered string or JSON body) generated by a Flask route function:

```python
from flask import jsonify
from app_factory import cache

@app.route('/api/v1/catalog')
@cache.cached(timeout=60)  # Caches full JSON response for 60 seconds!
def get_catalog():
    print("⚠️ [DATABASE QUERY] Fetching catalog records from DB...")
    products = Product.query.all()
    return jsonify([p.to_dict() for p in products])
```

## 2. Function Memoization (`@cache.memoize`)

Unlike View Caching (which caches HTTP endpoints), **Function Memoization** caches the return values of internal Python functions based on the exact positional and keyword arguments passed into them:

```python
@cache.memoize(timeout=300)
def calculate_user_loyalty_score(user_id, year):
    """Heavy mathematical calculation cached per (user_id, year) pair."""
    print(f"⚠️ [COMPUTATION] Computing loyalty score for user #{user_id} in {year}...")
    orders = Order.query.filter_by(user_id=user_id, year=year).all()
    score = sum(o.total_amount for o in orders) * 1.5
    return score
```

### 2. Event-Driven ORM Invalidation (`sqlalchemy.event`)
Automate cache invalidation using SQLAlchemy ORM event listeners:

```python
from sqlalchemy.event import listens_for

@listens_for(Product, 'after_update')
@listens_for(Product, 'after_delete')
def auto_invalidate_product_cache(mapper, connection, target):
    """Automatically flushes product cache whenever a Product is modified."""
    cache.delete('/api/v1/catalog')
    cache.delete_memoized(calculate_product_discount, target.id)
```

## 4. Mitigating Cache Stampede (Thundering Herd)

> ⚠️ **Cache Stampede**: Occurs when a high-traffic cache key (e.g. 10,000 req/sec) expires. Hundreds of web request threads discover a Cache Miss simultaneously and swarm the database at once, causing a server crash!

### Enterprise Mitigation Strategies:
1.  **Probabilistic Early Expiration (XFetch Algorithm)**: Recomputes cache in background before it expires.
2.  **Mutex Locking**: Uses a Redis lock so only 1 thread recomputes the cache miss while other threads wait.
