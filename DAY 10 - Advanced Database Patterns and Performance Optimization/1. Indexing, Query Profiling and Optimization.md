## 1. Database Indexing Mechanics

A database **Index** is a specialized B-Tree data structure that speeds up data retrieval operations on a table at the expense of additional storage space and slightly slower `INSERT`/`UPDATE` operations.

```
Without Index: Full Table Scan (O(N) - Scans 1,000,000 rows)
[ Row 1 ] -> [ Row 2 ] -> ... -> [ Row 1,000,000 ]

With B-Tree Index: Index Lookup (O(log N) - Scans ~20 node traversals)
                   [ Root Node ]
                  /             \
          [ Left Node ]     [ Right Node ]
```

### Types of Indexes in Flask-SQLAlchemy

```python
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class Order(db.Model):
    __tablename__ = 'orders'
    
    id = db.Column(db.Integer, primary_key=True)
    
    # 1. Single Column Index
    order_number = db.Column(db.String(50), unique=True, index=True, nullable=False)
    
    user_id = db.Column(db.Integer, db.ForeignKey('users.id'), index=True, nullable=False)
    status = db.Column(db.String(20), nullable=False)
    created_at = db.Column(db.DateTime, nullable=False)

    # 2. Composite (Multi-Column) Index
    __table_args__ = (
        db.Index('idx_user_status_created', 'user_id', 'status', 'created_at'),
    )
```

> **Rule of Thumb**: Always add indexes to Foreign Key columns, columns frequently filtered in `WHERE` clauses, and columns used in `ORDER BY` and `JOIN` operations.

## 2. Query Profiling & Performance Diagnostics

### 1. Enabling `SQLALCHEMY_ECHO`
For quick debugging in development environments, set `SQLALCHEMY_ECHO = True` to output raw SQL statements directly to stdout:

```python
app.config['SQLALCHEMY_ECHO'] = True
```

### 2. Capturing Query Latency with Event Listeners
Measure exact query execution time using SQLAlchemy event listeners:

```python
import time
from flask import g
from sqlalchemy import event
from sqlalchemy.engine import Engine

@event.listens_for(Engine, "before_cursor_execute")
def before_cursor_execute(conn, cursor, statement, parameters, context, executemany):
    context._query_start_time = time.time()

@event.listens_for(Engine, "after_cursor_execute")
def after_cursor_execute(conn, cursor, statement, parameters, context, executemany):
    total_time = (time.time() - context._query_start_time) * 1000
    if total_time > 50:  # Log slow queries (> 50ms)
        print(f"[SLOW QUERY ALERT] Duration: {total_time:.2f}ms | SQL: {statement}")
```

## 3. Optimizing Column Fetching (`load_only`)

By default, `db.select(Model)` retrieves all table columns. If a table contains large `TEXT` or `BLOB` fields (e.g. `user.biography`), loading unused columns consumes bandwidth and memory.

Use `load_only()` to fetch only required columns:

```python
from sqlalchemy.orm import load_only

# Fetch only 'id', 'username', and 'email' columns
stmt = db.select(User).options(load_only(User.id, User.username, User.email))
users = db.session.execute(stmt).scalars().all()
```
