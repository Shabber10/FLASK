## 🧠 Memory Mnemonics

### 1. Connection Pool Optimization Parameters
Remember **P-I-N-G** for SQLAlchemy pool settings:
- **P**: **`pool_size`** (Number of permanent idle connections in pool)
- **I**: **`max_overflow`** (Temporary burst connections allowed under load)
- **N**: **`pool_recycle`** (Recycle connections older than N seconds)
- **G**: **`pool_pre_ping=True`** (Guard against stale disconnect errors by testing connections)

---

### 2. Performance Diagnostic Checklist
- **`SQLALCHEMY_ECHO = True`**: Prints raw SQL to console during development.
- **`@event.listens_for(Engine, "before_cursor_execute")`**: Traps start timestamps.
- **`load_only(col1, col2)`**: Avoids fetching unnecessary heavy text/blob columns.
- **`text("SELECT ... WHERE col = :val")`**: Safe raw SQL execution with bound parameters.

## ⚡ Quick-Reference Code Snippets

### 1. Defining Composite Multi-Column Index
```python
class Order(db.Model):
    __tablename__ = 'orders'
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('users.id'))
    status = db.Column(db.String(20))

    __table_args__ = (
        db.Index('idx_orders_user_status', 'user_id', 'status'),
    )
```

### 2. Hybrid Property with SQL Expression
```python
from sqlalchemy.ext.hybrid import hybrid_property

class OrderItem(db.Model):
    unit_price = db.Column(db.Float)
    quantity = db.Column(db.Integer)

    @hybrid_property
    def total(self):
        return self.unit_price * self.quantity

    @total.expression
    def total(cls):
        return cls.unit_price * cls.quantity

# Used in SQL queries: db.select(OrderItem).where(OrderItem.total > 100)
```

### 3. Safe Bound Raw SQL Query
```python
from sqlalchemy import text

stmt = text("SELECT * FROM users WHERE status = :status AND score >= :min_score")
results = db.session.execute(stmt, {"status": "ACTIVE", "min_score": 750}).all()
```
