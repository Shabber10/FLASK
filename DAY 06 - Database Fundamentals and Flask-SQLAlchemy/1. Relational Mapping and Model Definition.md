## 1. Database Connection Helper Pattern

In Flask applications using `mysql-connector-python`, create a dedicated helper function to manage connections to your **`college`** database:

```python
from flask import Flask
import mysql.connector

app = Flask(__name__)

db_config = {
    'host': 'localhost',
    'user': 'root',
    'password': 'your_mysql_password',
    'database': 'college',
    'port': 3306
}

def get_db_connection():
    """Establishes and returns a new MySQL connection to 'college' database."""
    return mysql.connector.connect(**db_config)
```

## 2. Table Creation with Raw SQL (`CREATE TABLE IF NOT EXISTS`)

Before performing CRUD operations, create the **`student`** table using SQL DDL (`Data Definition Language`):

```python
def init_db():
    """Creates the 'student' table automatically if it does not exist."""
    conn = get_db_connection()
    cursor = conn.cursor()
    
    # SQL Table Definition Script for Student records
    create_table_sql = """
    CREATE TABLE IF NOT EXISTS student (
        id INT AUTO_INCREMENT PRIMARY KEY,
        sname VARCHAR(100) NOT NULL,
        sage INT NOT NULL,
        smarks DECIMAL(5, 2) NOT NULL,
        scity VARCHAR(100) NOT NULL
    ) ENGINE=InnoDB;
    """
    
    cursor.execute(create_table_sql)
    conn.commit() # Save table creation schema to MySQL disk
    cursor.close()
    conn.close()
    print("MySQL Table 'student' in database 'college' initialized successfully!")
```

## 3. MySQL Data Types Reference Table

| MySQL SQL Data Type | Python Equivalent Data Type | Description & Best Use Case |
| :--- | :--- | :--- |
| **`INT`** | `int` | Standard 32-bit integer for Primary Key IDs (`1, 2, 3`) |
| **`BIGINT`** | `int` | 64-bit large integer for high-volume IDs |
| **`VARCHAR(N)`** | `str` | Variable-length string up to `N` characters (`email VARCHAR(120)`) |
| **`TEXT`** | `str` | Long text field for body content or descriptions |
| **`DECIMAL(p, s)`** | `decimal.Decimal` / `float` | Exact decimal number (`DECIMAL(10, 2)` for money/currency) |
| **`BOOLEAN`** / `TINYINT(1)` | `bool` | True/False flag (`1` or `0`) |
| **`DATE`** | `datetime.date` | Date format (`YYYY-MM-DD`) |
| **`TIMESTAMP`** / `DATETIME` | `datetime.datetime` | Date and time format (`YYYY-MM-DD HH:MM:SS`) |

## 4. MySQL Column Constraints & Options

*   **`PRIMARY KEY`**: Designates column as the table's unique identifier.
*   **`AUTO_INCREMENT`**: Automatically increments ID number for each new row (`1, 2, 3...`).
*   **`NOT NULL`**: Prevents database from saving empty (`NULL`) values.
*   **`UNIQUE`**: Enforces that no two rows can have duplicate values (e.g. `email`).
*   **`DEFAULT val`**: Assigns a default value if no value is provided during `INSERT`.
*   **`ENGINE=InnoDB`**: Specifies MySQL's ACID-compliant transactional storage engine.
