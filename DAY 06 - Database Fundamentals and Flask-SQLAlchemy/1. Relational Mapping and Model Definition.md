## 1. Flask-SQLAlchemy Initialization Patterns

To use Flask-SQLAlchemy in your application, you must initialize the `SQLAlchemy` object and connect it to a database URI.

### Pattern 1: Direct Initialization (Small Single-File Applications)
```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)

# SQLite Database Connection URI
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///app.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

db = SQLAlchemy(app)
```

### Pattern 2: Deferred Extension Pattern (Enterprise Application Factory)
In modular production apps, initialize `db` without arguments first, and bind it inside your application factory function using `db.init_app(app)`:

```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

# Instantiate unattached extension object
db = SQLAlchemy()

def create_app():
    app = Flask(__name__)
    app.config['SQLALCHEMY_DATABASE_URI'] = 'postgresql://user:pass@localhost:5432/production_db'
    app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False
    
    # Bind db extension to active app instance
    db.init_app(app)
    return app
```

## 2. Defining Database Models & Columns

Every database table is represented by a Python class inheriting from **`db.Model`**:

```python
from datetime import datetime
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class Employee(db.Model):
    # Optional explicit SQL table name (Defaults to lowercase class name 'employee')
    __tablename__ = 'employees'

    # Primary Key Column (Unique ID for each row)
    id = db.Column(db.Integer, primary_key=True)
    
    # Text Columns with Data Constraints
    first_name = db.Column(db.String(50), nullable=False)
    last_name = db.Column(db.String(50), nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False, index=True)
    
    # Financial Numeric Column (10 digits total, 2 decimal places)
    salary = db.Column(db.Numeric(10, 2), nullable=False, default=0.00)
    is_active = db.Column(db.Boolean, default=True, nullable=False)
    
    # Date & Timestamp Columns
    hire_date = db.Column(db.Date, nullable=False, default=datetime.utcnow)
    created_at = db.Column(db.DateTime, nullable=False, server_default=db.func.now())

    def __repr__(self):
        return f"<Employee id={self.id} email='{self.email}'>"
```

| :--- | :--- | :--- |

| `db.Date` | `datetime.date` | `DATE` |
| `db.DateTime` | `datetime.datetime` | `TIMESTAMP` / `DATETIME` |

## 4. Column Constraints & Options

*   **`primary_key=True`**: Designates column as table's unique identifier.
*   **`nullable=False`**: Prevents database from saving `NULL` (empty) values.
*   **`unique=True`**: Enforces that no two rows can have duplicate values (e.g. `email`).
*   **`index=True`**: Creates a B-Tree search index on the column to drastically speed up `SELECT` queries.
*   **`default=val`**: Evaluates default value in Python at application level before inserting.
*   **`server_default=val`**: Adds default constraint directly inside database SQL schema (e.g. `server_default=db.func.now()`).

## 5. Enterprise Connection Pool Configuration

In high-concurrency production deployments (like PostgreSQL or MySQL), configure connection pooling using `SQLALCHEMY_ENGINE_OPTIONS`:

```python
app.config['SQLALCHEMY_ENGINE_OPTIONS'] = {
    'pool_size': 10,       # Number of permanent active database connections in pool
    'max_overflow': 20,    # Maximum extra temporary connections under heavy load spikes
    'pool_recycle': 1800,  # Recycle stale idle connections older than 30 minutes
    'pool_timeout': 30     # Seconds to wait for an available connection before raising error
}
```
