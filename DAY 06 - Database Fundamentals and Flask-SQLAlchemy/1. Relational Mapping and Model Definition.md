## 1. What is Object-Relational Mapping (ORM)?

Object-Relational Mapping (ORM) is a design pattern that bridges the gap between object-oriented Python code and relational database engines (SQLite, PostgreSQL, MySQL).

```
+------------------------------------+       +------------------------------------+
|         Python Application         |       |         Relational Database        |
|  - Class: `Employee`               |  <==> |  - Table: `employees`              |
|  - Attribute: `emp.name`           |  ORM  |  - Column: `name VARCHAR(100)`     |
|  - Instance: `emp1 = Employee()`   |  Map  |  - Table Row: `(1, 'Alice', ...)`  |
+------------------------------------+       +------------------------------------+
```

### Advantages of Using Flask-SQLAlchemy
- **Database Abstraction**: Switch backends (e.g. SQLite in Dev to PostgreSQL in Production) by changing a single URI connection string.
- **SQL Injection Defense**: All query parameters are automatically sanitized using bound parameters.
- **Unit of Work Pattern**: Tracks object state changes and batches database transactions efficiently.

## 2. Flask-SQLAlchemy Initialization Patterns

### 1. Direct Initialization (Small Apps)
```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///app.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

db = SQLAlchemy(app)
```

### 2. Deferred Extension Pattern (Application Factory)
```python
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

def create_app():
    app = Flask(__name__)
    app.config['SQLALCHEMY_DATABASE_URI'] = 'postgresql://user:pass@localhost/db'
    db.init_app(app)
    return app
```

## 3. Defining Database Models & Columns

Every ORM model inherits from `db.Model`:

```python
from datetime import datetime
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class Employee(db.Model):
    __tablename__ = 'employees'

    # Primary Key
    id = db.Column(db.Integer, primary_key=True)
    
    # Columns with Data Constraints
    first_name = db.Column(db.String(50), nullable=False)
    last_name = db.Column(db.String(50), nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False, index=True)
    
    salary = db.Column(db.Numeric(10, 2), nullable=False, default=0.00)
    is_active = db.Column(db.Boolean, default=True, nullable=False)
    
    # Date & Timestamp Columns
    hire_date = db.Column(db.Date, nullable=False, default=datetime.utcnow)
    created_at = db.Column(db.DateTime, nullable=False, server_default=db.func.now())
    updated_at = db.Column(db.DateTime, nullable=False, server_default=db.func.now(), onupdate=db.func.now())

    def __repr__(self):
        return f"<Employee id={self.id} email='{self.email}'>"
```

## 4. Column Data Types Reference

| SQLAlchemy Type | Python Type | SQL Standard Equivalent |
| :--- | :--- | :--- |
| `db.Integer` | `int` | `INTEGER` |
| `db.BigInteger` | `int` | `BIGINT` |
| `db.String(N)` | `str` | `VARCHAR(N)` |
| `db.Text` | `str` | `TEXT` |
| `db.Float` | `float` | `FLOAT` |
| `db.Numeric(p, s)` | `decimal.Decimal` | `NUMERIC(precision, scale)` |
| `db.Boolean` | `bool` | `BOOLEAN` |
| `db.Date` | `datetime.date` | `DATE` |
| `db.DateTime` | `datetime.datetime` | `DATETIME` / `TIMESTAMP` |

## 5. Database Connection Engine Options

Configure connection pooling for high-concurrency production databases using `SQLALCHEMY_ENGINE_OPTIONS`:

```python
app.config['SQLALCHEMY_ENGINE_OPTIONS'] = {
    'pool_size': 10,        # Maximum number of permanent connections to keep open
    'max_overflow': 20,     # Temporary burst connections allowed above pool_size
    'pool_recycle': 1800,   # Recycle connections older than 1800 seconds (30 mins)
    'pool_timeout': 30      # Seconds to wait before throwing a pool timeout exception
}
```
