# Day 06: Database Fundamentals & Flask-SQLAlchemy

## 1. Object-Relational Mapping (ORM) Concepts
Flask-SQLAlchemy provides an abstraction layer over SQL databases, translating Python classes into database tables and instances into table rows.

```python
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class User(db.Model):
    __tablename__ = 'users'
    
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)
    is_active = db.Column(db.Boolean, default=True)
```
