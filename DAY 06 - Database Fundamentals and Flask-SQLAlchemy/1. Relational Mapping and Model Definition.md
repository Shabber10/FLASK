## 1. Installing & Configuring `Flask-SQLAlchemy`

Install the extension:

```bash
pip install Flask-SQLAlchemy
```

### Initializing the Extension on Your Flask App:

```python
import os
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)

# Configure Database URI (SQLite database saved in instance folder)
app.config['SQLALCHEMY_DATABASE_URI'] = os.environ.get(
    'DATABASE_URL', 
    'sqlite:///company.db'
)

# Disable unnecessary modification tracking overhead
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

# Initialize the SQLAlchemy extension
db = SQLAlchemy(app)
```

## 2. Defining Database Models (`db.Model`)

A **Model** is a Python class that inherits from `db.Model`. Each model represents a **table** in your database, and each class attribute represents a **column**.

### 💻 Complete Employee Model Definition

```python
from datetime import datetime, timezone
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class Employee(db.Model):
    __tablename__ = "employees"  # Explicit SQL Table Name

    # Primary Key Column (Auto-incrementing unique integer)
    id = db.Column(db.Integer, primary_key=True)

    # String Columns with Length & Uniqueness Constraints
    name = db.Column(db.String(100), nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False, index=True)
    department = db.Column(db.String(50), nullable=False, default="Engineering")

    # Numeric & Boolean Columns
    salary = db.Column(db.Float, nullable=False)
    is_active = db.Column(db.Boolean, default=True, nullable=False)

    # Timestamp Column (Automatically records creation time in UTC)
    created_at = db.Column(
        db.DateTime, 
        default=lambda: datetime.now(timezone.utc), 
        nullable=False
    )

    def __repr__(self):
        return f"<Employee id={self.id} name='{self.name}'>"

    def to_dict(self):
        """Helper to serialize model instance to JSON dictionary."""
        return {
            "id": self.id,
            "name": self.name,
            "email": self.email,
            "department": self.department,
            "salary": self.salary,
            "is_active": self.is_active,
            "created_at": self.created_at.isoformat() if self.created_at else None
        }
```

## 3. Modern SQLAlchemy 2.0 Syntax (`Mapped[]` & `mapped_column`)

In modern Python 3.10+ and SQLAlchemy 2.0+, declarative models use **type annotations** for enhanced IDE auto-completion and static type checking:

```python
from __future__ import annotations
from datetime import datetime, timezone
from typing import Optional
from sqlalchemy.orm import Mapped, mapped_column
from sqlalchemy import String, Integer, Float, Boolean, DateTime
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class EmployeeModern(db.Model):
    __tablename__ = "employees_modern"

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    name: Mapped[str] = mapped_column(String(100), nullable=False)
    email: Mapped[str] = mapped_column(String(120), unique=True, nullable=False, index=True)
    department: Mapped[str] = mapped_column(String(50), default="Engineering")
    salary: Mapped[float] = mapped_column(Float, nullable=False)
    is_active: Mapped[bool] = mapped_column(Boolean, default=True)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), 
        default=lambda: datetime.now(timezone.utc)
    )
```

## 4. Common Column Types & Constraints

| Column Type | Python Equivalent | SQL Equivalent | Description |
| :--- | :--- | :--- | :--- |
| `db.Integer` | `int` | `INTEGER` | Whole numbers (default auto-increment on primary keys). |
| `db.String(N)` | `str` | `VARCHAR(N)` | Variable-length strings up to length `N`. |
| `db.Text` | `str` | `TEXT` | Unbounded long text (for blog posts, descriptions). |
| `db.Float` | `float` | `FLOAT` / `REAL` | Floating-point numbers. |
| `db.Boolean` | `bool` | `BOOLEAN` | True / False values. |
| `db.DateTime` | `datetime.datetime` | `DATETIME` / `TIMESTAMP` | Timestamps with timezone support. |

### Essential Column Constraints:
- `primary_key=True`: Marks the unique identity column for the row.
- `nullable=False`: Prevents `NULL` values (equivalent to `NOT NULL` in SQL).
- `unique=True`: Enforces that no two rows can have the same value (e.g. emails).
- `index=True`: Creates a database B-Tree index for ultra-fast `WHERE` query lookups.
- `default=...`: Sets default value if none is provided on creation.

## 5. Creating Tables with `db.create_all()`

In Flask 3.x, database operations require an **Application Context**:

```python
with app.app_context():
    # Inspects all subclasses of db.Model and executes CREATE TABLE IF NOT EXISTS
    db.create_all()
    print("✓ All database tables created successfully!")
```
