## 🧠 Memory Mnemonics

### 1. `db.session` Unit of Work Operations
Remember **A-S-C-R** for database transactions:
- **A**: **`db.session.add(obj)`** (Stage object for insertion)
- **S**: **`db.session.add_all([o1, o2])`** (Batch stage multiple objects)
- **C**: **`db.session.commit()`** (Flush pending SQL & commit transaction)
- **R**: **`db.session.rollback()`** (Abort transaction on error)

---

### 2. Session Object Lifecycle States
Remember **T-P-P-D-D** for model object states:
- **T**: **Transient** (Instantiated in Python, not added to session)
- **P**: **Pending** (Added to session via `add()`, awaiting flush/commit)
- **P**: **Persistent** (Committed in DB with assigned primary key ID)
- **D**: **Deleted** (Marked for deletion via `delete()`, pending commit)
- **D**: **Detached** (Session closed; object unlinked from DB context)

## ⚡ Quick-Reference Code Snippets

### 1. Model Definition Skeleton
```python
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class User(db.Model):
    __tablename__ = 'users'

    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(50), unique=True, nullable=False)
    created_at = db.Column(db.DateTime, server_default=db.func.now())
```

### 2. Querying with SQLAlchemy 2.0 Syntax
```python
# A. Get by Primary Key
user = db.session.get(User, 1)

# B. Get All Matching
stmt = db.select(User).order_by(User.username)
users = db.session.execute(stmt).scalars().all()

# C. Get Single or None
stmt = db.select(User).where(User.username == 'alice')
user = db.session.execute(stmt).scalar_one_or_none()
```

### 3. Safe Transaction Pattern with Exception Handler
```python
try:
    user = User(username='john')
    db.session.add(user)
    db.session.commit()
except SQLAlchemyError as e:
    db.session.rollback()
    print(f"Transaction failed: {e}")
```
