## 🔤 Flask-SQLAlchemy Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **ORM** | Object-Relational Mapping; maps Python classes to SQL database tables. | `class Employee(db.Model)` |
| **Model** | A Python class representing a specific database table. | `Employee` -> `employees` table |
| **Database URI** | Connection string specifying database dialect, driver, credentials, and host. | `sqlite:///company.db` |
| **`db.session`** | The Unit-of-Work staging area holding in-memory transactions. | `db.session.add(user)`, `db.session.commit()` |
| **`db.create_all()`** | Creates all defined SQL tables on disk if they do not already exist. | Run within `app.app_context()` |
| **Primary Key** | Unique identifier column guaranteeing each row is distinctly indexed. | `id = db.Column(db.Integer, primary_key=True)` |

---

## 🧠 Memory Mnemonics

### 1. The 4 CRUD Actions (`C-R-U-D`)
- **C** -> **Create** -> `db.session.add(obj)`
- **R** -> **Read** -> `db.session.get(Model, id)` / `select(Model)`
- **U** -> **Update** -> Modify attributes (`obj.salary = 80000`)
- **D** -> **Delete** -> `db.session.delete(obj)`

---

### 2. The 3 Session Steps (`A-C-R`)
- **A** -> **Add** (`db.session.add()` - stage changes in memory)
- **C** -> **Commit** (`db.session.commit()` - persist to disk)
- **R** -> **Rollback** (`db.session.rollback()` - abort on exception)

---

## ⚡ Quick-Reference Code Snippets

### 1. Initializing Flask-SQLAlchemy
```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///app.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

db = SQLAlchemy(app)
```

### 2. Defining a Model
```python
class Student(db.Model):
    __tablename__ = "students"
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False, index=True)
```

### 3. CRUD in View Functions
```python
# Create
new_student = Student(name="Alex", email="alex@dev.com")
db.session.add(new_student)
db.session.commit()

# Read
student = db.session.get(Student, 1)

# Update
student.name = "Alexander"
db.session.commit()

# Delete
db.session.delete(student)
db.session.commit()
```
