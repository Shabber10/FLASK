## 🧠 Memory Mnemonics

### 1. `mysql-connector-python` Pipeline (`C-E-F-C`)
Remember **C-E-F-C** for executing MySQL queries:
- **C** -> **Connect** (`conn = mysql.connector.connect(**db_config)`)
- **E** -> **Execute** (`cursor = conn.cursor()`, `cursor.execute(sql, params)`)
- **F** -> **Fetch / Commit** (`cursor.fetchall()` for SELECT, `conn.commit()` for INSERT/UPDATE/DELETE)
- **C** -> **Close** (`cursor.close()`, `conn.close()`)

### 1. Database Connection Helper
```python
import mysql.connector

def get_db_connection():
    return mysql.connector.connect(
        host='localhost',
        user='root',
        password='password',
        database='my_db',
        port=3306
    )
```

# CREATE
cursor.execute("INSERT INTO users (name, email) VALUES (%s, %s)", (name, email))

# READ (Dict Cursor)
cursor = conn.cursor(dictionary=True)
