## 🧠 Memory Mnemonics

### 1. `mysql-connector-python` Pipeline (`C-E-F-C`)
Remember **C-E-F-C** for executing MySQL queries:
- **C** -> **Connect** (`conn = mysql.connector.connect(**db_config)`)
- **E** -> **Execute** (`cursor = conn.cursor()`, `cursor.execute(sql, params)`)
- **F** -> **Fetch / Commit** (`cursor.fetchall()` for SELECT, `conn.commit()` for INSERT/UPDATE/DELETE)
- **C** -> **Close** (`cursor.close()`, `conn.close()`)
