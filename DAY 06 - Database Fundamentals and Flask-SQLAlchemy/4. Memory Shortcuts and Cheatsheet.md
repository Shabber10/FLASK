## 🔤 Database & ORM Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Database** | Software storing, searching, and managing data permanently. | SQLite, PostgreSQL, MySQL |
| **Table** | Grid structure holding related data records. | `users`, `products`, `orders` |
| **Column** | Named attribute field inside a table grid with a specific type. | `email VARCHAR(120)` |
| **Row** | A single data record inside a table grid. | `(1, 'Alice', 'alice@company.com')` |
| **Primary Key** | Unique identifier column value assigned to every row. | `id = db.Column(db.Integer, primary_key=True)` |
| **ORM** | Object-Relational Mapper converting Python objects to SQL rows. | Flask-SQLAlchemy |
| **SQLite** | Lightweight file-based local database engine. | `sqlite:///app.db` |
| **`db.session`** | Unit of Work container tracking pending database changes. | `db.session.add(obj)` |
| **Rollback** | Aborting a failed transaction to clear errors. | `db.session.rollback()` |

---

## 🧠 Memory Mnemonics

### 1. `db.session` Unit of Work Operations (`A-S-C-R`)
Remember **A-S-C-R** for database transactions:
- **A** -> **`db.session.add(obj)`** (Stage single object for insertion)
- **S** -> **`db.session.add_all([o1, o2])`** (Batch stage multiple objects)
- **C** -> **`db.session.commit()`** (Flush pending SQL & commit transaction to disk)
- **R** -> **`db.session.rollback()`** (Abort transaction on error and clear session)

---

### 2. Session Object Lifecycle States (`T-P-P-D-D`)
Remember **T-P-P-D-D** for model object states:
- **T** -> **Transient** (Instantiated in Python `User()`, not added to session)
- **P** -> **Pending** (Added to session via `add()`, awaiting flush/commit)
- **P** -> **Persistent** (Committed in DB with assigned primary key ID)
- **D** -> **Deleted** (Marked for deletion via `delete()`, pending commit)
- **D** -> **Detached** (Session closed; object unlinked from active DB context)

## ⚡ Quick-Reference Code Snippets

### 1. Model Definition Skeleton
```python
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class User(db.Model):
    __tablename__ = 'users'

    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(50), unique=True, nullable=False)
    created_at = db.Column(db.DateTime, server_default=db.func.now())
```

### 2. Querying with SQLAlchemy 2.0 Syntax
```python
# A. Get by Primary Key ID (Fastest)
user = db.session.get(User, 1)

# B. Get All Matching Records
stmt = db.select(User).order_by(User.username)
users = db.session.execute(stmt).scalars().all()

# C. Get Single Record or None
stmt = db.select(User).where(User.username == 'alice')
user = db.session.execute(stmt).scalar_one_or_none()
```

### 3. Safe Transaction Pattern with Exception Handler
```python
from sqlalchemy.exc import SQLAlchemyError

try:
    user = User(username='john')
    db.session.add(user)
    db.session.commit()
except SQLAlchemyError as e:
    db.session.rollback()
    print(f"Transaction failed and rolled back: {e}")
```
