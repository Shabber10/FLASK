## 1. What is a Database in Plain English?

A **Database** is an organized collection of data stored electronically on a server. 

### 🎯 Purpose in Flask Applications:
We use a database (such as **MySQL**) to store application data **permanently** so that data is not lost when the Flask server restarts.

Examples of data stored in MySQL:
- Student details (ID, Name, Age, Marks, City)
- User login credentials (Username, Hashed Password, Email)
- Product catalogs & Inventory
- Customer orders & Invoices

## 2. What is `mysql-connector-python`?

A Flask application is written in Python, while MySQL is a relational database management system. To allow Python to communicate with MySQL, we need a **driver/connector**:

```
Browser  ──(HTTP Request)──>  Flask App  ──(mysql-connector-python)──>  MySQL Database (`collegedb`)
```

```bash

```

## 4. What is CRUD? (Class Notes Core Concept)

**CRUD** represents the four fundamental operations required to manage persistent data in any application:

| Letter | Operation | Meaning / Description | HTTP Method (in APIs) | SQL Query Keyword |
| :---: | :--- | :--- | :---: | :--- |
| **C** | **Create** | Insert / Add new records into database | `POST` | `INSERT INTO student ...` |
| **R** | **Read** | Retrieve / Fetch existing records from database | `GET` | `SELECT * FROM student ...` |
| **U** | **Update** | Modify / Edit existing records in database | `POST` / `PUT` | `UPDATE student SET ... WHERE id=%s` |
| **D** | **Delete** | Remove / Delete existing records from database | `GET` / `DELETE` | `DELETE FROM student WHERE id=%s` |

## 5. Standard Cursor vs. Dictionary Cursor

*   **Standard Cursor (`conn.cursor()`)**: Returns each row as a plain Python **tuple** (e.g., `(1, 'Raju', 24, 85, 'Hyderabad')`). Accessed via numerical indices like `row[0]`, `row[1]`.
*   **Dictionary Cursor (`conn.cursor(dictionary=True)`)**: Returns each row as a Python **dictionary** (e.g., `{'id': 1, 'sname': 'Raju', 'sage': 24, 'smarks': 85, 'scity': 'Hyderabad'}`). Accessed via column keys like `row['sname']`.

---

## 6. Safe Parameterized Queries vs. SQL Injection 🛡️

Always pass user input using `%s` placeholders as a separate tuple parameter to prevent SQL Injection attacks:

```python
# ❌ DANGEROUS / VULNERABLE (DO NOT DO THIS!):
query = f"SELECT * FROM student WHERE id = {sid}"  # Hacker can inject SQL!

# ✅ SAFE & SECURE PARAMETERIZED QUERY (DO THIS!):
cursor.execute("SELECT * FROM student WHERE id = %s", (sid,))
```
