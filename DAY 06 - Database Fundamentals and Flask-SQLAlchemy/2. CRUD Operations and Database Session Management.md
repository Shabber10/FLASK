# Day 06: CRUD Operations & Session Lifecycle

In this section, we examine the SQLAlchemy Unit of Work pattern (`db.session`), object lifecycle states, CRUD operations using SQLAlchemy 2.0+ standard syntax (`db.select()`, `db.session.get()`), and transaction rollback error recovery.

---

## 1. Object Lifecycle States in `db.session`

Every model object instance exists in one of five distinct states within `db.session`:

```
+------------------+
|    Transient     |  Object instantiated in Python (`emp = Employee()`), not added to session
+--------+---------+
         | db.session.add(emp)
         v
+--------+---------+
|     Pending      |  Object attached to session, SQL INSERT not yet executed
+--------+---------+
         | db.session.commit() / flush()
         v
+--------+---------+
|    Persistent    |  Object has an ID and corresponds to an active row in the database
+--------+---------+
         | db.session.delete(emp)
         v
+--------+---------+
|     Deleted      |  Object marked for deletion in session, SQL DELETE pending commit
+--------+---------+
         | db.session.commit()
         v
+--------+---------+
|    Detached      |  Session closed or expunged; object exists in Python but unlinked from DB
+------------------+
```

---

## 2. Standard CRUD Operations (SQLAlchemy 2.0 Syntax)

### 1. Create (Insert)
```python
# Create new transient object
new_emp = Employee(
    first_name="Alice",
    last_name="Smith",
    email="alice@example.com",
    salary=75000.00
)

# Attach to session (Pending state)
db.session.add(new_emp)

# Commit transaction to DB (Persistent state)
db.session.commit()
```

### 2. Read (Querying)

```python
# A. Fetch single record by Primary Key (Fastest)
emp = db.session.get(Employee, 1)

# B. Fetch all records using `db.select()`
stmt = db.select(Employee).order_by(Employee.last_name)
employees = db.session.execute(stmt).scalars().all()

# C. Fetch single matching record or None
stmt = db.select(Employee).where(Employee.email == 'alice@example.com')
emp = db.session.execute(stmt).scalar_one_or_none()
```

### 3. Update
```python
# Retrieve persistent object
emp = db.session.get(Employee, 1)

if emp:
    # Modify attributes directly
    emp.salary = 82000.00
    emp.department = "Engineering"
    
    # Commit changes (SQL UPDATE executed automatically)
    db.session.commit()
```

### 4. Delete
```python
emp = db.session.get(Employee, 1)

if emp:
    db.session.delete(emp)
    db.session.commit()
```

## 3. Transaction Safety & Error Rollback

Database operations should always be wrapped in exception handling blocks to prevent corrupted session states and locks:

```python
from sqlalchemy.exc import SQLAlchemyError

def create_user_safely(data):
    try:
        user = User(username=data['username'], email=data['email'])
        db.session.add(user)
        db.session.commit()
        return user
    except SQLAlchemyError as e:
        # Rollback transaction on database constraint violation or connection error
        db.session.rollback()
        print(f"[DB ERROR] Transaction rolled back: {str(e)}")
        return None
```
