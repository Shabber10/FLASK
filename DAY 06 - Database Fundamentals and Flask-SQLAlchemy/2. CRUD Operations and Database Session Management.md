## 1. Understanding `db.session` (The Unit of Work Pattern)

In `Flask-SQLAlchemy`, all database transactions flow through **`db.session`**.

### 📖 How the Session Works:
1. **Staging Area**: When you create, modify, or delete Python objects, you register them with the session (`db.session.add()` or `db.session.delete()`).
2. **Transaction Boundary**: Changes are held in memory until you explicitly call **`db.session.commit()`**, which issues the SQL statements (`INSERT`, `UPDATE`, `DELETE`) inside a single atomic database transaction.
3. **Rollback Safety**: If an error occurs, calling **`db.session.rollback()`** safely cancels all pending changes.

```
┌────────────────────────────────────────────────────────┐
│                     FLASK APPLICATION                  │
│  employee = Employee(name="Alice", email="a@dev.com")  │
└───────────────────────────┬────────────────────────────┘
                            │ 1. db.session.add(employee)
                            ▼
┌────────────────────────────────────────────────────────┐
│                   SQLALCHEMY SESSION                   │
│             [ Staged: Pending INSERT ]                 │
└───────────────────────────┬────────────────────────────┘
                            │ 2. db.session.commit()
                            ▼
┌────────────────────────────────────────────────────────┐
│                   DATABASE (SQLite/Postgres)           │
│           [ INSERT INTO employees ... COMMIT ]         │
└────────────────────────────────────────────────────────┘
```

## 2. Step-by-Step CRUD Operations with Code Examples

---

### ➕ 1. CREATE (Insert Records)

To add new records to your database:

```python
from flask import request, jsonify
from models import Employee, db

@app.route('/api/employees', methods=['POST'])
def create_employee():
    data = request.get_json() or {}
    
    # 1. Instantiate the Model
    new_employee = Employee(
        name=data.get('name'),
        email=data.get('email'),
        department=data.get('department', 'Engineering'),
        salary=float(data.get('salary', 60000))
    )

    try:
        # 2. Stage the object in the session
        db.session.add(new_employee)
        # 3. Commit the transaction to disk
        db.session.commit()
        
        return jsonify({
            "message": "Employee created successfully",
            "employee": new_employee.to_dict()
        }), 201

    except Exception as e:
        # Rollback in case of duplicate email or constraint violation
        db.session.rollback()
        return jsonify({"error": "Failed to create employee", "details": str(e)}), 400
```

### 🔍 2. READ (Query Records)

Retrieve single or multiple records using primary key lookups or queries:

```python
from sqlalchemy import select

# 2a. Fetch ALL employees
@app.route('/api/employees', methods=['GET'])
def list_employees():
    # Modern SQLAlchemy 2.0 select syntax:
    stmt = select(Employee).order_by(Employee.id.asc())
    employees = db.session.execute(stmt).scalars().all()
    
    return jsonify({
        "total": len(employees),
        "employees": [emp.to_dict() for emp in employees]
    }), 200


# 2b. Fetch a SINGLE employee by Primary Key (ID)
@app.route('/api/employees/<int:emp_id>', methods=['GET'])
def get_employee(emp_id):
    # db.session.get() is the fast, modern primary key lookup
    employee = db.session.get(Employee, emp_id)
    
    if not employee:
        return jsonify({"error": "Employee not found"}), 404
        
    return jsonify({"employee": employee.to_dict()}), 200
```

### ✏️ 3. UPDATE (Modify Records)

To update an existing record, fetch it, modify its Python attributes, and commit:

```python

def update_employee(emp_id):
    employee = db.session.get(Employee, emp_id)

    if 'department' in data:
        employee.department = data['department']
    if 'salary' in data:
        employee.salary = float(data['salary'])

        "employee": employee.to_dict()
    }), 200
```

---

### 🗑️ 4. DELETE (Remove Records)

To delete a record, pass the model instance to `db.session.delete()`:

```python
@app.route('/api/employees/<int:emp_id>', methods=['DELETE'])
def delete_employee(emp_id):
    employee = db.session.get(Employee, emp_id)
    if not employee:
        return jsonify({"error": "Employee not found"}), 404

    # Stage the deletion and commit
    db.session.delete(employee)
    db.session.commit()
    
    return jsonify({
        "message": f"Employee {emp_id} deleted successfully"
    }), 200
```

## 3. Atomic Transactions & Safe Error Handling

Always wrap modifying database operations in `try ... except ... rollback` blocks to prevent corrupt or partial states:

```python
def transfer_department(emp_id, new_dept):
    emp = db.session.get(Employee, emp_id)
    if not emp:
        return False
        
    try:
        emp.department = new_dept
        db.session.commit()
        return True
    except Exception:
        db.session.rollback()  # Safely abort transaction!
        return False
```
