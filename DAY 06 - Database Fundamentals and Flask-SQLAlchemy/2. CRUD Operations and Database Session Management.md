# Day 06: CRUD Operations & Session Lifecycle

## 1. Database Session Lifecycle
- `db.session.add(obj)`: Stages new object for insertion.
- `db.session.commit()`: Flushes pending changes to DB transaction log and commits.
- `db.session.rollback()`: Aborts uncommitted transaction changes.

```python
# Create
new_user = User(username='john', email='john@example.com')
db.session.add(new_user)
db.session.commit()

# Read
users = db.session.execute(db.select(User)).scalars().all()
```
