# Day 16 - Module 1.1: Complete Step-by-Step Postman and API Testing Guide

Welcome to **Module 1.1** of Day 16! Before you start building complete CRUD APIs, learning how to test your endpoints with **Postman** is one of the most critical skills for every backend developer.

In this guide, you will learn how to send requests, test headers, inspect status codes, and debug JSON payloads in Postman.

---

## 1. What is Postman?

**Postman** is a tool that acts as an API client. While a regular web browser can only send `GET` requests easily by typing a URL in the address bar, Postman lets you:
*   Send any HTTP method (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`).
*   Send custom JSON request bodies.
*   Set request headers (e.g. `Content-Type: application/json`, `Authorization: Bearer <token>`).
*   Inspect the exact **HTTP Status Code** (e.g. `200 OK`, `201 Created`, `404 Not Found`).
*   Save and organize your API requests into **Collections**.

---

## 2. Setting Up a Postman Collection

1. Open Postman on your computer.
2. Click **New** ➔ **Collection** ➔ Name it: `Flask Student CRUD API`.
3. Inside your collection, click **Add request**.

---

## 3. Step-by-Step Guide for Each HTTP Method

Let's assume your Flask app is running locally at: `http://127.0.0.1:5000`

---

### Step 1: Sending a `GET` Request (Fetch All Students)
1. **Method**: Select `GET` from the dropdown.
2. **URL**: Enter `http://127.0.0.1:5000/students`
3. Click the blue **Send** button.
4. **Inspect Response**:
   * **Status Code**: Look at the top right of the response pane (`200 OK`).
   * **Time & Size**: Shows network latency and data payload size.
   * **Body**: Select `Pretty` ➔ `JSON`. You will see:
     ```json
     {
       "success": true,
       "data": [
         {"id": 101, "name": "Rahul", "email": "rahul@example.com"},
         {"id": 102, "name": "Priya", "email": "priya@example.com"}
       ]
     }
     ```

---

### Step 2: Sending a `POST` Request (Create a New Student)
1. **Method**: Select `POST` from the dropdown.
2. **URL**: Enter `http://127.0.0.1:5000/students`
3. Click on the **Body** tab below the URL bar.
4. Select the **raw** radio button.
5. In the format dropdown on the right, select **JSON** (this automatically sets the header `Content-Type: application/json`).
6. Enter the JSON payload:
   ```json
   {
     "name": "Kiran",
     "email": "kiran@example.com"
   }
   ```
7. Click **Send**.
8. **Inspect Response**:
   * **Status Code**: `201 Created` ✅
   * **Body**:
     ```json
     {
       "success": true,
       "message": "Student created successfully",
       "data": {
         "id": 103,
         "name": "Kiran",
         "email": "kiran@example.com"
       }
     }
     ```

---

### Step 3: Sending a `GET` Request for a Single Student
1. **Method**: Select `GET`.
2. **URL**: Enter `http://127.0.0.1:5000/students/101`
3. Click **Send**.
4. **Response**: `200 OK` with Rahul's details.
5. **Test 404 Not Found**:
   * Change URL to `http://127.0.0.1:5000/students/999`
   * Click **Send**.
   * Status Code will show: `404 Not Found` ❌
   * Body: `{"error": "Not Found", "message": "Student #999 not found"}`

---

### Step 4: Sending a `PUT` Request (Update Student)
1. **Method**: Select `PUT`.
2. **URL**: Enter `http://127.0.0.1:5000/students/101`
3. Click on **Body** ➔ **raw** ➔ **JSON**.
4. Enter the updated data:
   ```json
   {
     "name": "Rahul Kumar",
     "email": "rahul.kumar@example.com"
   }
   ```
5. Click **Send**.
6. **Inspect Response**:
   * **Status Code**: `200 OK`
   * **Body**: `{"success": true, "message": "Student updated successfully"}`

---

### Step 5: Sending a `DELETE` Request
1. **Method**: Select `DELETE`.
2. **URL**: Enter `http://127.0.0.1:5000/students/101`
3. Click **Send**.
4. **Inspect Response**:
   * **Status Code**: `204 No Content` (Empty body) or `200 OK` with confirmation message.
   * If you now send `GET /students/101`, it will return `404 Not Found`!

---

## 4. Testing Client Errors in Postman

To verify that your Flask error handling works, test these scenarios in Postman:

| Scenario | What to Send | Expected Status Code |
| :--- | :--- | :--- |
| **Malformed JSON** | `POST /students` with body `{ "name": }` | `400 Bad Request` |
| **Missing Required Field** | `POST /students` with body `{ "age": 20 }` (no name) | `422 Unprocessable Content` |
| **Duplicate Email** | `POST /students` with existing email `priya@example.com` | `409 Conflict` |
| **Wrong Method** | `POST /students/101` (when only `GET`, `PUT`, `DELETE` exist) | `405 Method Not Allowed` |
| **Non-existent ID** | `GET /students/9999` | `404 Not Found` |

## 5. Exporting and Sharing Collections

1. Click the three dots `...` next to your collection name in the left sidebar.
2. Click **Export** ➔ Choose **Collection v2.1 (recommended)**.
3. Save the `.json` file to share with teammates or submit in class!
