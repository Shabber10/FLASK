## 1. What is an API in Plain English?

**API** stands for **Application Programming Interface**.

In simple words: **An API is a bridge or medium that allows two different software applications to communicate and exchange data.**

### 🍽️ The Restaurant Analogy
Imagine going to a restaurant to eat:
*   👨 **You (The Customer)** = The **Client** (Browser, Mobile App, Postman).
*   🍽️ **The Waiter** = The **API**.
*   👨‍🍳 **The Chef / Kitchen** = The **Server & Database**.

```
    👨 Client (You)
          │
          │ "I want Biryani" (Request)
          ▼
    🍽️ Waiter (API)
          │
          │ Takes order to kitchen
          ▼
    👨‍🍳 Chef / Server (Database)
          │
          │ Prepares Biryani
          ▼
    🍽️ Waiter (API)
          │
          │ Brings Biryani (Response)
          ▼
    👨 Client (You eats food)
```

> **Key Takeaway**: The waiter does not cook the food. The waiter only **takes the request**, **gives it to the chef**, and **brings back the response**. That is exactly what an API does in software!

---

### 📱 Real-Life Software Examples of APIs

1.  **WhatsApp**:
    *   You open the WhatsApp app (Client) ➔ Sends API Request ➔ WhatsApp Server processes it ➔ Fetches chats from Database ➔ Returns API Response ➔ Chats are displayed on your phone screen.
2.  **Swiggy / Zomato**:
    *   Swiggy doesn't have its own satellite map. Swiggy uses the **Google Maps API** to show the delivery partner's live location on your phone.
3.  **ATM Machine**:
    *   You insert your card at an ATM (Client) ➔ ATM calls Bank Server API ➔ Bank checks your balance and deducts money ➔ ATM dispenses cash.
4.  **Weather App**:
    *   Your phone's weather widget calls an external Weather API to fetch current temperature in JSON format and displays it cleanly.

## 2. Minimal Flask API Example

Let's look at how simple an API in Flask is:

```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route("/")
def home():
    return "Welcome to Flask API!"

@app.route("/students")
def get_students():
    # Returning structured JSON data instead of an HTML webpage
    return jsonify([
        {"id": 101, "name": "Rahul"},
        {"id": 102, "name": "Priya"}
    ])

if __name__ == "__main__":
    app.run(debug=True)
```

When a browser or mobile app sends a request:
```
Client (Browser / Postman)
           │
           │ GET /students (HTTP Request)
           ▼
Flask Route (@app.route("/students"))
           │
           │ Generates JSON
           ▼
Client receives JSON: [{"id": 101, "name": "Rahul"}, {"id": 102, "name": "Priya"}]
```

## 3. What is REST?

**REST** stands for **Representational State Transfer**.

Don't let the long academic name confuse you!
> **Think of REST as a set of rules and best practices for creating APIs.**

Just like the game of cricket or football has rules that all players must follow, **REST gives rules on how to name URLs and how to use HTTP methods.**

Before REST was introduced by Roy Fielding in the year 2000, developers created random and confusing URLs:
*   ❌ `/getStudentData`
*   ❌ `/fetch_all_students_from_db`
*   ❌ `/saveNewStudent`
*   ❌ `/deleteStudentById?id=101`

REST standardizes this with **Clean Plural Nouns** and standard **HTTP Methods**:
*   ✅ `GET /students` ➔ Retrieve all students
*   ✅ `POST /students` ➔ Create a new student
*   ✅ `GET /students/101` ➔ Retrieve student #101
*   ✅ `PUT /students/101` ➔ Update student #101
*   ✅ `DELETE /students/101` ➔ Delete student #101

---

## 4. What are HTTP Verbs in REST?

Instead of putting action verbs in the URL path, REST uses the HTTP method itself to specify what action to perform:

| HTTP Verb | Action | Meaning | Real-World Example |
| :--- | :--- | :--- | :--- |
| **`GET`** | Read / Fetch | Retrieve data from server (Safe & Read-only) | `GET /students` (Fetch student list) |
| **`POST`** | Create | Submit new data to server | `POST /students` (Add a new student) |
| **`PUT`** | Update (Full) | Replace an existing record entirely | `PUT /students/101` (Replace student #101) |
| **`PATCH`** | Update (Partial) | Update only specific fields of a record | `PATCH /students/101` (Update only student's phone #) |
| **`DELETE`** | Remove | Delete an existing record | `DELETE /students/101` (Delete student #101) |

## 5. What is an HTTP Response & Status Code?

When a client sends a request to Flask, the server always returns an **HTTP Response** consisting of 3 parts:

```
HTTP Response
│
├── 1. Status Code  (e.g., 200 OK, 201 Created, 404 Not Found)
├── 2. Headers      (e.g., Content-Type: application/json)
└── 3. Body         (The JSON data payload)
```

### The 5 Status Code Families:
*   **1xx (Informational)**: Request received, continuing process.
*   **2xx (Success) ✅**: Everything went smoothly! (e.g. `200 OK`, `201 Created`, `204 No Content`).
*   **3xx (Redirection) 🔄**: URL has moved to another address.
*   **4xx (Client Error) ❌**: The client sent bad/invalid data or requested something that doesn't exist (e.g. `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`).
*   **5xx (Server Error) 💥**: The server crashed due to a bug or database outage (e.g. `500 Internal Server Error`, `503 Service Unavailable`).
