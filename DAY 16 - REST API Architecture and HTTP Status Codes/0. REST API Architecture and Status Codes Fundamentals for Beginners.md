## 1. What is an API in Plain English?

An **API (Application Programming Interface)** is a software messenger that allows two different computer applications to talk to each other and exchange data.

> **Analogy**: Imagine sitting at a table in a restaurant with a menu.
> *   **You**: The Client (Mobile app or Web browser).
> *   **The Kitchen**: The Server & Database holding all data.
> *   **The Waiter**: The **API**! You give your order to the waiter, the waiter takes your order to the kitchen, and then brings back your food (JSON data)! 🍽️

---

## 2. What is REST?

**REST (Representational State Transfer)** is a set of standardized architectural rules for building web APIs. A RESTful API organizes data into **Resources** and uses standard **HTTP Verbs** to interact with those resources.

### What is a Resource?
A **Resource** is an object or data entity in your system, identified by a clean plural URL path:
*   `/api/v1/users` -> Represents User resources.
*   `/api/v1/products` -> Represents Product resources.
*   `/api/v1/orders` -> Represents Order resources.

---

## 3. What are HTTP Verbs in REST?

Instead of inventing custom URL names like `/getUser` or `/deleteProduct`, REST uses standard HTTP Methods (verbs) on clean resource URLs:

| HTTP Verb | Action | Real-World Example | Expected Result |
| :--- | :--- | :--- | :--- |
| **`GET`** | Read / Fetch data | `GET /api/v1/products` | Returns a list of all products |
| **`POST`** | Create new resource | `POST /api/v1/products` | Creates a new product in database |
| **`PUT`** | Completely replace resource | `PUT /api/v1/products/42` | Replaces product #42 entirely |
| **`PATCH`** | Partially update resource | `PATCH /api/v1/products/42` | Updates only price of product #42 |
| **`DELETE`** | Remove resource | `DELETE /api/v1/products/42` | Deletes product #42 from database |

## 4. HTTP Status Code Families

When an API responds, it includes a 3-digit **HTTP Status Code** telling the client what happened:

```
┌────────────────────────────────────────────────────────────────────────┐
│ 2xx SUCCESS       --> Everything went great! (e.g. 200 OK, 201 Created)│
│ 3xx REDIRECTION   --> Go to another URL! (e.g. 301 Moved Permanently)   │
│ 4xx CLIENT ERROR  --> You sent bad data! (e.g. 400 Bad Request, 404)   │
│ 5xx SERVER ERROR  --> The server crashed! (e.g. 500 Internal Error)    │
└────────────────────────────────────────────────────────────────────────┘
```
