## 🔤 REST API & Status Codes Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **API** | Application Programming Interface allowing systems to talk. | Restaurant waiter carrying orders |
| **REST** | Representational State Transfer architecture style. | Resource URLs + HTTP verbs |
| **Resource** | Noun data entity identified by a plural URL path. | `/api/v1/products` |
| **Idempotency** | Property where repeating a request 10x yields identical server state. | `GET`, `PUT`, `DELETE` are idempotent |
| **RFC 7807** | Standardized JSON schema for returning HTTP API problem details. | `{"type": "...", "title": "...", "status": 404}` |
| **Response Envelope** | Wrapper enclosing API data and pagination metadata. | `{"status": "success", "data": [...]}` |
| **`201 Created`** | Success code returned after creating a new resource via POST. | Returns newly created record |
| **`204 No Content`** | Success code returned after deleting a resource (empty body). | `return '', 204` |
| **`422 Unprocessable`** | Client error when JSON structure is valid but validation rules fail. | Missing required field |

## 🧠 Memory Mnemonics

### 1. HTTP Verbs & Actions (`V-E-R-B-S`)
Remember **V-E-R-B-S** for matching HTTP verbs to actions:
- **V** -> **View Data (`GET`)** (Fetch resource list or single resource)
- **E** -> **Entry Creation (`POST`)** (Create new resource -> `201 Created`)
- **R** -> **Replace Entirely (`PUT`)** (Overwrites all attributes -> Idempotent)
- **B** -> **Branch Update (`PATCH`)** (Partially modifies specified attributes)
- **S** -> **Scrap Resource (`DELETE`)** (Removes resource -> `204 No Content`)

---

### 2. HTTP Status Code Families (`S-T-A-T-U-S`)
Remember **S-T-A-T-U-S** for status code families:
- **S** -> **Success 2xx** (`200 OK`, `201 Created`, `204 No Content`)
- **T** -> **Transfer Redirection 3xx** (`301 Moved Permanently`, `302 Found`)
- **A** -> **Authentication / Access Error 401 & 403** (`401 Unauthorized`, `403 Forbidden`)
- **T** -> **Target Missing Error 404** (`404 Not Found`)
- **U** -> **Unprocessable Payload Error 400 & 422** (`400 Bad Request`, `422 Unprocessable`)
- **S** -> **Server Crash 5xx** (`500 Internal Server Error`)
