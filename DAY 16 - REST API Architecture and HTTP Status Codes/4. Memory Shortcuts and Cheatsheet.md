## 🔤 REST API & Status Codes Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **API** | Application Programming Interface allowing systems to talk. | Restaurant waiter carrying food orders |
| **REST** | Representational State Transfer architecture style. | Clean resource URLs + HTTP verbs |
| **Resource** | Noun data entity identified by a plural URL path. | `/students`, `/api/v1/products` |
| **RESTful API** | An API that strictly satisfies all REST constraints. | *"Every sports bike is a bike, but not every bike is a sports bike."* |
| **Idempotency** | Repeating a request 10x yields identical server state. | `GET`, `PUT`, `DELETE` are idempotent |
| **`jsonify()`** | Flask utility to serialize data to JSON with headers. | `return jsonify(data), 200` |
| **`request.get_json()`** | Extracts JSON payload sent in request body. | `data = request.get_json()` |

## 🎯 Master Status Code "Remember Like This" Table

| Status Code | Meaning | Real-Life Story / "Remember Like This" | Typical Method |
| :--- | :--- | :--- | :---: |
| **`200 OK`** | Success | **Everything OK**: Waiter delivers the exact food. | `GET`, `PUT` |
| **`201 Created`** | Created | **New Resource Created**: Gmail account created successfully. | `POST` |
| **`204 No Content`** | Success, No Body | **Nothing to Return**: Throwing paper in a dustbin. | `DELETE` |
| **`400 Bad Request`** | Bad Request | **Invalid Request Syntax**: Form age written as `"Twenty"` or broken JSON. | Any |
| **`401 Unauthorized`** | Unauthorized | **Please Log In**: Trying to open Netflix without logging in. | Any |
| **`403 Forbidden`** | Forbidden | **Logged in, but No Permission**: Office worker trying to enter CEO's private room. | Any |
| **`404 Not Found`** | Not Found | **Does Not Exist**: Asking library for book number `999`. | `GET`, `PUT`, `DELETE` |
| **`405 Method Not Allowed`** | Method Not Allowed | **Wrong HTTP Method**: Asking a restaurant waiter to recharge your phone. | Any |
| **`409 Conflict`** | Conflict | **Data Already Exists**: Trying to assign Roll No `101` when already assigned. | `POST`, `PUT` |
| **`422 Unprocessable Content`** | Unprocessable Content | **Valid JSON, Invalid Data**: Form is filled out, but age is `-5`. | `POST`, `PUT` |
| **`500 Internal Server Error`** | Internal Server Error | **Server-Side Bug**: Chef accidentally burns the food inside the kitchen. | Any |
| **`503 Service Unavailable`** | Service Unavailable | **Under Maintenance**: Bank website displaying maintenance screen. | Any |

## 🧠 Memory Mnemonics

### 1. HTTP Verbs & Actions (`V-E-R-B-S`)
- **V** ➔ **View Data (`GET`)** (Fetch resource list or single resource -> `200 OK`)
- **E** ➔ **Entry Creation (`POST`)** (Create new resource -> `201 Created`)
- **R** ➔ **Replace Entirely (`PUT`)** (Overwrites all attributes -> Idempotent)
- **B** ➔ **Branch Update (`PATCH`)** (Partially modifies specified attributes)
- **S** ➔ **Scrap Resource (`DELETE`)** (Removes resource -> `200 OK` or `204 No Content`)

### 2. The Golden Two Interview Distinctions
*   **`401` vs `403`**:
    *   `401 Unauthorized`: ❌ Not logged in.
    *   `403 Forbidden`: ✔️ Logged in, but ❌ No permission.
*   **`400` vs `422`**:
    *   `400 Bad Request`: Broken/malformed syntax.
    *   `422 Unprocessable Content`: Valid syntax, but data values fail validation.
