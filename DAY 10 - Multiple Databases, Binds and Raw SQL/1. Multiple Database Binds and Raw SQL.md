## 1. Multiple Database Binds Architecture

Configure your primary database using `SQLALCHEMY_DATABASE_URI`, and additional databases using the `SQLALCHEMY_BINDS` dictionary:

```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)

# Primary Default Database URI
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///primary.db'

# Secondary Database Binds Dictionary
app.config['SQLALCHEMY_BINDS'] = {
    'analytics': 'sqlite:///analytics.db',
    'users_db':  'postgresql://user:secret@localhost:5432/user_db'
}
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

db = SQLAlchemy(app)
```

## 2. Binding Models to Specific Databases (`__bind_key__`)

By default, all models inheriting from `db.Model` connect to the primary database. To route a model to a secondary database bind, set the **`__bind_key__`** class attribute:

```python
# 1. Connected to Primary Database (primary.db)
class User(db.Model):
    __tablename__ = 'users'
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(50), nullable=False)

# 2. Connected to Analytics Database (analytics.db)
class AnalyticsLog(db.Model):
    __tablename__ = 'analytics_logs'
    __bind_key__ = 'analytics'  # Explicit Bind Routing!

    id = db.Column(db.Integer, primary_key=True)
    endpoint = db.Column(db.String(100), nullable=False)
    ip_address = db.Column(db.String(45), nullable=False)
```

> **Table Creation**: `db.create_all()` automatically inspects `__bind_key__` and creates the appropriate tables inside each designated database file/server!

## 3. Safe Raw SQL Execution (`sqlalchemy.text`)

When performing complex aggregations or executing raw SQL strings, wrap all queries in **`sqlalchemy.text()`**:

```python
from sqlalchemy import text

@app.route('/raw-search')
def raw_search():
    user_input = request.args.get('q', '')
    
    # SAFE: Using text() with bound parameter placeholders (:search_term)
    stmt = text("SELECT id, username FROM users WHERE username LIKE :search_term")
    
    # Execute query passing parameters dictionary
    result = db.session.execute(stmt, {"search_term": f"%{user_input}%"}).fetchall()
    
    # Process Row objects
    users_list = [{"id": row.id, "username": row.username} for row in result]
    return jsonify(users_list)
```

## 4. Retrieving Underlying Engines (`db.get_engine`)

To execute raw SQL queries against a specific secondary database bind (e.g., `'analytics'`), pass the bind key to `db.get_engine()`:

```python
# Get Engine instance for 'analytics' database bind
analytics_engine = db.get_engine(app, bind='analytics')

# Execute raw SQL directly against analytics engine
with analytics_engine.connect() as connection:
    result = connection.execute(text("SELECT COUNT(*) FROM analytics_logs"))
    total_logs = result.scalar()
```
