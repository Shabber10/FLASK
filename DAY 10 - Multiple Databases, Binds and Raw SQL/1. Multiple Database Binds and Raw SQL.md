# Day 10: Multiple Database Binds & Raw SQL Execution

## 1. Multiple Database Binds
Flask-SQLAlchemy supports routing different models to distinct database instances using `SQLALCHEMY_BINDS`:

```python
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///primary.db'
app.config['SQLALCHEMY_BINDS'] = {
    'analytics': 'sqlite:///analytics.db',
    'users_db': 'postgresql://user:pass@localhost/userdb'
}

class UserLog(db.Model):
    __bind_key__ = 'analytics'
    id = db.Column(db.Integer, primary_key=True)
```
