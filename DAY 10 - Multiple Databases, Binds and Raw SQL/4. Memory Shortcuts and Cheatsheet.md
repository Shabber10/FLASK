## 🔤 Multi-Database & Raw SQL Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Database Bind** | Named connection string pointing to an additional database. | `'analytics': 'sqlite:///analytics.db'` |
| **`__bind_key__`** | Model class attribute specifying which database engine to route to. | `__bind_key__ = 'analytics'` |
| **Raw SQL** | Native ANSI SQL string queries passed directly to database engines. | `text("SELECT * FROM users")` |
| **Parameter Binding** | Passing query parameters separately to prevent SQL Injection. | `db.session.execute(text(...), {"id": 1})` |
| **Connection Pool** | Fleet of pre-opened database connections kept open in memory. | `SQLALCHEMY_ENGINE_OPTIONS` |
| **QueuePool** | Default thread-safe pool implementation for PostgreSQL/MySQL. | `pool_size=10, max_overflow=20` |
| **NullPool** | Pool implementation that disables pooling (ideal for AWS Lambda/Serverless). | `poolclass=NullPool` |
| **`db.session.remove()`** | Method clearing scoped session and returning connections to pool. | `finally: db.session.remove()` |

## 🧠 Memory Mnemonics

### Multi-Database Configuration Steps (`B-I-N-D`)
Remember **B-I-N-D** for routing multi-database models:
- **B** -> **`BINDS` Configuration** (`app.config['SQLALCHEMY_BINDS'] = {'key': 'URI'}`)
- **I** -> **Identify Key** (Choose a clear bind key name e.g. `'audit'` or `'analytics'`)
- **N** -> **Name Model `__bind_key__`** (Add `__bind_key__ = 'audit'` on target model)
- **D** -> **Dispatch Query** (Call `db.create_all()` or run queries normally; Flask routes automatically)

## ⚡ Quick-Reference Code Snippets

### 1. Multi-Database Configuration & Model Binding
```python
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///primary.db'
app.config['SQLALCHEMY_BINDS'] = {
    'audit': 'sqlite:///audit.db'
}

class User(db.Model):
    # Uses Primary DB
    id = db.Column(db.Integer, primary_key=True)

class AuditLog(db.Model):
    # Uses Audit DB
    __bind_key__ = 'audit'
    id = db.Column(db.Integer, primary_key=True)
```

### 2. Safe Raw SQL Query with Parameter Binding
```python
from sqlalchemy import text

stmt = text("SELECT id, username FROM users WHERE email = :user_email")
result = db.session.execute(stmt, {"user_email": "alice@dev.com"}).fetchall()
```

### 3. Production Connection Pool Configuration
```python
app.config['SQLALCHEMY_ENGINE_OPTIONS'] = {
    'pool_size': 10,       # Permanent connections kept open
    'max_overflow': 20,    # Max temporary connections under heavy load
    'pool_recycle': 1800,  # Recycle connections every 30 minutes
    'pool_timeout': 30     # Max seconds to wait for available connection
}
```
