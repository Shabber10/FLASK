## 🧠 Memory Mnemonics

### 1. Multi-Tenant Database Isolation Selection
Remember **T-E-N-A-N-T** selection criteria:
- **Discriminator Column**: Lowest cost; filter by `tenant_id` on shared schema.
- **PostgreSQL Schemas**: Medium cost; switch `search_path` per tenant.
- **Database-per-Tenant**: Highest cost; dedicated DB instance per tenant.

---

### 2. Tenant Context Resolution Flow
- **Request Arrives** -> Inspect `X-Tenant-ID` header or Subdomain `acme.saas.com`.
- **Query Database** -> Load `Tenant` record.
- **Inject Proxy** -> Assign `g.tenant = tenant`.
- **Enforce Scope** -> Filter all queries by `g.tenant.id`.

---

## ⚡ Quick-Reference Code Snippets

### 1. Tenant Context Resolution (`before_request`)
```python
@app.before_request
def resolve_tenant():
    tenant_slug = request.headers.get('X-Tenant-ID')
    if tenant_slug:
        g.tenant = Tenant.query.filter_by(slug=tenant_slug).first()
    else:
        g.tenant = None
```

### 2. Isolated Model Definition
```python
class Order(db.Model):
    __tablename__ = 'orders'
    id = db.Column(db.Integer, primary_key=True)
    tenant_id = db.Column(db.Integer, db.ForeignKey('tenants.id'), nullable=False, index=True)
    amount = db.Column(db.Float, nullable=False)
```

### 3. PostgreSQL Schema Switching
```python
db.session.execute(text(f"SET search_path TO tenant_{tenant_slug}, public"))
```
