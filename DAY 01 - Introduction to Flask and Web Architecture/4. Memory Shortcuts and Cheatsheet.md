## 🧠 Memory Mnemonics

### 1. The WSGI Standard Callable Signature
Remember **W-E-S-S** for WSGI Application Callables:
- **W**: **WSGI Callable** (`app(environ, start_response)`)
- **E**: **`environ`** (Dictionary containing headers, path, CGI parameters)
- **S**: **`start_response`** (Callable accepting status string & headers list)
- **S**: **Stream Return** (Returns iterable list of byte strings `[b"body"]`)

---

### 2. Context Local Objects
Remember **A-R-C-G** for Flask's global context proxies:
- **A**: `current_app` (App Context - active application settings)
- **R**: `request` (Request Context - query args, form payload, headers)
- **C**: `session` (Request Context - encrypted/signed user session cookie)
- **G**: `g` (App Context - temporary request-scoped global storage dictionary)

## ⚡ Quick-Reference Commands Cheatsheet

### Environment & Package Setup
```bash
# Create virtual environment
python -m venv venv

# Activate virtual environment (Windows)
venv\Scripts\activate

# Activate virtual environment (Linux/macOS)
source venv/bin/activate

# Install Flask & dotenv support
pip install flask python-dotenv
```

### CLI Operations
```bash
# Run Development WSGI Server
flask run

# Run on Specific Host & Port
flask run --host=0.0.0.0 --port=8080

# Show Available CLI Routes
flask routes
```

## 📋 Core Code Snippets

### 1. Minimal Flask App
```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route('/')
def home():
    return jsonify(status="ok", message="Hello World")

if __name__ == '__main__':
    app.run(debug=True)
```

### 2. Pushing Application Context Manually
```python
from flask import Flask, current_app

app = Flask(__name__)

with app.app_context():
    print(f"Active App: {current_app.name}")
```

### 3. Custom WSGI Middleware
```python
class CustomMiddleware:
    def __init__(self, wsgi_app):
        self.wsgi_app = wsgi_app

    def __call__(self, environ, start_response):
        # Pre-processing logic
        return self.wsgi_app(environ, start_response)

app.wsgi_app = CustomMiddleware(app.wsgi_app)
```
