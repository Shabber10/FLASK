# Day 01: Memory Shortcuts & Cheatsheet

---

## 🔤 Web & Flask Terminology Decoder

| Term | Full Form / Meaning | Classroom Memory Shortcut |
| :--- | :--- | :--- |
| **Frontend** | Client-Side Presentation | What user sees (HTML/CSS/JS). |
| **Backend** | Server-Side Logic | What powers the site (Python/Flask/MySQL). |
| **Webpage** | Single Web Document | A single page of a book. |
| **Website** | Collection of Webpages | The entire book. |
| **Web Browser** | Client Software | Chrome/Edge requesting pages. |
| **Web Server** | Host Machine/Process | Flask development server delivering pages. |
| **HTTP** | HyperText Transfer Protocol | Standard rules for browser-server communication. |
| **WSGI** | Web Server Gateway Interface | Bridge between Web Server and Python Application. |
| **Microframework** | Minimal Core Architecture | Lightweight by default, extensible via libraries. |

---

## 🧠 Memory Mnemonics

### 1. HTTP Request-Response Cycle (`R-P-D-R`)
- **R** -> **Request Sent** (Browser sends HTTP Request)
- **P** -> **Processing** (Flask executes route & business logic)
- **D** -> **Database Query** (MySQL fetches records)
- **R** -> **Response Rendered** (Flask returns HTTP 200 + HTML/JSON)

---

## ⚡ Minimal Flask Application Code
```python
from flask import Flask

# 1. Create Flask App Object
app = Flask(__name__)

# 2. Define Route
@app.route('/')
def home():
    return "<h1>Welcome to Flask Web Development!</h1>"

# 3. Run Development Server
if __name__ == '__main__':
    app.run(debug=True)
```
