## 🧠 Memory Mnemonics

### 1. The WSGI Standard Signature Callable (`W-E-S-S`)
Remember **W-E-S-S** for raw WSGI applications:
- **W** -> **WSGI Callable** (`def app(environ, start_response):`)
- **E** -> **`environ`** (Dictionary containing headers, path, CGI parameters)
- **S** -> **`start_response`** (Callback setting HTTP status string & headers list)
- **S** -> **Stream Return** (Returns iterable list of byte strings `[b"body"]`)

---

### 2. Context Local Proxies (`A-R-C-G`)
Remember **A-R-C-G** for Flask's global context proxies:
- **A** -> `current_app` (App Context - active application configuration)
- **R** -> `request` (Request Context - incoming query args, form payload, headers)
- **C** -> `session` (Request Context - encrypted user cookie session)
- **G** -> `g` (App Context - temporary request-scoped global storage dictionary)

## ⚡ Quick-Reference Commands Cheatsheet

### Environment & Package Setup
```bash
# 1. Create virtual environment
python -m venv venv

# 2. Activate virtual environment (Windows Command Prompt / PowerShell)
venv\Scripts\activate

# 2. Activate virtual environment (Linux / macOS Terminal)
source venv/bin/activate

# 3. Install Flask & dotenv support
pip install flask python-dotenv
```

### CLI Operations
```bash
# Run Development WSGI Server (Uses .flaskenv automatically)
flask run

# Run on Specific Host & Port
flask run --host=0.0.0.0 --port=8080

# List All Registered Routes in Application
flask routes
```

## 📋 Core Code Snippets

### 1. Minimal Flask App
```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route('/')
def home():
    return jsonify(status="ok", message="Hello World")

if __name__ == '__main__':
    app.run(debug=True)
```

### 2. Pushing Application Context Manually
```python
from flask import Flask, current_app

app = Flask(__name__)

with app.app_context():
    print(f"Active App Name: {current_app.name}")
```

### 3. Custom WSGI Middleware
```python
class CustomMiddleware:
    def __init__(self, wsgi_app):
        self.wsgi_app = wsgi_app

    def __call__(self, environ, start_response):
        # Intercept incoming request or modify response
        return self.wsgi_app(environ, start_response)

app.wsgi_app = CustomMiddleware(app.wsgi_app)
```
