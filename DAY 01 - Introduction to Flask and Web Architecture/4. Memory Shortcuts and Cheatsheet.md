# Day 01 Cheatsheet: WSGI & Flask Basics

## Quick Command Cheatsheet
- Install Flask: `pip install flask python-dotenv`
- Run Dev Server: `flask run --port=5000`
- Debug Mode: Set `FLASK_DEBUG=1`

## Key Mnemonics
- **W-S-G-I**: Web Server Gateway Interface (Standard interface between web server and Python app)
- **E-S**: `environ` (dict) & `start_response` (callback)
