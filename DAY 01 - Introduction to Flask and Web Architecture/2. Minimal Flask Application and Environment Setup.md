## 1. Line-by-Line Breakdown of a Minimal Flask App

Here is a simple, complete Flask web application:

```python
# 1. Import the Flask class from the flask module
from flask import Flask

# 2. Create an instance of the Flask application
app = Flask(__name__)

# 3. Define a route for the home page (root URL '/')
@app.route('/')
def home():
    # This function returns a message when the root URL is accessed
    return "Hello from /home route! Jani Basha Shaik Hyderabad! Aha!"

# 4. Define a route for '/course'
@app.route('/course')
def courses():
    return "I am going to buy an HTML course!"

# 5. Define a dynamic route that captures any string passed in the URL
@app.route('/<name>')
def coursename(name):
    return f"Your course name is {name}"

# 6. Run the application only if this script is executed directly
if __name__ == '__main__':
    app.run(debug=True)
```

Let's dissect **every single line** of this code:

### 🚀 1. Importing Flask
`from flask import Flask`
*   We import the `Flask` class from the `flask` package.
*   This class is required to create our web application instance.

### 🏗️ 2. Creating Flask App
`app = Flask(__name__)`
*   This line creates the Flask application object named `app`.
*   **What is `__name__`?** A built-in Python variable that equals `'__main__'` when the script is run directly.
*   **Why does Flask need `__name__`?** Flask uses `__name__` to determine the root folder location of your script on your hard drive. Flask uses this root path to locate:
    1.  `templates/` folder (for Jinja2 HTML templates).
    2.  `static/` folder (for CSS stylesheets, JavaScript files, and images).

### 🌐 3. Defining Routes
Routes tell Flask what function to execute when a specific URL path is accessed.

*   **Home Route (`/`)**:
    ```python
    @app.route('/')
    def home():
        return "Hello from /home route!"
    ```
    When a user visits `http://127.0.0.1:5000/`, Flask executes `home()` and returns text.

*   **Static Route (`/course`)**:
    ```python
    @app.route('/course')
    def courses():
        return "I am going to buy HTML course!"
    ```
    When a user visits `http://127.0.0.1:5000/course`, this message is returned.

*   **Dynamic Route (`/<name>`)**:
    ```python
    @app.route('/<name>')
    def coursename(name):
        return f"Your course name is {name}"
    ```
    Whatever the user types after `/` is captured as a variable `name`.
    *   Visiting `http://127.0.0.1:5000/python` → `Your course name is python`
    *   Visiting `http://127.0.0.1:5000/java` → `Your course name is java`

### 🟢 4. Running the Flask App
```python
if __name__ == '__main__':
    app.run(debug=True)
```
*   `if __name__ == '__main__':` ensures the server runs only when executed directly (`python app.py`).
*   `debug=True` enables:
    1.  **Auto-Reloader**: Server auto-restarts whenever you edit and save code.
    2.  **Interactive Debugger**: Shows detailed error messages in browser if a crash occurs.

## 2. Introduction to `render_template()` Function

While returning string text or HTML strings directly from Python functions works for small tests, real-world web apps store HTML in separate files.

### 🔍 What is `render_template()`?
`render_template()` is a built-in Flask function used to render (display) HTML template files stored in a folder named **`templates`**.

```python
from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def home():
    # Looks inside 'templates/' folder for 'home.html'
    return render_template('home.html')

@app.route('/index')
def index():
    # Looks inside 'templates/' folder for 'index.html'
    return render_template('index.html')

if __name__ == '__main__':
    app.run(debug=True)
```

### 🗂️ Mandatory Flask Project Folder Structure
Flask **requires** template files to be placed inside a folder named `templates`:

```
your_project_folder/
│
├── app.py                  # Main Python application file
│
├── templates/              # MANDATORY folder for HTML files
│   ├── home.html
│   └── index.html
│
└── static/                 # MANDATORY folder for static files
    ├── style.css
    └── logo.png
```

### 📄 Example `templates/home.html`:
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Home Page</title>
</head>
<body>
    <h1>This is Home page</h1>
    <h2>From this page we learn Flask and Jinja2 rendering!</h2>
</body>
</html>
```

### 📄 Example `templates/index.html`:
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Index Page</title>
</head>
<body>
    <h1>This is index page!</h1>
    <h2>Here I am going to learn about index page rendering!</h2>
</body>
</html>
```

## 3. Core Flask App Summary Table

| Code Component | Purpose | Example |
| :--- | :--- | :--- |
| `Flask(__name__)` | Creates the main Flask application instance | `app = Flask(__name__)` |
| `@app.route()` | Defines the URL path for a view function | `@app.route('/course')` |
| `Dynamic Routes` | Handles URLs with variable placeholders | `@app.route('/<name>')` |
| `render_template()` | Renders an HTML page from `templates/` folder | `return render_template('home.html')` |
| `app.run(debug=True)` | Starts Werkzeug dev server with auto-reload | `app.run(debug=True)` |

## 4. Environment Variables (`.env` & `.flaskenv`)

Flask applications use `python-dotenv` to separate development settings and private keys from python code:

```
project_folder/
│── .env                <-- Private secrets (API keys, DB passwords - IGNORE IN GIT)
│── .flaskenv           <-- Public environment configs (FLASK_APP=app.py, FLASK_DEBUG=1)
│── app.py
```
