# Day 01: Minimal Flask Application & Context Internals

## 1. Flask Application Instance
Every Flask application begins with an instance of the `Flask` class:

```python
from flask import Flask

app = Flask(__name__)
```

- `__name__`: Specifies the module name so Flask knows where to locate static assets, templates, and root directories.

## 2. Environment Variables & CLI Integration
Flask 3.x uses `.env` and `.flaskenv` files managed via `python-dotenv`:

```ini
FLASK_APP=app.py
FLASK_ENV=development
FLASK_DEBUG=1
```
