# Day 01: Practice & Technical Interview Questions

### Q1: What is WSGI and why is it essential in Python web development?
**Answer**: WSGI (PEP 3333) standardizes how WSGI servers pass HTTP request data (`environ`) to Python web applications and receive status codes and headers (`start_response`). It decouples application logic from server implementation.

### Q2: What does `__name__` do when passed to `Flask(__name__)`?
**Answer**: It informs Flask of the import name of the main module so it can correctly locate relative paths for templates, static files, and configuration files.
