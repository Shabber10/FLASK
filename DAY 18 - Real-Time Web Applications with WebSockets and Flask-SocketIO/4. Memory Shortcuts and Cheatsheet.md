## 🧠 Memory Mnemonics

### 1. Flask-SocketIO Event Operations
Remember **E-M-I-T** rules for WebSockets:
- **E**: **`emit('event_name', data)`** (Dispatches named JSON event payload)
- **M**: **Multi-Room Channeling** (`join_room('room')` and `leave_room('room')`)
- **I**: **`include_self=False`** (Broadcasts event to room members excluding sender)
- **T**: **Targeted Room Emitting** (`emit('msg', data, to='room_name')`)

---

### 2. SocketIO Server Execution Rule
> ⚠️ **CRITICAL**: Use `socketio.run(app)` instead of standard `app.run()` to start the WSGI server with WebSocket transport support!

## ⚡ Quick-Reference Code Snippets

### 1. Flask-SocketIO Setup & Event Handlers
```python
from flask_socketio import SocketIO, emit, join_room, leave_room

socketio = SocketIO(app, cors_allowed_origins="*")

@socketio.on('connect')
def on_connect():
    print(f"Connected SID: {request.sid}")

@socketio.on('join')
def on_join(data):
    join_room(data['room'])
    emit('notice', {'msg': 'User joined'}, to=data['room'])

@socketio.on('chat')
def on_chat(data):
    emit('message', data, to=data['room'])
```

### 2. Socket.IO Client JS Integration
```html
<script src="https://cdn.socket.io/4.7.2/socket.io.min.js"></script>
<script>
    const socket = io();

    socket.on('connect', () => {
        socket.emit('join', { room: '#general' });
    });

    socket.on('message', (data) => {
        console.log("Received:", data);
    });
</script>
```

### 3. Scaling across Multi-Worker Processes
```python
# Pass Redis URL to enable cross-worker message broadcasting
socketio = SocketIO(app, message_queue='redis://localhost:6379/0')
```
