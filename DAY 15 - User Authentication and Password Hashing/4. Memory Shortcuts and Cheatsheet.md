## 🔤 Auth & RBAC Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Authentication** | Proving user identity ("Who are you?"). | Username & Password login |
| **Authorization** | Verifying access permissions ("What can you do?"). | Checking if user has `Admin` role |
| **One-Way Hash** | Irreversible mathematical function turning raw password into hash. | `scrypt:32768:8:1$...` |
| **Salt** | Random noise bytes added to passwords before hashing to stop attacks. | Unique per-user random string |
| **`UserMixin`** | Flask-Login mixin providing `is_authenticated`, `get_id()`. | `class User(UserMixin, db.Model)` |
| **`user_loader`** | Callback loading User instance from database by ID string. | `@login_manager.user_loader` |
| **RBAC** | Role-Based Access Control assigning permissions to user roles. | `Admin`, `Editor`, `User` |
| **`functools.wraps`** | Python helper preserving original function metadata on decorators. | `@wraps(f)` |

---

## 🧠 Memory Mnemonics

### 1. Authentication Lifecycle (`A-U-T-H`)
Remember **A-U-T-H** for authentication verification:
- **A** -> **Accept Credentials** (Receive username & raw password from request)
- **U** -> **Uncover User in DB** (`User.query.filter_by(username=...).first()`)
- **T** -> **Test Password Hash** (`check_password_hash(user.password_hash, raw_pass)`)
- **H** -> **Handle Session** (`login_user(user)`)

---

### 2. Role-Based Access Control (`R-B-A-C`)
Remember **R-B-A-C** for enforcing role security:
- **R** -> **Request Arrives** at protected route
- **B** -> **Before Execution Check Auth** (`if not current_user.is_authenticated -> 401`)
- **A** -> **Assert Role Match** (`if current_user.role not in allowed_roles -> 403`)
- **C** -> **Continue View Function** (Return response payload)

## ⚡ Quick-Reference Code Snippets

### 1. Werkzeug Password Hashing
```python
from werkzeug.security import generate_password_hash, check_password_hash

# Hash password
hashed_pw = generate_password_hash("RawPassword123")

# Check password
is_valid = check_password_hash(hashed_pw, "RawPassword123")  # True
```

### 2. Flask-Login Setup & User Loader
```python
from flask_login import LoginManager, UserMixin, login_user, logout_user, login_required, current_user

login_manager = LoginManager(app)
login_manager.login_view = 'login'

@login_manager.user_loader
def load_user(user_id):
    return User.query.get(int(user_id))
```

### 3. Custom RBAC Decorator Skeleton
```python
from functools import wraps
from flask import abort
from flask_login import current_user

def role_required(*roles):
    def decorator(f):
        @wraps(f)  # MANDATORY!
        def wrapper(*args, **kwargs):
            if not current_user.is_authenticated:
                abort(401)
            if current_user.role not in roles:
                abort(403)
            return f(*args, **kwargs)
        return wrapper
    return decorator
```
