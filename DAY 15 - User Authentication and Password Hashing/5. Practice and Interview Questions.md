# Day 15: Practice & Technical Interview Questions

This question bank is divided into **3 progression levels**, starting from password hashing basics up to `functools.wraps`, timing attack protection, and custom RBAC decorator construction.

---

## 🟢 Level 1: Absolute Beginner Questions

### Q1: What is the difference between Authentication and Authorization?
**Answer**:
*   **Authentication (AuthN)**: Verifying who a user is (e.g. validating username & password during login).
*   **Authorization (AuthZ)**: Verifying what permissions a user has (e.g. checking if a logged-in user has permission to view `/admin`).

---

### Q2: Why should passwords never be stored in plaintext inside a database?
**Answer**:
If a database is compromised during a security breach, plaintext passwords immediately expose every user's real credentials. Hashing ensures that even if database tables are leaked, the actual raw passwords remain protected because hash functions are mathematically one-way.

---

### Q3: What is Salt in password hashing and why is it used?
**Answer**:
A Salt is a string of random noise bytes appended to a password before hashing. It ensures that two users with identical raw passwords (e.g. `"password123"`) generate completely unique hashes, neutralizing Rainbow Table lookup attacks.

---

### Q4: What is Flask-Login?
**Answer**:
Flask-Login is the standard Flask extension for managing user session state. It handles logging users in and out, maintaining user sessions across requests, providing `current_user`, and protecting routes via `@login_required`.

---

### Q5: What methods/properties does `UserMixin` add to a SQLAlchemy User model?
**Answer**:
It adds default implementations for `is_authenticated` (returns `True`), `is_active` (returns `True`), `is_anonymous` (returns `False`), and `get_id()` (returns user ID as a string).

---

## 🟡 Level 2: Intermediate Questions

### Q6: Why is `functools.wraps(f)` mandatory when writing custom Flask route decorators?
**Answer**:
Flask relies on the `__name__` metadata of view functions for internal route mapping (`url_for`). Without `@wraps(f)`, decorated view functions would overwrite their names with the inner wrapper function's name (`wrapper`), causing Flask to crash with endpoint collision errors.

---

### Q7: What is the exact difference between HTTP `401 Unauthorized` and HTTP `403 Forbidden`?
**Answer**:
*   **HTTP 401 Unauthorized**: The user is unauthenticated (not logged in).
*   **HTTP 403 Forbidden**: The user is authenticated (logged in), but lacks necessary role permissions to access the resource.

---

### Q8: How does Werkzeug's `check_password_hash()` protect against Timing Attacks?
**Answer**:
`check_password_hash()` uses constant-time string comparison algorithms (`hmac.compare_digest`). This ensures that password comparison takes the exact same amount of execution time regardless of how many characters match, preventing hackers from measuring subtle response times to guess passwords character-by-character.

---

### Q9: What does `@login_manager.user_loader` do?
**Answer**:
It registers a callback function that Flask-Login calls on every request to reload a `User` model object from the database using the user ID stored in the session cookie.

---

### Q10: How do you log a user out using Flask-Login?
**Answer**:
Call `logout_user()`, which deletes the user ID from the active session dictionary and invalidates the session cookie.

---

## 🔴 Level 3: Advanced & Enterprise Questions

### Q11: How do modern hashing algorithms like Scrypt and Argon2 protect against GPU brute-force attacks?
**Answer**:
Traditional algorithms (like plain SHA-256) are blazingly fast, allowing specialized GPUs/ASICs to compute billions of hashes per second. Scrypt and Argon2 are **Memory-Hard** algorithms, requiring large amounts of RAM per hash calculation. This prevents hardware parallelization on GPUs.

---

### Q12: How do you construct a dynamic `@role_required(*allowed_roles)` decorator that supports multiple roles?
**Answer**:
```python
from functools import wraps
from flask import abort
from flask_login import current_user

def role_required(*allowed_roles):
    def decorator(f):
        @wraps(f)
        def decorated_function(*args, **kwargs):
            if not current_user.is_authenticated:
                abort(401)
            if current_user.role not in allowed_roles:
                abort(403)
            return f(*args, **kwargs)
        return decorated_function
    return decorator
```

---

### Q13: How can you enforce password strength policies before hashing passwords in Flask?
**Answer**:
Validate raw password input against entropy rules (minimum length 12+, uppercase, lowercase, numbers, special characters) or use libraries like `zxcvbn` before calling `generate_password_hash()`.

---

### Q14: What happens if `load_user(user_id)` returns `None`?
**Answer**:
If `user_loader` returns `None` (e.g. if the user was deleted from the database while their session cookie remained active), Flask-Login treats the user as anonymous (`current_user.is_authenticated` becomes `False`).

---

### Q15: How should Remember-Me functionality be implemented securely?
**Answer**:
When `login_user(user, remember=True)` is called, Flask-Login generates a long-lived signed persistent cookie (`REMEMBER_COOKIE`). Ensure `REMEMBER_COOKIE_HTTPONLY = True`, `REMEMBER_COOKIE_SECURE = True`, and `REMEMBER_COOKIE_DURATION` are configured properly.
