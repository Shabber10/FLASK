## 1. Hashing Passwords with Werkzeug (`generate_password_hash`)

Flask's underlying WSGI library `werkzeug.security` provides built-in functions for salted password hashing and verification:

```python
from werkzeug.security import generate_password_hash, check_password_hash

# 1. Hashing a raw password (Uses PBKDF2:SHA256 / scrypt with random salt)
password_hash = generate_password_hash("SuperSecretPass123!", method="scrypt")

# 2. Verifying user login input against stored hash
is_valid_user = check_password_hash(password_hash, "SuperSecretPass123!")  # True
is_wrong_pass = check_password_hash(password_hash, "WrongPassword")         # False
```

#### ⚖️ Plaintext Storage vs Cryptographic Password Hashing

| Security Aspect | Plaintext Passwords (`"secret123"`) | Cryptographic Hash (`generate_password_hash`) |
| :--- | :--- | :--- |
| **Database Leak Impact** | 🚨 Disaster: All user credentials stolen instantly | ✅ Safe: Hashes cannot be reversed back to passwords |
| **Reversibility** | 100% Readable by any database admin | Irreversible One-Way Mathematical Computation |
| **Salting** | No salt | Random salt bytes appended automatically per password |
| **Rainbow Table Defense** | ❌ Vulnerable to pre-computed lookup tables | ✅ Complete defense (Salt forces unique hashes) |

## 2. Integrating `Flask-Login`

`Flask-Login` handles session tracking for logged-in users.

### Step A: Configure `UserMixin` on your User Model
```python
from datetime import datetime, timezone
from flask_sqlalchemy import SQLAlchemy
from flask_login import UserMixin
from werkzeug.security import generate_password_hash, check_password_hash

db = SQLAlchemy()

class User(UserMixin, db.Model):
    __tablename__ = 'users'
    
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(50), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)
    password_hash = db.Column(db.String(255), nullable=False)
    role = db.Column(db.String(20), default='User')
    
    # Account Lockout fields
    failed_login_attempts = db.Column(db.Integer, default=0, nullable=False)
    locked_until = db.Column(db.DateTime, nullable=True)

    def set_password(self, password):
        self.password_hash = generate_password_hash(password)

    def check_password(self, password):
        return check_password_hash(self.password_hash, password)

    def is_locked(self):
        """Check if account is temporarily locked due to failed attempts."""
        if self.locked_until and self.locked_until > datetime.now(timezone.utc):
            return True
        return False
```

### Step B: Setup `LoginManager` & `user_loader`
```python
from flask import Flask
from flask_login import LoginManager

app = Flask(__name__)
app.config['SECRET_KEY'] = 'auth-secret-key-32bytes'

login_manager = LoginManager()
login_manager.init_app(app)
login_manager.login_view = 'login'  # Route unauthenticated visitors are redirected to
login_manager.session_protection = "strong"  # Session Fixation & Hijacking defense

@login_manager.user_loader
def load_user(user_id):
    """Callback returning User object given integer user_id."""
    return db.session.get(User, int(user_id))
```

## 3. Login, Logout, and Route Protection

```python
from flask import request, redirect, url_for, flash, render_template
from flask_login import login_user, logout_user, login_required, current_user

@app.route('/login', methods=['POST'])
def login():
    username = request.form.get('username')
    password = request.form.get('password')
    
    user = User.query.filter_by(username=username).first()
    
    if not user:
        flash("Invalid username or password.", "danger")
        return redirect(url_for('login'))

    # Check for temporary lockout
    if user.is_locked():
        flash("Account is temporarily locked due to failed login attempts. Try again later.", "warning")
        return redirect(url_for('login'))

    if user.check_password(password):
        # Reset failed login count on successful login
        user.failed_login_attempts = 0
        user.locked_until = None
        db.session.commit()
        
        login_user(user, remember=True)
        return redirect(url_for('dashboard'))

    # Increment failed attempts on wrong password
    user.failed_login_attempts += 1
    if user.failed_login_attempts >= 5:
        from datetime import timedelta
        user.locked_until = datetime.now(timezone.utc) + timedelta(minutes=15)
        flash("5 failed login attempts. Account locked for 15 minutes.", "danger")
    else:
        flash("Invalid username or password.", "danger")
        
    db.session.commit()
    return redirect(url_for('login'))

@app.route('/dashboard')
@login_required  # Blocks unauthenticated visitors automatically
def dashboard():
    return f"Welcome to your dashboard, {current_user.username}!"

@app.route('/logout')
@login_required
def logout():
    logout_user()
    return redirect(url_for('login'))
```

## 4. Timed Password Reset Tokens (`itsdangerous`)

### 📖 How Password Reset Flows Work:
1. User enters their email address at `/forgot-password`.
2. Server generates a cryptographically signed, timestamped token containing `user.id` using `itsdangerous.URLSafeTimedSerializer`.
3. Server emails a reset link: `https://app.com/reset-password?token=<TOKEN>`.
4. When clicked, server verifies token signature and ensures token is not older than 30 minutes (`max_age=1800`).

```python
from itsdangerous import URLSafeTimedSerializer, SignatureExpired, BadSignature

serializer = URLSafeTimedSerializer(app.config['SECRET_KEY'], salt="password-reset-salt")

# 1. Generate Token (Sent in Email Link)
def generate_reset_token(user_id):
    return serializer.dumps(user_id)

# 2. Verify Token when User Clicks Reset Link
def verify_reset_token(token, max_age_seconds=1800):
    """Returns user_id if valid and younger than 30 mins (1800s); otherwise None."""
    try:
        user_id = serializer.loads(token, max_age=max_age_seconds)
        return user_id, None
    except SignatureExpired:
        return None, "The password reset link has expired."
    except BadSignature:
        return None, "Invalid or tampered password reset token."


@app.route('/reset-password', methods=['GET', 'POST'])
def reset_password():
    token = request.args.get('token')
    user_id, err = verify_reset_token(token)
    
    if err:
        flash(err, "danger")
        return redirect(url_for('login'))

    user = db.session.get(User, user_id)
    if request.method == 'POST':
        new_password = request.form.get('new_password')
        user.set_password(new_password)
        db.session.commit()
        flash("Password updated successfully! You can now log in.", "success")
        return redirect(url_for('login'))

    return render_template('reset_password.html')
```
