## 1. Hashing Passwords with Werkzeug (`generate_password_hash`)

Flask's underlying WSGI library `werkzeug.security` provides built-in functions for salted password hashing and verification:

```python
from werkzeug.security import generate_password_hash, check_password_hash

# 1. Hashing a raw password (Uses PBKDF2:SHA256 with random salt by default)
password_hash = generate_password_hash("SuperSecretPass123!", method="scrypt")
print(password_hash)
# Output: scrypt:32768:8:1$vK9...$8d3f...

# 2. Verifying user login input against stored hash
is_valid_user = check_password_hash(password_hash, "SuperSecretPass123!")  # True
is_wrong_pass = check_password_hash(password_hash, "WrongPassword")         # False
```

> **Supported Hashing Algorithms**:
> *   `scrypt` (Flask Default in modern Werkzeug - High memory-hard security).
> *   `pbkdf2:sha256` (NIST recommended key derivation algorithm).

## 2. Integrating `Flask-Login`

`Flask-Login` handles session tracking for logged-in users.

### Step A: Configure `UserMixin` on your User Model
Inherit from `UserMixin` to automatically equip your `User` model with standard properties required by Flask-Login (`is_authenticated`, `is_active`, `is_anonymous`, `get_id()`):

```python
from flask_sqlalchemy import SQLAlchemy
from flask_login import UserMixin
from werkzeug.security import generate_password_hash, check_password_hash

db = SQLAlchemy()

class User(UserMixin, db.Model):
    __tablename__ = 'users'
    
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(50), unique=True, nullable=False)
    password_hash = db.Column(db.String(255), nullable=False)
    role = db.Column(db.String(20), default='User')

    def set_password(self, password):
        self.password_hash = generate_password_hash(password)

    def check_password(self, password):
        return check_password_hash(self.password_hash, password)
```

---

### Step B: Setup `LoginManager` & `user_loader`
Initialize `LoginManager` and define a `@login_manager.user_loader` callback to fetch user instances from the database by ID:

```python
from flask import Flask
from flask_login import LoginManager

app = Flask(__name__)
app.config['SECRET_KEY'] = 'auth-secret-key-32bytes'

login_manager = LoginManager()
login_manager.init_app(app)
login_manager.login_view = 'login'  # Route endpoint unauthenticated users are redirected to!

@login_manager.user_loader
def load_user(user_id):
    """Callback returning User object given integer user_id."""
    return db.session.get(User, int(user_id))
```

## 3. Login, Logout, and Route Protection

Use Flask-Login helper functions inside route handlers:

```python
from flask import request, redirect, url_for, flash, render_template
from flask_login import login_user, logout_user, login_required, current_user

@app.route('/login', methods=['POST'])
def login():
    username = request.form.get('username')
    password = request.form.get('password')
    
    user = db.session.execute(db.select(User).filter_by(username=username)).scalar_one_or_none()
    
    if user and user.check_password(password):
        login_user(user, remember=True)  # Logs user in and creates session cookie!
        return redirect(url_for('dashboard'))
        
    flash("Invalid username or password.", "danger")
    return redirect(url_for('login'))

@app.route('/dashboard')
@login_required  # Protects route! Blocks unauthenticated visitors automatically.
def dashboard():
    return f"Welcome to your dashboard, {current_user.username}!"

@app.route('/logout')
@login_required
def logout():
    logout_user()  # Clears user login session
    return redirect(url_for('login'))
```
