# Day 15: User Authentication & Password Hashing

## 1. Password Hashing Mechanics
Never store plaintext passwords. Use salted hashing algorithms (Argon2, Bcrypt, PBKDF2):

```python
from werkzeug.security import generate_password_hash, check_password_hash

# Hash password
hashed_pw = generate_password_hash('SecretPassword123', method='pbkdf2:sha256')

# Verify password
is_valid = check_password_hash(hashed_pw, 'SecretPassword123')
```
