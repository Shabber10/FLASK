## 1. Setting Up `Flask-Talisman`

Install `Flask-Talisman`:

```bash
pip install flask-talisman
```

Initialize `Talisman` on your Flask application object:

```python
from flask import Flask
from flask_talisman import Talisman

app = Flask(__name__)

# 1. Define Strict Content Security Policy (CSP) Directives
csp = {
    'default-src': "'self'",
    'script-src': [
        "'self'",
        'https://cdn.jsdelivr.net',
        'https://code.jquery.com'
    ],
    'style-src': [
        "'self'",
        'https://fonts.googleapis.com',
        'https://cdn.jsdelivr.net'
    ],
    'font-src': [
        "'self'",
        'https://fonts.gstatic.com'
    ],
    'img-src': "'self' data: https:",
    'object-src': "'none'"  # Blocks Flash / Java applets
}

# 2. Attach Talisman Security Hardening Extension
talisman = Talisman(
    app,
    content_security_policy=csp,
    force_https=False,              # Set to True in Production HTTPS!
    session_cookie_secure=True,     # Ensures cookies sent via HTTPS only
    session_cookie_http_only=True,   # Blocks JS cookie theft via document.cookie
    frame_options='DENY'            # Blocks Clickjacking iframe embedding
)
```

## 2. Deep Dive: HTTP Security Headers Injected by Talisman

When Talisman is active, every response contains the following production-grade security headers:

```http
Strict-Transport-Security: max-age=31536000; includeSubDomains
X-Frame-Options: DENY
X-Content-Type-Options: nosniff
X-XSS-Protection: 1; mode=block
Content-Security-Policy: default-src 'self'; script-src 'self' ...
Referrer-Policy: strict-origin-when-cross-origin
```

## 3. Dynamic CSP Nonces (`@talisman.nonce`)

If your Jinja2 HTML templates require inline `<script>` or `<style>` tags, hardcoding `'unsafe-inline'` in CSP breaks XSS protection!

Instead, use **CSP Nonces** (cryptographic one-time random tokens generated per request):

```python
from flask import render_template

@app.route('/dashboard')
def dashboard():
    return render_template('dashboard.html')
```

In Jinja2 template:
```html
<!-- Jinja2 template automatically accesses csp_nonce() from Talisman -->
<script nonce="{{ csp_nonce() }}">
    console.log("This inline script is trusted because its nonce matches the HTTP header!");
</script>
```
