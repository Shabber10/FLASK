# Day 17: Practice & Technical Interview Questions

This question bank is divided into **3 progression levels**, starting from serialization basics up to `Flask-Marshmallow` auto-schemas, `@post_load` hooks, and circular nested relationships.

---

## 🟢 Level 1: Absolute Beginner Questions

### Q1: What is the difference between Serialization and Deserialization?
**Answer**:
*   **Serialization (`dump`)**: Converting complex Python objects or SQLAlchemy database models into simple JSON dictionaries for API responses.
*   **Deserialization (`load`)**: Validating raw incoming JSON request payloads and converting them into clean Python dictionaries.

---

### Q2: Why is writing manual `to_dict()` methods on ORM models considered an anti-pattern for enterprise REST APIs?
**Answer**:
Manual `to_dict()` methods only format outgoing data; they do not perform input validation on incoming POST data. They lead to duplicated `if/else` validation checks across route handlers and risk leaking confidential fields (like `password_hash`).

---

### Q3: What is Marshmallow?
**Answer**:
Marshmallow is an ORM-agnostic Python library for data formatting (serialization) and input data validation.

---

### Q4: What does `schema.dump(obj)` return vs `schema.load(data)`?
**Answer**:
*   `schema.dump(obj)`: Returns a serialized JSON dictionary (or list of dictionaries if `many=True`).
*   `schema.load(data)`: Validates the data dictionary and returns a cleaned dictionary (or raises a `ValidationError`).

---

### Q5: What HTTP status code should an API return when Marshmallow validation fails?
**Answer**:
`HTTP 422 Unprocessable Entity` (or `HTTP 400 Bad Request`), returning JSON detailing the invalid fields.

---

## 🟡 Level 2: Intermediate Questions

### Q6: What is the difference between `dump_only=True` and `load_only=True` in Marshmallow fields?
**Answer**:
*   `dump_only=True`: Field is included ONLY during serialization (`dump`), e.g., auto-generated `id`, `created_at`.
*   `load_only=True`: Field is processed ONLY during deserialization (`load`), e.g., `password`. It is omitted from outgoing JSON responses.

---

### Q7: How do you write a custom field validator method in a Marshmallow Schema?
**Answer**:
Decorate a method with `@validates('field_name')` and raise `marshmallow.ValidationError` if validation fails:

```python
@validates('username')
def validate_username(self, value):
    if value.lower() == 'admin':
        raise ValidationError("Username 'admin' is reserved.")
```

---

### Q8: How do you serialize a list of multiple database objects using Marshmallow?
**Answer**:
Pass `many=True` when instantiating the schema or calling `dump()`:
```python
schema = UserSchema(many=True)
result = schema.dump(users_list)
```

---

### Q9: How do you serialize nested One-to-Many relationships?
**Answer**:
Use `fields.Nested()`:
```python
class AuthorSchema(Schema):
    name = fields.Str()
    books = fields.Nested(BookSchema, many=True, dump_only=True)
```

---

### Q10: How does Marshmallow handle `ValidationError` exceptions?
**Answer**:
When `schema.load()` encounters invalid fields, it stops processing and raises a `ValidationError` containing an `err.messages` dictionary mapping invalid field names to error messages.

---

## 🔴 Level 3: Advanced & Enterprise Questions

### Q11: What is `SQLAlchemyAutoSchema` in `Flask-Marshmallow`?
**Answer**:
`SQLAlchemyAutoSchema` automatically generates Marshmallow fields directly from SQLAlchemy model columns, eliminating redundant field definitions in schemas while maintaining custom validation capabilities.

---

### Q12: What is the purpose of the `@post_load` decorator in Marshmallow?
**Answer**:
`@post_load` marks a schema method that receives the validated dictionary after `schema.load()` and constructs/returns an actual ORM model instance:

```python
@post_load
def make_user(self, data, **kwargs):
    return User(**data)
```

---

### Q13: How do you resolve self-referential or circular nested schema references in Marshmallow?
**Answer**:
Use string references and the `exclude` parameter:
```python
class CategorySchema(Schema):
    id = fields.Int()
    name = fields.Str()
    subcategories = fields.Nested('self', many=True, exclude=('parent',))
```

---

### Q14: How does `partial=True` work during `schema.load()`?
**Answer**:
`partial=True` ignores `required=True` checks on missing fields during `schema.load()`, making it ideal for validating `PATCH` request payloads where only a subset of attributes is sent.

---

### Q15: How can you optimize performance when serializing thousands of objects with Marshmallow?
**Answer**:
Use `only=('id', 'name')` to limit serialized fields, avoid unnecessary nested relationship fields, or use lightweight dictionaries directly when extreme throughput is required.
