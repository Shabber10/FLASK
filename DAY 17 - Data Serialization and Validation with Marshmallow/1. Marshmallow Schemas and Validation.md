# Day 17: Data Serialization & Validation with Marshmallow

## 1. Why Marshmallow?
**Marshmallow** decouples input data validation and output JSON serialization from Flask route logic and database ORM models.

```python
from marshmallow import Schema, fields, validate, validates, ValidationError

class UserSchema(Schema):
    id = fields.Int(dump_only=True)
    username = fields.Str(required=True, validate=validate.Length(min=3))
    email = fields.Email(required=True)
    age = fields.Int(validate=validate.Range(min=18, max=100))
```
