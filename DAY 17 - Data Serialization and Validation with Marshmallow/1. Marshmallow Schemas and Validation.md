## 1. Defining Marshmallow Field Types

Marshmallow provides rich field types that automatically coerce types during `dump()` and `load()`:

```python
from marshmallow import Schema, fields, validate, validates, ValidationError

class ProductSchema(Schema):
    id = fields.Int(dump_only=True)                                     # Integer (Output only)
    name = fields.Str(required=True, validate=validate.Length(min=2))   # String with min length 2
    category = fields.Str(required=True, validate=validate.OneOf(['Electronics', 'Books', 'Clothing']))
    price = fields.Float(required=True, validate=validate.Range(min=0.01)) # Positive float
    in_stock = fields.Bool(default=True)                                # Boolean
    created_at = fields.DateTime(dump_only=True)                       # ISO 8601 Datetime string
```

## 2. Built-In Marshmallow Validators (`marshmallow.validate`)

Use pre-packaged validators inside field definitions:

*   **`validate.Length(min=3, max=50)`**: Enforces string/collection length bounds.
*   **`validate.Range(min=1, max=100)`**: Enforces numeric value ranges.
*   **`validate.OneOf(['Pending', 'Shipped', 'Delivered'])`**: Restricts inputs to an allowed enum whitelist.
*   **`validate.Regexp(r'^[A-Z0-9]+$')`**: Validates input matching regex patterns.

## 3. Authoring Custom Field Validators (`@validates`)

For complex business rules, define custom validator methods decorated with **`@validates('field_name')`**:

```python
class RegistrationSchema(Schema):
    username = fields.Str(required=True)
    email = fields.Email(required=True)

    @validates('username')
    def validate_username(self, value):
        """Custom validation method checking reserved names."""
        if value.lower() in ['admin', 'root', 'superuser', 'null']:
            raise ValidationError("This username is reserved and cannot be registered.")
```

## 4. Capturing `ValidationError` in Flask Routes

When `schema.load(request.json)` encounters invalid input data, it raises a **`ValidationError`**. Catch this exception in your Flask routes to return a standardized HTTP 422 JSON error payload:

```python
from flask import Flask, request, jsonify
from marshmallow import ValidationError

app = Flask(__name__)
product_schema = ProductSchema()

@app.route('/api/v1/products', methods=['POST'])
def create_product():
    json_data = request.get_json() or {}
    
    try:
        # Deserialize and validate incoming JSON data
        validated_data = product_schema.load(json_data)
    except ValidationError as err:
        # Return 422 Unprocessable Entity with dict of field error messages!
        return jsonify({
            "error": {
                "code": 422,
                "type": "UNPROCESSABLE_ENTITY",
                "message": "Input validation failed.",
                "details": err.messages
            }
        }), 422

    # Proceed with saving validated_data...
    return jsonify({"status": "success", "data": validated_data}), 201
```
