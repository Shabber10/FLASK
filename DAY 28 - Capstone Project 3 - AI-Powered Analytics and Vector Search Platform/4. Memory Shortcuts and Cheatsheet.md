## 🧠 Memory Mnemonics

### 1. The RAG Pipeline Steps
Remember **R-A-G** for LLM prompt grounding:
- **R**: **Retrieval** (Query vector DB via Cosine Similarity for top-$K$ chunks)
- **A**: **Augmentation** (Inject retrieved context into LLM prompt)
- **G**: **Generation** (LLM generates grounded answer streamed via SSE)

## ⚡ Quick-Reference Code Snippets

### 1. Cosine Similarity Function
```python
import math

def cosine_similarity(vec1, vec2):
    dot_product = sum(a * b for a, b in zip(vec1, vec2))
    mag1 = math.sqrt(sum(a ** 2 for a in vec1))
    mag2 = math.sqrt(sum(b ** 2 for b in vec2))
    return dot_product / (mag1 * mag2) if (mag1 and mag2) else 0.0
```

### 2. Flask SSE Token Streaming Response
```python
from flask import Response, stream_with_context

def stream_llm_tokens():
    for token in ["Hello", " ", "World"]:
        yield f"data: {token}\n\n"

@app.route('/stream', methods=['POST'])
def stream_api():
    return Response(
        stream_with_context(stream_llm_tokens()),
        mimetype='text/event-stream',
        headers={'X-Accel-Buffering': 'no'}
    )
```
