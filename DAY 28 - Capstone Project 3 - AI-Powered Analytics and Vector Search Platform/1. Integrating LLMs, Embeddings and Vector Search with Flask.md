## 1. Traditional Keyword Search vs. Vector Semantic Search

Traditional relational databases use exact keyword matching (`WHERE text LIKE '%keyword%'` or Full-Text Search TSVector). Keyword search fails when users search for synonyms or semantic concepts:

```
Keyword Search:
Query: "automobile price" ---> Matches ONLY documents containing exact words "automobile" or "price".

Vector Semantic Search:
Query: "automobile price" ---> Converts query into 1536-dimensional Vector Embedding
                          ---> Matches documents containing "car cost", "vehicle rate", "auto budget"!
```

---

## 2. What are Vector Embeddings?

A **Vector Embedding** is a high-dimensional mathematical representation of unstructured text (or images/audio) produced by neural network embedding models (e.g. OpenAI `text-embedding-3-small` or HuggingFace `all-MiniLM-L6-v2`):

$$\vec{v} = [-0.0142, 0.0891, 0.0034, \dots, -0.0512] \in \mathbb{R}^{1536}$$

Words, sentences, or document chunks with similar semantic meaning are mapped to spatial points close to each other in high-dimensional vector space.

## 3. Mathematical Vector Similarity Metrics

Vector similarity is calculated using mathematical distance metrics between query vector $\vec{A}$ and document vector $\vec{B}$:

### 1. Cosine Similarity (Recommended for Normalized Vectors)
Measures the cosine of the angle between two vectors, returning a value between $-1.0$ (opposite) and $+1.0$ (identical):

$$\text{Cosine Similarity}(\vec{A}, \vec{B}) = \frac{\vec{A} \cdot \vec{B}}{\|\vec{A}\| \|\vec{B}\|} = \frac{\sum_{i=1}^{n} A_i B_i}{\sqrt{\sum_{i=1}^{n} A_i^2} \sqrt{\sum_{i=1}^{n} B_i^2}}$$

### 2. Euclidean Distance (L2 Distance)
Measures the straight-line spatial distance between vector endpoints:

$$d(\vec{A}, \vec{B}) = \sqrt{\sum_{i=1}^{n} (A_i - B_i)^2}$$

## 4. Vector Databases (pgvector, ChromaDB, Qdrant)

Storing millions of high-dimensional vectors requires specialized **Vector Databases** or extensions utilizing **Hierarchical Navigable Small World (HNSW)** indexing:

- **`pgvector`**: PostgreSQL extension bringing vector storage and HNSW indexing into standard relational tables.
- **ChromaDB / Qdrant / Pinecone**: Dedicated vector database engines optimized for similarity search.
