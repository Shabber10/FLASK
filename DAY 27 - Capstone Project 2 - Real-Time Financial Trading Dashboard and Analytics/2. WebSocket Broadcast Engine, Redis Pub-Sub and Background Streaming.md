## 1. Flask-SocketIO Background Tasks

In WSGI applications, background loops must run asynchronously without blocking the main WSGI request-handling thread pool. 

Flask-SocketIO supplies `socketio.start_background_task()` to spawn cooperative background worker threads:

```python
import time
import random
from flask_socketio import SocketIO

socketio = SocketIO(app, async_mode='eventlet')

def generate_stock_ticks():
    """Background task pushing live stock price ticks every 500ms."""
    symbols = ['AAPL', 'GOOGL', 'TSLA', 'BTC']
    prices = {'AAPL': 175.50, 'GOOGL': 140.20, 'TSLA': 240.10, 'BTC': 62500.00}

    while True:
        socketio.sleep(0.5) # Cooperative non-blocking sleep!
        for sym in symbols:
            # Random price fluctuation
            delta = round(random.uniform(-1.5, 1.5), 2)
            prices[sym] = max(1.0, round(prices[sym] + delta, 2))
            
            # Emit tick message exclusively to clients in symbol room
            socketio.emit('price_tick', {
                'symbol': sym,
                'price': prices[sym],
                'change': delta,
                'timestamp': time.strftime("%H:%M:%S")
            }, to=sym)

# Start background thread during application startup
@app.before_request
def start_ticker_thread():
    global thread_started
    if not thread_started:
        socketio.start_background_task(target=generate_stock_ticks)
        thread_started = True
```

## 2. Redis Pub/Sub Backplane Integration

When running across multiple Gunicorn worker processes, background thread events published on Worker #1 are distributed to all other worker processes using Redis Pub/Sub:

```python
import redis
import json

redis_client = redis.Redis.from_url('redis://localhost:6379/0')

def redis_tick_listener():
    """Background listener consuming Redis Pub/Sub events."""
    pubsub = redis_client.pubsub()
    pubsub.subscribe('market_ticks')
    
    for message in pubsub.listen():
        if message['type'] == 'message':
            tick_data = json.loads(message['data'])
            symbol = tick_data['symbol']
            # Forward tick to connected WebSocket clients in symbol room
            socketio.emit('price_tick', tick_data, to=symbol)
```
