## 🧠 Memory Mnemonics

### 1. Real-Time Streaming Principles
Remember **T-R-A-D-E** for real-time systems:
- **T**: **Targeted Room Emitting** (`socketio.emit('price_tick', data, to='AAPL')`)
- **R**: **Redis Pub/Sub** (Cross-process broadcasting backplane)
- **A**: **Asynchronous Background Task** (`socketio.start_background_task(target_func)`)
- **D**: **Decoupled Data Generators** (Publish ticks without waiting for client ACK)
- **E**: **Event-Driven Client** (`socket.on('price_tick', handler)`)

## ⚡ Quick-Reference Code Snippets

### 1. Spawning SocketIO Background Threads
```python
def generate_ticks():
    while True:
        socketio.sleep(0.5) # Non-blocking sleep!
        socketio.emit('tick', {'price': 100.50}, to='AAPL')

@app.before_request
def start_stream():
    if not hasattr(g, 'thread_started'):
        socketio.start_background_task(target=generate_ticks)
```

### 2. Ticker Subscription Event Handlers
```python
@socketio.on('subscribe_symbol')
def on_subscribe(data):
    symbol = data['symbol']
    join_room(symbol)
    emit('status', {'msg': f'Subscribed to {symbol}'})
```

### 3. Redis Pub/Sub Listener Loop
```python
pubsub = redis_client.pubsub()
pubsub.subscribe('market_ticks')

for message in pubsub.listen():
    if message['type'] == 'message':
        tick = json.loads(message['data'])
        socketio.emit('price_update', tick, to=tick['symbol'])
```
