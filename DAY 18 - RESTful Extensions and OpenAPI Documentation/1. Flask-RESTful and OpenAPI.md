# Day 18: RESTful Extensions & OpenAPI Documentation

## 1. Flask-RESTful Class-Based Resources
**Flask-RESTful** introduces Object-Oriented resource dispatching:

```python
from flask_restful import Api, Resource

api = Api(app)

class UserResource(Resource):
    def get(self, user_id):
        return {"user_id": user_id}

api.add_resource(UserResource, '/users/<int:user_id>')
```
