# Day 18: Practice & Technical Interview Questions

This question bank is divided into **3 progression levels**, starting from API documentation basics up to `Flask-Smorest`, OpenAPI 3.0 specifications, and Swagger UI sandbox integration.

---

## 🟢 Level 1: Absolute Beginner Questions

### Q1: What is API Documentation and why is it essential for developers?
**Answer**:
API Documentation is an instruction manual for an API. It explains available endpoints, HTTP methods, required headers, request JSON formats, and sample response payloads so developers can integrate with the API without needing to inspect backend source code.

---

### Q2: What is the difference between OpenAPI and Swagger UI?
**Answer**:
*   **OpenAPI Specification**: A machine-readable JSON or YAML standard describing an API's endpoints, parameters, and data schemas.
*   **Swagger UI**: A web-based user interface generated automatically from an OpenAPI specification that allows developers to view documentation and test API endpoints interactively in their browser.

---

### Q3: What is a Class-Based REST Resource?
**Answer**:
A Class-Based Resource (such as `flask_smorest.MethodView` or `flask_restful.Resource`) is a Python class that groups all HTTP method handlers (`get`, `post`, `put`, `delete`) for a single API resource into one place.

---

### Q4: Why use `Flask-Smorest` instead of manual view functions?
**Answer**:
`Flask-Smorest` automatically validates input payloads using Marshmallow, formats output JSON, and generates an OpenAPI 3.0 specification (`/openapi.json`) and live Swagger UI (`/swagger-ui`) directly from your python code annotations.

---

### Q5: Where can developers interactively test endpoints in a Flask-Smorest app?
**Answer**:
At the `/swagger-ui` route (e.g. `http://127.0.0.1:5000/swagger-ui`).

---

## 🟡 Level 2: Intermediate Questions

### Q6: How does `@blp.arguments(Schema)` work in `Flask-Smorest`?
**Answer**:
`@blp.arguments(Schema)` intercepts the incoming HTTP request body, validates it against the specified Marshmallow Schema, and passes the validated data dictionary directly as an argument to the view method. If validation fails, it automatically returns an HTTP 422 JSON error response.

---

### Q7: What does `@blp.response(200, Schema)` do?
**Answer**:
It serializes the dictionary or object returned by the view method using the specified Marshmallow Schema, sets the HTTP status code to 200 OK, and documents the response structure in the auto-generated OpenAPI specification.

---

### Q8: What is the difference between `Flask-RESTful` and `Flask-Smorest`?
**Answer**:
*   `Flask-RESTful`: A classic extension using custom `reqparse` and `@marshal_with` for formatting, but lacking built-in OpenAPI 3.0 generation.
*   `Flask-Smorest`: A modern extension built on top of Marshmallow and Webargs that natively generates OpenAPI 3.0 JSON specs and Swagger UI documentation.

---

### Q9: How do you configure Swagger UI in Flask-Smorest?
**Answer**:
Set application configuration variables before initializing `Api`:
```python
app.config['OPENAPI_VERSION'] = '3.0.3'
app.config['OPENAPI_URL_PREFIX'] = '/'
app.config['OPENAPI_SWAGGER_UI_PATH'] = '/swagger-ui'
app.config['OPENAPI_SWAGGER_UI_URL'] = 'https://cdn.jsdelivr.net/npm/swagger-ui-dist/'
```

---

### Q10: How do docstrings on `MethodView` methods affect Swagger UI?
**Answer**:
The docstring of a method inside a `MethodView` (e.g., `"""List all products in catalog."""`) is automatically extracted by Flask-Smorest and rendered as the operation summary in Swagger UI documentation.

---

## 🔴 Level 3: Advanced & Enterprise Questions

### Q11: How do you document JWT Bearer Token authentication in Swagger UI using `Flask-Smorest`?
**Answer**:
Configure the security scheme on `Api.spec`:

```python
api = Api(app)
api.spec.components.security_scheme("bearerAuth", {
    "type": "http",
    "scheme": "bearer",
    "bearerFormat": "JWT"
})
```
Then decorate protected `MethodView` methods with `@blp.doc(security=[{"bearerAuth": []}])`.

---

### Q12: How can enterprise teams use `/openapi.json` to generate client SDKs?
**Answer**:
Tools like `openapi-generator` or `Swagger Codegen` can read the machine-readable `/openapi.json` specification file and automatically generate typed client SDK libraries in TypeScript, Swift, Kotlin, Java, or Go.

---

### Q13: How do you handle file uploads in `Flask-Smorest` with Marshmallow schemas?
**Answer**:
Use `flask_smorest.fields.Upload` field in Marshmallow schema and specify `content_type='multipart/form-data'` in `@blp.arguments()`.

---

### Q14: How does `Flask-Smorest` handle pagination documentation in OpenAPI?
**Answer**:
Decorate list endpoints with `@blp.paginate()`, which automatically parses `page` and `page_size` query parameters, injects pagination metadata into headers, and documents query options in Swagger UI.

---

### Q15: What is the advantage of OpenAPI 3.0 over Swagger 2.0?
**Answer**:
OpenAPI 3.0 improved structural components, supported multiple server host definitions (`servers`), provided better support for `oneOf`/`anyOf` polymorphic schemas, and separated request body definitions (`requestBody`) from parameters.
