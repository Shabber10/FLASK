# Day 18 - Module 2: Flask-Smorest & Swagger UI Integration

Welcome to **Module 2** of Day 18! While `Flask-RESTful` is classic, **`Flask-Smorest`** is the modern industry standard for building OpenAPI 3.0-compliant, self-documenting REST APIs with Marshmallow in Flask!

---

## 1. What is Flask-Smorest?

**Flask-Smorest** is an API framework that seamlessly connects **Flask**, **Marshmallow**, and **OpenAPI 3.0**.

### Key Benefits:
1.  **Strict Schema Validation**: Automatically validates incoming JSON bodies using Marshmallow (`@blp.arguments(Schema)`).
2.  **Schema Response Dumping**: Automatically formats outgoing response JSON using Marshmallow (`@blp.response(200, Schema)`).
3.  **Zero-Maintenance Swagger UI**: Automatically generates an OpenAPI 3.0 specification (`/openapi.json`) and renders an interactive **Swagger UI** page (`/swagger-ui`) directly from your python code!

---

## 2. Configuring OpenAPI & Swagger UI Metadata

Configure `Flask-Smorest` settings on your `Flask` application object:

```python
from flask import Flask
from flask_smorest import Api

app = Flask(__name__)

# OpenAPI 3.0 Configuration Settings
app.config['API_TITLE'] = 'E-Commerce Microservice API'
app.config['API_VERSION'] = 'v1'
app.config['OPENAPI_VERSION'] = '3.0.3'
app.config['OPENAPI_URL_PREFIX'] = '/'
app.config['OPENAPI_SWAGGER_UI_PATH'] = '/swagger-ui'
app.config['OPENAPI_SWAGGER_UI_URL'] = 'https://cdn.jsdelivr.net/npm/swagger-ui-dist/'

api = Api(app)  # Connect Smorest Api Manager
```

## 3. Smorest Blueprints & Method Views

In `Flask-Smorest`, routes are declared using `Blueprint` objects and `MethodView` classes:

```python
from flask.views import MethodView
from flask_smorest import Blueprint
from marshmallow import Schema, fields

# 1. Define Marshmallow Schema
class ItemSchema(Schema):
    id = fields.Int(dump_only=True)
    name = fields.Str(required=True)
    price = fields.Float(required=True)

# 2. Define Smorest Blueprint
blp = Blueprint('items', 'items', url_prefix='/api/v1/items', description='Items Operations')

# 3. Define Class-Based MethodView Resource
@blp.route('/')
class ItemListResource(MethodView):
    
    @blp.response(200, ItemSchema(many=True))
    def get(self):
        """List all items in catalog."""
        return items_list

    @blp.arguments(ItemSchema)
    @blp.response(201, ItemSchema)
    def post(self, new_item_data):
        """Create a new item in catalog."""
        # new_item_data is ALREADY validated by Marshmallow!
        new_item_data['id'] = len(items_list) + 1
        items_list.append(new_item_data)
        return new_item_data
```

## 4. Accessing Live Interactive Swagger UI

Once registered on your app (`api.register_blueprint(blp)`), start your Flask server and visit:

*   **`http://127.0.0.1:5000/swagger-ui`**: Displays the interactive Swagger UI sandbox where developers can view schemas and test API calls!
*   **`http://127.0.0.1:5000/openapi.json`**: Raw machine-readable OpenAPI 3.0 specification file.
