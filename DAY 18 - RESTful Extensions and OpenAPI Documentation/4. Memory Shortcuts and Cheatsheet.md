## 🔤 REST Extensions & OpenAPI Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **API Documentation** | Instruction manual explaining endpoints, inputs, and outputs. | Swagger UI webpage |
| **OpenAPI 3.0** | Machine-readable JSON/YAML specification for REST APIs. | `/openapi.json` |
| **Swagger UI** | Interactive browser sandbox generated from OpenAPI spec. | `/swagger-ui` |
| **Class-Based Resource** | Python class encapsulating `GET`, `POST`, `DELETE` methods. | `MethodView` / `Resource` |
| **`Flask-Smorest`** | Framework integrating Flask, Marshmallow, & OpenAPI 3.0. | Self-documenting Flask APIs |
| **`@blp.arguments`** | Smorest decorator validating request body via Marshmallow. | `@blp.arguments(ItemSchema)` |
| **`@blp.response`** | Smorest decorator formatting response JSON via Marshmallow. | `@blp.response(200, ItemSchema)` |

## 🧠 Memory Mnemonics

### 1. API Documentation Sequence (`D-O-C-S`)
Remember **D-O-C-S** for building self-documenting APIs:
- **D** -> **Define Schemas** (Create Marshmallow `ItemSchema`)
- **O** -> **Organize MethodViews** (Build class-based `ItemResource(MethodView)`)
- **C** -> **Config OpenAPI Settings** (`OPENAPI_VERSION = "3.0.3"`)
- **S** -> **Serve Swagger UI** (`OPENAPI_SWAGGER_UI_PATH = "/swagger-ui"`)

---

### 2. Flask-Smorest Workflow (`S-M-O-R-E-S-T`)
Remember **S-M-O-R-E-S-T** for the Flask-Smorest pipeline:
- **S** -> **Setup Api Manager** (`api = Api(app)`)
- **M** -> **Marshmallow Integration** (Connect Marshmallow schemas)
- **O** -> **OpenAPI Configuration** (`app.config['OPENAPI_VERSION'] = '3.0.3'`)
- **R** -> **Register Blueprints** (`api.register_blueprint(blp)`)
- **E** -> **Expose MethodViews** (`class ItemListResource(MethodView):`)
- **S** -> **Schema Decorators** (`@blp.arguments()`, `@blp.response()`)
- **T** -> **Test in Swagger UI** (`/swagger-ui`)

## ⚡ Quick-Reference Code Snippets

### 1. Flask-Smorest OpenAPI Setup
```python
from flask import Flask
from flask_smorest import Api, Blueprint

app = Flask(__name__)
app.config['API_TITLE'] = 'Inventory API'
app.config['API_VERSION'] = 'v1'
app.config['OPENAPI_VERSION'] = '3.0.3'
app.config['OPENAPI_URL_PREFIX'] = '/'
app.config['OPENAPI_SWAGGER_UI_PATH'] = '/swagger-ui'
app.config['OPENAPI_SWAGGER_UI_URL'] = 'https://cdn.jsdelivr.net/npm/swagger-ui-dist/'

api = Api(app)
blp = Blueprint('items', 'items', url_prefix='/api/v1/items')
```

### 2. MethodView Class with Schema Validation & Documentation
```python
from flask.views import MethodView

@blp.route('/')
class ItemListResource(MethodView):
    @blp.response(200, ItemSchema(many=True))
    def get(self):
        """List all items."""
        return items_list

    @blp.arguments(ItemSchema)
    @blp.response(201, ItemSchema)
    def post(self, new_data):
        """Create new item."""
        return save_item(new_data)
```
