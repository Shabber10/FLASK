## 🧠 Memory Mnemonics

### 1. The Core Rules of Microservices
Remember **M-I-C-R-O**:
- **M**: **Minimal Surface Area** (API Gateway handles routing & authentication)
- **I**: **Independent Databases** (Strict Database-per-Service pattern)
- **C**: **Circuit Breaker** (Prevent cascading worker thread exhaustion)
- **R**: **Resilient Retries** (Enforce HTTP timeouts on all inter-service requests)
- **O**: **Observer Tracing** (Propagate request correlation IDs across services)

---

### 2. Circuit Breaker States
- **`CLOSED`**: Normal state. All inter-service network requests pass through.
- **`OPEN`**: Failure threshold exceeded. Rejects requests immediately (Fast-Fail 503) without calling downstream service.
- **`HALF-OPEN`**: Trial state. Sends limited test requests to check if downstream service recovered.

## ⚡ Quick-Reference Code Snippets

### 1. Resilient HTTP Inter-Service Request with Timeout
```python
import requests

try:
    # Always specify timeout=2.0 to prevent worker thread blocking!
    res = requests.get("http://user-service:5000/users/101", timeout=2.0)
    res.raise_for_status()
    user_data = res.json()
except requests.exceptions.Timeout:
    print("User Service timed out!")
except requests.exceptions.RequestException as e:
    print(f"Service call failed: {e}")
```

### 2. Circuit Breaker Pattern (`pybreaker`)
```python
import pybreaker

breaker = pybreaker.CircuitBreaker(fail_max=5, reset_timeout=30)

@breaker
def call_downstream_api():
    res = requests.get("http://inventory-service:5000/items", timeout=1.5)
    return res.json()
```
