## 🧠 Memory Mnemonics

### 1. The Core `flask db` CLI Sequence
Remember **I-M-U-D** for database migration commands:
- **I**: **`flask db init`** (Initialize `migrations/` directory - Run ONCE per app)
- **M**: **`flask db migrate -m "msg"`** (Auto-generate migration script in `versions/`)
- **U**: **`flask db upgrade`** (Apply pending schema changes to target database)
- **D**: **`flask db downgrade`** (Roll back database schema to previous revision)

---

### 2. Alembic Revision Script Functions
- **`upgrade()`**: Emits `op.add_column()`, `op.create_table()`, `op.alter_column()`.
- **`downgrade()`**: Emits `op.drop_column()`, `op.drop_table()` (Reverses `upgrade()`).

## ⚡ Quick-Reference Code Snippets

### 1. Flask-Migrate App Setup
```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy
from flask_migrate import Migrate

app = Flask(__name__)
db = SQLAlchemy(app)

# Enable render_as_batch=True for SQLite batch alter table support
migrate = Migrate(app, db, render_as_batch=True)
```

### 2. Custom CLI Seed Command
```python
@app.cli.command('seed_db')
def seed_db():
    user = User(username='admin', email='admin@test.com')
    db.session.add(user)
    db.session.commit()
    print("Database seeded!")
```

### 3. Adding Non-Nullable Column Safely in Alembic Revision
```python
def upgrade():
    # 1. Add column as nullable
    op.add_column('users', sa.Column('is_verified', sa.Boolean(), nullable=True))
    # 2. Backfill existing NULL rows
    op.execute("UPDATE users SET is_verified = False WHERE is_verified IS NULL")
    # 3. Alter to NOT NULL
    op.alter_column('users', 'is_verified', nullable=False)
```
