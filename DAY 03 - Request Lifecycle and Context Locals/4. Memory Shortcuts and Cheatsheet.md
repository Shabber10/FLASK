# Day 03: Memory Shortcuts & Cheatsheet

---

## 🧠 Memory Mnemonics

### 1. Flask Global Context Proxies
Remember **A-R-C-G** for Flask's proxy objects:
- **A**: **`current_app`** (App Context: Configs, loggers, extensions)
- **R**: **`request`** (Request Context: Headers, args, body payload)
- **C**: **`session`** (Request Context: Signed user session storage)
- **G**: **`g`** (App Context Store: In-memory request-scoped temporary storage)

---

### 2. Request Lifecycle Order
Remember **B-V-A-T** for Flask hook execution:
- **B**: **`before_request`** (Executes pre-view; can short-circuit)
- **V**: **`View Function`** (Executes core endpoint business logic)
- **A**: **`after_request`** (Executes post-view; modifies Response object)
- **T**: **`teardown_request`** (Executes last; guaranteed cleanup even on exceptions)

---

## ⚡ Quick-Reference Code Snippets

### 1. Request Latency Audit & Header Injection
```python
@app.before_request
def start_timer():
    g.start = time.time()

@app.after_request
def add_latency_header(response):
    diff = (time.time() - g.start) * 1000
    response.headers['X-Response-Time-MS'] = f"{diff:.2f}"
    return response
```

### 2. Database Connection Teardown
```python
@app.teardown_request
def close_db(exception=None):
    db = g.pop('db', None)
    if db is not None:
        db.close()
```

### 3. Injecting Template Globals
```python
@app.context_processor
def inject_site_settings():
    return {'site_title': 'Enterprise Platform', 'year': 2026}
```
