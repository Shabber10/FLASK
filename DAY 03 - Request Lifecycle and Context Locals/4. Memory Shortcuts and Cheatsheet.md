# Day 03: Memory Shortcuts & Cheatsheet

---

## 🔤 Context & Lifecycle Terminology Decoder

| Term | Meaning | Real-World Example |
| :--- | :--- | :--- |
| **Context** | Background state/environment surrounding a request. | *"Which user sent this request?"* |
| **App Context** | Holds application settings, loggers, and DB pools. | `current_app`, `g` |
| **Request Context** | Holds incoming HTTP headers, form data, and cookies. | `request`, `session` |
| **`g` Object** | Temporary server-side backpack cleared after every request. | `g.db = connect_db()` |
| **`LocalProxy`** | Thread-safe proxy object pointing to the active thread's data. | `from flask import request` |
| **Lifecycle Hook** | Event triggers executing before/after views or on teardown. | `@app.before_request` |
| **Short-Circuiting** | Halting request execution early by returning a response in `@app.before_request`. | Returning `401 Unauthorized` |

---

## 🧠 Memory Mnemonics

### 1. Global Context Proxies (`A-R-C-G`)
Remember **A-R-C-G** for Flask's proxy objects:
- **A** -> **`current_app`** (App Context: Configurations, loggers, extensions)
- **R** -> **`request`** (Request Context: Incoming headers, query args, POST body)
- **C** -> **`session`** (Request Context: Encrypted client session storage)
- **G** -> **`g`** (App Context Store: In-memory request-scoped temporary storage)

---

### 2. Request Lifecycle Order (`B-V-A-T`)
Remember **B-V-A-T** for Flask hook execution:
- **B** -> **`before_request`** (Executes pre-view; can short-circuit)
- **V** -> **View Function** (Executes core endpoint business logic)
- **A** -> **`after_request`** (Executes post-view; modifies Response object)
- **T** -> **`teardown_request`** (Executes last; guaranteed cleanup even on exceptions)

---

## ⚡ Quick-Reference Code Snippets

### 1. Request Latency Audit & Header Injection
```python
import time
from flask import g, request

@app.before_request
def start_timer():
    g.start = time.time()

@app.after_request
def add_latency_header(response):
    diff = (time.time() - g.start) * 1000
    response.headers['X-Response-Time-MS'] = f"{diff:.2f}"
    return response
```

### 2. Guaranteed Database Connection Teardown
```python
@app.teardown_request
def close_db(exception=None):
    db = g.pop('db', None)
    if db is not None:
        db.close()
```

### 3. Injecting Template Globals
```python
@app.context_processor
def inject_site_settings():
    return {'site_title': 'Enterprise Platform', 'current_year': 2026}
```

### 4. Manually Pushing Contexts in CLI Scripts / Tests
```python
# Pushing App Context
with app.app_context():
    print(current_app.name)

# Pushing Request Context
with app.test_request_context('/search?q=flask'):
    print(request.args['q'])
```
