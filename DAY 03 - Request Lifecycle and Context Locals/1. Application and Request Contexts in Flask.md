# Day 03: Application & Request Contexts in Flask

## 1. Context Locals Explained
Flask uses Werkzeug's `LocalProxy` to make request-specific variables globally accessible without passing them through every function:

| Context | Global Objects | Description |
| :--- | :--- | :--- |
| **Application Context** | `current_app`, `g` | Bound to active Flask app instance & request-scoped temporary storage |
| **Request Context** | `request`, `session` | Bound to current HTTP request payload & session state |

```python
from flask import g, current_app

@app.before_request
def load_db():
    g.db_status = "Connected"
```
