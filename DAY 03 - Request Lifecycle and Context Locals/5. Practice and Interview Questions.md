# Day 03: Practice & Technical Interview Questions

This question bank is divided into **3 progression levels**, starting from absolute context concepts up to Werkzeug `LocalProxy` and `contextvars` mechanics.

---

## 🟢 Level 1: Absolute Beginner Questions

### Q1: What is a "Context" in Flask in simple terms?
**Answer**:
In simple terms, a "Context" is the temporary background information surrounding an active request (such as which user sent the request, what form parameters were submitted, or what database connection is active).

---

### Q2: Why are standard Python global variables dangerous in web applications?
**Answer**:
Web servers handle thousands of users concurrently across multiple threads. If a web app used standard global variables, User A's data would overwrite User B's data (a Race Condition), causing severe security leaks (e.g., User A seeing User B's bank account).

---

### Q3: What is Flask's `g` object and what is it used for?
**Answer**:
`g` is an in-memory, request-scoped storage container provided by Flask. It is used to store temporary data during a single request (like database connections or request start times). `g` is automatically wiped clean at the end of every request.

---

### Q4: What is the difference between `@app.before_request` and `@app.teardown_request`?
**Answer**:
*   `@app.before_request`: Runs before the view function executes (used for authentication or starting timers).
*   `@app.teardown_request`: Runs at the very end of the request and is **guaranteed to execute even if the application code crashes** (used for safely closing database connections).

---

### Q5: How do you pass global variables to all Jinja2 HTML templates automatically?
**Answer**:
Use `@app.context_processor`:
```python
@app.context_processor
def inject_globals():
    return {'site_name': 'My Platform', 'year': 2026}
```

## 🟡 Level 2: Intermediate Questions

### Q6: What is the difference between `g` and `session` in Flask?
**Answer**:
*   **`g`**: In-memory, request-scoped temporary storage bound to the server process. Destroyed when the request ends. Can hold complex Python objects (like database connections or sockets).
*   **`session`**: Multi-request persistent storage stored in a cryptographically signed client-side HTTP cookie (or server-side Redis). Persists across multiple user visits, but can only hold JSON-serializable primitives (strings, ints, dicts).

---

### Q7: Explain what happens if `@app.before_request` returns a response object instead of `None`.
**Answer**:
If `@app.before_request` returns a response object (e.g., `return jsonify({"error": "Unauthorized"}), 401`), Flask performs **request short-circuiting**:
1.  Execution of any remaining `@app.before_request` functions is skipped.
2.  The matched view function is **never executed**.
3.  Execution jumps directly to `@app.after_request` hooks and returns the short-circuited response.

---

### Q8: Compare `@app.after_request` and `@app.teardown_request`. When would you use each?
**Answer**:
*   **`@app.after_request`**: Accepts and returns a `Response` object. Used to modify response headers or set cookies. **Skipped** if an unhandled exception occurs in the view.
*   **`@app.teardown_request`**: Accepts an optional exception parameter. **Guaranteed to execute** even if unhandled errors or exceptions occur. Used to release database connections, locks, or file handles.

---

### Q9: What error occurs when accessing `current_app` outside an HTTP request, and how do you fix it in CLI scripts?
**Answer**:
It raises `RuntimeError: Working outside of application context`.
In CLI scripts or background tasks, fix it by manually pushing the application context:
```python
with app.app_context():
    print(current_app.config['SECRET_KEY'])
```

---

### Q10: How do you simulate an incoming HTTP request in unit tests to test `request.args`?
**Answer**:
Use `app.test_request_context()`:
```python
with app.test_request_context('/search?q=flask', method='GET'):
    assert request.args.get('q') == 'flask'
```

## 🔴 Level 3: Advanced & Enterprise Questions

### Q11: What is a `LocalProxy` in Flask and how does it prevent race conditions in multi-threaded web servers?
**Answer**:
`LocalProxy` is a proxy object provided by Werkzeug that forwards all attribute accesses and method calls to an underlying object bound to the current thread or coroutine (using Python's `contextvars`).

In a multi-threaded server (e.g. Gunicorn with thread workers), `LocalProxy` ensures `from flask import request` resolves dynamically to the specific `Request` object created for the executing thread, eliminating race conditions without passing `request` explicitly through view functions.

---

### Q12: Why shouldn't heavy database connections or socket objects be stored inside the `session` object?
**Answer**:
`session` data is serialized into a client-side HTTP cookie (or JSON-serialized into Redis). Complex Python objects like socket handles, thread locks, or database connections cannot be JSON/pickle-serialized safely into HTTP headers. Complex objects must be stored on `g`.

---

### Q13: Can multiple `@app.before_request` functions be registered, and in what order do they execute?
**Answer**:
Yes. Multiple `@app.before_request` functions execute in the exact order they were registered. If any hook returns a non-None response, execution short-circuits immediately.

---

### Q14: How does Flask 3.x handle context isolation in asynchronous (`async`/`await`) routes?
**Answer**:
Flask 3.x utilizes Python 3.7+'s native `contextvars` module under the hood instead of legacy `thread.local`. `contextvars` automatically preserves and isolates context state across asynchronous task boundaries, coroutines, and event loops.

---

### Q15: Write a custom lifecycle hook pattern that measures database query duration on `g`.
**Answer**:

```python
import time
from flask import g

@app.before_request
def start_db_timer():
    g.db_start_time = time.time()

@app.after_request
def log_db_duration(response):
    if hasattr(g, 'db_start_time'):
        duration = (time.time() - g.db_start_time) * 1000
        response.headers['X-DB-Duration-MS'] = f"{duration:.2f}"
    return response
```
