# Day 03: Request Lifecycle Hooks & Context Processors

## 1. Lifecycle Decorators
- `@app.before_request`: Executes before every request view function.
- `@app.after_request`: Executes after view function succeeds; receives response object.
- `@app.teardown_request`: Executes after request completes, even if an unhandled exception occurred.
- `@app.context_processor`: Injects custom variables into all Jinja2 template contexts automatically.
