# Day 23: Security Headers, Rate Limiting & Flask-Talisman

In this section, we examine HTTP Security Headers (`Flask-Talisman`), rate limiting (`Flask-Limiter`), Content Security Policy (CSP) rules, and brute-force mitigation.

---

## 1. HTTP Security Headers (`Flask-Talisman`)

Modern web browsers implement security policies declared by HTTP response headers. `Flask-Talisman` sets production security headers automatically:

```python
from flask import Flask
from flask_talisman import Talisman

app = Flask(__name__)

# Enforce Security Headers
talisman = Talisman(
    app,
    content_security_policy={
        'default-src': "'self'",
        'script-src': ["'self'", 'https://cdn.jsdelivr.net']
    },
    force_https=True
)
```

### Essential Security Headers Matrix

| HTTP Header | Purpose | Hardened Value |
| :--- | :--- | :--- |
| **`Content-Security-Policy` (CSP)** | Restricts origin of scripts, styles, images | `default-src 'self'` |
| **`Strict-Transport-Security` (HSTS)**| Forces browser to use HTTPS only for 1 year | `max-age=31536000; includeSubDomains` |
| **`X-Frame-Options`** | Prevents Clickjacking attacks in iFrames | `DENY` or `SAMEORIGIN` |
| **`X-Content-Type-Options`** | Prevents MIME-sniffing exploits | `nosniff` |
| **`Referrer-Policy`** | Restricts referrer URL leakage | `strict-origin-when-cross-origin` |

## 2. API Rate Limiting (`Flask-Limiter`)

Rate limiting protects APIs against Brute-Force password guessing, Credential Stuffing, and Denial of Service (DoS) attacks.

```python
from flask import Flask
from flask_limiter import Limiter
from flask_limiter.util import get_remote_address

app = Flask(__name__)

# Initialize Limiter using Client IP address
limiter = Limiter(
    get_remote_address,
    app=app,
    default_limits=["200 per day", "50 per hour"],
    storage_uri="redis://localhost:6379/0" # Redis storage across workers!
)

# Apply Strict Route Rate Limits
@app.route('/api/login', methods=['POST'])
@limiter.limit("5 per minute") # Max 5 login attempts per minute per IP!
def login():
    return jsonify({"status": "attempted"})
```

### Handling Rate Limit Exceeded Errors (`HTTP 429`)

When a client exceeds their quota, `Flask-Limiter` raises a `RateLimitExceeded` exception, returning HTTP status `429 Too Many Requests`:

```python
@app.errorhandler(429)
def ratelimit_handler(e):
    return jsonify({
        "error": "Too Many Requests",
        "message": f"Rate limit exceeded: {e.description}"
    }), 429
```
