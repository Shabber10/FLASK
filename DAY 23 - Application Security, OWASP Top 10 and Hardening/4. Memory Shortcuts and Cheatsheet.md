## 🧠 Memory Mnemonics

### 1. HTTP Security Headers Checklist
Remember **H-E-A-D-E-R-S** for production hardening:
- **H**: **HSTS** (`Strict-Transport-Security: max-age=31536000`)
- **E**: **Escape XSS** (Never use `| safe` on raw user inputs)
- **A**: **Anti-Clickjacking** (`X-Frame-Options: DENY`)
- **D**: **Default Denial CSP** (`Content-Security-Policy: default-src 'self'`)
- **E**: **Enforce HTTPS Only** (`force_https=True` in Talisman)
- **R**: **Referrer Restrict** (`Referrer-Policy: strict-origin-when-cross-origin`)
- **S**: **Sniffing Blocked** (`X-Content-Type-Options: nosniff`)

---

### 2. Rate Limiting Setup Rules
- Global Limits: `default_limits=["200 per day", "50 per hour"]`
- Route Limit: `@limiter.limit("5 per minute")`
- Storage Backend: `storage_uri="redis://localhost:6379/0"`

## ⚡ Quick-Reference Code Snippets

### 1. `Flask-Talisman` Security Headers Setup
```python
from flask import Flask
from flask_talisman import Talisman

app = Flask(__name__)
talisman = Talisman(app, force_https=True)
```

### 2. `Flask-Limiter` Setup & Route Limits
```python
from flask_limiter import Limiter
from flask_limiter.util import get_remote_address

limiter = Limiter(get_remote_address, app=app, storage_uri="redis://localhost:6379/0")

@app.route('/api/login', methods=['POST'])
@limiter.limit("5 per minute")
def login():
    return jsonify(status="ok")
```

# Always use ORM or parameterized bindings!
