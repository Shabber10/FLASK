# Day 08: Lazy Loading Strategies & N+1 Problem

## 1. Lazy Loading Types
- `select` (default): Loads related collection on-demand using a separate SELECT query.
- `joined`: Performs an SQL `LEFT OUTER JOIN` in the initial query.
- `subquery`: Loads relationship via a secondary subquery.
- `selectin`: Uses an `IN` clause for efficient secondary loading.
