## 1. One-to-Many & One-to-One Mappings

### One-to-Many Relationship
Declare `db.ForeignKey` on the child model and `db.relationship` on the parent model:

```python
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class Author(db.Model):
    __tablename__ = 'authors'
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    
    # One-to-Many: Author has multiple posts
    posts = db.relationship('Post', back_populates='author', cascade='all, delete-orphan')

class Post(db.Model):
    __tablename__ = 'posts'
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(200), nullable=False)
    author_id = db.Column(db.Integer, db.ForeignKey('authors.id'), nullable=False)
    
    author = db.relationship('Author', back_populates='posts')
```

---

### One-to-One Relationship
To restrict a One-to-Many relationship so that a parent holds at most **one** child instance, add `uselist=False` to `db.relationship` and `unique=True` to `db.ForeignKey`:

```python
class User(db.Model):
    __tablename__ = 'users'
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    
    # uselist=False instructs SQLAlchemy to treat user.profile as a single object, not a list
    profile = db.relationship('UserProfile', back_populates='user', uselist=False, cascade='all, delete-orphan')

class UserProfile(db.Model):
    __tablename__ = 'user_profiles'
    id = db.Column(db.Integer, primary_key=True)
    bio = db.Column(db.Text)
    user_id = db.Column(db.Integer, db.ForeignKey('users.id'), unique=True, nullable=False)
    
    user = db.relationship('User', back_populates='profile')
```

## 2. Many-to-Many Relationships

Many-to-Many relationships require a third table: the **Junction / Association Table**:

```python
# Association Table linking Posts and Tags
post_tags = db.Table('post_tags',
    db.Column('post_id', db.Integer, db.ForeignKey('posts.id', ondelete='CASCADE'), primary_key=True),
    db.Column('tag_id', db.Integer, db.ForeignKey('tags.id', ondelete='CASCADE'), primary_key=True)
)

class Post(db.Model):
    __tablename__ = 'posts'
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(200), nullable=False)
    
    # Point to Tag model using 'secondary=post_tags' parameter
    tags = db.relationship('Tag', secondary=post_tags, back_populates='posts')

class Tag(db.Model):
    __tablename__ = 'tags'
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(50), unique=True, nullable=False)
    
    posts = db.relationship('Post', secondary=post_tags, back_populates='tags')
```

## 3. Self-Referential Relationships (Hierarchies & Category Trees)

### 📖 What is a Self-Referential Relationship?
A relationship where a table references **itself** via a foreign key (e.g. An Employee having a `manager_id` pointing to another Employee in the same table, or nested Category folders).

```python
class Employee(db.Model):
    __tablename__ = 'employees'
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    
    # Self-referencing foreign key
    manager_id = db.Column(db.Integer, db.ForeignKey('employees.id'), nullable=True)
    
    # Manager relationship with remote_side specified for ambiguity resolution
    manager = db.relationship('Employee', back_populates='subordinates', remote_side=[id])
    subordinates = db.relationship('Employee', back_populates='manager')
```

## 4. Understanding Cascade Operations

Cascade settings instruct SQLAlchemy how to propagate operations (`add`, `delete`, `update`) from parent models down to child records.

```python
class Post(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    # Cascade: If Post is deleted OR a Comment is removed from post.comments list, delete Comment from DB!
    comments = db.relationship('Comment', back_populates='post', cascade='all, delete-orphan')

class Comment(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    body = db.Column(db.Text, nullable=False)
    post_id = db.Column(db.Integer, db.ForeignKey('posts.id', ondelete='CASCADE'), nullable=False)
    post = db.relationship('Post', back_populates='comments')
```

### Cascade Options Matrix:
- `save-update` (Default): Automatically stages child objects added to parent.
- `delete`: Deletes children when parent is deleted.
- `delete-orphan`: Deletes child from DB when unlinked from parent list (`post.comments.remove(c1)`).
- `all`: Shorthand for `save-update, merge, refresh-expire, expunge, delete`.

## 5. The Soft-Delete Pattern

### 📖 What is a Soft Delete?
Instead of executing a destructive SQL `DELETE FROM table`, you mark a record as inactive (`is_deleted = True` or `deleted_at = datetime.now()`).

### ❓ Why Use Soft Deletes?
- **Audit Compliance**: Legal requirements to retain historical customer records.
- **Accidental Deletion Recovery**: Allows restoring deleted items with 1 click.
- **Data Integrity**: Preserves foreign key references in financial ledgers.

### 💻 Code Example:

```python
from datetime import datetime, timezone

class Customer(db.Model):
    __tablename__ = 'customers'
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    is_deleted = db.Column(db.Boolean, default=False, nullable=False, index=True)
    deleted_at = db.Column(db.DateTime, nullable=True)

    def soft_delete(self):
        """Soft delete customer record."""
        self.is_deleted = True
        self.deleted_at = datetime.now(timezone.utc)
        db.session.commit()

    @classmethod
    def get_active(cls):
        """Query helper to automatically filter out soft-deleted records."""
        return cls.query.filter_by(is_deleted=False).all()
```

## 6. Polymorphic Model Inheritance (Single-Table Inheritance)

### 📖 What is Polymorphism in SQLAlchemy?
Allows creating a hierarchy of subclasses that share a single SQL table or join across specialized tables, automatically determined by a **`discriminator`** column.

### 💻 Code Example: Single Table Inheritance (STI)

```python
class Payment(db.Model):
    __tablename__ = 'payments'
    id = db.Column(db.Integer, primary_key=True)
    amount = db.Column(db.Float, nullable=False)
    payment_type = db.Column(db.String(50))  # Discriminator column

    __mapper_args__ = {
        'polymorphic_on': payment_type,
        'polymorphic_identity': 'generic_payment'
    }

class CreditCardPayment(Payment):
    card_last_four = db.Column(db.String(4), nullable=True)
    __mapper_args__ = {'polymorphic_identity': 'credit_card'}

class CryptoPayment(Payment):
    wallet_address = db.Column(db.String(100), nullable=True)
    __mapper_args__ = {'polymorphic_identity': 'crypto'}
```
