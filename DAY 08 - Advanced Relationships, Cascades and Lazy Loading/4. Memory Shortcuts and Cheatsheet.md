## 🧠 Memory Mnemonics

### 1. SQLAlchemy Lazy Loading Strategies
Remember **S-J-S-D** for relationship loading strategies:
- **S**: **`select`** (Default: Secondary `SELECT` on attribute access; prone to N+1)
- **J**: **`joined`** (Executes `LEFT OUTER JOIN` in primary query; best for 1-to-1 / Many-to-1)
- **S**: **`selectin`** (Executes 2nd query using `WHERE id IN (...)`; best for 1-to-Many collections)
- **D**: **`dynamic`** (Returns `Query` object; best for huge collections needing filtering)

---

### 2. Cascade Options
Remember **A-D-O** for relationship cascades:
- **A**: **`all`** (Propagate save-update, merge, delete, expunge)
- **D**: **`delete`** (Delete child records when parent is deleted)
- **O**: **`delete-orphan`** (Delete child record when removed from parent's collection list)

---

## ⚡ Quick-Reference Code Snippets

### 1. One-to-Many with Cascade Delete-Orphan
```python
class Parent(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    children = db.relationship('Child', backref='parent', cascade='all, delete-orphan', lazy='selectin')

class Child(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    parent_id = db.Column(db.Integer, db.ForeignKey('parent.id', ondelete='CASCADE'), nullable=False)
```

### 2. Many-to-Many Association Table
```python
post_tags = db.Table('post_tags',
    db.Column('post_id', db.Integer, db.ForeignKey('posts.id'), primary_key=True),
    db.Column('tag_id', db.Integer, db.ForeignKey('tags.id'), primary_key=True)
)

class Post(db.Model):
    tags = db.relationship('Tag', secondary=post_tags, backref='posts', lazy='selectin')
```

### 3. Explicit Eager Loading Query
```python
from sqlalchemy.orm import selectinload, joinedload

stmt = db.select(Post).options(
    joinedload(Post.author),
    selectinload(Post.comments)
)
posts = db.session.execute(stmt).scalars().all()
```
