## 🧠 Memory Mnemonics

### 1. Blueprint Lifecycle Operations
Remember **B-L-U-E-P-R-I-N-T** rules:
- **B**: **Blueprint Class** (`bp = Blueprint('name', __name__)`)
- **L**: **Logical Separation** (Decouples auth, admin, API into distinct files)
- **U**: **URL Prefixing** (`url_prefix='/api/v1'`)
- **E**: **Endpoint Namespacing** (`url_for('blueprint_name.view_function')`)
- **R**: **Register on App** (`app.register_blueprint(bp)`)
- **N**: **Nested Support** (`parent_bp.register_blueprint(child_bp)`)
- **T**: **Template Isolation** (`template_folder='templates'`)

---

### 2. `url_for()` Namespacing Summary

| Code Syntax | Execution Context | Target Resolved Route |
| :--- | :--- | :--- |
| `url_for('auth.login')` | Anywhere in app | `/auth/login` |
| `url_for('admin.dashboard')` | Anywhere in app | `/admin/dashboard` |
| `url_for('.login')` | Inside `auth` Blueprint | `/auth/login` |
| `url_for('api_parent.v1.health')` | Anywhere in app (Nested BP) | `/api/v1/health` |

## ⚡ Quick-Reference Code Snippets

### 1. Blueprint Declaration & Registration
```python
# Declaration (blueprints/admin.py)
admin_bp = Blueprint('admin', __name__, url_prefix='/admin')

@admin_bp.route('/users')
def users():
    return "Admin Users"

# Registration (app.py)
app.register_blueprint(admin_bp)
```

### 2. Nested Blueprints (Flask 2.0+)
```python
parent_bp = Blueprint('api', __name__, url_prefix='/api')
child_bp = Blueprint('v1', __name__, url_prefix='/v1')

@child_bp.route('/status')
def status():
    return "API v1 OK"

parent_bp.register_blueprint(child_bp)
app.register_blueprint(parent_bp)
# Final Route: /api/v1/status
```

### 3. Blueprint-Scoped Middleware Guard
```python
@admin_bp.before_request
def check_admin_permission():
    if not g.user.is_admin:
        abort(403)
```
