# Day 11: Subdomain Routing, Nested Blueprints & Prefixes

In this section, we examine advanced Blueprint patterns: Blueprint URL prefix versioning, subdomain binding (`subdomain='api'`), nested blueprints in Flask 2.0+, blueprint-scoped error handlers, and middleware hooks.

---

## 1. Subdomain Routing with Blueprints

Flask allows binding Blueprints directly to custom subdomains (e.g. `api.example.com` or `admin.example.com`).

### Subdomain Binding Configuration

```python
from flask import Flask, Blueprint, jsonify

app = Flask(__name__)
# Configure server domain name (Required for subdomain routing in Flask)
app.config['SERVER_NAME'] = 'example.com:5000'

# Declare API Blueprint bound to 'api' subdomain
api_bp = Blueprint('api_subdomain', __name__, subdomain='api')

@api_bp.route('/v1/health')
def health_check():
    return jsonify({"status": "healthy", "domain": "api.example.com"})

app.register_blueprint(api_bp)
```

> **Testing Subdomains Locally**: Map custom subdomains in your local OS hosts file (`127.0.0.1 api.example.com`).

## 2. Nested Blueprints (Flask 2.0+ Standard)

In large APIs, you can nest child blueprints inside parent blueprints, inheriting parent URL prefixes automatically.

```python
from flask import Blueprint

# Parent API Blueprint (URL Prefix: /api)
api_parent_bp = Blueprint('api_parent', __name__, url_prefix='/api')

# Child Version 1 Blueprint (URL Prefix: /v1)
v1_child_bp = Blueprint('v1_child', __name__, url_prefix='/v1')

@v1_child_bp.route('/users')
def list_users():
    return jsonify([{"id": 1, "username": "alice"}])

# Register Child Blueprint onto Parent Blueprint
api_parent_bp.register_blueprint(v1_child_bp)

# Register Parent Blueprint onto Flask Application
# Final Route Path: "/api/v1/users"
app.register_blueprint(api_parent_bp)
```

## 3. Blueprint-Scoped Lifecycle Hooks & Error Handlers

Blueprints support isolated lifecycle hooks and error handlers that execute **only** for routes registered within that specific blueprint:

```python
admin_bp = Blueprint('admin', __name__, url_prefix='/admin')

# 1. Blueprint-Scoped before_request Hook
@admin_bp.before_request
def restrict_admin_access():
    if not is_admin_authenticated():
        return jsonify({"error": "Forbidden", "message": "Admin clearance required"}), 403

# 2. Blueprint-Scoped Error Handler
@admin_bp.errorhandler(404)
def handle_admin_not_found(error):
    return jsonify({"error": "Admin Resource Not Found"}), 404

# 3. Blueprint-Scoped Context Processor
@admin_bp.context_processor
def inject_admin_theme():
    return {'admin_theme': 'dark'}
```

---

## 4. App-Wide Hooks from Blueprints (`@bp.app_errorhandler`)

If a blueprint needs to register a global error handler or global request hook across the **entire** application, use `@bp.app_errorhandler` or `@bp.app_before_request`:

```python
# Registered inside a Blueprint, but handles 500 errors APP-WIDE!
@auth_bp.app_errorhandler(500)
def handle_global_server_error(error):
    return render_template('errors/500.html'), 500
```
