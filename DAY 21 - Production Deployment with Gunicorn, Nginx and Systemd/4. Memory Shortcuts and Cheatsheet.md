## 🧠 Memory Mnemonics

### 1. The Gunicorn Worker Calculation Formula
$$\text{Workers} = (2 \times \text{CPU Cores}) + 1$$

### 2. Nginx Reverse Proxy Header Checklist
Remember **H-O-S-T-S** for Nginx proxy headers:
- **H**: `proxy_set_header Host $host;`
- **O**: `proxy_set_header X-Real-IP $remote_addr;`
- **S**: `proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;`
- **T**: `proxy_set_header X-Forwarded-Proto $scheme;`
- **S**: `proxy_pass http://unix:/tmp/gunicorn.sock;`

## ⚡ Quick-Reference Code Snippets

### 1. Gunicorn CLI Invocation
```bash
# Basic Gunicorn Execution with 5 Workers on Unix Socket
gunicorn --workers 5 --bind unix:/tmp/gunicorn.sock wsgi:app

# Multi-Threaded Execution
gunicorn -w 4 -k gthread --threads 2 -b 127.0.0.1:8000 wsgi:app
```

### 2. Nginx Configuration (`/etc/nginx/sites-available/app`)
```nginx
server {
    listen 80;
    server_name example.com;

    location /static/ {
        alias /var/www/app/static/;
    }

    location / {
        proxy_pass http://unix:/tmp/gunicorn.sock;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
