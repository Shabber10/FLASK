## 🧠 Memory Mnemonics

### 1. PEP 3333 WSGI Middleware Signature
Remember **W-S-G-I** for custom WSGI wrappers:
- **W**: **`__init__(self, app)`** (Stores target WSGI app callable `app.wsgi_app`)
- **S**: **`__call__(self, environ, start_response)`** (Required WSGI entry point signature)
- **G**: **Get Environ Headers** (Inspect/modify CGI environment dictionary)
- **I**: **Intercept Start Response** (Wrap `start_response(status, headers)` to capture status & inject headers)

---

### 2. Signals vs Hooks
- **Request Hooks** (`@app.before_request`): Can modify request/response streams or short-circuit views.
- **Flask Signals** (`user_registered_signal.send()`): Read-only event broadcasting for decoupled observers.

## ⚡ Quick-Reference Code Snippets

### 1. PEP 3333 Custom WSGI Middleware
```python
class CustomWSGIMiddleware:
    def __init__(self, app):
        self.app = app

    def __call__(self, environ, start_response):
        def custom_start_response(status, headers, exc_info=None):
            headers.append(('X-Custom-Header', 'Value'))
            return start_response(status, headers, exc_info)

        return self.app(environ, custom_start_response)

app.wsgi_app = CustomWSGIMiddleware(app.wsgi_app)
```

### 2. Reverse Proxy Fixing (`ProxyFix`)
```python
from werkzeug.middleware.proxy_fix import ProxyFix

app.wsgi_app = ProxyFix(app.wsgi_app, x_for=1, x_proto=1, x_host=1)
```

### 3. Custom Blinker Signal Creation & Emission
```python
from blinker import Namespace

signals = Namespace()
user_created = signals.signal('user-created')

# Subscriber
@user_created.connect
def on_user_created(sender, user_id):
    print(f"User created: {user_id}")

# Emitter (Inside View Handler)
user_created.send(app, user_id=101)
```
